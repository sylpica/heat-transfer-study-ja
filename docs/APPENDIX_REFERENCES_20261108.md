## 2. データ形式

章末データ（`data/chapter-problems/`）のエンベロープと reference ブロックの作法に合わせた。

- 配置：`data/appendix-references/appendix-a.json` / `appendix-b.json`
- エンベロープ：`{appendixId, language: "ja", source, bookPages, pdfPages, status: "complete",
  references: {heading: "参考文献", count, blocks}}`
- reference ブロック：`{type: "reference", id: "reference-A-1" 等, number: "A.1" 等,
  authors（原文どおり）, originalTitle, titleJa, publication（原文どおり、行末ハイフネーション解除）,
  noteJa/noteEn（本書自身の付記のみ）, url, doi（分離して保持）, bookPage, pdfPage}`
- 本書自身の付記を保持した例：[A.3]（書籍版 Supplement No. 1 の注記）、
  [A.11]（標準参照式に基づく旨＋URL https://www.nist.gov/srd/refprop ＋DOI 10.18434/T4JS3C）、
  [A.17]（2020年 prepublication 版に基づく旨）、[A.18]（IUPAC 後援の旨）。
  [A.40] は URL https://physics.nist.gov/cuu/Constants/、[B.1] は URL http://physics.nist.gov/SP811 を保持。

## 3. 表示方式

章末パネルと同系の作法に統一した。

- 読書画面の目次（付録リスト）で、付録A・Bの行に「参考文献のみ収録」のピルと
  「（付録A／参考文献／日本語訳を収録）」のボタンを追加。付録C・索引の行は従来どおり「未着手」。
- ボタンを押すと記事末尾に「付録A 参考文献」パネルが開く。中身は章末と同じ
  `<details>` 折りたたみ1段（「参考文献（41件）」等）で、各文献は既存の
  `renderBookBlock` で描画する。初期状態では一切開かない（本文を押し下げない）。
- 遅延読み込み：パネルを開くまで付録データは取得しない。取得後は章末と同様に
  エンベロープ・件数・ブロック型を表示前に検証し、失敗時は部分表示せず
  エラー表示＋再試行ボタンを出す。
- パネル末尾に小さな注記として、出典ページ・専門家校閲未実施・
  付録の本文（物性値・換算の表）は収録していない旨を明示した。
- オフライン対応：公開ビルドが `dist/data/appendix-references/` へ複製し（ファイル数2件を
  ビルドゲートで強制）、Service Worker の APP_SHELL に両ファイルを追加してプリキャッシュする。
- `book.json` は変更していない（章末表示統合の先例に従い、付録の状態表示は目次描画側で
  特別扱いした）。節ファイル76件のビルドゲート（section データのみの content-manifest）の
  意味は変えていない。
