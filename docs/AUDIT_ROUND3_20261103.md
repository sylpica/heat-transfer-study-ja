### A3-01 分野ラベルの断片化（P2・学習機能）

- **現象・再現**：`data/questions.json` の `field` が51種類あり、分野マップに51枚のカードが並んでいた。`熱放射`（5問）・`放射`（38問）・`放射熱移動`（3問）・`熱放射・放射交換`（4問）・`放射形態係数`（6問）のように同じ主題が分かれ、1〜4問だけのカードが多数あった。熱放射シミュレーターの「関連する分野の問題を選ぶ」は、選択肢の文字列に「熱放射」を含む最初の項目（`熱放射`）を選ぶため、**放射に関する58問のうち5問しか出題されなかった**。「熱伝導」「対流」も同様。
- **根本原因**：作成時期ごとに異なる分類名を付けた。さらに一部のラベルは内容と合わない（`対流` 39問のうち31問は第8章の自然対流・膜状凝縮、`熱伝導` には非定常のBi・Fo・αの問題が含まれる）。
- **影響**：分野別の理解度が細切れになり「記録不足」と判定されやすい。分野別の演習やシミュレーターからの演習が、関連する問題の一部にしか届かない。
- **修正**：`chapter-curriculum.mjs` に `questionFieldGroup()` を追加し、各問題を既存の `questionChapter()` で決まる本書の章の主題（11分野）へまとめた。章を持たない32問は、練習対象のガイド（`sim-conduction` 等）から章を決める。作成時の `field` は削除・変更せず、問題画面上部の細分類として表示を続ける。分野絞り込みは旧ラベルも受け付ける（`questionMatchesField()`）。シミュレーターの関連演習ボタンは分野名の**完全一致**で選ぶよう変更。学習ガイドに分野のまとめ方を1文追記。`scripts/coverage-summary.mjs` に分野別の問題数を追加。
- **互換性**：保存データの形式は変更なし。回答履歴は問題IDで結び付いているため、過去の回答も新しい分野で集計される。学習時間の記録キー（`activityContext`）は従来の `field` のまま変更していない。
- **結果**：11分野（44〜135問）。全751問がいずれかの分野に属し、未分類0。
- **テスト**：`tests/audit3.test.mjs`（全問が11分野のいずれかに属し各20問以上、誤解を招くラベルの分類、旧ラベルでの絞り込み、関連演習ボタンの値が実在する分野名と完全一致）。`tests/browser-distribution.mjs` の分野選択を新しい分野名へ更新。ブラウザーで分野マップ11枚・熱放射シミュレーターから「熱放射」が選ばれること・分野マップから熱放射の演習が始まること・ページエラー0件を確認。

### A3-02 平均ヌセルト数の式番号の誤記（P3・教材）

- **現象**：`supp-applied-6-5-v1` の解説が、平均式 Nū_L=0.664Re_L^½Pr^⅓ を「原典式(6.58)」とし、さらに「上限50は原典にはない」と、設問に登場しない値へ言及していた（以前の内部監査メモが学習者向け本文に残ったもの）。

## 5. 修正していない事項と理由

| 事項 | 理由・次の作業 |
|---|---|
| 公開URLへの反映 | デプロイは所有者の手動実行（`workflow_dispatch`）で、配信元は `codex/quality-audit-local-pack`。本作業は `claude/new-session-u5gn6b` へ保存しただけで、**公開URLは未更新**。反映には本ブランチの変更を配信元ブランチへ取り込み、デプロイを実行した後、配信ハッシュとブラウザー動作の再確認が必要 |
| 分野マップと章別ロードマップの重複感 | 分野が章の主題になったため、同じ画面の章別ロードマップと見出しが近い。役割（理解度の目安／読了・未回答の優先演習）は異なるため統合はしていない。画面構成の変更は利用者の判断を要する |
| 旧PC教材の移行、原本全文訳、外部専門家校閲 | 外部依存。`npm run audit:readiness:strict` は引き続き未達（0/76節）。基準は緩めていない |
| 実機 iPhone Safari・Android Chrome、Firefox・WebKit、スクリーンリーダー | 今回は Chromium（Playwright）のみ実行。WebKit は CI ジョブで実行される構成だが、本ブランチの変更に対する結果は未取得 |
| 作成時の `field` ラベルそのものの統一 | 細分類として表示に使われ、改訂番号や履歴とは無関係だが、データの大量書き換えを避けて据え置き |
