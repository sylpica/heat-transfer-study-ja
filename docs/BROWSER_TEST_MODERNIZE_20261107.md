## 1. 背景と決定

旧 `tests/browser.mjs` は、日本語本文が「ローカルパックのみ」に存在した時代の前提で書かれていた。本文76節が公開側に収録され、動的ラボ、用語集504語、タブ構成（全13画面）を持つ現行アプリとは前提がずれ、実行すると §7.6 のブロック待ちでタイムアウトして失敗する状態だった（着手時のベースライン実行で実測）。

ユーザー決定（2026-11-07）により、本スイートは廃止せず、現行アプリに合わせて更新し維持する。本記録は、前提の洗い出し結果と、アサーションごとの「更新／置換／除外」の判断と理由、実行結果を残す。

## 3. アサーションの対応（更新／置換／除外）

### 更新（検証意図は不変、前提だけ現行化）— 12件

1. §7.6 のブロック待ち・しおり対象: `7.6-b005` → `7.6-b5`、しおり用スクロール先 `7.6-b039` → `7.6-b30`（§7.6 は31ブロック）。
2. 原本ページ確認: 対象を式ブロックから図ブロック `7.6-b3`（`data-book-page="388"`）へ移し、あわせて全図の脚注に「書籍 p.数字」が入ることを確認。
3. §7.6 の図: `.book-figure` 8件と `.figure-placeholder` 8件を確認し、実画像の decode / naturalWidth 確認は `.lesson-diagram img` に適用。
4. オフライン確認パス: `./data/sections/7-6-ja.json` へ。
5. §8.2 の式件数: 8 → 7。
6. シミュレーターのモード切替: ピッカーを開いてからモードを選ぶヘルパー `pickMode` 経由に変更（resistance / convection / conduction / radiation）。
7. 分野マップ: `.map-grid` の先頭要素を対象に変更。
8. 横はみ出し確認の画面一覧: 11 → 13（lab・guide 追加）。
9. 既定タイムアウト: 12秒 → 60秒。用語集504行などの重い描画がこの VM では実測20秒超かかるための環境適応（検証内容は不変）。
10. 式の説明文（ストロハル数）の確認: 描画が落ち着くまで読み取りをポーリングしてから検証。落ち着いた DOM が正しいことは独立プローブ6回で確認済みで、二段階描画の途中状態を拾うテスト側のレースと切り分けた（アプリの実不具合ではない）。
11. タイムコンテキスト側にも同じ既定タイムアウト（60秒）を設定。
12. ファイル冒頭コメントに現行化の旨と本記録への参照を追記。
13. 誤答の選び方: 選択肢の表示順はセッションごとにシャッフルされる（`quizChoiceOrder`）現行仕様のため、「誤答の元の位置＋1」の数字キーを押す旧方式をやめ、DOM 上で誤答（元の選択肢インデックス）の表示位置を求めてその数字キーを押す方式に変更。キーボード選択→保存→再開復元→不正解判定という検証意図は不変。
14. 図つき問題の開始: 問題バンクは既定で閉じている（`#question-bank-panel` が hidden、開閉ボタン `toggle-question-bank`）現行UIのため、開始ボタンを押す前にバンクを開く手順を追加。検証意図は不変。

### 置換（検証意図は保ち、対象を現行の相当機能へ）— 5件

1. **問題検索〜演習一式**: 対象問題を `ch7-6-strouhal` から `supp-geometry-correlation-crossflow-reynolds-v1` へ置換。選定根拠: 第7章（`source.chapterId='ch7'`）の円柱横流れ・レイノルズ数の問題で、検索語 `Re_D=UD/ν` ＋種別=問題＋章=第7章で結果がちょうど1件になることを実測。4択・正解位置・ヒント・誤答理由4件が揃い、旧フロー（誤答→再開→引き継ぎ→ブックマーク→間違いノート→報告→復習開始）全体をそのまま検証できる。問題データの読み先も `data/questions.json` に変更。
2. **日英切替（§7.6）**: 英語本文が収録されていない節では英語ボタンが無効であること、注記が「原本PDF」案内であること、日本語設定（`contentLanguage='ja'`）が保持されることを確認する形に置換。検証意図「言語切替UIと設定の保持」のうち、現行アプリで成立する部分を正直な形で固定した。
3. **§8.3 の原本確認事項**: sourceNote は収録データに存在しないため、同節の書籍注記である脚注4件の表示確認に置換。
4. **図つき問題（§8.2 の原図問題）**: `supp-flat-thickness` の CSS 図解 `.wall-diagram` の表示確認に置換。
5. **ローカル教材なしの起動確認**: 「0節で起動」から「全76節収録のまま起動」（フッター文言）へ置換。ローカルパックは任意追加に変わり、無いことが欠落ではなくなったため。

### 置換のうえ一部除外 — 1件

- **§8.2 の英語表キャプション確認**（旧: EN 表示で表キャプション /Dimensional/ を確認）: 英語本文も §8.2 の表ブロックも現行データに存在せず、相当機能がないため、この小項目のみ除外した。同コンテキスト内の英語ボタン無効の確認は残してある。除外理由は本節の #9 の実測に基づく。

完全な除外（検証自体を落としたもの）は上記1小項目のみで、チェック単位での削除は0件。
