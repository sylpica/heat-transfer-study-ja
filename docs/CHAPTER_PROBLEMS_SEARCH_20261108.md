# 章末問題・参考文献の検索対応（2026-11-08）

ユーザー決定（2026-11-08、追加候補4件を全部入れる）の1件目。章末問題563件・
参考文献410件は読書画面から章ごとに開けるようになっていたが、表示統合
（CHAPTER_PROBLEMS_INAPP_20261107.md）の範囲判断で本文検索
（`buildSearchIndex`）の対象外のままだった。本作業で、本文・問題バンクと
同じ横断検索で章末問題・参考文献にも当たるようにした。

ブランチ `feiris/chapter-problems-search`（基点＝表示統合先端 `2f11b4a`）。
コミット：実装 `c881ab4`、結果カードのはみ出し修正 `ee99eef`、本記録。

## 検索設計

- **章ファイルを正本のまま共有する。** 索引専用データは作らない。索引
  エントリは、読書パネルと同じ遅延読み込みで取得・検証され
  `chapterProblemsCache` に `ready` で入っている章についてだけ
  `chapterExtrasSearchEntries()` が組み立てる。初回表示・起動コストは
  従来どおり（章データ約610 KBは起動時に読まない）。
- **検索が不足分を取得する。** `searchNow` はまず読み込み済みデータで
  結果を即時表示し、対象種別（すべて／章末問題／参考文献）と章フィルタが
  必要とする未読込の章だけを `ensureChapterExtrasForSearch()` が並列に
  取得する。本文のみ等の検索では章ファイルを一切取得しない。章フィルタが
  特定章ならその1ファイルだけ、補足説明バケットなら取得なし。取得中は
  「章末問題・参考文献も読み込んで検索しています…」を表示し、揃い次第
  結果を再計算する。取得に失敗した章は索引に入らない（部分表示はしない、
  というパネル側の既存方針と一致）。
- **エントリの形**は既存の検索エントリに合わせた。問題：種別
  `chapter-problem`／ラベル「章末問題」、タイトル「第N章 問題 X.Y」、
  検索テキストは問題文・小問・ヒント・一部解答・与式・参照図・図の説明と、
  帰属するデータ表（見出し・行の値）まで。参考文献：種別
  `chapter-reference`／ラベル「参考文献」、タイトルは和題（なければ原題）、
  検索テキストは著者・原題・和題・出版情報・注記・DOI・URL。対象フィルタに
  「章末問題」「参考文献」の2択を追加した。
- **結果からの遷移**は既存の `data-search-target` を拡張した。対象は
  `{route:'reader', chapterExtras:章ID, entryId:ブロックID}` で、クリックで
  `ui.extrasFocus` を立てて `openChapterExtras` を呼ぶ。パネル描画は
  フォーカスがある場合だけ、該当グループと該当問題の `<details>` を開いて
  描画し、対象要素へスクロールして一時ハイライトする。フォーカスなしの
  通常描画は従来どおり全て閉じたまま（既存表明を維持）。参考文献には
  アンカー用のラッパー要素（`chapter-extra-<id>`）を付けた。パネルを閉じる
  操作でフォーカスは解除される。

## 付随修正：検索結果カードのはみ出し

Chromium 検証で、混在結果ページが 375px 幅で 382px にはみ出すことを検出
した。切り分けの結果、基点でも用語集のみの検索で 704px にはみ出しており
（本変更と無関係の従来現象）、原因はグリッドの結果カードが最小コンテンツ
幅を保ち、長い不可分トークン（DOI・英題など）を持つ1枚が列全体を広げる
ことだった。本変更で参考文献カードが加わり表面化したため、結果カードに
`min-width: 0` と本文の `overflow-wrap: anywhere`（章末問題リードと同じ
作法）を付けた。修正後は混在結果・用語集検索とも 375px に収まる。
