# 用語集の単語帳モード＋用語ブックマーク（2026-11-08）

ユーザー指示（2026-11-08 01:09–01:10）による追加開発。用語集（504語）に単語帳モードを追加し、あわせて用語ブックマークを実装した。作業ブランチ `feiris/glossary-flashcards`（基点＝章末問題表示統合の先端 `2f11b4a`）。ローカルコミットのみで、push・PRはしていない。

## 設計

- **純粋モジュール `flashcards.mjs`（新規）**：デッキ構築・並び替え・シャッフル・位置クランプだけを持つ。`buildFlashcardDeck(terms, prefs, termBookmarks)` が範囲（すべて／ブックマークのみ）・章・分野の絞り込みと並び替え（標準順＝登録順／五十音順／章・分野順）を適用し、保存済みのシャッフル順序（id 配列）があればそれを優先して復元する（失効した id は落とし、後から増えた id は並び替え順の末尾に付ける）。
- **章帰属の判定**：用語の `source.section`（数値節があるのは504語中17語のみ）＋ `relatedSections` の章で判定する。章別カバレッジ（実測）：第1章21・第2章22・第3章24・第4章31・第5章42・第6章62・第7章50・第8章23・第9章55・第10章46・第11章85・帰属なし108。分野は `category`（43種）をそのまま使う。章・分野順ソートは代表節（`source.section`、無ければ `relatedSections` の最小）→分野→五十音で決める。
- **状態は利用者データ側のみ**：`study-core.mjs` の学習状態に `termBookmarks: []`（問題ブックマークと同型の id 配列）と `flashcards` 設定オブジェクト（mode／backFirst／sort／scope／chapter／category／order／index／flipped）を追加した。`data/glossary.json` は変更していない。
- **後方互換**：新フィールドの検証は `validateLearningData` の任意項目側に置き、旧形式の保存データ・書き出し JSON（新フィールド無し）がそのまま読み込める。読み込み時は既定値で補完し、書き出し・取り込み・マージ（ブックマークは和集合）も既存機構に合わせた。

## 機能

- **モード切替**：用語集見出しに「通常表示／単語帳」切替を追加。単語帳ではカードを1枚ずつ表示する。
- **裏返し**：カードの面をクリック／タップ、または「裏返す」ボタン、またはカードにフォーカスして Space／Enter で表（用語名＋英語名）⇔裏（説明）を切り替える。裏面は要約（太字）を先頭に置き、意味・初学者向け説明に続けて「詳細を表示」展開で詳細・単位・式・別名・例文・出典を読む。長い内容はカード内のスクロール領域（`.flash-scroll`、最大44vh）に収め、ページ自体ははみ出さない。左右キーで前後のカードへ移動でき、移動時は「裏から表示」設定に応じた面に戻る。
- **シャッフル**：並びをランダム化し、順序そのものを保存する。再読み込み後も同じ並び・同じ位置で再開できる。「並びを戻す」で現在の並び替え順に戻る。進捗表示（n／総数＋バー）は常に実デッキに追従する。
- **最初から裏を表示**：チェックすると即座に現在のカードも裏面になり、以後すべてのカードが裏面から始まる（用語名を当てる学習用）。設定は保存され次回も維持される。
- **ソートと絞り込み**：並び順は標準順／五十音順／章・分野順。範囲は「すべての用語／ブックマークのみ」、章（第1〜11章、用語が存在する章のみ選択肢化）と分野（43種）で絞り込める。並び順・絞り込みを変えると位置は先頭に戻る。
- **用語ブックマーク**：各用語に ☆／★ ボタンを付けた（単語帳カード上と通常表示の各行の両方から付け外し可能）。「ブックマークのみ」デッキでブックマークした用語だけを回せる。ブックマーク0件でこの範囲を選ぶと「ブックマークした用語がありません」の空表示＋「すべての用語で学習する」ボタンを出し、壊れた状態にはならない。絞り込みで0件の場合も同様の空表示になる。
