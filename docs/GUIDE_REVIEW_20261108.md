## 分類結果

### 古い説明：1件

1. **ガイド項目 `start`（はじめに・画面の歩き方）**：要約が「11の学習画面」で、本文の画面列挙もシミュレーターが1種の前提だった。現行のタブは13（`app.js` の `NAV_ITEMS` 実測）で、シミュレーターは簡易／通常（動的実験）の2種がある。

### 誤り：1件

2. **FAQ「本文が「未着手」と表示される」**：回答文が「その節の確認済み本文はまだ収録されていません」と、未収録の節が存在する前提だった。現行の公開版では全76節が日本語訳収録済みで、目次で節が「未着手」になる状態は存在しない（前提自体が現行状態と矛盾するため、古い説明ではなく誤りに分類した）。

### 不足：5件

3. **通常シミュレーター（動的ラボ）のガイド項目が存在しない**：ガイド画面にラボの項目がなく、ラボ画面側にも「この画面の使い方」リンクが付いていなかった（`app.js` の `guideLink` 対応表に `lab` がない）。
4. **章末問題・参考文献の開き方**（`reader` 項目に記載なし）：目次の章ごとボタンと記事末尾パネルの2導線、章単位の遅延読み込み、件数が未案内だった。
5. **節→実験の連携**（`reader` 項目に記載なし）：対応する節に出る「動的実験：〜」の案内（10節）が未案内だった。
6. **問題→実験の条件引き継ぎ**（`quiz` 項目に記載なし）：対象問題の回答後に出る「この条件のフィンを動的実験で観察する」リンクが未案内だった。
7. **読書本文・図表での用語リンク**：用語リンクの詳細説明（`quiz` 項目）の対応範囲列挙に、読書画面の本文・図表の説明が含まれていなかった（用語リンク自体は実装済み）。
