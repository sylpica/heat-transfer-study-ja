### FA-04（P1）§8.5 式(8.51) — 適用済み

- 変更：`data/sections/8-5-ja.json` block[10]
  - 旧：`u = [(ρf − ρg)/(2ρfν)]·gδ²·[(y/δ) − (1/2)(y/δ)²]`
  - 新：`u = [(ρf − ρg)/(2ρfν)]·gδ²·[2(y/δ) − (y/δ)²]`
- 担当者の独立再計算（mpmath）：前置因子 C = (958−0.6)·9.81·(10⁻⁴)²/(2·958·2.94×10⁻⁷) = 0.1667322440。印刷形の界面速度 u(δ) = 0.16673 m/s（記録の 0.1667 と一致）、旧アプリ形は 0.08337 m/s（記録の 0.0834 と一致）。印刷形を積分した ṁ = 0.0106486 kg/(m·s) は式(8.53) の値と一致し、旧形の積分はその半分 0.0053243。
- テスト追加：`tests/audit-round02-source-formulas.test.mjs` に、表示式そのものを解釈・評価する原形式テストを追加（界面速度の数値、単位前置因子での形状 2s−s²、Simpson 積分が式(8.53) の表示値と一致すること）。解釈器が e 表記リテラルを受け付けないため、水の物性値は δ と ν を ×10／×1000 に換算して評価し（u ∝ δ²/ν のため結果は印刷例のちょうど 1/10）、その旨をテスト内コメントに明記した。
