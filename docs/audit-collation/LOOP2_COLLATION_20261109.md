## 2. 確定論点（第15章）との関係 — 式(8.44a/b) と式(9.40)

- **式(8.44a/b)**：第15章の確定扱いは「印刷形 (8.44a) は (8.44b)＋(8.40)/(8.41) と係数 0.630 の分だけ不整合（全 Pr で比 0.630000）。印刷形と不整合率を記録し、計算は (8.44b) を使う。黙って統一しない」。今回のページ画像（PDF p.453）が示す印刷形は、(8.44a) に 0.630 があり分子に Pr があり、(8.44b) に 0.630 がなく分子に Pr がある、という形であり、確定測定（比 0.630）と正確に整合する。Codex の変更は (i) 両式の分子へ Pr を復元（＝印刷形そのもの。旧アプリ形は両式とも Pr を欠いており転記誤りだった）、(ii) (8.44b) の表示を印刷形（0.630 なし）にし、独立導出（(6/5)·0.630·[…]）との差異を説明文に明記して無条件に同一視しない、というもので、確定扱いと矛盾しない。計算経路（`dynamic/dev/natural-convection-wall.mjs`）は印刷 (8.44a) を使わず (8.44b)＋(8.40)/(8.41) を使う旨と 0.630 の不整合をヘッダとテスト（比 0.630 を assert）で保持しており、今回の変更でも不変。**確定論点は変更しない**（新たな一次資料＝ページ画像は確定測定を裏付けた）。
- **式(9.40)**：2026-11-01 監査で「テキスト層から復元不能」とされた項目は、PDF p.524（書籍 p.510）の画像で解決した。画像上の印刷形は qmax/(ρg·hfg·ujet) = (0.21 + 0.0017·ρf/ρg)·(djet/D)^(1/3)·[(1000·ρg/ρf)/WeD]^A（A は式(9.41) の r=ρf/ρg の多項式）。径比の 1/3 乗と WeD を含む括弧の A 乗が別因子であることを画像で確認した。これが本件の解決根拠（ページ番号と画像上の形態）である。
