## 3. 所見一覧（重大度は指令書 第31章の定義）

### A5-F01（P3）用語の詳細表示で、簡単な説明と同じ文が続けて二重に表示される

- 対象：用語集の行展開詳細、単語帳モードの裏面（いずれも brief の後に detail を続けて表示する面）。
- 実測：`data/glossary.json` の全504語のうち **32語**で、`detail` フィールドが `brief` フィールドと同一の文で始まっている（例：「熱」brief＝「温度差があるために、ある物体や領域から別の物体や領域へ移るエネルギー。」、detail も同文で開始し「熱は物体に蓄えられた物質ではなく…」と続く）。表示面では同じ文が間隔なく2回続けて読める状態になる（行展開・単語帳裏面の双方で DOM テキストとスクリーンショット `usage-evidence/u3c-flash-back-375.png` により確認）。「内部エネルギー」のように detail が brief で始まらない語では発生しない。
- 再現手順：用語集で「熱」を検索→「詳しく見る」で展開（375px）。または単語帳モードで「熱」のカードを裏返す。
- 性質：内容の誤りではなく表示上の冗長（二重表示に見える）。学習を妨げないため P3 とする。対処するなら detail 冒頭の重複文を除くか、表示側で brief と detail の重なりを避ける形が考えられる（本記録では修正しない）。

### A5-F02（P3）使い方ガイド「検索と用語集」が、章末問題・参考文献の検索に触れていない

- 対象：ガイド項目「検索と用語集」（#guide/search）。
- 実測：検索画面には種別フィルタ「章末問題」「参考文献」があり実働する（種別=章末問題で「木星の大気」→ 問題11.3 に到達できることを本使い倒しで確認）。一方、ガイド項目の全文には「章末問題」の語がなく、検索対象の列挙（本文・見出し・ノート・講義・用語・問題・解説・メモ・しおり・ブックマーク）にも章末問題と参考文献が含まれていない。単語帳・ブックマークへの言及は同項目にある。
- 性質：機能は正常で、ガイド側の説明不足のみ。P3 とする。

### 観察 O1（欠陥としない）公開ビルドで local-content-manifest.json の 404 がコンソールに出る

- 全ページの読込時に `GET data/local-content-manifest.json` が 404 となり、コンソールに "Failed to load resource" が1件出る。私用ローカルパックの有無を探る設計上のリクエストであり（不在時は収録済み教材で起動する。テスト側も 404 を意図的に再現して検証している）、画面表示・機能への影響はない。欠陥としては登録しない。

### 候補として棄却したもの（測定方法の誤りを訂正した記録）

- 「ラボの計算が進まない」：当初、非表示状態の予想パネルボタンをスクリプトから直接クリックしたため時計が 0.000 s のままに見えた。可視 UI の正規手順（学び方を選択→準備→予想確定→計算）で再実測し、時計・測定点温度が正しく進行することを確認した。製品の欠陥ではない。
- 「ポップアップガイドが Esc で閉じない」：当初、DOM 内の要素存在で判定したため、非表示（hidden）状態を「開いている」と誤認した。可視性（computed style＋寸法）で再実測し、Esc・外側クリック・閉じるボタンのすべてで閉じることをラボ本画面と開発画面の両方で確認した。製品の欠陥ではない。
