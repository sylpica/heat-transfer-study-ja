## 4. 候補として棄却したもの（測定方法の誤りを訂正した記録）

- 「h_{fg} の表示が不足する」（R7-W1 初回）：計数正規表現 /hfg/ が、アプリのレンダリング形式（`h_{fg}` 波括弧形・`h_fg` 形）を取りこぼした測定側の誤り。R7-W1b/W1c で 'fg' トークンと形式別件数を実測し、データ件数と一致することを確認した（§2.2）。製品の欠陥ではない。
- 「リロード後にブックマークが保持されない」（R7-W4 初回）：リロード直後の描画途中に読み取ったための誤測（ループ4 W1 初回と同型）。R7-W4b でポーリング再測し、localStorage と ★ 表示の両方で保持を確認した。製品の欠陥ではない。
- 記事内部の 2〜4px 級 scrollWidth 超過（§2.1）：`.reader-toolbar` の +4px はループ4 観察 O2 と同一（視覚的症状なし）。deep-lesson-block 等の +2px も overflow-x: visible で文書はみ出しにならず、スクリーンショットでも欠け・重なりなし。欠陥として登録しない。
