### R9-01式(9.37) Bergles–Rohsenow 重ね合わせ式 — 二乗の適用範囲の誤り
- 所在：`data/sections/9-7-ja.json` block 11（式(9.37)）。
- 原典印刷形（書籍 p.509＝PDF p.523）：q = q_FC·√{1 + [(q_B/q_FC)·(1 − q_i/q_B)]²}。二乗は積全体に掛かる（展開形は (q_B/q_FC)²·(1 − q_i/q_B)²）。
- アプリ現行形：q = qFC·[1 + (qB/qFC)²·(1 − qi/qB)]^(1/2)。第2因子の二乗が欠落し、数学的に非等価。
- 影響（q_FC=1 で評価）：q_B=2, q_i=0.5 → 原典 1.803 に対しアプリ式 2.000（+10.9%）。q_B=3, q_i=1.5 → 原典 1.803 に対し 2.345（+30.1%）。中間域で核流動沸騰熱流束を系統的に過大評価する。
- 統合側の独立検証：コーディネーターが PDF p.523 を 300dpi で再描画し、式(9.37) の二乗が閉じ括弧の外側（積全体）に付くことを目視で確認した。上記2ケースの数値も再計算一致。
- 伝播：誤形のパターン `(qB/qFC)²·(1 − qi/qB)` は grep で本ブロックのみに存在（発展教材・問題集に同一リテラルなし）。発展教材の Bergles 言及箇所の意味的再確認は修正段階の申し送りとする。

### R10-01例題10.9・式(10.38) の数値代入表記が原典の並列合成を再現しない
- 所在：`data/sections/10-4-ja.json` block 36（例題10.9 の解、式(10.38) とする行）。
- 原典印刷形（PDF p.590）：分母 = 0.7/0.3 + 1/( 1/(1/0.8 + 1/0.8) + 0.2) + 0.5/0.5 = 5.0。中央項は直列路コンダクタンス 0.4 と直接路コンダクタンス 0.2 の和の逆数（1.6667）。
- アプリ現行形：「…/[0.7/0.3 + 1/(1/0.8 + 1/0.8) + 1/0.2 と 0.5/0.5 の合成] = 198 W/m」。並列合成が加算項へ分解され「の合成」という曖昧な文言で括られている。コンダクタンス 0.2 が 1/0.2（抵抗5）に化けているのが核心。
