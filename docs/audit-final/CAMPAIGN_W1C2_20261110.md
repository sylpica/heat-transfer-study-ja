## 確定所見

### W1C2-01（P3）記号の体系的正規化（グリフ・表記の置換、5箇所）

- (a) §10.2・PDF 568、式(10.11)：原典は **≅**（U+2245）。アプリ `10-2-ja.json` block 17 は **≒**（U+2252）。
- (b) §11.2・PDF 644、m_CO,s の近似：原典は **≅**。アプリ `11-2-ja.json` block 37 は **≊**（U+224A）。
- (c) §2.1・PDF 68、式(1.3) 再掲・式(2.5)：原典は率をドットなし **Q** で印刷。アプリ `2-1-ja.json` blocks 25・32・35 は **Q̇**（Q + U+0307）に統一（§1.2 のデータにも同じ方針）。
- (d) §2.1・PDF 68：原典の単位法線ベクトルは **n⃗**（矢印）。アプリ blocks 22・26・30・32 は **n̂**（n + U+0302）。
- (e) §2.1・PDF 68、式(2.4)/(2.5)：原典の括弧 **(n⃗ dS)** がアプリ blocks 30・32 では落ちて `n̂ dS`（dS はスカラーのため数学的には等価）。

裏取り：統括が切り出し画像（式(10.11)、例題11.2、式(2.4)/(2.5)、式(1.3) 再掲）とコードポイント実測で全て確認。参考データとして、別ラインの実測では担当4ファイル中で U+2245 は0回・U+2243（≃）は13回であり、アプリはこのグリフ族を体系的に置換している。
影響：意味・数値とも影響なし。印刷形との記号一致のみの問題であり、印刷形に戻すかアプリの表記方針として受容するかは修正バッチの判断事項として記録する。(c)(d)(e) はワーカーが「表記上の観察」として切り分けたものを、(a)(b) と同種（印刷記号の置換）として統括裁定で本件に統合した。

## 棄却・非所見リスト（理由つき）

1. PDF 644：「32.0/2 kg O₂」→ アプリ「16.0 kg O₂」。数値的に同一の簡約であり内容等価。
2. PDF 22、式(1.4)：原典は下括弧ラベル（Q_rev、Wk_rev）を用い、アプリは Q̇_rev を左辺として明示する。内容等価の形式差。
3. PDF 238、表5.3：erfc(1.10) = 0.11980 は原典自身の丸め不整合（真値 0.1197949…、正しい丸めは 0.11979 で、原典は erf + erfc = 1.00001 になる）。アプリは印刷形をそのまま保持しており誤りではない。
4. 例題1.1 の Q = 27 kW（PDF 27 の印刷）：厳密な積 68 × 0.4 = 27.2 の原典側丸め。アプリは印刷値を保持。
5. PDF 89：「3𝒯 = 159 s」は 53.1 × 3 = 159.3 の原典側丸めで、アプリは印刷値を保持。なお「95%の温度降下」の記述自体は正しい（1 − e^−3 = 0.9502）。
6. PDF 176：「T₁ + q̇L/2h」の箇条は原典自身が上線なしの h を印刷する箇所（原典内で h̄／h が不統一）。アプリ block 25 は印刷形どおりであり、W1C2-08 の数に含めない。
7. 例題9.1（PDF 495 付近、本統括の担当外）：116°C の R_b の印刷値と再計算値の差は原典側の中間丸めであり、第4弾Aで記録済みのため新規所見にしない。
