### W2C3-02（P2）§1.3・図1.6 のダイヤモンド熱伝導率の誤帰属 — PDF 29
- 原典の印刷形：図1.6（熱伝導率の対数軸 0.0003〜10,000 W/m·K）で Diamond IIb の印は 1,000 の目盛のすぐ右（10³台、約2×10³級）にあり、10,000 は軸の最大目盛。軸の最上位は 10,000 を超える方向へ矢印が伸びる Heat pipes（see Section 9.10）（統括が200dpi画像で直接確認）。
- アプリの現行形：`data/sections/1-3-ja.json` block 31（図1.6）の description は「ダイヤモンド（約10,000 W/m·K級）まで」、alt は「最も高いのはダイヤモンドである」。
- 影響：ダイヤモンドの k を図の位置（約2×10³）に対し約5倍に過大表示し、軸最大値／ヒートパイプの実効値の領域をダイヤモンドに誤帰属する。図の読み取りに限定され、この値を用いる計算・例題・問題は節データ・発展教材の検索範囲に存在しない（波及なし）。

### W2C3-03（P3）§2.4・例題2.10 の h̄／h̄_b 上線欠落 — PDF 93

### W2C3-05（P3）§6.1・μ の日本語術語の誤り — PDF 286

- アプリの現行形：`data/sections/6-1-ja.json` block 13 は「ρ と µ はそれぞれ kg/m³ の流体密度と kg/(m·s) の**動粘度（dynamic viscosity）**である」。日本語の「動粘度」は kinematic viscosity（ν）の術語であり、括弧内の英語および原典と矛盾する。同節 block 14 では ν を正しく「動粘度（kinematic viscosity）」としており、節内で術語が衝突している（正しくは「粘度（動的粘度）」等）。
- 影響：式(6.1) 自体は正しく数値影響なし。μ と ν の混同を招く術語のみの問題。

## 5. 棄却した候補（理由つき）

- **PDF 644（§11.2）質量収支の表記**：原典は "32.0/2 kg O₂"、アプリは "16.0 kg O₂" と簡約表記。再計算で等価（32.0/2 = 16.0）のため所見にしない。
- **PDF 45（§1.3）式(1.31) のドット**：原典は Q_net（ドットなし）、アプリは熱流量率の記法 Q̇_net に正規化。意味・数値に影響なく、原典自体の表記ゆれの範囲として所見にしない。
- **PDF 93（§2.4）"1/160,000 W/m²·K" の単位表記**：次ページ（PDF 94）冒頭の原典文の逐語どおりであり、原典自体の表記に従っているため所見にしない。
- **PDF 377（§7.2）図7.4 の漸近値 3.658**：原典図自身のラベルであり（式(7.23) は 3.657）、アプリは図の数値を転記していないため、原典側の図表記として所見にしない。
- **PDF 388（§7.3）例題7.4 の f 代入式の符号表記**：原典の代入式は "1.8 log₁₀" と負号なしで印字されるが、全体が ^(−2) のため数値は同一（再計算 0.026513 で ±両形とも一致）。アプリは式(7.50) の正準形どおり −1.8 を用い結果も一致するため、原典側の表記として所見にしない。
