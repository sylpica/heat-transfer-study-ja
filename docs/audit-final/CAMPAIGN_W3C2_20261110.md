### W3C2-02（P2）§7.2 式(7.29)の括弧帰属の誤り（セクションファイル） — 原典 PDF 376（書籍362）
- 原典形：`Nū_D = 3.657 / tanh(2.264·Gz^(−1/3) + 1.7·Gz^(−2/3)) + 0.0499·Gz·tanh(Gz^(−1))`

- 影響（統括の再計算）：Gz=11.8 で原典形 4.2659 に対し現行形 4.8541（**+13.8%**）。Gz=50 で +14.7%、Gz=100 で +13.2%、Gz=1000 で +7.2%。等温壁・熱的入口領域の平均 Nu の表示式そのものの誤りで、指数・括弧帰属クラスと同族。

## 5. 棄却した候補（理由つき）

- **§8.1 ディープレッスンの学習順序文**（W3b の軽微候補）：レッスンは「§8.5で関連の適用判断を学ぶ」とするが原典 §8.1 は凝縮が §8.5 と明記する、という指摘。しかし §8.2 は原典でも対流・凝縮の支配方程式を並行展開する節であり、レッスンの要約は擁護可能で、事実誤認と断定できない。式・数値への影響もないため所見化しない。
- **PDF 288 のサイドバー description の一文省略**（W5b の記録事項）：レイノルズ人物紹介の「19世紀後半の流体力学への重要な貢献者であった [6.3]」の一文が description に含まれていない。description は要約フィールドであることが仕様であり、年代・数値（1842–1912 等）は全て正しいため、誤りとはしない（W3C2-01 はキャプション自体がほぼ逐語転記でありながら印刷値を落とした点で別種）。
