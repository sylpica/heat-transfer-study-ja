## 9. プローブ側の誤りの履歴（製品欠陥ではない）

1. 静的集計で問題付属の table ブロックまで数え「569問」と誤認した。type 別の内訳で問題は563問・宣言値一致と確定（第1節）。

3. F2 初回実行群：(a) 検索はフォーム送信で実行される設計なのに fill だけで済ませた、(b) 種別フィルタは送信時の FormData で適用されるのに合成 change イベントで切り替えようとした、(c) 参考文献の初回判定は未フィルタ状態の本文カード（Fourier 数への言及）を拾った見かけの合格だった。(a)〜(c) を全て直し、厳格な条件（全カードが対象種別であること）で再実行してグリーン。
4. F5 初回実行：(a) ガイド表示中の背景確認を「再生」＋1.8 秒待ちで行い、VM 負荷下の起動遅延で時計が進まず FAIL とした。再実行では「1コマ」で決定的に進み、再生でも長めの待ちで進んだため、非モーダルであることを確認（初回は計測タイミングの誤り）。(b) チュートリアルの「測定点を左側へ移す」手順を飛ばしたため計算ボタンが正当に disabled のままとなり、プローブがタイムアウトで異常終了し後続区画（解法設定・inert）が未実行になった。手順どおりに直して再実行し全てグリーン。
