## 根本原因の分析（フェイリスがコードで確認）

数式表記の欠陥の大半は、描画経路ごとに数式変換の有無・能力が違うことに起因する。

1. 問題の「与えられた式」（formulaBlocks）は escapeHTML のみで数式変換が一切ない
   → 問題 9.34 の式が LaTeX 生文字列のまま表示される（P1-1）。
2. app.js の renderMathText は `_{...}`・`^{...}`・`^（英字）`・`^（...）`（英字入り）に
   未対応で、`_f,sat` のようなカンマ入り添字も途中で切れる（P2-2 の一部、P1-1 の一部）。
3. リーダー本文経路（renderTermLinks）は数式変換を一切行わない設計で、本文データ側の
   `^(...)`・`_` 表記がそのまま出る（P2-2、P2-6）。
4. 用語シート・用語集の formula 欄は平文表示（P2-3）。
5. データ側に「上付き修飾文字を添字のつもりで使った」箇所がある（ρᶠ など、P2-4）。
