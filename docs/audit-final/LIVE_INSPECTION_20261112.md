# 実サイト点検記録と修正リスト（2026-11-12）

公開（main ワークフロー実行 #55、承認コミット 9df9075、14:45 JST 成功）の直後、
ユーザー指示「デプロイしたら実サイトを徹底的に見て、文字のずれ・読みづらいところを
なくす」に基づき実サイト https://sylpica.github.io/heat-transfer-study-ja/ を点検した。

## 点検方法と制約（正直な記録）

- ブラウザ実地操作による全画面点検を実施。ただし操作ブラウザの表示幅は 1919px 固定で、
  375px／1280px への切替はできなかった。以下の所見はすべて 1919px での実表示確認。
- 375px／1280px の確認は、ローカル環境の Playwright（Chromium）で別途実施する
  （修正前ベースライン＋修正後）。スマホ幅特有の崩れはそちらで確定させる。

## 根本原因の分析（フェイリスがコードで確認）

数式表記の欠陥の大半は、描画経路ごとに数式変換の有無・能力が違うことに起因する。

1. 問題の「与えられた式」（formulaBlocks）は escapeHTML のみで数式変換が一切ない
   → 問題 9.34 の式が LaTeX 生文字列のまま表示される（P1-1）。
2. app.js の renderMathText は `_{...}`・`^{...}`・`^（英字）`・`^（...）`（英字入り）に
   未対応で、`_f,sat` のようなカンマ入り添字も途中で切れる（P2-2 の一部、P1-1 の一部）。
3. リーダー本文経路（renderTermLinks）は数式変換を一切行わない設計で、本文データ側の
   `^(...)`・`_` 表記がそのまま出る（P2-2、P2-6）。
4. 用語シート・用語集の formula 欄は平文表示（P2-3）。
5. データ側に「上付き修飾文字を添字のつもりで使った」箇所がある（ρᶠ など、P2-4）。

## 修正リスト

### 描画系（コード）
- L-01 問題 formulaBlocks に renderMathText を適用する。
- L-02 renderMathText を拡張：`_{...}`、`^{...}`、`^(...)` の英字・ギリシャ文字、
  `^x`（英字・ギリシャ文字1字）、カンマ入り bare 添字、上線は U+0304 も対象。
  URL 文字列の中では変換しない。
- L-03 renderTermLinks／renderTermLinksFast の本文断片にも同じ数式変換を適用する
  （用語ラベル自体は変換しない。URL は保護）。
- L-04 用語シート・用語集の formula 欄に数式変換を適用する。
- L-05 図の出典行でページ未記録のときは「未記録」を繰り返さず、その部分を省略する
  （§11.10 の図。記録済みの節には影響しない）。
- L-06 ヘッダーの表示モード切替ボタンが右端で半分切れる問題を CSS で直す。
- L-07 .inline-term に white-space: nowrap を付け、用語が行中で分断されないようにする。
- L-08 目次タイトルの1文字孤立（第2章）を CSS で緩和する。
- L-09 簡易シミュレーターの入力ラベル内の用語が全幅に伸びる問題を CSS で直す。
- L-10 用語詳細内の URL が単語途中で折れる問題を CSS（overflow-wrap）で緩和する。
- L-11 動的実験室のグラフ軸ラベルの重なり・切れ（横軸ラベルと目盛りの重なり、
  縦軸ラベルの左端切れ）を描画コードで直す。
- L-12 動的実験室の右パネル：材料表示の途中切れと進捗バーの浮きを CSS で直す。

### データ系
- L-13 上付き修飾文字を添字用途で使った箇所（78件を全数点検し、添字意図のものだけ
  `_x` 表記へ置換。上付き意図のものは現行維持）。
- L-14 図 11.19 の説明文・代替テキストの添字を表記統一（n_salt、ρ_salt、j_salt、
  m_H2O,e 等）し、CaCO_3・CaSO_4·2H_2O を下付き表記にする。図 11.24 代替テキストの
  括弧内改行は表示側の折り返しであり、文言自体は変更しない（L-07 で緩和）。
- L-15 用語 strouhal：原書 式（7.64）の記号を ahtt.txt で確認し、式・別名・単位の
  表示不整合を原書に合わせて直す。
- L-16 細部：放射の問題の「W/(m²K)」の「・」抜け、A1/F12/T1 の添字なし表記、
  §7.7 代表式の「r無次元。」の句読点。

### 対応しないもの（判断の記録）
- 日本語の通常の折り返しで生じる1文字孤立（「す。」のみの行など）は禁則処理の
  範囲として現行維持。用語の分断（L-07）と区別する。
- 図 11.24 の代替テキスト内の改行位置はブラウザの折り返しであり文言は正しい。
- L-06（ヘッダーの☾ボタン見切れ）：欠陥ではないと判定。ローカル Chromium で
  375/1280/1919px の実測幾何（ボタン右端 359/1242/1881px、グリフ右端
  343/1226/1865px、docScrollWidth＝innerWidth）とクリップ撮影で完全表示を
  確認。クラウドブラウザ側の右端オーバーレイによる見かけと判断。次周の実地で
  一度だけ再確認する。
- 簡易シミュレーター結果の単位「W」が小さい：`.result-number i` の意図的な
  デザイン（数値を主役に単位を抑制）。欠陥ではない。
- 動的実験室の縦軸ラベル「温度 [℃]」半分切れ：ローカル Chromium 375/1280px で
  再現しない。横軸ラベルの重なり（L-09）は実在し修正済み。
- 積分上限の修飾文字 ᴸ/ᵗ/ᶻ（61件）と下付き文字 ᵢ/ᵥ（101件）：位置・文字種とも
  正規であり誤記ではない（data/ 全数走査で確認）。L-13 の実修正は ᶠ 23件のみ
  （用語集12・問題11、全件 _f 記法へ）。
- strouhal の式自体（Str=fv·D/u∞）：原書 式（7.64）・付録C記号一覧とも Str が
  正しく、St はスタントン数の記号。L-15 は式ではなく unit/aliases/example/
  detail の St・U 表記を原書（Str・u∞・f_v）にそろえる修正として実施した。
