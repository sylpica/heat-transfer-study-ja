## 1. 方法

1. 機械抽出（スキャナ v2）：全ブロックの text / expression / alt / explanation / caption / description / items / title（教材は blocks と equations の expression / meaning 等）を走査し、ラテン文字ラン（U+0304 結合マクロン・合成済みマクロン・数字・アンダースコア・Unicode 下付き文字を含む）をトークン化。関数名・固有名詞（cosh/sinh/tanh/cos/sin/tan/ln/log/exp/erf/erfc/max/min/lim、Nusselt 等）を除外し、平均量になりうる基底記号 {h, q, Nu, u, v, m, T, F, C, M, k, X, Y, U, Θ, τ} について「バー付き／無印」を出現単位で記録した。総出現数 **16,894 件**。
2. 不統一の列挙：同一ファイル・同一記号内でバー付きと無印が混在する箇所を一次所見とし、さらに「ファイル全体で無印だが、その量が平均量である」族（一様無印族）も既知の平均量公式（0.664 系、Churchill–Bernstein 系、管群・凝縮系 等）の grep と文脈サンプリングで捕捉した。
3. 原典照合：**PDF のテキスト層はマクロンを完全に脱落させる**（実測確認済み）ため、原典のバー有無はページ画像でのみ確認できる。本走査では 200dpi レンダリングで以下の PDF ページを直接読影した：35, 36, 181, 183, 187, 189, 209, 210, 211, 323, 335, 336, 394, 404, 405, 407, 410, 432, 440, 441, 444, 452, 462。加えて、先行監査で画像照合済みの記録（A2／A3 トランシェ、FA／FB 所見）を根拠として用いた箇所はその旨を明記する。
