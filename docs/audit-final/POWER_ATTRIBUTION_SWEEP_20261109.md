## 4. 所見

### PA-01式(8.43b)（§8.4、`data/sections/8-4-ja.json` block 26）— 16/45 乗が商全体に掛かり、分子の 1/5 乗が脱落

- アプリ: `NuL = [0.73·Ra*_L/(1 + (0.492/Pr)^(9/16))]^(16/45)`
- 原典（PDF452）: `NūL = 0.73·(Ra*_L)^(1/5) / [1 + (0.492/Pr)^(9/16)]^(16/45)`（16/45 乗は分母括弧のみ）
- 導出整合: (8.43a) で 0.68 を落とすと Nu_L^{5/4} = 0.67(Ra*_L)^{1/4}/[...]^{4/9} → Nu_L = 0.67^{4/5}(Ra*_L)^{1/5}/[...]^{16/45} = 0.726(Ra*_L)^{1/5}/[...]^{16/45} ≈ 印字形と一致。アプリ形はこの変形と両立しない。
- 数値影響（独自再計算）: Ra*_L = 10¹⁰、Pr = 0.7 → 正 59.00 に対しアプリ形 2597.06（**44.0 倍の過大**）。Ra*_L = 10⁸ → 正 23.49 に対し 505.09（21.5 倍）。
- 伝播: 同一ファイル内の散文・他ブロック、深掘りレッスンに同式の再述なし（当該 expression のみ）。

### PA-02式(9.37)（§9.7、`data/sections/9-7-ja.json`）— 二乗の範囲が積の第1因子だけに狭窄

- アプリ: `q = qFC·[1 + (qB/qFC)²·(1 − qi/qB)]^(1/2)`
- 原典（PDF523）: `q = qFC·√(1 + [(qB/qFC)(1 − qi/qB)]²)`（二乗は積全体 `[(qB/qFC)(1 − qi/qB)]` に付く）
- 数値影響（独自再計算）: qB/qFC = 2、qi/qB = 0.5 → 正 q/qFC = 1.414 に対しアプリ形 1.732（+22.5%）。qi/qB = 0.9 → +16.0%。qB/qFC = 3、qi/qB = 0.5 → +30.1%。
- 傍証: 深掘りレッスン側の再述 `[(q″_FC)² + (q″_B − q″_i)²]^(1/2)` は原典形と代数的に等価（qFC·√(1 + [(qB/qFC)(1−qi/qB)]²) = √[qFC² + (qB − qi)²]）であり正しい。誤りは節ブロック側のみ。
