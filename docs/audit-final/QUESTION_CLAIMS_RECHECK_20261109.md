# 問題集「解説・数値主張クラス」再監査記録（2026-11-09）

対象：`data/questions.json` 全751問の explanation・distractors・hints・solutionSteps に含まれる検証可能な主張（数値・式の形・大小関係・因果の帰属）。
位置づけ：第3回監査で、正解キーは正しいのに誤答理由文・解説の補足数値が誤っている所見が6件（R3-01〜R3-06）出たクラスは、751問全体では体系的に再監査されていなかった。本監査はその全面実施である。製品データは変更していない（監査のみ）。

## 方法

- 全751問を16バッチに分け（数値を含む主張のある590問を12バッチ、残り161問を4バッチ）、各バッチを独立ラインが担当した。
- 各ラインは prompt の設定値だけから独立に解き直し、保存キーと照合したうえで、各フィールドの主張を再計算／物理の基本関係で検証した。
- 誤りの型として特に、distractors の理由文が記述する誤操作を実際に適用したときに当該選択肢の値になるか（第3回型）を全件で再現確認した。
- 統括側（本記録の作成者）は、報告された P2 全28件を実データから自ら再導出し、全件を確認した。R3-01〜R3-06 の修正箇所も統括側が独立再計算で再確認した。
- 主張の計数はラインごとに粒度がやや異なる（数値系バッチは数値・式・再現確認を単位とし、概念系バッチは文・理由文を単位とした）ため、主張総数は目安として扱う。問題単位のカバー率は厳密である。

## 検出パターン

1. **誤操作の再現不能（大半）**：理由文が「〜を誤った値」と述べるが、その誤操作を適用しても当該選択肢の値にならない。別の誤操作に対応する値であることが多い。
2. **理由文の相互入れ替わり（2組を確認）**：
   - `supp-chapter-ch2-series`：「温度差に全抵抗を掛けた」は 12×0.60=7.2 W であり、付けられた選択肢36 Wではなく隣の選択肢7.2 Wに対応する（7.2 W側の理由文も再現不能）。
   - `supp-next-nusselt-invert-h-v1`：「Lで割り忘れた」は Nu·k_f=5（選択肢20ではない）、「Nuを2倍」は h=20（選択肢40ではない）。2件の理由文が相互に入れ替わっている。
3. **増減の向きの誤り**：例 `supp-expanded-tau-calc`「面積を考慮し忘れて大きくなる」— 面積を落とすと時定数は小さくなる（200 s）うえ、当該選択肢20,000 sにもならない。
4. **explanation 側の軽微な問題（P3）**：
   - 編集・見直しメモの混入：`supp-chapter-ch8-ra` の解説末尾に「見直し注意：数値と計算過程が一致するか確認してから回答してください」が残存（数値自体は正しい）。`supp-geometry-correlation-square-pressure-v1` の出典照合メモは学習者向け案内とも読めるため要確認。
   - 定義文の不正確さ：`supp-section-11-6` が Sh を「物質移動係数と分子拡散係数の比」と文章定義するが k_m/D_AB だけでは次元が 1/m で無次元にならない（直後の式 Sh=k_mL/D_AB は正しい）。
   - 断定の強さ：`supp-applied-6-5-v1` 解説の「原典式(6.68)のPr条件に上限50はない」は版によって裏付けが分かれるため要確認（原典突合を推奨。本問の正答には無影響）。`supp-section-6-6` の Colburn 類推の不成立範囲の断定も要確認。
   - 唐突な注記：`supp-section-5-5` の「λ₁=1は説明用の仮定値…」は本問で代入していない値への注記で誤解を招き得る。
5. **定型テンプレートの不整合（P3、plain-01 の5件）**：概念問題に「単位と代表長さを特定せよ」型の定型ヒントのみが付く、数値のない問題の solutionSteps に「数値を代入し検算する」と書かれる等。第3回の R3-OBS-01（汎用テンプレート観察）と同系で、物理的主張の誤りではない。
