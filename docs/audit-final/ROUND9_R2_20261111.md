- book.json の `pdfEnd` は、多くの節で「次節の開始ページ」（境界ページの共有）またはその −1 であり、節自身の最終ページを意味しない。したがって **ヘッダ終了ページと book.json 終了ページの差異だけでは不一致としない**（ブリーフの「開始ページ基準の重なり設計は不一致としない」を終了側にも適用）。

- なお book.json は §8.4 以後の30節について `pdfEnd` 自体を持たない（開始ページのみのスキーマ）。当該節では3者突合はヘッダ対自ファイルブロックの2者照合に縮退する（book.json 側の欠落はスキーマ特性として記録するに留め、所見化しない）。

### レッスン別の検証結果（全件、逆転なし）
- **lessons[5]（§2.1）**: 伝導方程式の適用条件「非圧縮性の媒質・静止していること」は節本文の適用限界の記述と一致。(2.11) の形が k の温度・位置依存が小さい場合に限る旨も原典の構成と矛盾しない。
- **lessons[9]（§2.5）**: 条件・大小関係の主張は直列/並列の接続条件の確認等の方法論的なもののみで、節（章のまとめ）と矛盾する定量主張なし。
- **lessons[14]（§4.1）**: Dirichlet = 第1種、Neumann = 第2種、対流境界 = 第3種という帰属は節本文と一致。「原典では Robin という名称は使われていない」も節本文に Robin の語が無いことで裏づけられる。
- **lessons[20]（§5.2）**: Bi≪1 で内部伝導抵抗が表面対流抵抗より小さいという向き、式(5.12)・(5.14) の形と時定数 𝑻（U+1D47B）の使い方、二平板の集中化条件（各 Bi≪1）は節本文と一致。Bi<0.1 は「保証される定理ではない工学的目安」と留保つきで述べられており、逆転ではない。
- **lessons[23]（§5.5）**: 一項近似の誤差が 0.1% 未満になる条件「球で Fo≧0.28、平板で Fo≧0.43」、誤差は Bi≈1 付近で最大、精度を問わなければ Fo≧0.2 で使用可 — 節本文と逐語的に一致。
- **lessons[34]（§6.8）**: 気体 Nu_x≈0.0296 Re_x^0.8 Pr^0.6、非金属液体 Nu_x≈0.032 Re_x^0.8 Pr^0.43（Pr≤85 で ±15% 程度）、底層補正式が等温・等熱流束の両条件に使える旨 — 第3次 C06 の 600dpi 照合結果とも一致し、逆転なし。

- **lessons[44]（§8.2）**: 境界条件 (8.6a)（壁面 u=0・v=0、両問題共通）と (8.6b)（凝縮では膜表面で ∂u/∂y=0、自然対流では u=0）の区別は原典テキストと一致。自然対流で Pr が大きいと δ>δ_t になりうるという向きも原典の境界層の議論（Pr>1 で δ>δ_t）と一致。Re_f≲30 の波状遷移は「厳密な普遍境界ではない目安」と留保つき。
