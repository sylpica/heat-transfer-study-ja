## 3. 追加の裁定観察 — 例題11.17 の Ω_μ(Ar)（原書側の不整合）

例題11.17 の印刷入力（PDF 712）から式(11.116) μ_A = 2.6693×10⁻⁶ √(MT)/(σ²Ω_μ) を独立に再計算した。

- N₂：再計算 1.7870×10⁻⁵ ＝ 印刷 μ_calc 1.787×10⁻⁵ ✓。O₂：2.0695×10⁻⁵ vs 印刷 2.069×10⁻⁵ ✓。
- Ar：印刷 Ω_μ = 1.0848 を使うと **2.4381×10⁻⁵** となり、印刷 μ_calc = 2.282×10⁻⁵ と一致しない。印刷 μ_calc から逆算した Ω_μ は ≈ 1.1590 で、これは T* = 300/143.8 = 2.0862 における Neufeld 相関値（再計算 1.15899）およびアプリ表11.4（block 16：T* = 2.00 で 1.1753、2.20 で 1.1379 → 2.086 で ≈1.159）と整合する。
- 式(11.118) による k_calc は印刷 μ から全種再現でき、φ_ij 6値も印刷 μ_calc から丸めの範囲で再現できる（φ31 のみ再計算 0.9391 vs 印刷 0.9393、未丸め中間値による差と判断）。
- **結論：印刷された Ω_μ(Ar) = 1.0848 の方が原書内部で不整合**（本の μ_calc は Ω_μ ≒ 1.159 で計算されている）。アプリは印刷値をすべて忠実に転記している。**アプリ所見ではない。** 決着済みの印刷不整合群（例題6.6、6.9、7.6、7.7 等）と同族として、印刷値保持が正しい。
