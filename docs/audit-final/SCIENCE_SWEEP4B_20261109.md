## 4. 所見詳細

### FB4B-01（P2）§6.6 式(6.74)・(6.78) の左辺分母：Re_x が √Re_x になっている

- 原典印刷形（PDF 327／書籍313、400dpi 拡大で確定）：
  - 式(6.74)：Nu_x/(Re_x·Pr^{1/3}) = 0.332/√Re_x
  - 式(6.78)：Nu_x/(Re_x·Pr^{1/3}) = 0.4587/√Re_x ≠ C_f/2 = 0.332/√Re_x
  - 左辺分母の Re_x には根号が付かない。根号は右辺の分母にのみ付く。
- アプリ現行形（`6-6-ja.json`）：
  - block 3：`Nux/(√Rex·Pr^(1/3)) = 0.332/√Rex`
  - block 9：`Nux/(√Rex·Pr^(1/3)) = 0.4587/√Rex ≠ Cf/2 = 0.332/√Rex`
- 影響：アプリの表示形をそのまま解くと Nu_x = 0.332·Pr^{1/3}（Re_x に無関係）となり、同節の基礎である式(6.58)（Nu_x = 0.332√Re_x·Pr^{1/3}、§6.5 のアプリ表示も正しい）と矛盾する。Re_x = 10⁵ では真値の 1/√Re_x ≈ 1/316 になる。「右辺はちょうど C_f/2 である」という本文の論旨も、印刷形でのみ成立する。
- 波及確認：誤った変形パターン `Nux/(√Rex·Pr^(1/3))` はリポジトリのデータ全体でこの2ブロックにのみ存在する。発展教材（§6.6 教材に当該変形の再掲なし）・問題データ（0.4587 の出現は式(6.71) 相関形の言及のみ）への波及なし。
- 類別：表示式の分母構造の転記誤り。先行事例（第3弾 F2：式(8.30) 代入表示の誤り＝P2）と同格と判断した。
