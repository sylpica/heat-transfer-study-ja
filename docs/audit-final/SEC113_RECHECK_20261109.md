## 3. 数値の独立再計算

- 式(11.36)：T=313 K、p=1 atm で D = 1.87×10⁻¹⁰×313^2.072 = **2.77×10⁻⁵ m²/s**。block 20 の explanation「約 2.8×10⁻⁵ m²/s、表11.1 の値と ±10% 以内で一致」は正しい（表値 2.88×10⁻⁵ に対し −3.8%）。T=298 K では 2.50×10⁻⁵ m²/s。
- 発展教材 workedExample（T=300 K、P=101325 Pa、D_AB=2.0×10⁻⁵、L=0.010 m、y_A: 0.20→0.05）：c = 101325/(8.3144626×300) = **40.62 mol/m³**、cD_AB/L = **0.08124**、(a) 等モル N_A = **0.01219 mol/(m²·s)**、(b) 停滞 B N_A = 0.08124×ln(0.95/0.80) = **0.01396 mol/(m²·s)**。教材の記載値と全て一致。
- 発展教材の流束式：N_A = J_A + y_A·N_t（N_t = N_A + N_B）、J_A = −cD_AB∇y_A、J_B = −J_A、等モル積分形 N_A = (cD_AB/L)(y_A1 − y_A2)、停滞 B の対数形 N_A = (cD_AB/L)·ln[(1−y_A2)/(1−y_A1)]、J_A = −D_AB∇c_A（c 一定）はいずれも標準形と一致し、式(11.30) のモル形と整合。教材 block 7 の表11.1 引用値（空気–CO₂ 1.42、空気–He 6.24、空気–水 2.88、Ar–He 8.3/32.1/81.0、エタノール–ベンゼン 2.25、CO₂–水 2.00、水–エタノール 1.24、メタン–水 0.85→3.55）も印刷表と全件一致。

### S113-01 式(11.37) 左辺の添字が原典の i から 1 へ無言で置換されている（P3）
- 所在：`data/sections/11-3-ja.json` block 25（式(11.37)）。
- 原典印刷形（書籍 p.637＝PDF p.651、400dpi 拡大で確認）：左辺は **j⃗_i**（イタリックの i。ドットのある字形で、式(11.31) の j⃗_i と同一字形。同じ行の ∇m₁ や 𝒟₁₂ の数字「1」は直立体で明確に異なる）。
- アプリ現行形：**j⃗1**。
- 影響：数値・計算への影響はなし。ただし原典は右辺が種1の量（∇m₁、𝒟₁₂、M₁M₂/M²）でありながら左辺を一般の種 i と書いており（原典側の i/1 の不整合）、アプリは記録なく 1 へ寄せている。同ファイル内でも式(11.31) は j⃗_i を正しく保持しており、ファイル内で表記が割れている。C3-S02 で確定した原則（原典の形の相違は無言で統一しない）に従えば、印刷形 j⃗_i へ戻すか、その旨の訳注を付すべき相違である。
- 付記：block 25 の explanation は「原典PDF p.651 の画像で質量比の分数配置を照合した」と明記し分数配置は実際に正しいが、左辺添字はその照合をすり抜けている。
