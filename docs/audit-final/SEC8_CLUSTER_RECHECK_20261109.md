### F1式 (8.43b) の括弧帰属誤り — §8.4（8-4-ja.json、formula ブロック）

- 原典印刷形（PDF 452）: Nū_L = 0.73 (Ra*_L)^{1/5} / [1 + (0.492/Pr)^{9/16}]^{16/45}
- アプリ現行形: `NuL = [0.73·Ra*_L/(1 + (0.492/Pr)^(9/16))]^(16/45)`（括弧全体に 16/45 乗がかかり、0.73 と Ra*_L にも 16/45 乗がかかってしまう）
- 影響: Ra*_L = 10¹⁰、Pr = 0.7 で再計算すると、原典形 = 59.0 に対しアプリ形 = 2597（約 44 倍）。一様熱流束の平均 Nusselt 数を与える実用相関式であり、表示どおり計算すると桁違いの誤値になる。第 3 回の C3-S01（式 (8.13b)）と同型の括弧帰属欠陥が同一密集地に残存していたもの。発展教材 §8.4 は (8.43b) を再掲していないため、伝播は節ファイル内に限られる。

### F2例題 8.4 の式 (8.30) 代入表示の括弧誤り — §8.4（8-4-ja.json、例題段落）

- 原典印刷形（PDF 445）: Nū_D = {0.6 + 0.387 [576.2 / [1 + (0.559/0.707)^{9/16}]^{16/9}]^{1/6} (g-level)^{1/6}}²、括弧内の係数は原書の波括弧注記どおり 0.926
- アプリ現行形: `NuD = {0.6 + 0.387[576.2/(1 + (0.559/0.707)^(9/16))]^(1/6)·(g レベル)^(1/6)}² = {0.6 + 0.926(g レベル)^(1/6)}²`（分母括弧の 16/9 乗が脱落し、1/6 乗の帰属もずれている）
- 影響: アプリの代入式をそのまま評価すると係数は 1.005 となり、アプリ自身が併記する 0.926 および結果表と矛盾する（再計算で確認: 原典形 = 0.9265、アプリ形 = 1.0052）。ただし最終形 {0.6 + 0.926(g レベル)^{1/6}}² と結果表 4 行（g = 10⁻⁶: NuD 0.480 / h 2.85 / Q 4.47、10⁻⁵: 0.542 / 3.22 / 5.06、10⁻⁴: 0.639 / 3.80 / 5.97、10⁻²: 1.061 / 6.30 / 9.90）は原典印刷値どおり正しい。なおアプリ自身の式 (8.29)（原典形と同等の RaD^{1/6}/[…]^{8/27} 形であることを確認済み）から代入すれば 0.926 が得られるため、誤りは例題内の代入表示に局在する。結果表の Q は未丸めの Nu で再計算すると ±0.01 の差が出るが、これは丸め経路の違いであり、アプリは原書印刷値を再現している。

### F3式 (8.61) の分母が √Pr になっている — §8.5（8-5-ja.json formula ブロック、発展教材レッスン 47 block[10]・式項目「垂直板の理想層流膜状凝縮」の meaning）

- 原典印刷形（PDF 460、400dpi 拡大で確認）: h′fg = hfg [1 + (0.683 − 0.228/Pr) Ja]
- アプリ現行形: `h′fg = hfg[1 + (0.683 − 0.228/√Pr)·Ja]`（√Pr は 3 箇所に伝播）
- 影響: アプリ自身の例題 8.6 は 0.228/1.85（Pr = 1.85、すなわち /Pr 形）で計算しており h′fg = 2281 kJ/kg と原書に一致するが、表示式の √Pr 形で計算すると 2279 kJ/kg となり例題と矛盾する。Ja が小さいため h′fg への数値影響は約 0.1% にとどまるが、相関式そのものの表示誤りであり内部不整合を生む。

### F4式 (8.63)/(8.64) の分子への積分記号の混入 — §8.5（8-5-ja.json formula ブロックと (8.63) の説明、発展教材レッスン 47 の式項目 (8.63)・block[11]）

- 原典印刷形（PDF 463、400dpi 拡大で確認）: geff ≡ x (gR)^{4/3} / ∫₀^x g^{1/3} R^{4/3} dx、帰着形 (8.64): geff = x g^{4/3} / ∫₀^x g^{1/3} dx（分子に積分はない）
- アプリ現行形: 節ファイル (8.63) は `geff ≡ [∫₀^x (x·g·R)^(4/3) dx / ∫₀^x g^(1/3)·R^(4/3) dx]`、同ブロック説明中の (8.64) は `[∫₀^x (xg)^(4/3)dx] / [∫₀^x g^(1/3)dx]`。発展教材は `[∫_0^x (g(x) R(x))^(4/3) dx] / [x · g^(1/3) · R^(4/3)]` と、また異なる形で、block[11] の文章説明（「g(x)^(4/3) と R(x)^(4/3) の積を x まで積分し…」）もこの誤った形に沿っている。
- 影響: 定数 g・R の場合、原典形は geff = g に帰着するが、節ファイル形は (3/7) x^{1/3} g となり x に依存してしまい、原典自身の帰着と両立しない。アプリの例題 8.7 の結果（geff = ge cos θ、式 (8.65)/(8.66)）の表示自体は正しいため、影響は定義式 2 式と発展教材の説明に限られる。
