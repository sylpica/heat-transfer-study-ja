## Candidate discrepancies

### C1 — PDF 42 (book p.28), subscript nesting flattened in α_{λ_b}
- App location: `data/sections/1-3-ja.json`, block 145 (paragraph).
- Current form: `α_b すなわち α_λb = 1` (string "α_λb": λ and b at the same subscript level).
- Printed form (400 dpi image): α_b or **α_{λ_b}** = 1 — the b is a nested subscript of λ (set smaller and lower than λ), and ρ_b = τ_b = 0.
- Class: symbol/subscript structure. Semantic referent is the same; the printed two-level subscript is flattened in the app string.

### C2 — PDF 43 (book p.29), Figure 1.13 alt/description omit the printed in-figure condition "kept at a uniform temperature"
- App location: `data/sections/1-3-ja.json`, block 141 (figure 1.13, alt + description).
- Current form: alt describes the opening, trapping, absorption/scattering and reflections dying out; description repeats absorption/scattering only. Neither field mentions uniform temperature.
- Printed form: the figure carries the label "The hohlraum is kept at a uniform temperature" (plus "A ray of radiant energy" and "Once the ray enters, it is trapped. The walls absorb and scatter the energy, and reflections die out quickly."). The caption itself matches the app caption exactly; the uniform-temperature condition appears nowhere else in the app's §1.3 radiation text, so it is lost entirely.
- Class: figure alt/description completeness (minor candidate — alt texts in this file are summaries; flagged because the omitted item is a physical condition, not decoration).

### C3 — PDF 44 (book p.30), subscript nesting flattened in e_{λ_b}, Eq. (1.30)
- App location: `data/sections/1-3-ja.json`, block 157 (formula, number "1.30").
- Current form: `e_λb = 2πhc₀² / (λ⁵ [exp(hc₀/(k_B T λ)) − 1])` (string "e_λb": λ and b at the same subscript level).
- Printed form (400 dpi image): **e_{λ_b}** — b is a nested subscript of λ. All other structure verified correct: the square applies to c_o only (2πhc_o²), the 5th power applies to λ only (λ⁵ in the denominator), and the exp argument is hc_o/(k_B Tλ).
- Class: symbol/subscript structure (same class as C1).

### C4 — PDF 44 (book p.30), speed-of-light symbol printed as c_o (letter o), app uses c₀ (digit zero)
- App location: `data/sections/1-3-ja.json`, block 157 — expression (hc₀², hc₀) and explanation (c₀).
- Current form: c with subscript U+2080 "₀" (digit zero).
- Printed form: c_o with subscript italic letter "o" (confirmed visually at 400 dpi and by the PDF text layer, which extracts "co"). The numerical value in the app explanation, 2.99792458×10⁸ m/s, matches the printed value exactly.
- Class: glyph substitution (notation-level candidate; adjudication may treat c₀ as an accepted equivalent convention).

### C5 — PDF 44 (book p.30), deep lesson gives σ to more digits than the book prints
- App location: `data/original-deep-lessons.json`, lessons[2] (sectionId "1.3"), equations[2] ("灰色面と大きな黒体囲いの放射交換") and workedExample steps (c).

- Class: number precision differs from the printed book value (the lesson's value is the older CODATA figure and is internally consistent; flagged as a candidate because it does not match the book as printed).
