- App location: `data/sections/1-3-ja.json` block 178 (formula, alt + explanation).

Formula, numbers (block 179: (0.4)(5.6704×10⁻⁸)[(100+273)⁴ − (T_tc+273)⁴]; block 180: 23.5 °C) are correct; only the added explanatory direction wording is reversed.
