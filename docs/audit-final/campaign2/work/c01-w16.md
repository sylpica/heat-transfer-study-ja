## Candidate discrepancies

### C1 — Eq. (2.1): unit vectors printed with vector arrows, app uses circumflex hats
- PDF page: 64 (book p. 50), eq. (2.1).
- App location: `data/sections/2-1-ja.json`, block 9 (`formula`, number "2.1"), in both `expression` and `explanation`.
- Current (app) form: `∇T ≡ (∂T/∂x) î + (∂T/∂y) ĵ + (∂T/∂z) k̂` — i.e. i, j, k each with COMBINING CIRCUMFLEX ACCENT (U+0302); explanation likewise "î、ĵ、k̂ は…単位ベクトル".
- Printed form: `∇T ≡ (∂T/∂x) ı⃗ + (∂T/∂y) ȷ⃗ + (∂T/∂z) k⃗` — dotless ı, ȷ, and k each carrying a rightward vector arrow above (verified at 300 dpi crop: the mark over each letter is a horizontal arrow with arrowhead, identical in kind to the arrow over r in T(r⃗, t) on the same page).
- Note: same circumflex-vs-arrow class as the earlier campaign's n̂ findings. (The same hat forms also appear in the Laplacian-expansion formula block later in `2-1-ja.json`, outside this packet's pages; flagged here only for the eq. (2.1) instance.)

### C2 — Fig. 2.1 alt text omits the unit normal vectors n⃗ shown in the printed figure
- PDF page: 64 (book p. 50), Figure 2.1.
- App location: `data/sections/2-1-ja.json`, block 5 (`figure`, figureNumber "2.1"), `alt`.
- Current (app) form: 「等温面 T₁、T₂、… が描かれた三次元物体の模式図。温度は位置と時間の関数である。」 — mentions only the isotherms.
- Printed form: the figure draws, on two isotherm surfaces, unit normal vectors labelled n with a rightward vector arrow above (n⃗, verified at 300 dpi crop), alongside the labels "T = T(x,y,z,t) = T(r,t)", "T = T₂ = constant (an isotherm)", "T = T₁", and the x/y/z axes. The app alt has no counterpart for the n⃗ unit normals (nor for the T = T(x,y,z,t) = T(r,t) label).
- Caption itself matches: printed "Figure 2.1 A three-dimensional, transient temperature field." vs app 「図2.1　三次元・非定常の温度場。」 — no discrepancy.
