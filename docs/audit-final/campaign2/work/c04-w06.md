  30°C environment → rack in a 5°C refrigerator, properties ≈ water, h̄ ≈ 6 W/m²K (natural

  Bi = (h̄ro/k) = 6(0.05)/0.603 = 0.498 ≈ 0.5; "we read from Fig. 5.9 in the upper middle

  The 20°C property-evaluation subscript is carried by the app as a parenthetical
  （物性値は20°Cで評価）— meaning preserved, not counted.
  Spot-recompute: Fo = 0.603·3600/(997.6·4180·0.0025) = 0.2082 → 0.208 ✓;
  Bi = 0.4975 → 0.498 ✓; T = 0.84·25 + 5 = 26.0 ✓.
- Block 19: printed Θ = (10 − 5)/(30 − 5) = 0.2; Bi still 0.5; from Fig. 5.9 Fo ≈ 1.3 = αt/ro²;

- Block 20: printed (p.214, continued p.215) Φ ≈ 0.82 = [∫₀ᵗ Q dt]/[ρc(4/3 πro³)(Ti − T∞)]
