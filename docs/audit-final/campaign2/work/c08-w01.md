## Where the counterparts actually live (important mapping note)

The packet brief pointed at `data/original-section-questions.json` and `data/questions.json`. Those files contain **no** Chapter 8 chapter-end problems: every Ch. 8 item in them is an independently written supplement whose `source` field explicitly states it does not reproduce the book's problems (e.g. `supp-condensation-reynolds-definition-v1`, `supp-section-8-1` … `supp-section-8-5`). The actual counterparts of Problems 8.46–8.59 and References [8.1]–[8.10] are in **`data/chapter-problems/chapter-08.json`** (`problems.blocks[]`, ids `problem-8-46` … `problem-8-59`; `references.blocks[]`, ids `reference-8-1` … `reference-8-10`), which holds full Japanese translations with page metadata. All comparisons below are against that file, cross-checked against §§8.3–8.5 in `data/sections/8-3-ja.json`, `8-4-ja.json`, `8-5-ja.json` where a problem references a body equation.

## Book-side observation — NOT an app discrepancy (already adjudicated in the app)

- Problem 8.53 property line (PDF p. 479, verified on a 400 dpi render): the book prints "μ = 9.75 × 10⁻⁶ **kg/m³**" — the same unit as ρ on the same line; dimensionally this must be kg/(m·s). The app (`problem-8-53`, `continuation`) preserves the value and the printed unit verbatim and already carries a bilingual `sourceNote` flagging it as a book misprint ("正しくは kg/(m·s) とみられる"). No action needed; recorded here so the printed form is on record.
- Settled point honored, not reported: Problem 8.54 (Re_c on hydraulic diameter is 4× the thickness-based value) — the app's body equation (8.72) in `data/sections/8-5-ja.json` block[32] uses the book definition Re_c ≡ Γ_c/μ, and the supplement questions treat the 4Γ/μ form only as an explicitly-labelled alternative definition. No discrepancy.
