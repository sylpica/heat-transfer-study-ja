  As written, the figure description can be read as contradicting block [6].
  Suggested direction: 「ジェットの基本モジュールの間隔は λd1（格子間隔は λd2）」.

  jets as seen on an infinite horizontal heater surface"; a. plan view of

  relation correctly (λ_d2 = √2·λ_d1, eq. (9.7)), so no lesson change follows.
