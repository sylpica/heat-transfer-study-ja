- 式(9.34)（PDF 517）: 印刷 q_min,Berenson = 0.09 ρ_g h_fg · ⁴√[σg(ρ_f−ρ_g)/(ρ_f+ρ_g)²]。4乗根は分数のみに掛かり、² は分母 (ρ_f+ρ_g) のみに付く。アプリ `9-5-ja.json` blocks[3].expression は完全に同形。一致。
- 式(9.35)（PDF 517、400 dpi 拡大で確認）: 印刷 q_min = 0.515 [ 18 / (R′²(2R′²+1))]^{1/4} q_min,Berenson。アプリ blocks[4].expression = `0.515·[18/(R′²(2R′² + 1))]^(1/4)·qmin,Berenson` と完全一致（分母第二因子は 2R′²+1 であり 2R′+1 ではないこと、1/4 乗は括弧全体のみで q_min,Berenson には掛からないことを画像で確認）。プライムは U+2032 ′ で一致。
- 例題9.8（PDF 517）: 代入値 0.09(0.597)(2,257,000)、4乗根内 [9.8(0.0589)(958)/(959)²]、結果 q_min = 19.0 kW/m²、図9.2 読み値 20.0 kW/m²、式(9.34) と例題9.5 の物性を使う旨——全て `9-5-ja.json` blocks[5] と一致。再検算: 0.09×0.597×2,257,000 ≈ 1.213×10⁵、根号内 ≈ 6.01×10⁻⁴、その 1/4 乗 ≈ 0.157、積 ≈ 19.0 kW/m² で印刷結果と一致。
