## 候補

### W14-01（提案 P2）erf 解の拡散係数から媒体添字「1」が脱落
- PDF 665 | `data/sections/11-5-ja.json` block[16]（例題11.9 解、インライン表示式） | text 内の式
- 現在形（逐語）: `(mi − mi,u)/(mi,0 − mi,u) = erf[x/(2√(𝒟im·t))]`
- 印刷形（逐語、400dpi で確認）: `(𝓂_i − 𝓂_{i,u})/(𝓂_{i,0} − 𝓂_{i,u}) = erf( x / (2√(𝒟_{i𝓂_1} t)) )` — 拡散係数の添字は `im1`（種 i、媒体 **1**）
- 理由: アプリ形は媒体添字の `1` を欠き、一般媒体の 𝒟_im になっている。当該問題で定義される係数は式(11.57) の 𝒟_im1 であり、アプリ自身の block[17]（式11.57）は `𝒟im1` と正しい。表示された解の式としては係数の同一性が誤り（導出・表示誤りとして P2 を提案。表示式の虚偽として P1 にするかは中央裁定に委ねる）。左辺・erf 引数の他の部分は印刷と一致。

### W14-02（提案 P3、中央裁定へ付託）質量分率記号のスクリプト字形 𝓂 の平坦化
- PDF 665–668 | `11-5-ja.json` blocks[16], [20], [22]（式11.58a）, [23]（積分形）, [24]（式11.58）, [25]（式11.59、B の添字 m を含む）, [26]（式11.60 の B）, [27]（式11.61）
- 現在形: プレーンな `m`（ファイル全体でスクリプト 𝓂 U+1D4C2 のコードポイント数 0 を確認）
- 印刷形: 質量分率は一貫してスクリプト字形 `𝓂`（400dpi で識別済：erf 式の 𝓂_i、式(11.58a) の d𝓂_2/dx と 1−𝓂_2、式(11.59) の 𝓂_{2,0}−𝓂_{2,L} と B_{𝓂,2} の添字 m、式(11.61) の全 𝓂、p.666 散文の 𝓂_2、B_{𝓂,2}）
- 理由: 文字同一性は正しく意味は不変だが、原典は質量分率を質量 m と区別するため意図的にスクリプト書体を用いる。§11.2 の C10-06 と同族・同扱いとし、級は中央裁定に委ねる。なお図11.12・図11.13 の図中ラベルは図版自体の書体（手描き／サンセリフ）であり転記対象でないため含めない。

### W14-05（原典の不整合 — アプリ欠陥ではない）p.666 散文の B 近似の符号が式(11.59) の定義と矛盾
- PDF 666 | 対応アプリ位置: `11-5-ja.json` block[20]
- 印刷形（逐語、400dpi で確認、2箇所）: "when 𝓂₂ is small, 1 − 𝓂_{2,0} ≈ 1 so B_{𝓂,2} ≈ 𝓂_{2,L} − 𝓂_{2,0}." および "ln(1 + B_{𝓂,2}) ≈ B_{𝓂,2} ≈ 𝓂_{2,L} − 𝓂_{2,0}."
- 不整合の内容: 式(11.59) の定義は B_{𝓂,2} = (𝓂_{2,0} − 𝓂_{2,L})/(1 − 𝓂_{2,0}) であり、1 − 𝓂_{2,0} ≈ 1 の下では B ≈ 𝓂_{2,0} − 𝓂_{2,L}（散文と符号が逆）。直後の「式(11.59) は式(11.52) に帰着する」との主張も、式(11.52) が (𝓂_{2,0} − 𝓂_{2,L}) を含むため、散文の符号では成立しない。原典内部の符号不整合として記録する。
- アプリ側の状態: block[20] はこの符号付き近似連鎖を再現していない（「その駆動力の大きさは濃度差そのものとほぼ等しく」と大きさで言い換え、ln の連鎖も `ln(1 + Bm,2) ≈ Bm,2` で止める）。したがってアプリは原典の符号誤りを継承していない。ただし符号付き近似形そのものもアプリには存在しない点は、転記不完全（P3）とみなすか原典誤りの回避として許容するか、中央裁定に委ねる。
