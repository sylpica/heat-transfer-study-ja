## PDF 689（書籍 p. 675、§11.8 例題11.15 解の後半）

確認した要素: 式(11.82) の適用形、B_{m,H2O} の並べ替え、m_{H2O,s} の解、m_{salts} の関係、CP の定義式、n_{H2O,s} の数値計算（998、15、10⁻³、3600、−4.16×10⁻³、−9.71×10⁻³)、CP = 10.9% / 27.5%、B_{m,H2O} = −0.217、式(11.65) 参照、[11.31] 参照。𝒢 は原書・アプリとも脚本体で一致。n_{H2O,s} は原書・節データともドットなしで一致。

### 候補

- **W3-689-1**（添字 salts の単複）
  - アプリ側: `data/original-deep-lessons.json` §11.8 レッスン block[8] 本文「塩については m_salt,s=m_salt,e exp(−n_H2O,s/g*_m,H2O) となる」、同 eq[6] expression「CP≡(m_salt,s−m_salt,e)/m_salt,e=exp(|n_H2O,s|/g*_m,H2O)−1」、同 eq[7] expression「m_salt,s=m_salt,e exp(−n_H2O,s/g*_m,H2O)」— いずれも添字は単数形 `salt`。
  - 原書（PDF 689 画像）: CP ≡ (m_{salts,s} − m_{salts,e}) / m_{salts,e}、および m_{salts,s} = m_{salts,e} exp(−n_{H2O,s}/𝒢*_{m,H2O}) — 添字は複数形 `salts`。
  - 備考: 節データ `11-8-ja.json` block[20] は `msalts`（複数形）で原書と一致。相違は深掘りレッスン側のみ。

- **W3-689-2**（n の数値計算行の表記圧縮）要確認
  - アプリ側: `data/sections/11-8-ja.json` block[20]「nH2O,s = −(998)(15×10⁻³)/3600 = −4.16×10⁻³ kg/m²·s」。
  - 原書（PDF 689 画像）: n_{H2O,s} = −[(998 kg/m³)(15 L/m²h)(10⁻³ m³/L)] / (3600 s/h) = −4.16×10⁻³ kg/m²s — 10⁻³ m³/L は独立した因子として置かれ、各因子に単位注記がある。
  - 備考: アプリは (15)(10⁻³) を 15×10⁻³ に合并し単位注記を落とした形。数値・結果は一致。要約表記か転記相違かは要確認。

- **W3-689-3**（同上、深掘りレッスン側）要確認
  - アプリ側: `data/original-deep-lessons.json` §11.8 レッスン block[9]「質量流束は n_H2O,s=−(998)(15×10⁻³)/3600=−4.16×10⁻³ kg/(m²·s) となり」。
  - 原書: W3-689-2 と同じ（10⁻³ m³/L が独立因子、単位注記付き）。数値・結果は一致。

- **W3-689-4**（中間形の欠落）要確認
  - アプリ側: `data/sections/11-8-ja.json` block[20] は「nH2O,s = 𝒢m,H2O*·ln(1 + Bm,H2O) である」と最終形のみを記す。
  - 原書（PDF 689 画像）: n_{H2O,s} = 𝒢*_{m,H2O} [ ln(1 + B_{m,H2O}) / B_{m,H2O} ] B_{m,H2O} = 𝒢*_{m,H2O} ln(1 + B_{m,H2O}) と中間の積の形を明示してから最終形に至る。
  - 備考: 最終形は一致。圧縮による欠落か否か要確認。

- **W3-689-5**（式(11.82) の因子順序）要確認
  - アプリ側: `data/sections/11-8-ja.json` block[13]（式 11.82) expression「n2,s = 𝒢m,2*·Bm,2·[ln(1 + Bm,2)/Bm,2] = 𝒢m,2*·ln(1 + Bm,2)」— B_{m,2} が括弧の前に置かれる。
  - 原書（PDF 689 画像、H2O の場合）: 𝒢*_{m,H2O} [ ln(1 + B_{m,H2O}) / B_{m,H2O} ] B_{m,H2O} — 括弧 [ln(1+B)/B] が先、B は後。
  - 備考: 積の順序のみの相違で値は同一。表記順序の相違として記録。

### 候補

- **W3-690-1**（面積分記号の字形）
  - アプリ側: `data/sections/11-9-ja.json` block[3] 本文中の式「−∮S(−k∇T)·n⃗ dS − ∮S Σi ρiĥiv⃗i·n⃗ dS = 0」— 積分記号は2箇所とも ∮ (U+222E CONTOUR INTEGRAL)。
  - 原書（PDF 690 画像、400 dpi 拡大で確認）: −∫_S (−k∇T)·n⃗ dS − ∫_S (Σ_i ρ_i ĥ_i v⃗_i)·n⃗ dS = 0 — 積分記号は通常の ∫ に添字 S を付けた形（閉曲線記号のループなし）。

- **W3-690-2**（和の括弧の欠落）
  - アプリ側: 同 block[3]「∮S Σi ρiĥiv⃗i·n⃗ dS」— Σ の和全体を囲む括弧がない。
  - 原書（PDF 690 画像）: ∫_S ( Σ_i ρ_i ĥ_i v⃗_i ) · n⃗ dS — 和全体が丸括弧で囲まれ、その外側で ·n⃗ が掛かる。

- **W3-690-3**（式(11.83) の括弧種別）
  - アプリ側: `data/sections/11-9-ja.json` block[5]（式 11.83) expression「∇·[−k∇T + Σi ρiĥiv⃗i] = 0」— 角括弧 [ ]。
  - 原書（PDF 690 画像、400 dpi 拡大で確認）: ∇·( −k∇T + Σ_i ρ_i ĥ_i v⃗_i ) = 0 — 丸括弧 ( )。
  - 備考: 構造・項・符号は一致。括弧種別のみ相違。
