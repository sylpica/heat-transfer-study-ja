## Common structure (all 4 pages)

- Running head: *Appendix A: Some thermophysical properties of selected materials*
- Table heading on every page: **Table A.3: saturated liquids…continued**
- Column headers (identical on all 4 pages):
  *Temperature* — K | °C — then ρ (kg/m³) | c_p (J/kg·K) | k (W/m·K) | α (m²/s) | ν (m²/s) | Pr | β (K⁻¹)
- Scaling convention (important for transcription): in the α and ν columns the **first row of each substance block carries the explicit power of ten** (e.g. `8.82 × 10⁻⁸`, `7.10 × 10⁻⁷`); following rows in that block print only the mantissa in the same ×10ⁿ units, until a new block starts. Sample rows below give the printed form, with the inherited factor shown in parentheses where it is not printed on that row.
- **Footnotes: none on any of the four pages.** The only qualifications are in the block headings themselves: “Lead (1 atm, not saturated)”, “Oils (some approximate viscosities; 1 atm, not saturated)”, “Olive Oil (1 atm, not saturated)”.
