## 候補一覧

### W07-1: 式(1.6)(1.7) 周辺で原典に無いドット（Q̇）がアプリに付いている（字形・記号、要判定）
- ページ: PDF 23（書籍 p.9）。担当本体の PDF 25–28 の外だが、指示で保持確認を求められた式(1.6) の照合で発見したため候補として挙げる。
- 原典（600dpi 画像で確認）: このページの Q は**すべてドットなし**。
  - 式(1.6): `Ṡ_res = Q / T_res`（分子の Q にドットなし。ドットがあるのは左辺 Ṡ のみ）
  - 後続文: "Now Q_res 1 is negative and equal in magnitude to Q_res 2"（両 Q ともドットなし）
  - 式(1.7): `Ṡ_Un = |Q_res 1| (1/T₂ − 1/T₁)`（Q にドットなし）
  - 末段落: "The rate of heat transfer, Q, and hence Ṡ_Un, is determined by…"（rate と呼びながら Q はドットなし）
- アプリの現行内容（すべて Q にドットあり）:
  - `data/sections/1-2-ja.json` block 28（式1.6）expression: `Ṡ_res = Q̇ / T_res`、同 explanation: 「熱移動率 Q̇_res の符号は…」
  - block 29 text: 「Q̇_res,1 は負で、その大きさは Q̇_res,2 と等しいため…」
  - block 30（式1.7）expression: `Ṡ_Un = |Q̇_res,1| (1/T₂ − 1/T₁)`
  - block 31 text: 「熱移動率 Q̇、したがってエントロピー生成率 Ṡ_Un は…」
- 不一致内容: 原典の字形（ドットなし Q）に対し、アプリは5か所で Q̇ に正規化している。物理的には Ṡ=Q̇/T の方が一貫し、原典自体が他の箇所では熱移動率に Q̇ を使う（例: 式(1.12) の Q̇_net）ため、意図的な正規化の可能性もある。ただし全ページ照合の基準（原典字形との一致）では差異として記録する。裁定は統合側に委ねる。
- 付随する軽微な差異: 添字のカンマ。原典は `Ṡ_res 1` のように「res 1」（空白区切り、カンマなし）だが、アプリは blocks 26／29／30 で `Ṡ_res,1` のようにカンマを入れている。意味は変わらない。

### W07-2: 図1.5 の alt／description が図内要素を一部欠く（図の説明、軽微）
- ページ: PDF 28（書籍 p.14）、図1.5。
- 原典図（600dpi で確認）: 左 "Hot wall"／右 "Cool wall"、中央に "Gas"、縦軸 T・横軸 x、太い直線が "Temperature profile"。勾配を示す直角三角形には横の辺の下に **"1"** のラベルがあり、左に `dT/dx` が置かれる。さらに温度分布の直線は**気体の中だけで終わらず、両側の固体壁の中へ勾配を緩めて（壁面で折れて）延びている**。
- アプリの現行内容: `data/sections/1-3-ja.json` block 25

  - description: 「縦軸が温度 T、横軸が位置 x です。左側の高温壁から右側の低温壁に向かって、気体中の温度はほぼ直線的に低下します。直線に沿った三角形は温度勾配 dT/dx を表します。」
- 不一致内容: 誤った記述はないが、(a) 勾配三角形の底辺ラベル "1"（dT/dx の定義の一部）への言及がない、(b) 温度分布が壁内部へ緩い勾配で続くこと（式(1.10) の「k が大きい固体では勾配が小さい」という本文の論点と対応する図の要素）への言及がない。"Cool wall" を「低温壁」と訳す点は本文（低温の壁）と整合し、候補としない。
