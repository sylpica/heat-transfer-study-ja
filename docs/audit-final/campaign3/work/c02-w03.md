## 疑いが解消した項目（候補化せず）

1. **γ の字形（式(2.17a)(2.17b)）**: PDF 77 を 400dpi で拡大し、電気伝導率の記号が γ であることを目視で確認した。アプリ blocks[4][7] の γ と一致。テキストレイヤでは判定していない。字形候補として記録しない。
2. **𝒟₁₂ のスクリプト体（式(2.19)・例題2.3）**: PDF 78 の拡散係数はスクリプト体 𝒟 で印刷されており、アプリ blocks[11][13] も 𝒟₁₂ のまま保持している。平文 D への脱落はない。
3. **熱抵抗の添字表記（重点確認、第2次 C02-F03）**: 第2次確定所見 F03 は、カンマ線形化（例: 原典の入れ子添字を「R_t,slab」とカンマ形で書くこと）を誤りとし、原典形は入れ子添字（カンマなし）である。本範囲で確認した現行データは、式(2.22) の R_{t_cyl}（blocks[37] expression）と平板の R_{t_slab}（同 explanation）ともに入れ子添字形（アンダースコア表記、カンマなし）であり、カンマ線形化への逆行はない。PDF 80 を 400dpi で拡大した原典も、t の添字に cyl / slab が一段小さく付く入れ子形で、カンマは見えない。保持を確認したため候補化しない。なお本ファイルの範囲外ブロックにはカンマ形（R_{t,condensation}、R_{t,equiv} 等）が残るが、原典 PDF 83 以降の担当範囲であり、本メモでは登録しない。
4. **円筒長さ l の字形（式(2.21)(2.22)）**: PDF 80 の長さ記号は通常の数式イタリックの l であり、スクリプト体 ℓ ではない。アプリ blocks[35][37] の l と一致。
5. **式(2.23) の評価記法**: 式(2.23) および例題2.5の境界条件は原典 PDF 81（書籍 p.67）にあり、本担当範囲（PDF 77–80）にはかからないため本メモでは照合・登録しない。第3次 W02 メモ「疑いが解消した項目」3 が現行データでの保持を既に記録している。
