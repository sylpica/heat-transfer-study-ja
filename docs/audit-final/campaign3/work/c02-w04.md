## 書籍側記録（印刷不整合等、アプリは原典に忠実 — 候補ではない）

- **B-1 簡約式の符号（PDF 82）**: 原典の簡約式は h̄(T∞ − C₁ ln rₒ − C₂) = −kC₁/rₒ と印刷されている（400dpi で右辺の符号は minus のみであることを確認）。しかし式（2.23）の左辺 h̄[(C₁ ln r + C₂) − T∞] を r = rₒ で評価して両辺に −1 を掛けると、右辺は +kC₁/rₒ になるはずであり、印刷形は (2.23) と符号が整合しない。アプリ blocks[48] は印刷形をそのまま再現しておりアプリの誤りではない。後続の C₁・C₂ は正しい形で導かれている。

- **B-3 図版の単位長さ形（PDF 83・84、第2次 C02-B10 の再確認）**: 図2.12・図2.13 の図版ラベル R_{t,cond} = ℓn(rₒ/rᵢ)/(2πk)（図2.13 は k_mag）は分母に長さ l を含まない単位長さ形で、本文の式（2.22）・（2.25）系（ln(rₒ/rᵢ)/(2πkl)）と異なる。アプリ本文は本文式に、図2.13 alt は図版形に従っており、いずれも原典側の表記差である。
