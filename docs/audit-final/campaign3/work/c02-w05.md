## 疑いが解消した項目（候補化せず）

1. **h のオーバーライン（件別判定）**: 原典でバー付きを確認した箇所は、p.72 比較段落の h̄ 2件、例題2.7 問題文の h̄ = 13、図2.15 回路ラベル R_t,conv = 1/(h̄A)（400dpi 切り出しでバーを目視確認）、並列合成式の Ah̄ と A(h_rad + h̄)、例題2.8 の h_eff = h̄ + h_rad。アプリ側はいずれも h̄ で一致。バーなしが正の箇所（h_rad、h_eff、図2.15 の R_t,rad = 1/(h_rad A)）もアプリと一致。原典にないバーの追加もなし。
2. **ℱ の字形**: 式（1.34）を 400dpi 切り出しで確認し、原典はスクリプト体 ℱ であった。アプリの ℱ₁₋₂ 表記（(1.34)・(2.28)・(2.29)・特殊な場合の段落）と一致するため字形候補としない（テキストレイヤではなく画像で判定）。
3. **Q へのドット**: 本範囲の原典は Q・Q_net・Q_conv・Q_rad ともドットなしで、セクション側もドットなし。深層レッスン側の Q̇ 表記は恒常裁定により不所見として再登録しない。
4. **近似記号の表記ゆれ（参考観察）**: 原典は式（2.28）末行と T_m 表示で「≅」を印刷するが、アプリは「≊」を用いる（例題2.8 の k ≊ 10 も同様）。意味・数値に影響しない表記ゆれとして記録のみとし、候補化しない。
5. **図2.15 の alt 完全性**: 原典図は上段の抵抗器模式図（T_resistor、Q_conv・Q_rad の波矢印）と下段の並列回路（節点 T_resistor／T_air、R_t,conv = 1/(h̄A)、R_t,rad = 1/(h_rad A)）からなる。アプリ alt は「対流と放射の2つの並列な経路…それぞれの熱抵抗を示す図」と要約しており虚偽なし。各抵抗の式自体は式（2.26）・（2.30）としてデータ内に別途収載済みのため、欠落候補としない。
