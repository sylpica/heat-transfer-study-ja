## 疑いが解消した項目（候補化せず）

1. **式（2.33）・（2.34）の h のバー（件別判定）**: 200dpi では h の上に線が二重に見えたため PDF 92 を 400dpi で切り出して確認。二重に見えた線は「内側分数の横線＋h のオーバーライン」であり、原典は単一バーの h̄。アプリの h̄ 表記（blocks 7・9）と一致。原典にないバーの追加もなし（h_rad に相当する箇所は本範囲になし、k・U・R 系はバーなしで一致）。
2. **時定数記号 𝒯**: PDF 89 の画像でスクリプト体 𝒯 を確認（C02 確定済み字形リストにも 𝒯 は実在のスクリプト体として記録済み）。アプリ block 101・102 の 𝒯 と一致するため字形候補としない（テキストレイヤではなく画像で判定）。
3. **図2.16 の alt 完全性**: 原典図は左の接触面模式図（Interstitial heat transfer／Solid conduction の矢印、気体の間隙）と右の T–x 図（Temperature gradient の注記、界面での温度降下）からなる。アプリ alt は「接触点と気体の間隙を誇張して描き、界面を横切る温度変化を示す図」と要約しており虚偽なし。二経路の説明は本文 blocks 105・107 に収載済みのため、欠落候補としない。
4. **図2.17 の alt 完全性**: 原典図は左 Configuration（T–x 図、厚さ L＋L の2枚、界面での温度ステップ）と右 Thermal circuit（R = L/k、R_c = 1/h_c、R = L/k の直列、単位面積のため A なし）からなる。アプリ alt は「2枚の平板と接触抵抗を含む熱回路」と要約しており虚偽なし。各抵抗の式は例題2.9 解答（block 115）に A を含む完全形で収載済みのため、欠落候補としない。
5. **図2.18 の alt 完全性**: アプリ alt は「多数の熱抵抗が直列に接続された熱回路の模式図」と要約。図中ラベル R₁・R₂・R_n・ΔT の逐一の列挙はないが虚偽はなく、等価抵抗式はキャプションに収載済みのため、欠落候補としない。
6. **R_t,equiv のカンマ表記（参考観察）**: 原典キャプション・本文は添字を「t_equiv」（カンマなし）で印刷するが、アプリは全体を通して「R_{t,equiv}」（カンマあり）で統一している。数学的意味に差はなく、アプリ側の統一表記として記録のみとし、候補化しない。
7. **Q へのドット**: 本範囲の原典は Q ともドットなしで、セクション側もドットなし。深層レッスン側の Q̇ 表記は恒常裁定により不所見として再登録しない。
