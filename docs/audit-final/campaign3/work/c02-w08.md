## 疑いが解消した項目（候補化せず）

1. **U 表示式の h_i・h_o にバーはあるか**: 200dpi では判別しにくかったため 400dpi で切り出して確認した。式中の 1/h_i と r_i/(r_o h_o) はバーなしの平文であり、アプリ blocks[33] も平文で一致する。字形候補として残さない（コーディネーターが 600dpi で再判定する場合は crop97-formula.png が本判定の根拠画像）。
2. **図2.21 の h̄_i・h̄_o のバー**: 400dpi 切り出し（crop97-fig.png）で両ラベルともバーを確認し、アプリ alt の h̄ 表記と一致した。あわせて r_p の引き出し線の着地点は図上では管壁内周寄りに見えるが、式の幾何からは r_p = 管の外半径が強制され、アプリ blocks[33] explanation の説明と矛盾しないため候補化しない。
3. **問題2.2 の積分限界の字形**: 原典は下限が添字形 T_left、上限が上付き形 T^right と非対称に組まれている（400dpi、crop100-p22.png）。アプリの `∫_{T_left}^{T_right}` は上限を上付き位置に置く等価な平文表記であり、数学的内容は同一のため候補化しない。
4. **深層レッスン §2.4 の h 表記**: レッスン本文・式は一貫して平文の h_i・h_o を使う（原典本文の主表記は h̄ 系）。独立要約であり、主張・式・数値のいずれも原典と矛盾しないため、本キャンペーンの照合基準（深層レッスンは矛盾の有無を見る）では候補化しない。記録としてのみ残す。
5. **Q̇ へのドット付加**: 恒常裁定により不所見とし、本範囲でも再登録しない。
