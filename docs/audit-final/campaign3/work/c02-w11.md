## 疑いが解消した項目（候補化せず）

1. **[2.9] 著者名 "Suitor" の i の有無**: 200dpi では "Sutor" とも読めたため 400dpi 切り出し（crop112-refs.png）で再読し、u と t の間に i のドットと縦棒を確認した。JSON の "Suitor" と一致するため字形候補として残さない（コーディネーターが 600dpi で再判定する場合は同 crop が根拠画像）。
2. **[2.6] "Sekulić" のアキュート**: 400dpi で c の上にアキュートがあることを確認し、JSON の表記と視覚的に一致したため字形候補として残さない。同様に [2.8] Müller の ü、[2.9] Kakaç の ç も 400dpi で確認し一致。
3. **問題2.48 表示式の分数配置**: 原典は ΔT_i = (R_i / Σ_{i=1}^{N} R_i) ΔT と分数の外に ΔT を置く組版、JSON は線形文字列 `ΔT_i = R_i ΔT/Σ_{i=1}^N R_i`。後者は (R_i·ΔT)/(ΣR_i) と等価で数学的内容は同一のため候補化しない。
4. **[2.6] アプリ側の格納形（記録のみ、原典字形の判定ではない）**: JSON の authors は "Sekulic"＋結合アキュート（U+0301）の分解形で格納されており、表示上は合字形 ć と同一になる。これはアプリファイルの符号化の観察であり、原典画像の読みとは無関係のため候補化しない。統一が必要かはコーディネーターの判断に委ねる。
5. **問題2.45(b) 直後の "(Continues on next page.)"**: 原典 PDF 109 では (b) の直後にこの継続注記が印刷されているが、(c) も同一ページに続いており、内容情報を持たない組版注記である。JSON に無いのは翻訳上の省略として扱い、候補化しない（書籍側の表記として分離記録する性質のもの）。
