## 疑いが解消した項目（候補化せず）

- 式（3.14）の表記差: 原典は F の引数を2つの分数そのものとし、下括弧で P・R を名指す。アプリは F(P, R) と書き P・R の定義を同じ expression 内に併記する。数学的内容は同一であり、表示式の誤りではないため候補化しない。

- 図3.13 の添字表記: 原図の添字は T_h,in 等が圧縮された図版レタリング（h と in/out が同一添字段）だが、アプリ alt の「T_h,in」表記は同一の意味であり候補化しない。
- 図3.12 の alt の「右下に約2 m のスケール矢印」: 図中のスケールは右側中下部にある縦両矢印「~2 m」であり、「右下」「約」は妥当な要約と判断し候補化しない。
