## 不一致候補

### C1（軽微・表記）PDF 220／式(5.33) の Σ 上限 ∞ の欠落
- 対象: `data/sections/5-3-ja.json` blocks[26]（formula, number 5.33）。同表記は `data/original-deep-lessons.json` §5.3 の equations「式 (5.33) 級数解と係数」および blocks「係数 Gn の明示形と級数解」本文の Σ_{n:奇数} にもある。
- 現行: `Θ(ξ, Fo) = (4/π)·Σ(n = 奇数) (1/n)·e^(−(nπ/2)²Fo)·sin(nπξ/2)` — Σ の条件は「n = 奇数」のみで上限 ∞ が書かれていない。
- 原典（600dpiで確認）: Θ(ξ, Fo) = (4/π) Σ^∞_{n=odd} (1/n) e^{−(nπ/2)²Fo} sin((nπ/2)ξ) — Σ の上部に ∞、下部に n=odd。
- 備考: 奇数 n 全体にわたる無限級数であることは文脈上明らかで数学的内容は等価。ただし同ファイルの式(5.30)(5.31)(5.32) は ∞ を明示しており、表示転記としての不一致として候補に挙げる。

- B1（PDF 219／書籍p.205 本文）: 原典の本文は「We multiply eqn. (5.31) by **sin(mπ/2)**」と ξ を欠いた形で印刷されている（600dpiで確認）。式(5.32)自体は sin((mπ/2)ξ) と正しい。現行 blocks[21] および blocks[22] explanation は sin(mπξ/2) と完全な形で書いており、これは原典本文の脱落を補った正しい形なので候補にしない。
