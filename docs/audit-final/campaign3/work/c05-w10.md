## 一致を確認した主要要素

### 書籍 p.295（PDF 309）§6.3
- 式(6.36) 全体: `d/dt ∫_R ρû dR = −∫_S (ρĥ) u⃗·n⃗ dS − ∫_S (−k∇T)·n⃗ dS + ∫_R q̇ dR`、4つのブレースラベル — アプリ式・解説と一致。
- 体積分形 `∫_R [∂(ρû)/∂t + ∇·(ρu⃗ĥ) − ∇·k∇T − q̇] dR = 0`、微分形 `∂(ρû)/∂t + ∇·(ρu⃗ĥ) − k∇²T − q̇ = 0` と展開 `= ρu⃗·∇ĥ + ĥ∇·(ρu⃗)` — 一致。
- 脚注参照「pg. 55 in Chapter 2」→ アプリ「第2章55ページの脚注」— 一致。参照式 (2.7)・(2.8) も一致。
