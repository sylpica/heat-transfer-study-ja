### 候補 W3-1 — 問題6.3 箇条書き第1・第2項の df′/dη のプライム・微分の帰属

- PDFページ: 351（書籍 p.337）
- データ側の場所: `data/chapter-problems/chapter-06.json`、problems.blocks の problem-6-3、items[0] および items[1]
- 現在のアプリ表記:
  - items[0]: 「η = 0 における f′（df/dη）の値を推測することから始める。例えば f′ = 1 とする。η が大きい（例えば6や10）とき、f′ は定数へ漸近的に近づく。その定数が1より大きければ、より小さい f′ の推測に戻り（あるいはその逆）、定数が1に収束するまで続ける。」
  - items[1]: 「f′ の正しい値は η = 0 でおよそ0.33206である。」
  - すなわち推測・漸近・正解値の対象が一貫して裸の f′ になっている。
- 原典の印刷形:
  - 第1項: 「guessing a value of df′/dη at η = 0 — say, df′/dη = 1. When η is large — say, 6 or 10 — df′/dη will asymptotically approach a constant. If the constant > 1, go back and guess a lower value of df′/dη, or vice versa, until the constant converges on one.」— df′/dη（f′ の η 微分）が4回現れる。
  - 第2項: 「The correct value of df′/dη is approximately 0.33206 at η = 0.」— 0.33206 は df′/dη の η = 0 における値として印刷されている。
  - 対照: 第3項は原典でもプライムなしの df/dη = 1 at η = ∞ であり、データ items[2] も df/dη のままで一致している。つまり原典は第1・第2項（df′/dη）と第3項（df/dη）で表記を使い分けており、データは第1・第2項だけが f′ に置き換わっている。
- 根拠: 600dpi クロップ（/tmp/c06w03/crops/p351_63-351.png）で目視判定。第1・第2項のすべての該当箇所で、f の右上にプライム記号が明確にあり、その全体が d…/dη の分子に入っている（df′/dη）。第3項の同位置にはプライムがなく df/dη と読める。200dpi 全ページ画像でも同じ読みが得られ、600dpi で確定した。テキストレイヤは判定に用いていない。
- 重大度提案: P2（導出・表示の誤り）
  - 理由: η = 0 で 0.33206 という数値が帰属する対象が、原典の df′/dη からデータの f′ へ変わっている。items[0] 自身が括弧内で f′ を df/dη と定義しているため、データ内部でも「(df/dη の η 微分) = 0.33206」という原典の主張と「f′ (= df/dη) = 0.33206」というデータの主張が食い違う。問題文中の数値の帰属の誤りとして P2 を提案する（裁定時に、他箇所で df′/dη を f′ と略記する翻訳慣行があるかどうかの確認を推奨）。
