### C1 — 式(7.32) 適用条件の不等号: 原典 ≳ に対しデータは ≧
- PDFページ: 381（書籍 p.367）
- データ側の場所: `data/sections/7-3-ja.json` block 13（式 7.32）の explanation
- 現在のアプリ表記: 「この式は Pr ≧ 0.7 に対して、…適用されます」
- 原典の印刷形: "This equation applies for Pr ≳ 0.7 and for either uniform q_w or uniform T_w situations."（≳ = greater than or approximately equal to、下段は波線）
- 根拠: 600dpi クロップ（~/tmp_w11/crop381b-381.png）で該当字形を拡大確認。上段の「>」の下に、真っ直ぐな線ではなく波形（~）の小さいストロークが明瞭に見えた。対照として同条件で確認した PDF 382 の Re_D ⩾ 10,000（crop382b）と PDF 383 の ⩽ 群（crop383-prrange / crop383b）はいずれも下段が真っ直ぐな斜め線であり、字形の違いは印刷上区別されている。したがって本件は単なる書体差ではなく、近似付き不等号を通常の不等号に置換したものと判定する。
- 重大度提案: P3（字形・意味の微差。式自体は正しく、数値計算には影響しないが、適用下限が「およそ0.7」である原典の含意が落ちる）
