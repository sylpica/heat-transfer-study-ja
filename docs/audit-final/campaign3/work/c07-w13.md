## 重点確認（総括）

- 式(8.51)（FA-04 の P1 修正保持）: 現行 blocks[11] は `u = [(ρf − ρg)/(2ρfν)]·gδ²·[2(y/δ) − (y/δ)²]`。600dpi クロップで原典印刷形 `(ρf − ρg)gδ²/(2ρfν) · [2(y/δ) − (y/δ)²]` と一致を確認。ブラケットは半分化していない（第1項の係数 2、第2項は (y/δ)² 全体にかかる）。数値裏取り: 界面 y=δ ではブラケット = 2−1 = 1 で界面速度は前係数そのもの。例題8.6 の物性値（ρf=961.9、ρg=0.60、g=9.806、ν=3.091×10⁻⁷、δ=1.04×10⁻⁴）で Simpson 積分すると ∫₀^δ ρf·u dy = 1.143485×10⁻² となり、式(8.53) の解析値 g(ρf−ρg)δ³/(3ν) と比 1.000000 で一致。ブラケットが半分なら積分は 0.5 倍となり (8.53) と矛盾する。→ 修正保持を確認、候補なし。
- 式(8.59): 現行 blocks[17] は `Nux = 0.707·[g(ρf − ρg)h′fg·x³/(νk(Tsat − Tw))]^(1/4)`。600dpi クロップで原典の枠囲み表示と一致（h′fg のプライムは h の右上、x³ は分子のみ、1/4 乗は角括弧全体）。係数裏取り: 式(8.56) を Nux = x/δ に代入すると係数は (1/4)^(1/4) = 0.707107 → 印刷 0.707 と一致。→ 保持正、候補なし。
- 式(8.60): 原典印刷形は `Nux/⁴√Π4 = fn(Ja, Pr) → 1 as Ja → 0`（600dpi クロップで確認）。現行 blocks[17] explanation はこの印刷形をそのまま掲出し、訳注で「式(8.59) からは Ja→0 で Nux/Π4^(1/4) → 0.707（= 4^(−1/4)）、1 に近づくのは図8.12 の Nux/(Π4/4)^(1/4) の方」と正規化の区別を明記している。数値確認: 0.707107 × 4^(1/4) = 1.000000 で訳注の区別は正しい。書籍の印刷不整合という確定事項どおりの状態であり、**再登録しない**。
