### 候補
#### C1problem-8-1: Π4 の解釈が積になっている（原典は除算）
- 対象: `data/chapter-problems/chapter-08.json` problem-8-1 の text および formulaBlocks
- 現行 text:「膜凝縮問題における Π₄ が、Pr·Re²·Ja と正しく解釈できることを示せ。」
- 現行 formulaBlocks: `Π_4 = Pr Re² Ja`
- 原典（PDF 470、600dpi クロップ c81b-470 で確定）: "Show that Π4 in the film condensation problem can properly be interpreted as **Pr Re²/Ja**." — Re² と Ja の間にスラッシュがあり、Π4 = Pr·Re² **／** Ja が正。
- 数値・代数による裏付け: 特性速度を自由落下速度 U = √(gL) とすると Re² = gL³/ν²。Π4·Ja = g(ρf−ρg)L³/(νkΔT) · cpΔT/hfg ÷ … を Pr = ρf ν cp/k で整理すると Π4·Ja = [(ρf−ρg)/ρf]·Pr·Re² となり、ρg ≪ ρf で Π4 = Pr Re²/Ja。これは §8.5 本文（8-5-ja.json block 5）「Π4 に Ja を掛ければ凝縮液膜に対するレイリー数とみなすことができる」（= Π4·Ja ≒ Pr·Re²）と整合し、アプリ現行の積表記 Π4 = Pr·Re²·Ja は原典とも内部整合とも矛盾する偽の等式（Ja ≈ 0.0183 の例では Ja² ≈ 3.3×10⁻⁴ 倍ずれる）。表示式が偽であるため P1。
