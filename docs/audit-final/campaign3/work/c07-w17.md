## 重点1: 問題8.15 の修正保持（第2次 P2）— 保持を確認

- 原典（PDF 472 末尾〜473 冒頭、600dpi クロップで確定）:
  - "In eqn. 8.7, we linearized the temperature dependence of the density difference. Suppose that a wall at temperature T_w sits in water at T_∞ = 7°C. Use the data in Table A.3 to plot **|ρ_w − ρ_∞|** and **|−ρ_f β_f (T_w − T_∞)|** for 7°C ≤ T_w ≤ 100°C, where (..)_f is a value at the film temperature. How well does the linearization work?"

- アプリ現行（problem-8-15 の text 全文）:
  - 「式（8.7）では、密度差の温度依存性を線形化した。温度 T_w の壁が、T_∞ = 7 °Cの水の中にあるとする。表A.3のデータを使って、7 °C ≤ T_w ≤ 100 °C に対して |ρ_w − ρ_∞| と |−ρ_f β_f (T_w − T_∞)| をプロットせよ。ここで (‥)_f は膜温度における値である。線形化はどれだけうまく機能するか。」

- 備考: 原典の不等号は ⩽ 字形（斜め二重線）、アプリは ≤（U+2264）で表記。意味同一であり、W01 の先例どおり候補としない。
