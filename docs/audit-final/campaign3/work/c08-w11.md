### W11-1図9.15 alt の q_max レベル線の線種誤り
- ページ: PDF 520（書籍 506）、図9.15
- 原典の形: q_max の水平レベル線は一点鎖線（dash-dot: 長いダッシュと点の繰り返し）。q_min のレベル線は長い破線。600dpi クロップで目視確認。
- アプリの現行: `data/sections/9-6-ja.json` block[5]（figure 9.15）alt =「qmax（実線）と qmin（破線）のレベル線と3本の曲線（核・遷移沸騰、液固接触ありの膜・遷移沸騰、接触なしの膜沸騰）を示す沸騰曲線の図」— q_max を「実線」としているが原典は実線ではない（q_min の「破線」は概ね正しい）。
- 提案: 「qmax（一点鎖線）」等へ修正。

### W11-2図9.14 description 上パネル凡例の簡略化による意味のずれ
- ページ: PDF 519（書籍 505）、図9.14 上パネル凡例
- 原典の形: ●「clean, both smooth and rough」／×「unclean, both oxidized」／○「and not oxidized」（○も unclean の継続で「未清浄・非酸化」）。600dpi クロップで目視確認。
- アプリの現行: `data/sections/9-6-ja.json` block[3]（figure 9.14）description =「上パネルは表面の清浄度（● 清浄、× 未清浄・酸化、○ 非酸化）、下パネルは…」— ○ の「非酸化」だけでは「未清浄」が落ち、清浄な非酸化面と誤読しうる。● の「滑らか・粗い両方」も落ちている。
- 提案: 「○ 未清浄・非酸化」「● 清浄（滑らか・粗い両方）」等へ補う。
