## 候補一覧

### W16-1（P3）図9.22 の description が中間部の「Insulation（断熱）」ラベルを欠き、断面インセットの記述が同語反復になっている
- ページ: PDF 539（書籍 525）、図9.22
- 原典の形: 600dpi クロップで目視確認。管は左端 Evaporator／中間の斜行部／右端 Condenser の3区間からなり、斜行部の下側に「Insulation」のラベルがあり、斜行部の両端にはハッチング境界がある。断面インセット（Cross section）は中央が Vapor、外周の環が Wicking material。
- アプリの現行: `data/sections/9-11-ja.json` block[2]（figure 9.22）description =「蒸発器（Qin の矢印）で生じた蒸気は凝縮器（Qout の矢印）へ流れ、液体はウィックを通って蒸発器へ戻る。断面の inset には蒸気・ウィック材・断面が示される。」— 蒸発器・凝縮器・蒸気流／液体還流の向き・Qin/Qout・インセットの蒸気とウィック材は含むが、図に明示ラベルがある断熱区間（Insulation）に一切触れない。また末尾「断面の inset には…断面が示される」は同語反復で、インセットの内容（中央の蒸気コア＋外周のウィック材環）を正確に言えていない。
- 提案重大度: P3（図説明完全性の欠落＋文言）。提案: 「中間部は断熱（Insulation）区間。断面インセットは中央の蒸気と外周環状のウィック材を示す。」等へ補う。

### W16-2（P3）図9.21 の description がパネル (a) の2時点対比とパネル (b) の乾いた経路の位置を欠く
- ページ: PDF 537（書籍 523）、図9.21
- 原典の形: 200dpi 全面で目視確認。パネル (a) は「Before」と「A Moment later」の2枚の板の対比で、左注記「Droplets grow and merge until one drop is large enough to fall」、右下注記「Drop slides off wiping the plate dry in its wake」。パネル (b) の写真キャプションは乾いた経路の位置を「左側と、中央の液滴の跡（in the wake of the middle droplet）」と特定する。
- アプリの現行: `data/sections/9-10-ja.json` block[3]（figure 9.21）description =「a は液滴の成長・合体・滑落による液体除去の過程。b はミキッチ提供の滴状凝縮の写真で、滑り落ちた液滴が拭った乾いた経路が強調される。」— 成長・合体・滑落と (b) の写真・乾いた経路自体は含む（F33 の中核は保持、下記）が、(a) が Before／A Moment later の2時点対比であること、(b) の乾いた経路が左側と中央液滴の跡にあることは description に現れない（位置情報は caption 欄にはある）。
- 提案重大度: P3（図説明完全性）。提案: (a) に「落下前と落下直後の2時点を対比」を、(b) に「乾いた経路は左側と中央の液滴の跡に残る」を補う。

## 式・字形の検証（不一致なし）

- **式(9.57)**（PDF 539、600dpi クロップで目視）: 原典 q = T^0.8 (5ΔT + 0.3ΔT²) kW/m²。冪の帰属は 0.8 が T のみ、2 が括弧内第2項の ΔT のみ（括弧全体や第1項には掛からない）。アプリ `9-10-ja.json` block[6] expression「q = T^0.8·(5ΔT + 0.3ΔT²) kW/m²」と完全一致。適用条件・説明（大気圧付近〜1 kPa、接触角 90°付近、T は °C、ΔT はバルク蒸気と表面の温度差、裏付けデータの ΔT は一般に 8 K 未満）も block[4] 末尾・block[6] explanation と一致。
- **メリット数 M**（PDF 540、600dpi クロップで目視）: 原典 M = h_fg σ / ν_f。ν はギリシャ文字ニュー（斜体 ν、添字 f）でありラテン文字 v ではない。アプリ `9-11-ja.json` block[4] items[0] は「M = hfgσ/νf」で ν は U+03BD（実測）＝一致。範囲 10¹⁰〜10¹² kg/s³・問題9.36 参照も一致。深層レッスン 9.11 equations の「M = h_fg σ / ν_f」も同形で一致（別エントリの ν_l 表記は ν_l=μ_l/ρ_l と定義した同量の別記法であり誤りではない）。
