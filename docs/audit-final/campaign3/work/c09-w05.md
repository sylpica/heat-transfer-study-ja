## 書籍側の印刷不整合・原典状態の記録

1. **添字順の同ページ内不整合（→ W05-C1）**: 書籍547ページ本文では `e_{bλ}(T)`、同ページ図10.2挿入図では `e_{λb}` と、黒体単色放射力の添字順がページ内で異なる。データは図側の順を採用している。
2. **dω の因子順の表記揺れ**: 書籍550ページ本文では `dω = sinθ dθ dφ`、同ページ図10.4内では `dω = dθ dφ sinθ` と因子順が異なる（積としては等価）。データは本文箇所（ブロック22）では本文順、図説明（ブロック24）では図順と、原典の出所どおりに使い分けており、不一致ではない。
3. **Q／q の大小**: 式 (10.6) は `dQ_outgoing`（大文字 Q、全エネルギー率）、式 (10.7a) は `q_outgoing`（小文字 q、熱流束）と原典で書き分けられており、データも保持している。誤記ではない原典状態として記録する。
4. その他、数値の印刷誤り・符号誤り・式番号の誤りに相当する原典側の不整合は本担当4ページでは検出されなかった（5772 K、0.6、20°／90°、2π／π/2、4π 等は全て明瞭に判読できた）。
