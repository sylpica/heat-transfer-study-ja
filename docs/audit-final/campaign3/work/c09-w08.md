### W08-01 [P2] 表10.2 配置5：パラメータ a の定義が図の寸法線と異なる
- 対象ブロック: `10-3-ja.json` block 21（表10.2 の list）の配置5 item
- 現行: 「配置5（帯と平行円柱）：F1–2 = [r/(b − a)]·[tan⁻¹(b/c) − tan⁻¹(a/c)]。ここで r は円柱の半径、**a は円柱の左端を通る鉛直線から中心線までの距離**、b は帯の左端から中心線までの距離、c は帯の面から中心線までの鉛直距離。」
- 原典: 書籍561（PDF575）表10.2 配置5 の図では、a の寸法線は帯（面1）の円柱側（右）端を通る鉛直線と、円柱の中心線との間に引かれている。b の寸法線は帯の左端と中心線の間であり、したがって b − a が帯の長さそのものになる。tan⁻¹(b/c) と tan⁻¹(a/c) も、中心線から帯の両端までの水平距離 b・a を c で割った角度として構成されている。現行定義の「円柱の左端を通る鉛直線から中心線までの距離」は円柱半径 r そのもの（a ≡ r）になってしまい、独立な配置パラメータとして成り立たない。
- 根拠ページ: 書籍561（PDF575）表10.2 配置5 の図（400dpi 拡大で寸法線の帰属を確認：a の左側ティックは帯の右端の鉛直線上にあり、円柱の左端接線とは一致しない）
- 判定理由: 配置5 の式そのもの（r/(b−a)、tan⁻¹ の引数 b/c・a/c、符号）は原典と一致するが、a の定義文が図と異なり、この定義で数値計算すると誤った a（= r）を代入することになるため、表の表示・説明の誤りとして P2 とする。b・c・r の定義文は原典図と一致する。
- 修正案: 「a は帯の円柱側の端を通る鉛直線から中心線までの水平距離」

- 位置: 表10.3 配置1 の式、第1行 ln 項の右端。
