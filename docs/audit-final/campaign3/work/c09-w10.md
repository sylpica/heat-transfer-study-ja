### W10-01 [P3] 式(10.21)：左端の q_net A = が無く、2つの分母形の順序が原典と逆
- 対象ブロック: `10-4-ja.json` block 7（formula, number 10.21）
- 現行: 「Qnet = (eb − B)/((1 − ε)/(εA)) = (eb − B)/((ρ/ε)/A)」
- 原典: 書籍567（PDF581）の式(10.21) は `q_net A = Q_net = (e_b − B)/(ρ/εA) = (e_b − B)/((1 − ε)/εA)`（400dpi 拡大で確認）。すなわち (1) 左端に `q_net A =` がある、(2) 分母形は ρ/εA の形が先、(1 − ε)/εA の形が後、の順である。
- 根拠ページ: 書籍567（PDF581）式(10.21)
- 判定理由: 現行の2つの分数は、直前の条件（不透明 τ = 0、灰色 α = ε、すなわち ρ = 1 − ε）の下では原典の2形と値が等しく、式自体は偽ではない。相違は表示上の欠落（q_net A =）と導出順序の入れ替えに限られるため、表示・文言レベルの P3 とする。なお後続の本文（block 2）が表面抵抗として参照する (1 − ε)/εA の形は現行にも含まれており、参照関係は壊れていない。
- 修正案（採否はコーディネーター判断）: 「qnet·A = Qnet = (eb − B)/((ρ/ε)/A) = (eb − B)/((1 − ε)/(εA))」の順に直す。
