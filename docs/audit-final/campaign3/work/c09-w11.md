## 書籍側の印刷不整合の記録（データ側の誤りではない）

- **B-1: 例題10.8 シールド付き一般形の neglect 項の添字（PDF 586、書籍 572、式の中段）**
  原典は `(1 − ε_c) / (ε_2 A_c)` と印刷されている（400dpi で分子の添字 c と分母の ε の添字「2」が明確に異なる字形であることを確認）。文脈上この項はチャンバー（c）の表面抵抗であり、正しくは `(1 − ε_c)/(ε_c A_c)`。式(10.31) の一般形から 1→l、2→c、s→s と置換する際に分母の ε の添字だけ置換漏れになったものと見られる。データ（例題10.8 一般形ブロックおよび本文）は論理的に正しい `ε_c` 形に正常化しており、数値計算はこの項を neglect するため影響なし。**原典の状態は「分子 ε_c／分母 ε_2 A_c」として記録する。**
- **B-2: 断熱壁の段落の式番号引用（PDF 588、書籍 574）**
  原典は「eqn. (10.33b) shows that e_{b3} = B_3」と引くが、Qnet_3 = 0 から e_{b3} = B_3 を直接与えるのは式(10.33a) であり、(10.33b) が与えるのは各面への放射の和がゼロという条件である。引用は緩い（誤り寄り）。データ段落は原典に忠実に「式(10.33b)」としており翻訳の誤りではない。なお深レッスン §10.4 はこの関係を正しく (10.33a) に帰属させている。
- **B-3: 導入文の冗長な前置詞（PDF 587、書籍 573、冒頭文）**
  原典は「as pictured **in at** the bottom and left-hand sides of Fig. 10.15」と二重の前置詞で印刷されている。データの訳文「図10.15の下部と左側に描かれるような」は通常の訳で、意味への影響なし。原典の状態として記録するのみ。
