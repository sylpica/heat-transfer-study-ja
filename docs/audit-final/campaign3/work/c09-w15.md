### W15-01 [P3] 式(10.53)：データ側の表示式に原典にない末尾の等式が付加されている
- 対象ブロック: `10-5-ja.json` block 17（式(10.53)）
- 現行: 「iλ(L) = iλ0·e^(−ρκλL) + iλb·(1 − e^(−ρκλL)) = τλ·iλ0 + ελ·iλb」
- 原典: 書籍587 の表示式は「iλ(L) = i_{λ0} e^(−ρκλL) + i_{λb} (1 − e^(−ρκλL))」までで終わり、末尾の「= τλ·iλ0 + ελ·iλb」は存在しない。代わりに原典は下括弧で、第1項の指数因子に「= τλ」、第2項の括弧に「≡ ελ」という注記を付けている（400dpi 拡大で確認）。
- 根拠ページ: 書籍587（PDF601）中部
- 判定理由: 付加された等式は定義 (10.49)(10.54) から数学的に等価であり、式が偽になるわけではないため P1/P2 ではない。しかし表示式の構造が原典と異なる（原典の下括弧注記が等式への書き換えになっている）ため、表示忠実度の問題として P3 候補とする。
