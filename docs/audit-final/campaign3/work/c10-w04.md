## 重点確認: 問題10.44 の ℱ（第2次 C10-16）

- 結論: **現行データは ℱ で印刷と一致。復元済みであることを確認した。**
- データ側: `chapter-10.json` の problem-10-44 の `text` 中に「ℱ_{1–2} に10%未満の誤差を導入するために…」とあり、当該文字は **U+2131 SCRIPT CAPITAL F（ℱ）** であることをコードポイントで確認した（ファイル全体で U+2131 の出現はこの1箇所のみ。平文の `F_{1–2}` ではない）。
- 印刷側: 書籍 p.611（PDF625）、問題10.44 の第3行 "be in order to introduce less than 10% error in ℱ_{1–2} if the small…" に所在する。200dpi 画像およびその拡大切り出しでも、当該字形は筆記体（script）の F であり、直上の問題10.43 の平文イタリック "F_{1–2}" とは字形が明確に異なることを対照確認した。
- 添字: 印刷は "1–2"（ハイフン様の短い横線）。データも `_{1–2}` で、他の形態係数表記と同一の規約（en ダッシュ）であり、不一致とはしない。
- 留意: 字形の最終判定はコーディネーターの 600dpi 検証に委ねる事項であり、本ワーカーの判定は「200dpi＋拡大で筆記体と判読でき、データの U+2131 と矛盾しない」までとする（要600dpi検証：最終字形同定のみ）。
