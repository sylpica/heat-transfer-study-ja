## 棄却観察（候補にしない理由）
1. **式(11.9) x_i 側の等式チェーンの並び順**: 印刷は x_i = Mm_i/M_i = (m_i/M_i)/Σ_k(m_k/M_k) の順、アプリ blocks[11] は逆順。ただし両辺とも等式として成立し（M = 1/Σ(m_k/M_k) の代入で相互に一致）、両形式が過不足なく含まれ、アプリ explanation 自身が「原書の配置に基づく再構成を含みます」と開示している。数値・等式内容の不一致ではないため候補にしない。
2. **不等号の字形**: 印刷 式(11.3)(11.7) は斜め等号付き ⩽ 型、アプリは ≤（U+2264）。不等号の許容符号化とする裁定（≧ の裁定と同種）に従い登録しない。
3. **図11.2 の description が空文字**: 図11.3–11.5 も同じく空でありアプリ全体の慣行。印刷側に対応する説明文はなく、caption と alt は正確なため不一致ではない。
4. **段落のブロック統合**: §11.1 末尾は印刷4段落（p.623 に2段落、p.624 冒頭に2段落）が blocks[8] の1ブロックに、§11.2 本文も blocks[2]/[13] に統合されている。文の脱落・順序変更はなく、データ設計上の統合として候補にしない（c10-w06/w08 と同じ扱い）。
5. **組成表 O₂ モル分率セルの赤字「find this」**: アプリは色情報を符号化せず「これから求める」と文言で保持。内容は等価であり不一致ではない。
6. **molarity の訳語**: 印刷は molar concentration と molarity を区別するが、アプリは両方を「モル濃度」とし molarity は原語併記。日本語の標準訳語もモル濃度であり、意味の誤りではないため候補にしない。
