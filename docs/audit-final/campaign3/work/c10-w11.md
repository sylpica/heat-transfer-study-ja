## 棄却観察（候補にしないものと理由）

- **無番号の総和表示式**（p.639、`Σ_i[∂ρ_i/∂t + ∇·(ρ_i v⃗)] = Σ_i(−∇·j⃗_i + ṙ_i) = −∇·Σ_i j⃗_i + Σ_i ṙ_i = 0`）に独立の式ブロックがない: 内容は本文 blocks[2] に畳み込まれており（全種にわたる合計、式(11.1)/(11.16)/(11.21) の適用、正味の質量生成なし → 式(11.41)）、記号は式(11.40)/(11.41) と本文の Σṙ_i = 0 から回復可能。虚偽ではなく導出中間の畳み込みとして棄却（第2次 c10-w11 と同判断）。

- **lessons[68] equations[2] のラベル「一定ρ,Dの二成分モデル」と pitfalls の「可変D」**: 一般名としての D の略記であり、数式インスタンス（本文・式の 𝒟_AB ×4）は C10-22 の修正で全てスクリプトに復元済み。ラベル・注意文の略記は登録対象だった数式字形の欠陥とは別として棄却。
