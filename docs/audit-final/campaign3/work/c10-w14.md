## 棄却観察（候補にしない理由つき）
1. **(11.62)・(11.63)・Fig.11.14 の N が平文**: 「𝒩 は真のスクリプト体」の一般原則から疑ったが、600dpiクロップで本範囲の N はいずれも平文イタリック（𝒟 のスクリプト体と明確に異なる字形）と確定。データの平文 N が原典どおりであり、不一致ではない。
2. **(11.58) の番号**: 印刷表示には番号なし（600dpiで右余白まで空白を確認）。ただし直後の本文が "We can write eqn. (11.58) as" とこの表示を (11.58) と参照しており、データの number "11.58" は原典の参照体系と一致する。虚偽の番号ではないため候補にしない（書籍側記録として番号なし表示であることを残す）。
3. **(11.58a) の積↔除**: 印刷は2因子の積、データは除算形。代数的に等価で値・意味は同一。
4. **(11.64) の括弧再編成**: 印刷 ([…]/2(t−t_0))(ρ/M_2)(…) とデータ {[…]·ρ/[2(t−t_0)·M_2]}·… は代数的に等価。
5. **B_{m,2} 近似の記述**: 印刷（600dpi確定）は "B_{m,2} ≈ m_{2,L} − m_{2,0}" および "ln(1+B_{m,2}) ≈ B_{m,2} ≈ m_{2,L} − m_{2,0}" という符号付き連鎖。データは符号付き等式を再現せず「駆動力の大きさは濃度差そのものとほぼ等しく」「ln(1 + Bm,2) ≈ Bm,2」と大きさ・要点のみを述べるため、虚偽の記述にはなっていない。候補にしない（下記・書籍側記録参照）。
6. **Fig.11.12/11.13/11.14 の description 空欄**: 第11章全体に同状態の図が多数あり（11.2, 11.3–11.5, 11.6, 11.25–11.27 等）、原典側に description という対応物自体が存在しない。caption・alt は照合済みで一致しているため、原典との不一致としては候補にしない。
7. **(11.63) explanation の省略**: 印刷の下括弧は左右とも "per unit area" を含むが、データ explanation は左辺にのみ「単位面積あたり」を付け、右辺を「蒸気の質量流束」と略す。explanation はデータ側の要約補助であり式自体は正確なため、候補にせず観察として記録する。
