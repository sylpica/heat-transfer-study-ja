### C3-W17-01（P2）例題11.12 の NuD 相関インライン形の指数帰属誤り（PDF 678）

- 所在: `data/sections/11-7-ja.json` blocks[2]（例題11.12 の段落内インライン式）。
- アプリ現行形: `NūD = [0.560(2·GrD·Pr)^{1/4}/(1 + (0.492/Pr)^{9/16})]^{4/9}`
- 原典印刷形（PDF 678 を 200dpi で読解）: NūD = 0.560·√2·GrD^{1/4}·Pr^{1/4} / [1 + (0.492/Pr)^{9/16}]^{4/9} — すなわち (1) 係数は √2（2^{1/2}）で 1/4 乗は GrD と Pr にのみ帰属し、(2) 4/9 乗は分母の括弧にのみ帰属する。
- 誤りの内容: アプリ形は 1/4 乗が積 (2·GrD·Pr) 全体に帰属し（√2 が 2^{1/4} に化ける）、さらに 4/9 乗が分子を含む括弧全体に帰属している。指数帰属誤りのクラス（本アプリで既知の系統的クラス）。
- 数値検証（独立再計算、GrD = 2.756×10⁶、Pr = 0.708）: 印刷形では Nu = 22.71 となり、アプリ自身が同じ文で述べる結果 22.7 と一致する。アプリ形を文字どおり計算すると Nu ≒ 3.20 となり、同じ文の結果 22.7 と両立しない（約7分の1）。
- 影響と重大度: 番号付き formula block ではなく例題本文中のインライン形であり、後続の数値（NūD = 22.7、h̄ = 6.89、Q 値群）は全て印刷どおり正しいため数値の波及はない。しかし相関式そのものの記述が偽であり、学習者がこの形で計算すると誤る。導出・表示の誤りとして P2 とする（番号付き表示式自体の偽ではないため P1 とはしない。コーディネーターの再格付け余地を残す）。
- 付記: 物質移動側 Num,D についてはアプリは式形を記さず結果 21.5 のみで、これは印刷と一致する。同種の誤りは範囲内に他にない。

- マクロン: Nū・h̄・ḡ・ĥ のバーは範囲内の全出現箇所でアプリに保持されていることを確認した（特に式(11.72b) と p.664 の ḡm,H2O はバー付きが印刷どおり）。
