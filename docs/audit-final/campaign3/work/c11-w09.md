### L1 [P3] レッスン例題の問題文で Maxwell–Stefan 対係数に 𝒟_AB（Fick 記号）が混在

- 対象データ箇所: `data/original-deep-lessons.json` §11.11 レッスン（lessons[75]）`workedExample.problem`
- 現行文字列: 「𝒟_AB=1.0×10⁻⁵、D_AC=2.0×10⁻⁵、D_BC=1.5×10⁻⁵ m²/s。モル平均基準のJ_A,J_B,J_CをMaxwell–Stefan式と総和ゼロから求める。」（𝒟 は U+1D49F、AC/BC は平文 D = U+0044。同一リスト内で字形が不統一）
- 原典の形: §11.11 では2記号が厳密に区別される。𝒟_ij は多成分 Fick 行列の係数（式(11.120a/b) PDF 713・式(11.121) PDF 714、600dpi で真のスクリプト体を確認）、Đ_ij は Maxwell–Stefan 対係数（式(11.126) で Đ_12 ≡ (cR°T)/a と定義、式(11.127a/b)・(11.128)、PDF 715–716、600dpi で横棒付き Đ を確認）。Maxwell–Stefan 式で解く例題の入力対係数は Đ_AB / Đ_AC / Đ_BC と書くべきもの。
- 根拠: レッスン自身の `equations` と本文は対係数を Đ_ij で統一し、pitfalls でも「Maxwell–Stefanの対Dと実効Fick行列を同一視しない」と明記している。それにもかかわらず例題の第1係数だけが Fick 側の 𝒟 でラベルされている。steps の分母（40×10⁻⁵、40×2×10⁻⁵）はこの値を Đ として使っており、記号だけが誤っている。
- 影響の限定: 数値（1.0 / 2.0 / 1.5 ×10⁻⁵ m²/s）と計算結果には影響なし（下記クリーン項目のとおり全 steps を再計算し正しいことを確認）。表示式そのものが偽になるわけではないため P3（字形・記号）。
