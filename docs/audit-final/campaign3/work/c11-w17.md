### PDF 747（書籍 p.733）— 対応物なし

- ランニングヘッド: “Appendix A: Some thermophysical properties of selected materials / 733”。
- 散文のみ（表・図なし）。内容の要約:
  - Table A.1 の続き: 熱伝導率 *k* はほとんどの値が有効数字2桁に丸められていることとその理由（純アルミニウムと99%純アルミニウムの差、合金アルミニウムではさらに大きい差）。金属の特性・用途の追加情報は ASM *Metals Handbook* [A.13]。
  - *k* の温度依存性は Table A.1 のほとんどの金属で示されるが、比熱容量は 20°C でのみ示されること。極低温では熱容量がはるかに小さいこと（例: アルミニウム、鉄、モリブデン、チタンの *c*p は 200 K から 20 K へ温度が下がると2桁低下する）。300 K から 800 K では *c*p の変化は緩やか（数十%から2倍程度）で、さらに高温では鉄・チタンに固体–固体相転移に伴う *c*p の大きなピークがあること。
  - Table A.2 は非金属物質について Table A.1 と同じ物性を与えること。出典は [A.2] の Volumes 2 and 5 と [A.3]。*k* のばらつきは金属より大きく、砂では500倍、グラファイト類では50倍の例。充填・含水率への感度のため一部の *k* は有効数字1桁に制限したこと、湿った土と乾いた土のデータで含水率の影響を示すこと、建築材料データの一部は [A.14] から。
  - ポリマーのデータは主に製造業者データで Table A.1 の金属より信頼性が低いこと、値は主に室温のもの、加工時は数百度で *c*p が室温の2倍になりうること、改質形態や強化フィラー（例: ガラス繊維を重量で 10 to 40%）の影響。
  - ページ末尾: “Table A.3 gives *ρ*, *c*p, *k*, *α*, *ν*, Pr, and *β* for several liquids.” と Table A.3 の説明が始まる。水のデータは [A.15] と [A.16]（2007年までの IAPWS 勧告と一致）、アンモニアは [A.4, A.5, A.17]、二酸化炭素は [A.6–A.8]、メタノールは次ページへ続く。
- 対応物なし（同上）。
