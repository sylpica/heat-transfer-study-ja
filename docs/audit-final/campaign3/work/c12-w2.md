## 4. アプリ側に対応物がないことの再確認（第2次結論の再検証）

実施した軽量確認（2026-11-10、本ワーカー）:

1. `grep -ri "appendix" data/content-manifest.json` → **ヒットなし**（終了コード1）。manifest の `files` は `./data/sections/*-ja.json` の76ファイルのみを列挙し、付録・物性表ファイルは含まれない（manifest 全文80行を確認）。
2. `data/` 配下のファイル名一覧: 物性表データを名乗るファイルは**存在しない**。存在するのは本文 sections（76件）、chapter-problems、questions 系、glossary、original-notes 等のみ。
3. 唯一の付録関連ディレクトリ `data/appendix-references/` には `appendix-a.json` / `appendix-b.json` があるが、両者ともトップレベルキーは `references` のみで **`tables` キーは存在しない**:
   - `appendix-a.json`: Appendix A の**参考文献41件**（A.1〜A.41 の文献エントリ）の日本語訳。対象範囲は自ら `bookPages: "734–738"`, `pdfPages: "748–752"` と宣言しており、本パケットの表ページ（書籍739以降）を含まない。物性値セルは一切含まれない。
   - `appendix-b.json`: Appendix B の参考文献1件のみ。
   - 注: ここの文献番号「A.1」は**文献番号**であり、物性表の「Table A.1」とは別物。
4. 補助確認: スポット値（例: Duralumin、19,320 等）で `data/sections/*.json`・トップレベルJSONを grep → 物性表としてのヒットなし（`questions.json` の1件は解説文中の数値断片「1.2707…」の偶然一致であり表データではない）。表タイトル文字列 "Properties of metallic (solids)" の表データとしての収録もなし。

**結論: 第2次の結論どおり、付録A 物性表 A.1・A.2（および A.3 以降）に対応するアプリデータは存在しないことを再確認した。** したがって本パケットでは照合（セル単位の突合）は行っておらず、行ってもいないと明記する。実施したのは原典側の存在確認・同定と上記スポット転記のみである。
