## 共通の列見出しと単位（Table A.6 全ブロック共通）

| 列 | 見出し |
|---|---|
| 1 | T (K) |
| 2 | ρ (kg/m³) |
| 3 | c_p (J/kg·K) |
| 4 | μ (kg/m·s) |
| 5 | ν (m²/s) |
| 6 | k (W/m·K) |
| 7 | α (m²/s) |
| 8 | Pr（無次元） |

表記上の注意（転記の前提）:

- μ・ν・α 列は、各物質ブロックの**先頭行だけ**に `×10⁻⁵`（Helium の ν・α は `×10⁻⁴`）が明記され、2行目以降は倍率が省略されて数値のみが印字されている。以下のスポット転記では、2行目以降について倍率を括弧で補った。
- Helium ブロックは ν・α の倍率が他の気体と異なる（先頭行: ν = 0.0624×10⁻⁴、α = 0.0940×10⁻⁴）。μ は他と同様 ×10⁻⁵ 系。
