## 2. 用語集スポット確認用転記（指定6記号）

転記は原文の英語のまま、句読点・単位表記を含め正確に写した。数式部分は LaTeX 記法で表す。

### α — 範囲内にある（PDF 784 / 書籍 p.770、右段 “Greek symbols” 冒頭）

$\alpha$ には連続する2項がある。両方を転記する。

1. 単独の $\alpha$:

> α — thermal diffusivity, $k/\rho c_p$ (m²/s), or helix angle (rad.)

2. 直後の項 $\alpha, \alpha_g$:

> α, α_g — absorptance (–); gaseous absorptance (–)

※ 書体注記: 第1項の $\alpha$ と第2項の $\alpha, \alpha_g$ は原典でも同じギリシャ文字 $\alpha$ で、意味は文脈依存として併記されている転記上の事実のみ記す（判定はしない）。

### $D_h$ — 範囲内にある（PDF 781 / 書籍 p.767、右段）

> $D_h$ — hydraulic diameter, $4A_c/P$ (m)

### $k_{\mathrm{B}}$ — 範囲内にある（PDF 782 / 書籍 p.768、右段、$k$ の直後）

> $k_{\mathrm{B}}$ — Boltzmann's constant, $1.38065 \times 10^{-23}$ J/K

（参考として直前の項: $k$ — thermal conductivity (W/m·K)）

### $\eta_f$ — 範囲内になし

- 根拠: ギリシャ文字表は PDF 784（p.770）右段で始まり、同ページでは $\alpha$ から $\varepsilon_A, \varepsilon_{AB}$ までで終わる。$\eta$ の項（$\eta_f$ を含む）はアルファベット順で $\varepsilon$ の後になるため、本範囲（781–784）には現れない。ローマ字側にも $\eta_f$ に相当する項はない（$f$, $f_o$, $f_v$ の項はあるが別記号）。

### Bi — 範囲内になし

- 根拠: ローマ字 B の項は PDF 781（p.767）左段の $B$（radiosity (W/m²) or the function defined in Fig. 8.14）および $B_{m,i}$（mass transfer driving force …）のみで、Bi（Biot 数）の項はない。本範囲内の他ページにも Bi の項は現れない。

- 根拠: ローマ字 N の項は PDF 783（p.769）左段の $N$ / $\vec{N}$ / $N_A$ / $\mathcal{N}, \mathcal{N}_i$ / $\vec{n}$ / $n$ のみで、Nu の項はない。本範囲内の他ページにも $Nu$, $Nu_x$, $\overline{Nu}_L$ の項は現れない。
