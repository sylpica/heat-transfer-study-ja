4. **図10.7 の alt**: 第3次台帳は「上面の注記を alt へ」と記すが現行 alt は一般形。ただし上面（面 (4) の右辺とそれに続く上辺）は説明文で特定されており実質は保持されている。台帳の欄名との齟齬のみで回帰ではない。
