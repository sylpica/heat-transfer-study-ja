## 所見

### C5-C02-01ラプラシアン導出の途中式が原典表記と相違（原典誤植の無言訂正＋因子順序・括弧）
- 場所: `data/sections/2-1-ja.json` blocks[51]（式番号なし、式(2.11)直後の導出式）
- 原典: PDF 70（書籍 p.56）、600dpi確認（W1 が拡大画像でグリフ判定）
- 原典の実測: `∇·k∇T ≃ k∇·∇T = k( ı⃗ ∂/∂x + ȷ⃗ ∂/∂y + k⃗ ∂/∂x)·( (∂T/∂x)ı⃗ + (∂T/∂y)ȷ⃗ + (∂T/∂z)k⃗)`
- 第1因子の第3項の分母は、600dpi拡大で第1項の `x` と同一グリフであり、第2因子第3項の `z` とは形状が異なることを確認した。すなわち原典は `∂/∂z` とすべき箇所を `∂/∂x` と印刷している（原典側の誤植）。
- 原典は `∇·k∇T`（括弧なし）であり、第2因子は微分が単位ベクトルに先行する順序。
- データ側の現状: `∇·(k∇T) ≃ k∇·∇T = k(ı⃗ ∂/∂x + ȷ⃗ ∂/∂y + k⃗ ∂/∂z)·(ı⃗ ∂T/∂x + ȷ⃗ ∂T/∂y + k⃗ ∂T/∂z)`
- 第3項は `∂/∂z` に訂正されており数学的には正しいが、原典とは一致せず、訂正した旨の注記もない。第2因子の因子順序も原典と逆（意味は不変）。`∇·(k∇T)` の括弧付与も原典にない（意味は不変）。
- 判定理由: 内容の誤りではないため P3。原典誤植の扱い（忠実再現＋誤植注記／訂正維持＋注記追加）は統合側の方針判断事項として記録する。

### C5-C02-02図2.20 alt で面積ラベル A_p / A_s の帰属取り違え
- 場所: `data/sections/2-4-ja.json` blocks[24]（図2.20）の alt
- 原典: PDF 95（書籍 p.81）、600dpi確認（W2）
- 原典の実測: 左図（Configuration）で A_p は松材（Pine）帯の幅を示す寸法矢印（図の左下に注記）、A_s はおがくず（Sawdust）帯の幅を示す寸法矢印（図の右下に注記）。壁の左面・右面はいずれも全面積 A で、両面とも h̄ が付く。右図（回路）では R_t = L/(k_p A_p)（上枝）と R_t = L/(k_s A_s)（下枝）の並列。
- データ側の現状: alt が「左側が (T_∞ℓ)・h̄・面積 A_p、右側が (T_∞r)・h̄・面積 A_s とラベルされる」と述べ、A_p を左面、A_s を右面の面積であるかのように帰属している。実際は A_p＝松材部分の面積、A_s＝おがくず部分の面積であり、左右面への帰属は誤り。
- 判定理由: 本文・式（例題2.11解答の Q・U 式、k_p A_p / k_s A_s の帰属）自体は原典どおり正しく、誤りは alt 限定のため P3。
