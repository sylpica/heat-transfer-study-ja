### C6-C05-02（P3）式(6.85b) の ≡ ρ·εm の帰属範囲が原典の下括弧と異なる
- 場所: `data/sections/6-7-ja.json` の式(6.85a–6.85c)ブロックの expression と explanation。
- 内容: 原典（PDF 332）の下括弧「≡ ρ·εm」は丸括弧の因子部分「(some other factor, which reflects turbulent mixing)」のみに掛かり、後続の ∂ū/∂y は括弧の外にある（コーディネーターが 600dpi で括弧の左右両端の位置を実測して確定: 左端は開き括弧の真下、右端は閉じ括弧の真下）。アプリの expression は角括弧の第2項全体 `[（…因子）·∂ū/∂y]` の直後に「（この第2項 ≡ ρ·εm）」と置き、explanation も「第2項が…因子で、ρ·εmと定義されます」と述べており、第2項全体（∂ū/∂y を含む）が ρ·εm に等しいと読める。原典の定義は因子そのものが ρ·εm で、第2項は ρ·εm·(∂ū/∂y) である。なお §6.8 導入部の同型式ではアプリ側が正しく括弧内に ≡ ρcp·εh を置いている。式(6.85c) 自体と数値・条件は正しく、意味は復元可能なため P3。

### C6-C05-03（P3）用語集「遷移レイノルズ数」の補正定数 C≈871 に系統の断りがない
- 場所: `data/glossary.json` 用語「遷移レイノルズ数」（id: transition-reynolds-number）の detail。
- 内容: detail は「補正定数C=0.037Re_c^(0.8)−0.664Re_c^(1/2)（Re_c=5×10⁵で約871）が現れる」と提示する。数値自体は検算一致する（0.037×(5×10⁵)^0.8 − 0.664×√(5×10⁵) = 871.32）。しかしこの形は Pr^(1/3) を両区間に共通に使う他教科書系の形であり、原典 §6.9 の式(6.120)（PDF 348）は乱流項が Pr^0.6・層流項が Pr^(1/3) で単一の C に括れない形をしており、レッスン6.9 は Pr 依存の C′ として正しく提示し「Pr^(1/3)を一律に使う形は他教科書で見られる別系統の式であり、原書の2式とは一致しない」と明記している。用語集側にこの断りがないため、レッスンと矛盾して読める。数値誤りではなく提示上の欠落として P3。
