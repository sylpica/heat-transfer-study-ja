## 所見

### C6-C09-01（P2）用語集「平均ビーム長」の定義式が原典と異なる

- 場所: data/glossary.json の id `mean-beam-length`（用語「平均ビーム長」）の detail および formula フィールド。
- 現行データ: detail は「幾何学的平均ビーム長は L_0 = 3.6·V/A（V は気体体積、A は周囲面積）で与えられ」と定義し、formula は「L_0 = 3.6 V/A（原典 §10.5、表10.4）」と原典帰属まで付けている。
- 原典根拠: 式(10.58) の定義は L0 ≡ 4V/A（節本文 data/sections/10-5-ja.json blocks[25] も「L0 ≡ 4×（気体の体積）/（照射される境界の面積）」で正しい）。原典 PDF 603 の本文は「より強く吸収する気体では、式(10.58) の定数 4 を 3.6 で置き換えることで精度が上がる（平均ビーム長が10%下がる）」と明記しており、3.6 は強吸収の場合の置換値であって定義ではない。
- 内部不整合: 同エントリが引用する表10.4 の値（立方体 2ℓ/3・球 2D/3・無限円柱 D）はすべて 4V/A から導かれる値で、3.6V/A（立方体 0.6ℓ・球 0.6D・無限円柱 0.9D）とは両立しない。
- 検証経緯: W3 が検出し、コーディネーターが原典 PDF 603 の印刷文・用語集実データ・節本文の三方で親検証して確定した。誤りは用語集のみで、節本文・例題10.11（L0 = D の使用）は正しい。

### C6-C09-02（P3）例題10.9(a) の原典単位誤植が注記なく修正されている

- 場所: data/sections/10-4-ja.json blocks[40]（例題10.9 解答本文）。
- 現行データ: 「B3 = σT3⁴ = 221.5 W/m²」。
- 原典: PDF 590（書籍 p.576）は「221.5 W/m²K」と印刷する（W2 が 600dpi 拡大クロップで確定、コーディネーターもテキスト層で裏取り）。B（ラジオシティ）の単位として W/m² が物理的に正しく、数値 221.5 = σ·250⁴ も正しい。すなわち書籍側の単位誤植をデータ側が正しい形に直しているが、指示書の原則（書籍側の印刷不整合は保存し、逸脱する場合は注記する。§2.1 の誤植処理が前例）に照らすと、注記なく原典印刷形から逸脱している点が扱いの不統一として残る。値そのものの誤りではないため P3。
