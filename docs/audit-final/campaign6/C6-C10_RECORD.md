### C6-C10-02（P3）式(11.59) の駆動力の希薄極限に書籍側の符号不整合があり、訳注の開示がない
- 場所: data/sections/11-5-ja.json、式(11.59) の後の希薄極限の説明。
- 原典根拠: PDF 666（書籍 p.652）。原典は式(11.59) で B_m,2 = (m_2,0 − m_2,L)/(1 − m_2,0) と定義しながら、同ページ下段で「1 − m_2,0 ≈ 1 so B_m,2 ≈ m_2,L − m_2,0」「ln(1 + B_m,2) ≈ B_m,2 ≈ m_2,L − m_2,0」と定義と逆符号の近似を印刷している（200dpi ページ画像とテキスト層の双方で確認。符号の意味内容の不整合であり字形争点ではない）。
- 日本語側の状態: 誤りは再現されていない。日本語は「駆動力の大きさ」と絶対値で述べて符号問題を回避し、式(11.52) への帰着も定義式の符号で正しく成立する。事実誤りではないが、指示書の「注記のない新たな書籍側不整合は所見化する」に該当する。式(8.41)・Ja 例の先例どおり訳注で開示する修正が整合的である。

### C6-C10-03（P3）lessons[68] の再検算メモが原典値と異なる値を「原典値と一致」と記す
- 場所: data/original-deep-lessons.json lessons[68]（§11.4）の例題11.5 解説ブロック末尾。
- 原典根拠: 例題11.5（PDF 659、書籍 p.645）は p_CO2 = (1.63×10⁸)(0.00287) = **468 kPa** と印刷し、節ファイル 11-4-ja の値も 468 kPa で一致する。レッスン本文の計算も 468 kPa と正しいが、末尾の再検算メモだけが「p_CO2 ≈ **467 kPa** と原典値と一致することを確認した」と記す。(1.63×10⁸)(0.00287) = 467.8 であり 468 に丸めるのが正しく、未丸めの x_CO2 = 0.0028666 を使うと 467.2 となる丸め水準のずれ。結論への影響はなく P3。

### C6-C10-04（P3）例11.11 の拡散係数の単位: 原書の印刷誤植を注記なく訂正している
- 場所: data/sections/11-6-ja.json 例11.11 本文「𝒟_nap,air = 0.86×10⁻⁵ m²/s」。
- 原典根拠: PDF 674（書籍 p.660）は「𝒟_nap,air = 0.86×10⁻⁵ **m/s**」と印刷されている（600dpi クロップでコーディネーターが親確認。証跡画像は本クローンの c6img/w4-600-p674-Dunit2-674.png）。拡散係数の単位として m/s は次元的に誤りで、原書側の印刷誤植である（直後の Sc = 1.867×10⁻⁵/0.86×10⁻⁵ = 2.17 の計算も m²/s でなければ成立しない）。
- 日本語側の状態: m²/s は物理的に正しく、値 0.86×10⁻⁵ と下流の数値（Sc = 2.17、Nū_m,L = 99.5 等）は全て原典と一致する。ただし確定方針「書籍側の印刷不整合は保存＋訳注で開示」から見ると注記なき訂正であり、第5次 C5-C02-01（§2.1 誤植）と同型。値を正しい m²/s のまま維持し、原典が m/s と印刷する旨の注記を追加する扱いが、問題5.28 の単位誤植に対する sourceNote の先例と整合する。
