### 「熱伝達率」の記号結び付き用法（W1・W2 の候補2件を統合裁定）
W1（§2.3 の blocks[61]・[76]・[77]・[79]・[83]・[90]・[100]）と W2（§2.4 の h̄_f、問題2.5・2.25・2.37・2.41・2.45・2.46(b)）が、用語境界に反する残存として候補を挙げた。コーディネーターが一次記録（第5次ラインB台帳の判定基準、ADJ-C5-3、R11-2 記録）と原典に当たって精査し、**いずれも所見としない**と裁定する。理由は箇所ごとに次のとおり。
- §2.3 の放射熱伝達率 h_rad（blocks[76]・[77]・[79]・[83]・[90]）と有効熱伝達率 h_eff（blocks[100]）: 固有記号を持つ命名量であり、第5次台帳の判定基準（複合語と固有記号を持つ命名量は置換対象外）で保持が裁定済み。R11-2 は節ファイル全件を文脈精査し「§2.3 の11件は h_rad・h_eff の命名量（第5次台帳で保持裁定済み）」「節ファイル側に未裁定の残存なし」と確定している。W1 の「R11-2 の対象はレッスンのみで節本文は未裁定」という前提は R11-2 記録の記載（節ファイル76件・13件を全件精査）と異なり、採用しない。
- §2.3 blocks[61]「h̄ = 20 W/m²·K の熱伝達率が」: 例題2.6 の導入文。コーディネーターが PDF 83 の原典英文を直接確認したところ "a heat transfer coefficient of h̄ = 20 W/m²·K" と叙述文中で一般名詞として使われており、データはその忠実な訳である。呼称の付与や定義文ではなく、境界で保持される一般言及にあたる。
- §2.4 blocks[36]「もう1つの熱伝達率 h̄_f」・§2.5 blocks[4]「熱伝達率そのものが」: ADJ-C5-3 で確定事項（R11-2 記録も同旨を明記）。再指摘しない。
- 章末問題の各箇所（問題2.5 の h̄_i／h̄_o、2.25 の h̄_o、2.37 の h̄ の式、2.41 の h̄ = 6、2.45 の h̄ = 2ΔT^(1/4)、2.46(b) の h̄_o／h̄_i と「総括熱伝達率 U」）: 問題文は原典の転記レイヤーであり、「熱伝達率」はこのファイルの確立した訳語として全14件一貫している（「熱伝達係数」は0件）。統一の対象となったのは一貫して補足レイヤー（レッスン）のクラスタのみで（第5次の全120ファイル走査でも変更は lessons[13] の1件のみ）、問題文の用法は第1〜6次と R11-2 を通じて一度も欠陥とされていない。指示書の境界が所見対象とするのは「新規の」記号結び付き用法であり、長期に確立した転記レイヤーの訳語はこれに当たらない。なお 2.46(b) の「総括熱伝達率 U」が §2.4 の「総括熱伝達係数 U」とレイヤー間で割れている点は W2 の指摘どおりだが、同一の理由（転記レイヤーの確立訳語）により所見化しない。
