### C7-C05-01（P3）裸の「熱伝達率」による h 呼称がノート・用語集・節別問題に残存
- 場所と現行値（コーディネーターがデータで読み戻して確認）:
  - `data/original-notes.json` §6.1 の explanation および `data/original-notes/ch6.json` §6.1 の explanation（同一文）:「熱伝達率hは材料固有の定数ではなく、流れの速さ、物性、形状、境界条件で変化する。」
  - 派生の節別問題 `data/original-section-questions.json` の supp-section-6-1（explanation と distractor の説明文に同文が含まれる）。
  - `data/glossary.json` の `stanton-number` detail:「hは熱伝達率、Uは代表流速…」。
  - 同 `boundary-layer-shape-factor` detail:「熱伝達率hやエンタルピーHと記号が重なるときは区別する」、confusions:「形状係数Hは熱伝達率h[W/(m²·K)]と記号が似ても全く別の量。」
- 根拠: 第6次裁定の用語境界では、記号に結び付く用法（h の呼称・定義文）は「熱伝達係数」への統一が確定している。R11-2 の全数走査の対象はレッスンと節ファイルであり、ノート・用語集・節別問題は走査範囲外だった。上記はいずれも修飾語のない裸の「熱伝達率」が h を直接呼称・定義する形で、レッスン側で修正対象となった形と同形である（第6次 C6-C03-02 と同クラスの扱い）。
- 対象外として数えなかったもの: 「対流熱伝達率h」（複合語、R11-2 で対象外と確定）、ノート §6.5 の「局所熱伝達率h_x」（修飾語付き呼称）、用語集の「位置別熱伝達率」「平均熱伝達率」（複合語）、記号を伴わない一般言及、確立した用語名への参照。
- 影響: 意味・数値の誤りではなく、用語統一の定着範囲が周辺データに及んでいない提示上の一貫性の問題。

### C7-C05-02（P3）用語集の粘性底層・緩衝層の境界値が原典 §6.7 と異なる（y⁺=5 vs 7）
- 場所と現行値: `data/glossary.json` の `viscous-sublayer`（formula「U⁺≈y⁺（滑らかな壁、y⁺≲5）」、detail「y⁺≲5を粘性底層の目安」）と `buffer-layer`（formula「5≲y⁺≲30（代表的な緩衝層範囲）」、detail 同旨）。

- 差: 境界が用語集では 5、原典・節本文では 7。対数域の下限（30）は両者一致。用語集の値は外部資料由来の汎用慣例で「典型的／代表的」と断られており、5–30 の区分自体は標準的だが、原典および同じアプリの節本文との境界値の相違への言及がない。併読時に食い違うため提示上の不整合として記録する。
