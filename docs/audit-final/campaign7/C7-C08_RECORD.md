## 所見

### C7-C08-01（P2）章別ノート ch9.json §9.4 の relation が原典の否定する単純加算形のまま残存

- 場所: `data/original-notes/ch9.json` の §9.4 `relation`
- 現行文: 「総熱流束の近似としてq″_total≈q″_film+q″_radiationと分ける場合がある。ただし二つの寄与の重ね合わせと温度依存性はモデル条件を確認する。」
- 原典根拠（PDF 515、コーディネーターが本文を直接確認）: 原典は単純加算について "Unfortunately, such addition would not be correct" と明示的に否定し（放射が蒸気膜を厚くして h_boiling を下げるため）、Bromley の近似として式 (9.31) h_total = h_boiling + (3/4)h_rad（h_rad < h_boiling）を与える。
- 状況: アプリが実際に読む集約版 `data/original-notes.json` の同フィールドは是正済み（「熱流束を単純にq″_film+q″_radiationと足す形はこの重み付けと一致しない」）で、レッスン §9.4・設問 9-4 の解説も正しい。誤りは章別ファイル内に限定されるが、章別ファイルは再生成の源泉であり、誤った物理（原典が否定する加算形を利用可能な近似として提示）がデータ内に残存する実質的誤りとして P2 とする。
- 修正方針（統合側）: ch9.json §9.4 relation を集約版の是正済み文言に同期する。

### C7-C08-02（P3）章別ノート ch9.json §9.8 の relation の括弧書きが実乾き度の定義条件を誤らせる

- 場所: `data/original-notes/ch9.json` の §9.8 `relation`
- 現行文: 「質量乾き度x=ṁ_v/(ṁ_v+ṁ_l)（平衡で気相と液相を区別できる場合）」— 熱力学的平衡の下でのみ乾き度が定義できると読める。
- 是正済みの集約版: 「（気相・液相それぞれの質量流量が判別できれば定義でき、熱力学的平衡は不要）」。実乾き度は質量流量が判別できれば平衡を要しないため、章別ファイル側の文言が誤り。同根の未同期であり P3。
- 修正方針（統合側）: ch9.json §9.8 relation を集約版の是正済み文言に同期する。
- なお W4 が両ファイルの全フィールド比較を行い、ch9.json と集約版の差分は上記2フィールドのみであることを確認済み。
