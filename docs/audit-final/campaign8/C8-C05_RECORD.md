### C05-F02（P3）例題6.6 と式(6.72) の原典側係数不整合が学習者向けに未開示

- 原典の事実（統合担当が PDF 326 を 600dpi で直接読解して確定）: 式(6.72) は Nū_L = 0.688·√Re_L·Pr^(1/3)。一方、例題6.6 の解は「式(6.72)から」として ΔT̄ = (0.4587/0.6795)·ΔTmax = 60.5°C、T̄w = 75.5°C と印字する。0.6795 は式(6.72) の 0.688 と整合しない原典側の印刷不整合。
- データの状態: data/sections/6-5-ja.json は両値を忠実に転記している（式(6.72) ブロックに 0.688 が2箇所、例題6.6 に 0.6795 が1箇所あることを統合担当が確認）。転記自体に誤りはない。
- 独立再計算（統合担当）: ΔTmax = [420(0.6)/0.0281] / [0.4587·√(0.6(1.8)/(1.797×10⁻⁵))·(0.705)^(1/3)] = 89.60°C（原典 89.6 と一致）。0.4587/0.6795 = 0.67506 → ΔT̄ = 60.48 ≈ 60.5°C（原典の計算は自らの印字値とは整合）。正しい係数では 0.4587/0.688 = 0.66672 → ΔT̄ = 59.74 ≈ 59.7°C、T̄w ≈ 74.7°C。一様熱流束では ΔT ∝ x^(1/2) のため ΔT̄/ΔTmax = 2/3 であるべきこと、0.4587×3/2 = 0.68805 ≈ 0.688 であることとも整合する。
- 開示の状態: §6.5 の節本文内に訳注・sourceNote はない。唯一の記録は data/book.json の chapters[5].sections[4].translationProgress.reviewNotes[1]（kind: source_arithmetic_inconsistency）にある英語の内部レビューノートで、「independent subject-matter review is required」と未決事項として記されたもの。app.js は reviewNotes を一切参照せず（描画されない）、公開ビルドでも削除対象フィールドに含まれないため配信ファイルには残るが、学習者が例題6.6 の傍らで目にする開示ではない。したがって指示書の除外対象（訳注・sourceNote により開示済みのもの）には当たらない。
- 重大度の裁定: W2 は P2 として提出したが、転記が原典に忠実で修正方法が開示注記の追加である本種（原典側の内部不整合）は、式(11.59)（第6次）および例題11.17 の Ωμ 不整合（第7次、ワーカー P2 → コーディネーターが P3 に裁定）の先例により P3 とする。
- 修正案: 例題6.6 の解の段落に開示注記を追加する（原典の 0.6795 は式(6.72) の 0.688 と整合せず、0.688 で計算すると ΔT̄ ≈ 59.7°C・T̄w ≈ 74.7°C となる旨。印字値は保持）。
