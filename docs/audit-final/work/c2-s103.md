## 5. 原典側の印刷不整合（アプリ所見ではない）

### O1. 図10.9 の表題が図10.10 と同一文（原典の表題重複誤り）

- 所在: 図10.9（書籍 p.563 / PDF p.577）、アプリ block 21。
- 原典の印刷形: `Figure 10.9: The view factor for three very small surfaces "looking at" three large surfaces (A1 ≪ A2).` — 図10.10（書籍 p.564）の表題と一字一句同一。
- しかし図10.9 のパネル自体には小表題 `Facing rectangles, case 1., Table 10.3` / `Intersecting rectangles, case 2., Table 10.3` / `Facing concentric discs, case 3., Table 10.3` が付き、本文（書籍 p.560）も「Figure 10.9 … includes graphs for configurations 1, 2, and 3 from Table 10.3」と明記する。「非常に小さい表面」の説明が合うのは図10.10 のパネル（微小面 1 対 大面 2）のみ。よって図10.9 の印刷表題は原典側の重複誤り。
- アプリの現行形: block 21 表題「図10.9　表10.3の配置1、2、3に対する形態係数のグラフ」— 本文・パネル小表題に沿った正しい内容。字面転記ではないが、原典の誤りの側に合わせるべきではないため所見としない。なお block 22（図10.10）のアプリ表題は原典印刷と一致する。

### O2. 表10.3 配置1 ln 項の指数 1/2 が括弧の外に印刷（原典の組版不整合）

- 所在: 表10.3 配置1（書籍 p.562 / PDF p.576）、アプリ block 20。
- 原典の印刷形（400dpi 拡大で確定）: `ln[ ((1 + X²)(1 + Y²)/(1 + X² + Y²)) ]^{1/2}` と、指数 1/2 は角括弧の外側に置かれる。字面どおり「ln 全体の平方根」と読むと:
  - X = Y = 1（a = b = c の対向正方形）で F = **0.449710**。
  - しかし式 (10.17a) の Monte Carlo 積分（N = 4,000,000）は **0.19981**、図10.9 配置1 のパネル（a/c = 1, b/c = 1 で F ≈ 0.20）とも矛盾する。
- アプリの現行形: `ln[((1 + X²)(1 + Y²)/(1 + X² + Y²))^{1/2}]`（= (1/2)·ln(分数) の標準形）。同幾何で **0.199825** を与え、独立積分 0.19981 と一致する。
- 判定: 原典の括弧配置（組版）の不整合であり、アプリの現行形が科学的に正しい。所見としないが、字面との相違点としてここに記録する。
