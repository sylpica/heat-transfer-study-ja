## 5. 所見

### F-1 [P2] 例題10.9・式(10.38) の数値代入表記が原典の並列合成を再現していない（block 36）

- 所在: block 36（例題10.9 の解、部分 (b)）、式番号 (10.38)。原典 PDF p.590（書籍 p.576）。
- 原典の印刷形: 分母 = 0.7/0.3 + **1 / ( 1/(1/0.8 + 1/0.8) + 0.2 )** + 0.5/0.5。
  中央項は、直列路のコンダクタンス 1/(1/0.8 + 1/0.8) = 0.4 と直接路のコンダクタンス 0.2（= A1F1–2）の和を逆数にした並列合成抵抗で、値は 1/0.6 = 1.6667。分母合計は正確に 5.0、Q = 992.25/5.0 = 198.45 → 198 W/m。
- アプリの現行形: `Qnet1–2 = (5.67×10⁻⁸)(400⁴ − 300⁴)/[0.7/0.3 + 1/(1/0.8 + 1/0.8) + 1/0.2 と 0.5/0.5 の合成] = 198 W/m（式(10.38)）`
  中央の並列合成が「1/(1/0.8 + 1/0.8)」と「1/0.2」という2つの加算項に分解され、「と … の合成」という曖昧な文言で括られている。書かれたまま文字どおり加算すると分母 = 0.7/0.3 + 0.4 + 5 + 1 = 8.7333 となり、Q = **113.6 W/m** になって表示結果 198 W/m と一致しない。特に原典でコンダクタンス 0.2 である項が 1/0.2（抵抗 5）に化けている点が誤りの核心。
- 影響: 局所的。支配式である式(10.35) 本体（block 34）は正しく評価可能な形で保持され、例題の最終結果 198 W/m も正しい。誤りは例題10.9 (b) の1箇所の代入表記のみ。ただし学習者がこの行を検算すると結果が再現できないため、P3 ではなく P2 とする。修正するなら原典どおり `1/(1/(1/0.8 + 1/0.8) + 0.2)` の入れ子形に戻すのが直接的。
