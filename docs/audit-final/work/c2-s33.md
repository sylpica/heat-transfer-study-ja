## 所見

### P3-1: 式(3.20) の「≡」が「=」になっている

- 所在: block 13、式(3.20)（並流の有効度）。
- 原典の印刷形: $\varepsilon \equiv \dfrac{1-\exp[-(1+C_{\min}/C_{\max})\mathrm{NTU}]}{1+C_{\min}/C_{\max}} = \mathrm{fn}\!\left(\dfrac{C_{\min}}{C_{\max}}, \mathrm{NTU\ only}\right)$（書籍 p.122、枠内）。左辺は定義記号 ≡。
- アプリの現行形: `ε = [1 − exp(−(1 + C_min/C_max)NTU)]/(1 + C_min/C_max) = fn(C_min/C_max, NTU) のみ`。式本体（分子・分母・指数の符号と括弧）は印刷形と完全一致だが、左辺の ≡ が = になっている。
- 影響: なし。(3.20) は定義ではなく式(3.9) からの導出結果であり、= でも意味・計算は変わらない。なお式(3.18) では原典の ≡（NTU ≡ UA/C_min）をアプリも ≡ で保持しており、本件は (3.20) のみの表記差。原典側も導出式に ≡ を使うのはやや特異な印刷である（「原典印刷側の注記」N3 参照）。

### P3-2: block 30 で原典の "effectively be infinite" の概念が落ちている

- 所在: block 30（単一流れの極限の説明、第2文相当）。
- 原典の印刷形: "Alternatively, it might effectively *be* infinite. That would be the case if one fluid were boiling or condensing and underwent phase change at a constant temperature, as in Fig. 3.9."（書籍 p.126）。相変化する流れの熱容量率が実質無限大 → 比 C_min/C_max → 0 という趣旨。
- アプリの現行形: 「あるいは、それが実質的に生じる場合もある。図3.9のように、一方の流体が一定温度で沸騰または凝縮して相変化する場合がそれである。」。"infinite"（無限大）に当たる表現がなく、「実質的に生じる」と圧縮されている。
- 影響: なし。相変化・一定温度・図3.9 への参照は保持され、物理的内容（この極限が相変化で実現すること）は伝わる。数値・式への影響はない翻訳圧縮。なお原典の当該文は主語の指示対象が曖昧な印刷でもある（注記 N4 参照）。

上記2件以外に、アプリが原典印刷と食い違う箇所はなかった。

### 重点確認 (a): item 1（直行流・両流体未混合、R>0.3, NTU>1）— Codex 第2回修正の維持

アプリ現行形を R=0.5, NTU=2 で独立評価:

```
ε = [1 + 0.44(1−0.5)] · {1 − [0.92 + (π·0.5^0.15·2)^1.25]^(−0.4)} = 0.727448
```

- 期待値 **ε ≈ 0.7274 と一致**。旧誤式の値 1.0568（ε>1 で物理的に不可能）は再現されず、**修正は維持されている**。
- 400dpi 画像でも、1.25 乗が (πR^0.15 NTU) 全体に掛かり、−0.4 乗が [0.92 + …] 全体に掛かる配置を直接確認した。

### 重点確認 (b): item 6（Nシェルパス）— Z 形の等価性

アプリの Z 形と原典の積形を R=0.5, ε_p=0.5, N=2 で独立評価:

```
Z = [(1 − 0.5·0.5)/(1 − 0.5)]^2 = (0.75/0.5)^2 = 2.25
ε(Z形)  = (Z − 1)/(Z − R) = 1.25/1.75 = 0.7142857143 = 5/7
ε(印刷の積形) = (Z − 1)·(Z − R)^(−1) = 0.7142857142（浮動小数点誤差のみ）
```

- 期待値 **ε = 5/7 ≈ 0.7143 と一致**。N 乗は比 (1−ε_pR)/(1−ε_p) 全体に掛かる形で正しく保持されており、**修正は維持されている**。アプリ item 6 の注意書き（「N乗はRだけでなく比の全体に掛かる」）もこの構造と整合。

## 原典印刷側の注記（アプリの欠陥ではない）

- **N1（例題3.6 の「1%」と図表読み取り）**: 印刷は2つの面積の差を「1%」とするが、厳密には (23.00−22.73)/22.73 = 1.19%。また NTU≃1.15 は図3.16 の読み取り値で、式(3.20) の厳密反転値は 1.1365（これを使うと A=22.73 m² となり LMTD 法と完全一致）。印刷自身が差異の理由を「図表の読み取りの不正確さ」と明記しており、アプリは印刷値（1.15、23.00 m²、22.73 m²、「1%異なる」）をそのまま保持しているため欠陥ではない。
- **N2（例題3.5 の丸め連鎖）**: 印刷の ε=0.596 は厳密値 0.596401 の丸めであり、Q・出口温度はすべて丸め後の ε から計算されている（厳密 ε を使うと Q=656,041 W になるが、印刷はその値を採用していない）。アプリは印刷の丸め連鎖を正確に保持しているため欠陥ではない。
- **N3（式(3.20) の ≡）**: 印刷は導出結果である (3.20) の左辺にも ≡ を使う（定義式 (3.18) と同じ記号）。P3-1 はこの印刷形との文字レベルの差として記録したもので、科学的内容の差ではない。
- **N4（書籍 p.126 の "be infinite"）**: "it might effectively be infinite" は主語の指示対象が曖昧な印刷（比そのものが無限大では C_min/C_max → 0 と矛盾するため、指すのは相変化側の熱容量率と解するのが自然）。P3-2 はこの曖昧な印刷文に対する翻訳圧縮として記録した。
- **N5（PDF p.141 の節見出し位置）**: 書籍 p.127 のページ見出しは既に「§3.4」だが、ページ冒頭の「バランスした向流熱交換器」「P-NTU法」は §3.3 の内容であり、§3.4 の見出しは同ページ中ほどから始まる。アプリが block 33–39 を §3.3 に帰属させているのは正しく、節範囲メタデータ（書籍 120–127／PDF 134–141）にも誤りはない。
