## 重点確認項目

### 1. 式(7.74)（block 27）— Codex 第2回修正済み形の「維持」を確認

原典画像（PDF p.410／書籍 p.396）:

$$Nu_D = \left(4.60 + 0.193\,Pe_D^{0.614}\right)\sqrt{C\,\frac{P-D}{P}\left(\frac{\sin\varphi + \sin^2\varphi}{1 + \sin^2\varphi}\right)}$$

アプリ現行形:

```
NuD = (4.60 + 0.193·PeD^(0.614))·√[C·((P − D)/P)·((sin φ + sin²φ)/(1 + sin²φ))]
```

- 判定: **維持されている**。平方根は $C$・$(P-D)/P$・$\sin$ 分数の全体に掛かり、定数項 4.60 を含む括弧の外側にある。括弧・指数 0.614 とも印刷形どおり。再修正提案なし。
- 付随説明（block 27 explanation）も原典の箇条書き（書籍 p.396）と一致: PeD＝管間の最も狭い開口部の平均流速に基づくペクレ数、C＝図7.18 の定数、P＝管配列のピッチ、D＝管径、**30° ≦ φ ≦ 90°**（φ は流れとロッド軸のなす角）、原子炉では燃料棒に平行な液体金属流が一般的、平行流資料 [7.46]、管束熱交換器・圧力損失の設計資料 [7.47]（書籍 p.397 冒頭まで確認）。

### 2. 式(7.65) と (7.66)/(7.68) の段差 — 決着済みにつき再提起しない。転記一致のみ確認

- (7.65) block 12: $Nu_D = 0.3 + \dfrac{0.62\,Re_D^{1/2}Pr^{1/3}}{[1+(0.4/Pr)^{2/3}]^{1/4}}\left[1+\left(\dfrac{Re_D}{282{,}000}\right)^{5/8}\right]^{4/5}$ — 印刷形（書籍 p.390）と一致。
