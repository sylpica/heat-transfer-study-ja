## 所見

### C2-9X-01 式(9.37) Bergles–Rohsenow 重ね合わせ式 — 二乗の適用範囲が原典と異なる

- 所在: `9-7-ja.json` **block 11**（formula, number 9.37）
- 原典印刷形（書籍 p.509＝PDF p.523、400 dpi 拡大で確認）:
`q = q_FC · √{ 1 + [ (q_B/q_FC)·(1 − q_i/q_B)]²}`
すなわち二乗は積全体 `[(q_B/q_FC)(1 − q_i/q_B)]` にかかる。展開すれば `(q_B/q_FC)²·(1 − q_i/q_B)²`。
- アプリ現行形:
`q = qFC·[1 + (qB/qFC)²·(1 − qi/qB)]^(1/2)`
`(1 − qi/qB)` に二乗がなく、原典と数学的に非等価。
- 影響: 科学的に誤った式が正しい相関式として表示される。数値例（q_FC=1 と置く）: q_B=2, q_i=0.5 では原典 1.803 に対しアプリ式 2.000（+10.9%）。q_B=3, q_i=1.5 では原典 1.803 に対し 2.345（+30.1%）。q_i=0 または q_i=q_B の極限でのみ一致し、核流動沸騰の熱流束予測が中間域で系統的に過大になる。
- 修正方向（本ラインでは実施しない）: `q = qFC·[1 + ((qB/qFC)·(1 − qi/qB))²]^(1/2)` の形にすること。

### 例題9.8 独立再計算（9-5 block 5）
原典（p.503）: qmin = 0.09(0.597)(2,257,000) · ⁴√[9.8(0.0589)(958)/(959)²] = 19.0 kW/m²、図9.2 の読み 20.0 kW/m²。
再計算:
- 前因子 0.09 × 0.597 × 2,257,000 = 121,268.61
- 根号内: 分子 9.8 × 0.0589 × 958 = 552.9768、分母 959² = 919,681、比 6.0127×10⁻⁴、4乗根 0.156591
- qmin = 121,268.61 × 0.156591 = **18,989.6 W/m² = 18.99 kW/m² → 19.0 kW/m²** でアプリ／原典の値と一致（図読み 20.0 との差は原典の述べるグラフ精度内）。アプリの代入数値（0.09, 0.597, 2,257,000, 9.8, 0.0589, 958, 959）も原典印刷どおり。
