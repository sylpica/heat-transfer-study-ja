確認した主な項目：
- 図1.9 キャプション（block 61）：原典 “The convective cooling of a heated body” ⇔ アプリ「加熱された物体の対流冷却」一致。図内ラベル T_∞／T_body は alt と一致。

- 式 (1.17)（block 69）：原典は枠囲み q = h̄(T_body − T_∞)。アプリ `q = h̄ (T_body − T_∞)` の h̄ は h＋U+0304（COMBINING MACRON）であることをコードポイント実測で確認。一致。
- 本文（block 71）：定数 h̄＝膜係数／熱伝達係数、バー＝表面全体の平均、バーなし h＝局所値、単位 W/m²K すなわち J/(s·m²·K) — 原典 “W/m²K or J/s·m²·K” と等価・一致。
- 換算表示 (1.18)（block 72）：原典は本ページ下部に因子連鎖
  1 = (0.0009478 Btu/J)·(K/1.8°F)·(3600 s/h)·((0.3048 m)²/ft²)
  を表示（この表示自体に式番号は付されていない）。アプリは結合比 `1 = 0.1761 (Btu/h·ft²·°F)/(W/m²K)`（番号 1.18）を与え、explanation に4因子すべてを保持。独立再計算：0.0009478/1.8×3600×0.3048² = 0.17611 ✓ ＝ 0.1761。結合比は連鎖と数学的に同一であり値も正しいため**非所見**（PDF 28 で他統括登録済みの換算表示所見とは別ページ・別項目であり、その再掲でもない。本件は ×/÷ の反転ではなく正値の結合形）。

### 候補 M1-W2-1（提案 P3）— 表1.1 見出し文での h̄ のバー脱落
- 箇所：`1-3-ja.json` block 85（表1.1 の見出し段落）
- 原典形：表の値列見出しは **h̄, W/m²K**（400dpi でバー明瞭）。表の値は平均熱伝達係数 h̄ の値。
- 現行形：「h の単位は W/m²K」（h はプレーン、U+0304 なし。コードポイント実測で確認）

- 提案重大度：P3（先例「上線の脱落＝P3」に従う）

### 候補 M1-W2-2（提案 P3）— 発展教材 §1.3：時定数 𝒯 が通常の T に置換
- 箇所：`original-deep-lessons.json` §1.3 レッスン「集中熱容量法と時定数」block 本文、および equations の「原典 (1.22) 集中熱容量解」「原典 (1.23) 時定数」
- 原典形：時定数は筆記体 **𝒯**（式 (1.22) (T−T_∞)/(T_i−T_∞) = e^(−t/𝒯)、式 (1.23) 𝒯 = mc(1/h̄A)）。節JSON側は 𝒯＝U+1D4AF で正しく保持（block 97・99・115 で実測）。
- 現行形：発展教材では時定数がすべて通常の T（U+0054）。同レッスン内に U+1D4AF は 0 件（実測）。特に (1.22) 式では分母の T（時定数）が分子の T（温度）と同一式内で衝突し、意味注記「T は時定数」で辛うじて判別できる状態。
- 影響：中〜小。発展教材内での記号の曖昧さ。数値・物理内容の誤りはない。
- 提案重大度：P3（グリフ置換の先例クラスに従う）
- 備考：原典の式 (1.22)・(1.23) 自体の印刷位置は PDF 36（書籍 p.22）で本担当ページ外。ただし発展教材の当該 block は式 (1.19)（本ページ PDF 35 所載）を起点に §1.3 レッスンとして転記対象に指定されていたため本メモに登録する。統括側で PDF 36 担当への付け替え可。

候補以外の注記：発展教材の (1.23) 併記形 ρcV/(h̄A) = mc/(h̄A) は m = ρV により原典形と等価＝非所見。同レッスンの「Bi < 0.1」表記と原典本文「Bi ≲ 0.1」（PDF 36–37 側）の差は本担当ページ外のため候補にしない。
