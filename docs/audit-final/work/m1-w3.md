## PDF 36（書籍 p.22）— 結果：候補あり（P3×4件：節JSON 3件＋深掘り1件）

対象範囲：式(1.20)(1.21)(1.22)(1.23)、時定数の説明段落、Bi導入段落・表示式、脚注6。式(1.19)自体は前ページ（PDF 35）。

### 確認した主な項目（一致）
- 式(1.20)（block 92）：原典 d(T−T∞)/dt = −(h̄A/ρcV)(T−T∞)。現行一致。h は h+U+0304 実測。
- 式(1.21)（block 95）：原典 ln(T−T∞) = −t/(ρcV/h̄A) + C（分母は括弧付き分数 ρcV/h̄A）。現行 `−t/(ρcV/h̄A)` は等価な線形表記で一致。h̄実測あり。
- 式(1.22)（block 97）：原典は枠囲み (T−T∞)/(Ti−T∞) = e^(−t/𝒯)。現行一致（𝒯 = U+1D4AF 実測）。
- 式(1.23)（block 99）：原典 𝒯 = mc(1/h̄A)。現行一致（𝒯・h̄とも実測あり）。
- Bi表示式（block 102）：原典 Bi ≡ h̄L/k_b ≪ 1 implies that T_b(x,t) ≃ T(t) ≃ T_surface（≃は400dpiで確認）。現行 `Bi ≡ h̄L/k_b ≪ 1 のとき、T_b(x, t) ≃ T(t) ≃ T_surface` 一致（h̄・≃ U+2243 実測）。
- 脚注6（block 93）：原典の T_ref→T_∞ 置換の説明と内容一致。
- 段落数値・定性文：1/e＝37%、m = ρV、§2.3参照（block 99 explanation側に保持）等、内容一致。

### 候補
1. **節JSON block 96（段落）・h̄バー脱落 — P3**
   - 原典形：本文 "The group ρcV/h̄A is the time constant"（h̄、400dpiでバー確認）。
   - 現行形：「グループ ρcV/hA は時定数 𝒯 である」— h は U+0068 単独で U+0304 なし（実測）。
   - 影響：時定数を定義する文での平均量バーの脱落。数値・式の意味は変わらない。先例（バー脱落＝P3）に従う。
2. **節JSON block 100（段落）・h̄バー脱落 — P3**
   - 原典形："a body with less surface area or lower h̄ will also take longer to cool"（h̄、400dpiでバー確認）。
   - 現行形：「表面積が小さい物体や、h が低い物体も」— h に U+0304 なし（実測）。
   - 影響：同上、軽微。
3. **節JSON block 101（段落）・h̄バー脱落（式形自体は等価変形） — P3**
   - 原典形："if L/(k_b/h̄) ≪ 1"（400dpi確認：k_b の下に h̄、バーあり）。
   - 現行形：「(hL/k_b) ≪ 1 であれば」— h に U+0304 なし（実測）。なお L/(k_b/h̄) = h̄L/k_b なので代数形の組み替え自体は数学的に等価（その点は非所見）。バーの有無のみが差異。
   - 影響：Bi の導入条件文でのバー脱落。軽微。
4. **深掘り §1.3「集中熱容量法と時定数」block本文＋equations (1.22)(1.23)・時定数グリフ 𝒯→T — P3**
   - 原典形：時定数は筆記体 𝒯（U+1D4AF）で温度 T と区別される（式(1.22) e^(−t/𝒯)、式(1.23) 𝒯 = mc(1/h̄A)）。節JSON側は 𝒯 で正しく保持。
   - 現行形（深掘り）：本文「解は … = e^(−t/T) となる（原典 (1.22)）」「ここで T = ρcV/(h̄A) = mc/(h̄A) を時定数という（原典 (1.23)）」、equations でも「(T − T_∞)/(T_i − T_∞) = e^(−t/T)」「T = ρcV/(h̄A) = mc/(h̄A)」と通常の T（U+0054）で実測。meaning欄で「T は時定数」と断ってはいる。
   - 影響：(1.22)では分子の温度 T と指数部の分母 T が同字形になり、原典引用式として紛らわしい。数値計算への影響なし。記号グリフの転記差異として P3。
   - 付記：深掘りの (1.23) に ρcV 形を併記する点は (1.21) の群 ρcV/h̄A と m=ρV から等価（非所見）。深掘りの (1.19) 形 −h̄A(T−T∞) = ρcV dT/dt は原典 d[ρcV(T−T_ref)]/dt と等価（非所見）。

### 非所見メモ
- block 100本文では原典の「量 1/h̄A は対流熱損失に対する抵抗と考えられる（§2.3参照）」の一文が本文に無く、block 99 の explanation に同内容が保持されている（情報の欠落ではなく配置の移動として非所見扱い）。

対象範囲：図1.11（図本体＋キャプション）、大きなBiの場合の熱伝導方程式と境界条件文、精度3%・Bi≲0.1の文、例題1.4の題意。前段落（Bi≫1の導入）と脚注7は前ページ（PDF 37）。

- 熱伝導方程式（block 108）：原典 ∂²T_b/∂x² = (1/α)(∂T_b/∂t)。現行一致（400dpi確認）。
- 境界条件（block 107 の本ページ部分）：原典 "T_b(x,t) = T_∞ when x = L"。現行「x = L において T_b(x, t) = T_∞」一致。
- 精度文（block 110）：原典 "accurate within about 3% if Bi ≲ 0.1 … [1.3]"。現行「Bi ≲ 0.1 であれば通常およそ3%以内…［1.3］」一致。≲ は原典グリフ（400dpi確認）と現行 U+2272 が対応。
- 例題1.4題意の数値（block 112）：直径1 mm、初期20°C、気体200°C、250 W/m²K、k=45 W/m·K、ρ=9300 kg/m³、c=0.18 kJ/kg·K — 全て原典と一致。

### 候補
1. **節JSON block 106（図1.11キャプション）・h̄バー脱落 — P3**
   - 原典形："The cooling of a body for which the Biot number, h̄L/k_b, is large."（h̄、400dpiでバー確認）。
   - 現行形：「図1.11　ビオ数 hL/k_b が大きい物体の冷却。」— caption の h は U+0068 単独（実測）。
   - 影響：キャプション中の Bi 構成式でのバー脱落。軽微。
2. **節JSON block 112（例題1.4題意）・h̄バー脱落 — P3**
   - 原典形："The heat transfer coefficient h̄ is 250 W/m²K"（h̄、400dpiでバー確認）。
   - 現行形：「熱伝達係数 h は 250 W/m²K であり」— h に U+0304 なし（実測）。数値250自体は一致。
   - 影響：与条件の係数が平均値である旨の表示が落ちる。後段の計算（次ページ）では h̄ として使われており実害は軽微。
3. **深掘り §1.3「Bi数」block本文＋equations・不等号グリフ ≲→< — P3**
   - 原典形：Bi ≲ 0.1（≲＝U+2272相当、本ページ400dpi確認）。
   - 現行形（深掘り）：本文「原典は、Bi < 0.1 なら集中熱容量解は通常約3%以内…」、equations 意味欄「Bi < 0.1 が…目安（原典引用 [1.3]）」と、いずれも通常の < （U+003C）。
   - 影響：境界 0.1 ちょうどの扱いが原典（≲、0.1を含む目安）よりわずかに厳しくなる。実務影響はほぼ無いが、原典引用を明記した箇所のグリフ差異として記録。なお節JSON block 110 は ≲ で正しい。

### 参考（担当ページ外・非カウント）
- 節JSON block 107 の「Bi = hL/k_b ≫ 1」の h にもバーが無い（実測）が、この句は原典では PDF 37（書籍p.23）側に載る文であり、PDF 38 側は「…to heat transfer.」以降。本ページ候補には数えず、PDF 37担当への参考情報とする。同様に図1.10キャプション（block 103、PDF 37）の hL/k_b も同型。

- 図1.12（block 113）：キャプション「高温の気体流に対する熱電対の応答」は原典 "Thermocouple response to a hot gas flow" と一致。図本体は T_i = 20 から T_∞ = 200 への指数上昇曲線、t = 𝒯（接線構成）・t = 3𝒯 の破線、3𝒯 で「元の温度差の95%に到達」の注記。現行 alt の「t = 𝒯 で初期温度差の約63%（独立確認：1−e^(−1) = 63.2% ✓）、t = 3𝒯 で95%」は図・原典と整合。𝒯 グリフも実測で正しい。
