## PDF p.82（§2.3、原書 p.68）— 一致（候補なし。原典側の観察1件）

### 照合済み（所見なし）
- **式 (2.23)**（blocks[45]）: 原典 `h̄[(C₁ ln r + C₂) − T∞]_{r=r_o} = −k[∂/∂r (C₁ ln r + C₂)]_{r=r_o}`。アプリ `h̄[(C₁ ln r + C₂) − T∞]|_{r=rₒ} = −k ∂/∂r (C₁ ln r + C₂)|_{r=rₒ}` と一致。左辺全体への代入・評価位置 r=r_o・右辺の負号すべて一致。
- **C₁**（blocks[46]）: 原典 `C₁ = (T∞ − Tᵢ) / [k/(h̄r_o) + ln(r_o/rᵢ)] = (T∞ − Tᵢ) / [1/Bi + ln(r_o/rᵢ)]`（400dpi で分母第1項が `k/(h̄r_o)` であること、h̄ のバーを確認）。アプリと一致。1/Bi = k/(h̄r_o)（Bi = h̄r_o/k）とも整合。
- **C₂**（blocks[46]）: 原典 `C₂ = Tᵢ − [(T∞ − Tᵢ)/(1/Bi + ln(r_o/rᵢ))] ln rᵢ`。アプリと一致。
- **Step 6 の T**（blocks[47] 本文）: 原典 `T = [(T∞ − Tᵢ)/(1/Bi + ln(r_o/rᵢ))] ln(r/rᵢ) + Tᵢ`。アプリと一致。
- **式 (2.24)**（blocks[48]）: 原典 `(T − Tᵢ)/(T∞ − Tᵢ) = ln(r/rᵢ) / [1/Bi + ln(r_o/rᵢ)]`。アプリと一致（分子・分母の帰属、ln の引数とも）。
- **Step 7 本文数値**（blocks[49]）: r_o/rᵢ = 2 に固定、Bi ≫ 1 で例題2.4 の解に帰着、Bi ≪ 1 で (T − Tᵢ)/(T∞ − Tᵢ) が Bi のオーダー、Bi < 0.1 で内部温度が約 ±3% で一定、Bi > 20 で対流を約5%誤差で無視可 — 全数値・不等号（≫ は U+226B、≪ は U+226A で実測）ともアプリと一致。§1.3 への参照も一致。
- 「よくある誤り」段落（blocks[46] 冒頭）: 左辺に T = T_o を代入してはいけない、T_o は利用可能な情報ではない — 原典と一致。
- 発展教材 lessons[7]: 本ページの式・数値を直接転記する箇所は無し（(2.25) の転記は p.83 側で照合）。

### 原典側の観察（非所見・候補にしない）
- **式 (2.23) の簡約行の符号**: 原典印刷は `h̄(T∞ − C₁ ln r_o − C₂) = −kC₁/r_o`（400dpi で負号を確認）。厳密には (2.23) の左辺括弧の符号を反転すれば右辺も `+kC₁/r_o` になるはずで、印刷の簡約行は (2.23) および直後の（正しい）C₁ 導出と符号の点で整合しない。アプリ blocks[46] はこの印刷形をそのまま保持し、C₁・C₂・(2.24) の最終形はすべて正しい。原典自身の印刷不整合をアプリが保持するケースとして非所見とし、ここにメモとしてのみ記録する。
