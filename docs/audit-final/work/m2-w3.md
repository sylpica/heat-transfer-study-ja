所属節：§4.2。

照合した要素：
- 式(4.5) ∂²T/∂x² = (1/α) ∂T/∂t：`4-2-ja.json` block 28、一致。

- 独立再計算：積解を (4.5) に代入 → 𝒳″𝒯 = (1/α)𝒯′𝒳 → 両辺を 𝒳𝒯 で割り (4.7a)、分離定数 −λ² で (4.8) の2式が得られ、(4.9) はその一般解であることを検算済み。数値要素はこのページになし。符号・係数に誤りなし。

候補あり（1件）：

### M2-W3-160-1 (候補/P3提案) 筆記体 𝒯／𝒳（分離関数の専用字形）の平字化
- 箇所：`sections/4-2-ja.json` block 29（本文の仮定 T = 𝒯(t)·𝒳(x)）、block 30（式(4.6) と explanation の 𝒯′ = d𝒯/dt、𝒳″ = d²𝒳/dx²）、block 32（式(4.7a)）、block 34（式(4.7b)）、block 36（式(4.8)）、block 38（式(4.9)）。
- 原典形：時間のみの関数を筆記体 **𝒯**（mathematical script capital T）、空間のみの関数を筆記体 **𝒳**（script capital X）で書き、温度場 T(x, t) 本体と意図的に区別する（400dpi 拡大で両字形を明認）。たとえば仮定は「T = 𝒯(t) · 𝒳(x)」、式(4.6) は「𝒳″𝒯 = (1/α) 𝒯′𝒳」。
- 現行形：すべて平字 T／X（例 block 29「T = T(t)·X(x)」、block 30「X″T = (1/α) T′X」、explanation「T′ = dT/dt」）。`4-2-ja.json` 全体で数学筆記体（U+1D400–U+1D7FF）= 0（実測）。
- 影響：式の数学的内容・符号・係数は正しいが、原典の区別（温度 T と時間関数 𝒯 の別記号化）が失われ、「T = T(t)·X(x)」は字面だけ見ると温度自身を自分で定義する形になり、初学者には紛らわしい。字形（グリフ）区別の脱落として扱う。
- 重大度提案：**P3**。
- 発展教材の同種箇所：`original-deep-lessons.json` §4.2 lesson（index 15）block 6 と equations (4.7) は 𝒯（U+1D4AF）は保持する一方 𝒳 は平字 X（𝒳（U+1D4B3）は lesson 全体で 0、実測）。部分的な同種脱落として記録する（𝒯 側は非所見）。
