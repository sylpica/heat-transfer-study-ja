### 候補
- **式(5.3)・block 8（formula, number 5.3）**：
  - 原典形：Π4 ≡ ζ = x/√(αt) （this is exactly ξ/√Fo）。根号の被覆は分母 √(αt)・√Fo のみで、分子 x・ξ は根号の外。
  - 現行形：`Π4 ≡ ζ = √(x/(αt)) ［これはちょうど √(ξ/Fo) である］`（expression・altとも同形）。コードポイント実測：√ U+221A の直後に (x/(αt)) 全体が続く＝根号が商全体に被さる。
  - 証拠：200dpi全ページ読影＋400dpi crop（/tmp/m3w2/crop-5_3.png）で分数形 x/√(αt)、ξ/√Fo を確認。数値反例（L=0.1, x=0.04, αt=0.01）：原典形 ζ=0.40（両形一致）。現行形は √(x/(αt))=2.0、√(ξ/Fo)≈0.632 で、原典とも互い同士とも一致しない。次元検算：x/√(αt) は無次元だが √(x/(αt)) は 1/√(長さ) の次元を持ち π群になり得ない。
  - 提案重大度：**P1**（定義式そのものの誤り。根号の帰属誤り＝既知の「指数・根号の帰属誤り」クラス。ζは後節の相似変数の基礎）。

### 所見なしの根拠
- 上記以外の式・数値・記号は原典画像（200dpi、式(5.2)(5.3)周辺は400dpi）と一致。h̄上線は本ページ範囲の全出現（block 3×2、block 9、block 11、block 13）が h+U+0304 で復元済み＝残存脱落なし。
