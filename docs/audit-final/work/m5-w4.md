## 候補(1)：例題7.7 の U の中間式における前置因子 1/A_inside の脱落

### 原典形（画像読み取り、400dpi確定）
PDF 399（書籍p.385）例題7.7解の表示式は次のとおり（2行構成）：

```
U = (1/A_inside) [ 1/(hA)_inside + R_t,wall + 1/(hA)_outside ]^(−1)
                    └─ R_t,wall の下に下波括弧＋「neglect」
  = ( 1/4.371 + 1/5 )^(−1) = 2.332 W/m²K
```

- 前置因子 **1/A_inside は原典に明瞭に存在する**（分数形で括弧の外、400dpi切り出しで確定）。
- 括弧内の (hA) の h は**無印**（バーなし、400dpi確定。候補(2)と混同しないこと）。
- 第2行の代入 (1/4.371 + 1/5)^(−1) は、A_inside ≃ A_outside のもとで面積が相殺された後の形であり、原典内部では整合している： (1/A)[1/(h_in A) + 1/(h_out A)]^(−1) = [1/h_in + 1/h_out]^(−1)（A_in = A_out の場合）。

### 現行形（アプリ側、blocks[9]「解」段落）
`7-5-ja.json` blocks[9] の該当部分（ファイル文字列そのまま）：

```
U = [1/(hA)inside + Rt,wall + 1/(hA)outside]^{−1}（壁抵抗は無視する） = [1/4.371 + 1/5]^{−1} = 2.332 W/m²·K
```

- **前置因子 1/A_inside がない。** 脱落は原典側ではなく**アプリ側**で起きている（第1波C3候補の含意と逆向きの確定）。
- その結果、アプリの第1式は字面どおりには総括熱伝達係数 U の定義式になっておらず、次元も W/K（熱コンダクタンス）になる。第2式 [1/4.371 + 1/5]^{−1} は (hA) へ h の値を代入した形であり、面積相殺の過程が表示上消えている。

### 再計算（python3）
- ダクト内面面積：周長 P = 4×0.3 = 1.2 m、L = 15 m → A_inside = 18.0 m²。
- アプリ第1式を字面どおり評価：[1/(4.371×18) + 1/(5×18)]^(−1) = [0.0238211 K/W]^(−1) = **41.98 W/K**。印刷最終値 2.332 のちょうど **18.0倍**（＝A_inside）。
- 前置因子を付けた原典形：(1/18)×41.9795 = **2.3322 W/m²K → 2.332 ✓**（印刷値 h = 4.371、5 を使用）。
- したがって「最終値 2.332 は面積相殺で正しい」という従来説明は原典形については正しい。アプリ形は第1式≠第2式の不整合を表示したまま最終値だけが正しい状態。

### 重大度提案・裁定への意見
- **提案：確定相当、P2。** 先例「表示された中間式自体が誤りで最終結果が正しいものは P2」に正確に該当する。原典が正しくアプリが落としているため、「原典の印刷不整合をアプリが保持」は適用できない（非所見ルールの対象外）。
- 切り分け注記：h の印刷値 4.371（再計算 4.356）問題とは独立。本候補は h に印刷値を代入した上でも成立する表示式の脱落であり、決着済みの件の再提起ではない。
