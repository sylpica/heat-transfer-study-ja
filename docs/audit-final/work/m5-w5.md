### 照合項目

1. **冒頭段落（ブロック[2]後半）— 一致**
   - 原典: "very thin and flows rather like a b.l." / 自然対流は上下両方向、凝縮液は下向きのみ / 液膜内温度は冷壁 Tw から外縁 Tsat へ上昇。

2. **δ・δt 段落（ブロック[5]）— 一致（全句照合）**
   - 境界層諸仮定を許容できる薄さ、式(6.13)後続議論への言及 ✓
   - 凝縮膜では膜縁が両境界層の縁 → δ = δt ✓
   - 自然対流では Pr が1程度以下で δ ≈ δt（冷却/加熱流体はすべて浮揚しなければならないため）✓
   - Pr 大では高粘度のため未加熱流体も引きずり δ が δt を超えうる ✓
   - 「以下に続く解析は δ ≊ δt の場合」✓
   - 記号実測: アプリは δ ≊ δt に **≊ U+224A** を使用。原典400dpiでも同形（≊）であり一致。脱落・混同なし。
