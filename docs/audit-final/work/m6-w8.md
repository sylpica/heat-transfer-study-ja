## 候補

### M6W8-F01 脚注27：平均分子速度 C̄ の上線（バー）脱落 ×2
- 箇所：`11-11-ja.json` 脚注ブロック index 9（脚注27）。
  現行文：「Z12 = N1N2σ12C であり、ここで σ12 = π(d1 + d2)²/4 であり、C は式(11.101) からの平均分子速度である[11.56]。」
- 原典形（400dpi 画像確認）：Z₁₂ = 𝒩₁𝒩₂σ₁₂C̄ where σ₁₂ = π(d₁+d₂)²/4 and C̄ is the average molecular speed from eqn. (11.101) [11.56]。C には2箇所とも（Z₁₂ 式中と定義文「C̄ is the average molecular speed」）上線がある。
- 現行形（コードポイント実測）：2箇所ともプレーンな `C`（U+0043）。節JSON全体で U+0304（COMBINING MACRON）の出現数は 0。
- 数値影響の試算：なし（数式の値・構造は不変）。ただし C が「平均分子速度」であることを示すバーが消え、通常の C と区別できない。
- 提案重大度：**P3**。先例「上線（平均量バー）の脱落＝P3（定義式でもP3、C̄ も同クラス）」に直接該当。定義文での脱落も同クラスとして先例が明示している。

### M6W8-F02 筆記体 𝒩（数密度）のプレーン N への脱落（計6箇所）
- 箇所：
  - 段落ブロック index 8 ×2：「単位体積あたりの各種の分子の数 Ni」「Ni = NA·c·xi」— 原典は 𝒩_i（筆記体）。
  - 式ブロック index 14（11.123）×2：「Z12 ∝ N1N2 ∝ x1x2」— 原典は Z₁₂ ∝ 𝒩₁𝒩₂ ∝ x₁x₂。
  - 脚注ブロック index 9（脚注27）×2：「Z12 = N1N2σ12C」— 原典は 𝒩₁𝒩₂。
- 原典形（400dpi 画像確認）：数密度は筆記体 𝒩（SCRIPT CAPITAL N, U+1D4A9 相当）で、同じ行の N_A（アボガドロ数、通常イタリック N）とは字形で区別されている。「𝒩_i = N_A c x_i」の両辺で区別が意味を持つ。
- 現行形（コードポイント実測）：全箇所プレーンな `N`（U+004E）。節JSON全体で U+1D4A9 の出現数は 0。
- 数値影響の試算：なし。ただし数密度 𝒩 とアボガドロ数 N_A（および後段のモル流束 N_i）との字形区別が失われ、「Ni = NA·c·xi」では両辺の N が同形になる。
- 提案重大度：**P3**。既報の 𝒟→D 脱落（W2C2 F03）と同種の筆記体グリフ脱落クラス。数値・式構造への影響はないため P3 が相当と提案する。𝒟 の件とは別記号のため新規候補として記録する（統括側で既報クラスへ統合する場合はその裁定に従う）。

### M6W8-F03 フラクトゥール 𝔪（粒子質量）のプレーン m への脱落（計6箇所）
- 箇所：
  - 式ブロック index 13（11.122）×4：「∆P⃗2 ∝ [m1m2/(m1 + m2)]·(v⃗1 − v⃗2)」— 原典は分子・分母ともフラクトゥール 𝔪₁𝔪₂/(𝔪₁+𝔪₂)。
  - 段落ブロック index 8 ×2：「ここで m1 と m2 は、それらの粒子の質量である」— 原典散文も 𝔪₁, 𝔪₂（400dpi で黒体字形を確認）。
- 原典形（400dpi 画像確認）：粒子質量はフラクトゥール 𝔪（FRAKTUR, U+1D522 相当）。本節前頁の式(11.120a/b) で質量分率に使われる通常イタリック m（∇m₁ 等）とは字形で区別されている。
- 現行形（コードポイント実測）：全箇所プレーンな `m`（U+006D）。節JSONにフラクトゥール文字なし。
- 数値影響の試算：なし。ただし式(11.122) の m を質量分率 m_i と混同し得る字形区別の喪失。
- 提案重大度：**P3**。F02 と同じ字形区別脱落クラス（数値影響なし）。

## 照合して非所見とした事項（理由つき）

1. **標準状態記号 R°（特別指示による重点確認）**：原典は R の右肩の小円（R°）。現行形は段落ブロック index 8 の2箇所（「Ð12 ≡ (cR°T)/a」「cR°T = p」）・式ブロック index 17（11.126）とも `°` = **U+00B0 DEGREE SIGN** で実測され、正しい字形。W1C1 で他ページ（式(11.131)(11.132)）に見つかった ◦（U+25E6）への置換は **p.715 には存在しない**。非所見。
2. **Maxwell–Stefan 係数 Đ**：原典は横線付き D（Đ₁₂）。アプリは節全体で一貫して Ð（U+00D0 LATIN CAPITAL LETTER ETH、25箇所）で表記し、プレーン D（フィック係数等）との「線付き／なし」の区別は保持されている。字形の線位置の差はフォント表現の範囲と判断し非所見。
3. **式(11.122)**：∆（U+2206）、P⃗・v⃗₁・v⃗₂ の矢印（U+20D7 ×3）、∝（U+221D）すべて保持。現行の角括弧と中点 `·` は原典の分数配置と数学的に等価な書式。非所見。
4. **式(11.124)**：Ṗ は U+1E56（ドット付き P、原典のドットありと一致。Q̇ 統一のような付加ではない）、添字 1→2 の矢印（U+2192）あり。v₁, v₂ に矢印がない点も原典どおり（z 成分）。係数 a・x₁x₂・A・dz すべて一致。非所見。
5. **式(11.125)**：原典と完全一致。非所見。
6. **式(11.126)**：現行「(cR°T)·[x1x2(v1 − v2)/Ð12]」は原典の分数配置 (cR°T)·x₁x₂(v₁−v₂)/Đ₁₂ と数学的に等価。非所見（等価変形）。
7. **脚注28**：N_A = 6.0221×10²³ 分子/mol — 原典の桁（6.0221、指数23）と完全一致。非所見。
8. **脚注27 の数値・参照**：σ₁₂ = π(d₁+d₂)²/4、式(11.101) 参照、文献 [11.56] は一致（差異は F01 の C̄ と F02 の 𝒩 のみ）。本文側の参照 [11.75]、問題11.55、式(11.111) も一致。非所見。
