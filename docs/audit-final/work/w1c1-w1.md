### 候補 W1-1（P3提案）：近似記号のグリフ差 ≅（原典）→ ≊（アプリ）、2箇所

- 原典の印刷形：式(11.110)「𝒟_{im} ≅ 𝒟_{iA}」および直前節の本文「J⃗_j ≅ 0 for j ≠ i」の近似記号はいずれも **≅（U+2245 APPROXIMATELY EQUAL TO、チルダが等号の上）**。400dpi拡大（`w1-p705-hi-705.png` 切り出し）でチルダ／等号の上下配置を確認した。
- アプリの現行形：[22]「Dim ≊ DiA」、[20]「J⃗j ≊ 0」とも **≊（U+224A ALMOST EQUAL OR EQUAL TO）**（コードポイント実測）。
- 数値影響：なし（再計算値なし）。≅ と ≊ はどちらも「ほぼ等しい」を表し、意味・計算結果は変わらない。転記の厳密性（原典グリフの忠実再現）の観点でのみ挙げる候補。統括側の記号統一ポリシー（例：アプリ内で ≃／≊ を許容するか）により棄却もあり得る。
