### 候補 W2-718-1: 標準状態記号の字形（横線入り円 ⊖ 系）がアプリでは中空円 ◦ になっている

- 重大度の提案: **P3**（数値影響なし。記号の識別情報の喪失のみ）
- 原典の印刷形: 化学ポテンシャルの標準状態記号は「横線の入った円」（plimsoll 系記号）。400dpi 拡大で、μ の右肩の記号には円の中央に横線が通っていることを確認した。本文の `x_i` の標準状態値 `x_i^{⊖} = 1` も同じ横線入り円。一方、気体定数 `R°` の右肩は横線のない中空円であり、原典は両者を字形で区別している。テキスト層でも裏取り可能: 原典テキスト層は標準状態記号を「−◦」の合成として出し、`R◦` は単独の「◦」として出す（両者が別字形である証拠）。
- アプリの現行形: `µi◦(p, T)`（U+25E6 WHITE BULLET、中空円）— 式(11.131) block 30、式(11.132) block 31、本文 block 27 の `µi◦(p, T)` および `xi◦ = 1`。R° の °（U+00B0）と実質同じ「中空円」側に寄せられており、原典の横線の区別が落ちている。
- 数値影響: なし（再計算対象なし）。意味（標準状態）は文脈から復元可能。ただし記号体系としては原典と異なる。
- 該当ブロック: 11-11-ja.json block 30（式11.131）、block 31（式11.132）、block 27（本文中の µi◦ と xi◦）。
- 備考: 発展教材 §11.11 レッスンでは標準状態を `μ_i°`（U+00B0）で書いており、節データの ◦ とも原典の横線入り円とも異なる第3の表記。統括側でアプリ全体の標準状態記号ポリシー（原典字形に寄せるか、現行表記を house style として是認するか）の判断材料として挙げる。

### 候補 W2-718-2: 式(11.132) 右辺の μ に原典では添字 i がない（アプリにはある）— 原典側の脱落と推定、アプリは正

- 重大度の提案: **P3（情報提供。アプリの欠陥ではない。アプリを原典に合わせて「修正」してはいけない事例）**
- 原典の印刷形: 式(11.132) は `μ_i = μ^{⊖}(p, T) + R°T ln(γ_i x_i)`。400dpi 拡大で、右辺の μ には下付き添字 i がなく、右肩の標準状態記号のみがあることを確認した。テキスト層も `µi = µ −◦ (p, T) + ...` と右辺 μ 単独で出ており、画像と一致する。対照的に、式(11.131) の右辺は `μ_i^{⊖}(p, T)` と添字 i＋標準状態記号の両方を持ち、本ページ本文の定義（「where μ_i^{⊖}(p,T) is the potential in a reference state」）も添字 i 付きである。よって (11.132) 右辺の添字欠落は原典側の脱落（誤植）と推定される。
- アプリの現行形: block 31 は `µi = µi◦(p, T) + R°T·ln(γi·xi)` と右辺にも添字 i があり、意味的に正しい形（(11.131) および本文定義と整合）。
- 数値影響: なし。アプリ側に変更不要。原典誤植候補として記録する目的の候補。
- 該当ブロック: 11-11-ja.json block 31（式11.132）。

### 観察事項（候補としない）

- 式(11.131) 左辺の引数: 原典は組成ベクトルを表すスクリプト体 `μ_i(𝒙)`。アプリ block 30 は通常の `µi(x)`。アプリ全体の線形テキスト表記の範囲内の字形差で、引数の同一性は文脈上自明なため候補としない。
- 式(11.131)/(11.132) のその他の構成（`+ R°T ln(x_i)`、`ln(γ_i x_i)`、ideal/nonideal solution のラベル、脚注30「1 mol/kg の仮説的理想溶質 [11.76]」、脚注31「R° = kB·NA」）はすべてアプリと一致。γ の字形は原典の数学イタリック体とアプリの U+03B3 で対応。
