## PDF p.186（§4.5、書籍p.172）— 候補あり（1件、上線脱落）。数値は全て原典どおり

対象: 例題4.8（直径2.0 cm、k＝205 W/m·K、長さ8.0 cm のアルミ棒、壁150°C、空気26°C、h̄＝120 W/m²K、先端伝導の重要性判定）。

### 候補 W4-186-1（例題4.8 問題文の h̄ 上線脱落、3箇所）
- 重大度の提案: **P3**（問題文散文の表記。解法ブロック側はバーを保持し、数値・結論に影響なし）
- 原典の印刷形（400dpiで確定）: 「…and **h̄** ＝ 120 W/m²K」「make the very crude assumption that **h̄** ≃ **h̄**_L」
- アプリの現行形: blocks[51]: 「h = 120 W/m²·K」「h ≃ hL という非常に粗い仮定」— 3箇所すべて U+0304 なし。与件の数値そのもの（2.0 cm、205、8.0 cm、150°C、26°C、120）は原典どおり
- 数値影響: なし。なお解法 blocks[52] は mL = √(h̄P L²/(kA)) と Biax = h̄L·L/k の2箇所で U+0304 を保持しており、節内でも表記が不統一

### 数値の独立再計算（given: D＝0.020 m、L＝0.080 m、k＝205、h̄＝120、T₀＝150、T_∞＝26 から計算。アプリ/原典の印刷値と全て一致）
- P/A ＝ 4/D ＝ 200、A/P ＝ 0.005（原典の代入形 0.01/2 と同値）
- mL ＝ √(h̄PL²/(kA)) ＝ 0.865603 → 印刷 0.8656 ✓
- Bi_ax ＝ h̄L/k ＝ 120×0.08/205 ＝ 0.046829 → 印刷 0.0468 ✓
- cosh(0.8656) ＝ 1.398618 → 印刷 1.3986 ✓、(0.0468/0.8656)·sinh(0.8656) ＝ 0.052900 → 印刷 0.0529 ✓
- 近似 Θ_tip ＝ 1/1.3986 ＝ 0.714991 → 印刷 0.7150 ✓、T_tip ＝ 26＋0.715×124 ＝ 114.66 → 印刷 114.7°C ✓
- 「Θ_tip の4%の差」: 再計算 (0.714991−0.688934)/0.688934 ＝ 3.78% → 印刷の "four percent" と整合 ✓

### 参考観察（候補としない）: 厳密 Θ_tip の印刷値 0.6886 について
- 原典・アプリ blocks[52] ともに計算連鎖「1/[1.3986 + 0.0529] = 0.6886」と印刷されているが、この丸めた中間値から逆算すると 1/1.4515 ＝ 0.68894、全精度計算でも Θ_tip ＝ 0.688934（→0.6889）となり、印刷値 0.6886 とは 0.0003（0.05%）の差がある。これは原典自体の丸め由来の差異で、アプリは原典印刷形を忠実に再現しているため転記誤りの候補とはしない。T_tip はどちらの値でも 111.4°C（0.6886→111.39、0.688934→111.43）で結論不変
- 前文 blocks[50]（h̄_L は予測がほぼ不可能）も原典 p.186 冒頭と整合し、バーも保持
