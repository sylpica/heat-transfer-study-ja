## PDF p.331（書籍 p.317、§6.7）― 候補あり（1件、同種2箇所）

### 候補 W5-C1：式(6.45a) 再掲部と直後の箇条書きで、平均分子速度 C̄ の上線が脱落

- **重大度の提案：P3**（数値影響なし。ただし平均量を示す上線の脱落であり、C̄ と未定義の裸の C では意味が変わる記号転記誤り）
- **原典の印刷形**（400dpiで確認）：
  - 式(6.45a)： τyx = (constant)(ρ**C̄**)(ℓ ∂u/∂y)、下線注 = u′。C の上に明確なマクロン（上線）がある。
  - 箇条書き第3項： "**C̄** is replaced by v = v̄ + v′, the instantaneous vertical speed of the fluid parcel" ― 先頭の C にも上線があり、同じ文中の v̄ にも上線がある。
- **アプリの現行形**：
  - ブロック[12]（6-7-ja.json、paragraph text）：「τyx =（定数）·ρ**C**·ℓ(∂u/∂y)」。コードポイント確認：C = U+0043 の直後は U+00B7（中点）で、U+0304 は存在しない。
  - ブロック[13] items[2]（list）：「**C** は、流体塊の瞬時的な鉛直速度 v = v̄ + v′ に置き換えられる。」先頭の C = U+0043 の直後は空白で U+0304 なし。一方、同じ文中の v̄ は v + U+0304 で正しく上線保持されている（＝C だけが脱落した不整合）。
- **数値影響**：なし（再計算値なし）。(6.45a) の「定数」は原典でも未指定で、このページに C̄ を用いる数値計算は存在しない。影響は記号の意味のみ：C̄ は分子の平均速度を表す平均量であり、上線なしの C は本節で未定義。
- **対照（正常な箇所）**：同じページの ū はブロック[13] items[3] で合成済み U+016B（ū）として2箇所保持、ブロック[15] の v̄ も U+0304 保持。C には合成済みマクロン形が存在しないため C + U+0304 が必要で、そこだけ脱落している。統括指示の「§6.7 の ū は復元済み・バーがあれば正常」とは別箇所の話であり、本候補は C̄ の脱落である。
- **該当ブロック**：6-7-ja.json ブロック[12] text 内の式(6.45a)再掲、およびブロック[13] items[2] 先頭。
