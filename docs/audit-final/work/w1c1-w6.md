## PDF p.333（§6.7、原書 p.319）— 候補あり（P3 のみ。式 (6.86a/b)・(6.87) はクリーン）

### 照合済み（所見なし）
- **式 (6.86a)**: 原典 `ρε_m ∂ū/∂y = −ρ·overline{v′u′} = −ρ(constant)(±ℓ|∂ū/∂y|)(∓ℓ ∂ū/∂y)`。
  アプリ 6-7 blocks[19]: `ρεm(∂ū/∂y) = −ρ·v′u′バー = −ρ（定数）[±ℓ|∂ū/∂y|][∓ℓ(∂ū/∂y)]`。
  ±（第1因子）と ∓（第2因子）の順序、絶対値の付く因子（第1因子のみ）、ℓ の帰属すべて一致（400dpi で確認）。
- **式 (6.86b)**: 原典 `= ρ(constant)ℓ²|∂ū/∂y| ∂ū/∂y`（絶対値は第1の勾配因子のみ、第2因子は符号付きのまま）。
  アプリ blocks[19] 末尾 `= ρ（定数）ℓ²|∂ū/∂y|(∂ū/∂y)` と一致（400dpi で確認）。
- **式 (6.87)**: 原典 `ε_m = ℓ²|∂ū/∂y|`。アプリ blocks[20] `εm = ℓ²|∂ū/∂y|` 一致。
- **上線**: 原典の ū はアプリでは U+016B（ū、49 件）で保持され表示上バーあり。v̄ は v+U+0304。積の平均 overline{v′u′} はアプリの他ブロック（[17][18]）と同じく「v′u′バー」の語尾表記で原典のバー範囲（積全体）と意味一致 — 表記規約として扱い候補にしない。
- 本文数値・条件: `∂ū/∂y < 0` のとき絶対値が必要、定数を 1 と置く、等は blocks[19] と一致。見出し “Turbulence near walls” = blocks[21]「壁近くの乱流」一致。
- 原典の `u′ ≃ ℓ(∂ū/∂y)` の ≃ をアプリは ≊ で統一表記（意味同一・数値影響なし、候補にしない）。
- 発展教材 lesson[33]: κ≈0.41、B≊5.5、式 (6.102) `Cf(x)=0.455/[ln(0.06·Rex)]²` の引用は節データ [28][36][40] と整合。本ページ範囲と矛盾なし（例題の B≈5 は「丸めた例示値」と教材内で明記済み）。

## PDF p.337（§6.8、原書 p.323）— 候補あり（P2 ×1。(6.103)–(6.105) はクリーン）

### 照合済み（所見なし）
- **式 (6.103)**: 原典 `q = −ρc_p(α + ε_h) ∂T̄/∂y`。アプリ 6-8 blocks[4] `q = −ρcp(α + εh)(∂T̄/∂y)` 一致。
- **式 (6.104)**: 原典 `Pr_t ≡ ε_m/ε_h`。アプリ blocks[5] `Prt ≡ εm/εh` 一致。
- **式 (6.105)**: 原典 `q = −ρc_p(ν/Pr + ε_m/Pr_t) ∂T̄/∂y`。アプリ blocks[6] `q = −ρcp[ν/Pr + εm/Prt](∂T̄/∂y)` 一致（括弧種のみ相違）。定義代入 ν/Pr=α、ε_m/Pr_t=ε_h で (6.103) と等価であることも確認。
- **箇条書き**: Pr の性質、Pr_t は通常 1 に近く 2 倍以内・非金属流体ではしばしば **0.85** 近く、液体金属は扱わない — アプリ blocks[7] と全数値一致。
- **上線**: T̄ は T+U+0304 で保持（6-8 全体で 13 件）。Boussinesq 1877 年・式 (6.85)・文献 [6.22] の帰属も blocks[3] と一致。
- 発展教材 lesson[34]: Pr_t≈0.85 の記述は本ページの 0.85 と整合。

### 候補 W6-2（P2 提案）
- **該当**: 6-8 blocks[3]（無番号の導入式の言い換え文）。
- **原典の印刷形**: `q = −k ∂T̄/∂y − (another constant, which reflects turbulent mixing) ∂T̄/∂y`。括弧内の定数の**下にのみ**下括弧があり `≡ ρc_p·ε_h` と定義される（400dpi で括弧の範囲を確認: 後続の ∂T̄/∂y は括弧範囲に含まれない）。原典に `= −ρc_p·ε_h (∂T̄/∂y)` という等式は**存在しない**。全体は `q = −(k + ρc_p ε_h)∂T̄/∂y` であり、これが次の式 (6.103) `−ρc_p(α+ε_h)∂T̄/∂y`（k=ρc_p α を使用）へつながる。
- **アプリの現行形**: 「q = −k(∂T̄/∂y) −（乱流混合を反映する別の定数）(∂T̄/∂y) **= −ρcp·εh(∂T̄/∂y)** の形。」— 末尾の等式が付加され、分子伝導項 −k∂T̄/∂y が消えた形になっている。
- **数値影響（独立再計算）**: 正しい係数は (k + ρc_p ε_h)。ε_h = α の場合 ρc_p ε_h = k なので正しい係数は 2k、アプリの形は k のみで **|q| を 50% 過小** にする。壁近傍（底層、ε_h→0）ではアプリの形は q→0 を含意し、フーリエ伝導が支配するという本ページ・本節の主張そのものと矛盾する。(6.103) 自体は正しいため、誤りはこの導入文に限定される。
- **根拠の所在**: p.337「The Reynolds-Colburn analogy for turbulent flow」直下の表示式とその下括弧。
