## PDF p.350（書籍 p.336、§6.9 末尾）— 結論: 所見なし

対照ブロック: 6-9-ja.json block[27]（例題6.10 解）、block[29]（例題6.11 解）、block[31]（最終段落）。発展教材 lesson[35]。

### 照合済み項目

1. **例題6.10 の等置式**（400dpi確認）
   - 原典印刷形: `(0.332 Re_l^{1/2} Pr^{1/3})(Re_u/Re_l)^c = 0.0296 Re_u^{0.8} Pr^{0.6}`
   - アプリ block[27]: `0.332·√Rel·Pr^(1/3)·(Reu/Rel)^c = 0.0296·Reu^0.8·Pr^0.6`
   - 係数 0.332／0.0296、指数 1/2（√表記と等価）・1/3・c・0.8・0.6、冪の帰属（c は比 Re_u/Re_l のみに掛かる）すべて一致。
2. **例題6.10 の整理式**（400dpi確認）
   - 原典: `Re_u^{2.55−0.8} = 0.0296(0.708)^{0.6}(400,000)^{2.55} / [0.332(400,000)^{1/2}(0.708)^{1/3}]`
   - アプリ block[27] は同一形（分子・分母の係数、0.708 の指数 0.6 と 1/3、400,000 の指数 2.55 と 1/2）一致。
   - 独立再計算: c = 0.9922·log10(400,000) − 3.013 = 2.5454 → 2.55（印刷どおり）。c=2.55 で解くと Re_u = 870,260。原典・アプリの **870,300** とは 0.005% 差で、中間丸めの範囲内。一致と判定。
3. **例題6.11 の簡約式**（400dpi確認）
   - 原典: `Nu̅_L ≡ h̄L/k = 0.037 Pr^{0.6}(Re_L^{0.8} − Re_trans^{0.8}) + 0.664 Re_trans^{1/2} Pr^{1/3}`（Nu には Nu 全体へのバー、h にはバー）
   - アプリ block[29]: `NūL ≡ h̄L/k = 0.037·Pr^0.6·(ReL^0.8 − Retrans^0.8) + 0.664·√Retrans·Pr^(1/3)` — 一致（√ = 1/2 乗）。
   - 上線: block[29] に U+0304 が4箇所（基底 u・h・u・u）あり、出現箇所は原典のバー位置と対応。Nu のバーは原典では "Nu" 両文字に架かるが、アプリは本データセットの慣行どおり u + U+0304 の単一結合文字で表す（h̄ と同方式）。有無基準では充足。
   - 独立再計算（Pr=0.708、Re_L=1.270×10⁶）: Re_trans=400,000 → **1760.1**（印刷 1760、基準1433比 +22.8% → 印刷 +23% と一致）。Re_trans=870,000 → **1151.9**（印刷 1152、−19.6% → 印刷 −20% と一致）。アプリ block[29] の 1760／+23%／1152／−20% はすべて原典・再計算と一致。
4. **最終段落**（block[31]）: 圧力勾配 (dp/dx)、k-ε モデル、文献 [6.35, 6.36] — 原典と一致する数値・記号はこれのみで、すべて一致。
5. **発展教材 lesson[35]**: 例題6.11 の帰結（+23%／−20%）、式(6.120) の形、例題6.9 の内訳（599.9／374.3／459.2／計1,433、c=2.55）は原典と一致。式(6.120) の各項の再計算でも 599.9／374.3／459.2／計1,433.4 を再現した。

### 確認して候補から除外した事項

- 例題6.9 の「遷移領域は全体の35%」という記述（6-9-ja.json block[25]、lesson[35] も「約35%」）は、内訳 459.2/1,433 = 32.0% と厳密には合わない。しかし文脈確認のため参照した原典 p.349（担当外）自体が "contributes 35% of the total" と印刷しており、**アプリ側の転記誤りではなく原典自身の概数表現**である。転記照合の候補とはしない（数値の是非は原典の記述として統括側の判断に委ねる）。なお例題6.11 の +23%／−20% は基準 1,433 に対して再計算で裏付け済みで、この35%表現の影響を受けない。

## PDF p.236（書籍 p.222、§5.6 相似変換）— 結論: 所見なし

対照ブロック: 5-6-ja.json block[11]（有次元関数方程式）・block[12]（式5.44）・block[13]（変換3式）・block[14]（式5.45）・block[16]（式5.46）。発展教材 lesson[24]。指示メモの「§5.6 の図 alt の t>0 は修正済み」は本ページには図がなく、対象外であることを確認した。

### 照合済み項目

1. **有次元関数方程式**: 原典 `T − T_∞ = fn[t, x, α, (T_i − T_∞)]`、変数5つ・次元 K, m, s・無次元群2つ ＝ アプリ block[11]。一致。
2. **式(5.44)**: 原典 `(T − T_∞)/(T_i − T_∞) ≡ Θ = fn( x/√(αt) ≡ ζ )` ＝ アプリ block[12] `(T − T∞)/(Ti − T∞) ≡ Θ = fn(x/√(αt)) ≡ fn(ζ)`。分数の分子・分母、√(αt) の帰属（x のみに √ は掛からない）一致。
3. **相似変換3式**（400dpi拡大で確認。本ページ最大の冪帰属リスク箇所）
   - 原典:
     - `∂T/∂t = ΔT·(−x/(2t√(αt))) ∂Θ/∂ζ`（ΔT ≡ T_i − T_∞）
     - `∂T/∂x = (ΔT/√(αt)) ∂Θ/∂ζ`
     - `∂²T/∂x² = (ΔT/(αt)) ∂²Θ/∂ζ²`
   - アプリ block[13] は3式とも同一の最終形を与える。分母 `2t√(αt)` の "2t"、負号、係数 1/√(αt)、1/(αt) すべて一致。導出としても ζ = x/√(αt) から ∂ζ/∂t = −x/(2t√(αt))、∂ζ/∂x = 1/√(αt) を独立に検算し一致。
4. **式(5.45)**: 原典 `d²Θ/dζ² = −(ζ/2) dΘ/dζ` ＝ アプリ block[14]。負号と ζ/2 の帰属（ζ のみに 1/2 が掛かる形）一致。
5. **式(5.46)**: 原典 `T(t = 0) = T_i、すなわち Θ(ζ → ∞) = 1` ＝ アプリ block[16]。一致。
6. **発展教材 lesson[24]**: ζ = x/√(αt) の定義は式(5.44) と一致。同レッスンが使う η = x/(2√(αt)) は ζ/2 に当たる別約束として明示的に区別されており、p.236 の定義との混同はない。式(5.45)・(5.46) の逐語引用はないが、矛盾する記述なし。
