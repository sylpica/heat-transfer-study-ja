## R1-P2-03【修正済み】動的ガイド内の用語リンクの着地先が壊れている（#term-<id> ハッシュ未処理）

1. ID：R1-P2-03
2. 重大度：P2（リンク・導線の問題。公開画面のガイド内用語リンクが全面的に機能しない）
3. 対象：動的実験室のポップアップガイド（`dynamic/sim-guide.mjs`）の用語リンク × シェル `app.js` のハッシュルーティング
4. 再現条件：公開 dist の `dynamic/index.html` でガイド ON → ステップ 3/8 の文中「熱伝導率」をクリック。別タブは開くが URL は `index.html#term-thermal-conductivity` で、着地は学習ホームになり用語項目は表示されない。
5. 根本原因：発行側は `termUrlBase + '#term-' + id` を開く設計だが、受信側 `routeFromHash()` に `#term-<id>` の解釈がなく、未知ルートとしてホームに落ちていた。実装記録の検証は「新しいタブで開くこと」までで着地先の内容は未検証だった。

7. 実測結果：UI/UX スライスの実操作で発見され、本体がコード実物で機構を確認した。シェル内部の用語導線（用語シート→用語集で展開・スクロール）は正常動作を実測済みで、壊れているのはガイドからの外部着地のみ。
8. 修正方針：既存の用語着地挙動（展開＋中央スクロール）に合わせて、シェル側で `#term-<id>` を解釈する。用語が実在すれば用語集リスト表示に切り替え、対象を展開してスクロールする。未知 ID は用語集一覧への着地とする。
9. 修正コミット：`ffa6e17`
10. 回帰テスト：`docs/audit-round1/probe-term-hash.mjs`（実 dist・Chromium）。`tests/app.test.mjs` 30/30、`tests/flashcards.test.mjs` 14/14。
11. 修正後の結果：プローブで 着地=用語集、対象要素あり、展開=true、画面内表示、pageerror 0 を確認。未知 ID は用語集一覧に着地し、通常のホーム表示にも影響なし。
