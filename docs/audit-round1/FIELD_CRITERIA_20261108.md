# 分野別8基準表（第13章・第33.4節）— Muse 第1回監査

基準 S0 = `dbd42cb`。基準8（実ブラウザー操作確認）は全分野とも Chromium のみ実施で **WebKit 未実施**のため、全分野で「一部」とする（環境制約は UIUX_EVIDENCE に記録）。モデル単位の判定と分野単位の判定を区別する。

凡例：○＝充足、△＝一部、×＝未充足。

## 1. 非定常熱伝導

| 基準 | 判定 | 根拠 |
|---|---|---|
| 1 支配方程式 | ○ | 矩形 FVM・径方向（円筒／球）・三角形 P1・3D 直方体の各定式化を §21 説明書と照合 |
| 2 数値計算の正しさ | ○ | 積解・級数・独立直接解と照合（3D 直方体：観測次数 2.06／2.02、定常限界 6.8e-13 K） |
| 3 動的可視化 | ○ | 等温線・プロファイル描画を実画面で確認 |
| 4 操作機能 | ○ | 時間操作・条件変更を実動確認 |
| 5 日本語説明 | ○ | §21 の16項目をアプリ内に反映（240項目の一部として） |
| 6 独立検証 | ○ | 変物性×対流＋放射連成を独立エンタルピー形参照と照合（定常限界 1.3e-10 K） |
| 7 回帰テスト | ○ | 全スイートにベンチマーク固定テストを含む |
| 8 実ブラウザー | △ | Chromium のみ（WebKit 未実施） |

範囲決定：自由輪郭（自由形状）の非定常計算は対象外として正式に決定済みで、拒否表示を仕様として維持している。分野判定：**充足（基準8のみ一部）**。

## 2. フィン・ヒートシンク

| 基準 | 判定 | 根拠 |
|---|---|---|
| 1 支配方程式 | ○ | 解析モデル群（直線・対流先端・環状）＋動的フィン連成＋ヒートシンク連成の定式化を確認 |
| 2 数値計算の正しさ | ○ | 解析値一致（q = 5.2597314113 W、環状 η 補正 0.8399254018949405）。ヒートシンク連成は参照計算と最細格子で温度 +5.0e-8 K |
| 3 動的可視化 | ○ | フィン温度分布・ヒートシンク場の描画を確認 |
| 4 操作機能 | ○ | 形状・風速→h 連携を含む操作を確認 |
| 5 日本語説明 | ○ | フィン系4モデルの §21 説明書をアプリ内反映 |
| 6 独立検証 | ○ | 監査側が η・q を独立再計算し全桁一致 |
| 7 回帰テスト | ○ | ベンチマーク固定あり |
| 8 実ブラウザー | △ | Chromium のみ |

注：ヒートシンク連成モデルは開発画面（dev）上のモデルで、公開側のヒートシンクは静的モード＋UI 拡張の範囲。この区別はアプリ内で誤解のない形になっていることを確認した。分野判定：**充足（基準8のみ一部）**。

## 3. 強制対流

| 基準 | 判定 | 根拠 |
|---|---|---|
| 1 支配方程式 | ○ | Graetz（3境界条件）・円管等壁温／等熱流束・Blasius の定式化を確認 |
| 2 数値計算の正しさ | △ | 温度・Nu は解析値と 1e-10 級で一致。一方、CFD 的圧力場の連続解精度は 64 格子で 6.84% の残差があり未承認 |
| 3 動的可視化 | ○ | 温度場・プロファイル描画を確認 |
| 4 操作機能 | ○ | 条件変更・解法設定（キャビティ系と共通基盤の一部）を確認 |
| 5 日本語説明 | ○ | 強制対流4モデルの §21 説明書をアプリ内反映 |
| 6 独立検証 | △ | Nu・固有値・Blasius は独立再計算で一致。圧力精度は独立検証で未承認であることが正しく記録されている |
| 7 回帰テスト | ○ | ベンチマーク固定あり |
| 8 実ブラウザー | △ | Chromium のみ |

分野判定：**一部**（圧力精度の残件による。公開側モデルは圧力の正しさを主張しておらず、公開モデルの温度・Nu は全基準を満たす）。フィン間流れは dev モデル＋画面まで完成（公開ではない）。

## 4. 自然対流

| 基準 | 判定 | 根拠 |
|---|---|---|
| 1 支配方程式 | ○ | 密閉キャビティ（MAC＋多重格子投影）・鉛直加熱壁（相似解）・共役の定式化を確認 |
| 2 数値計算の正しさ | ○ | 公開範囲 Ra≤1000 は de Vahl Davis と照合（3定義を区別）。dev の高 Ra は 1e6 まで参照と6桁一致 |
| 3 動的可視化 | ○ | 温度場描画・共役の一体場表示を確認 |
| 4 操作機能 | ○ | 解法設定の露出（圧力投影の許容値・上限回数）を含む |
| 5 日本語説明 | ○ | キャビティの §21 説明書をアプリ内反映（原典に密閉キャビティ専用節がないことは正直に注記） |
| 6 独立検証 | ○ | ω–ψ 独立ソルバーと3定義すべて 0.002 以内で一致（過去検証）。本ラウンドでも格子系列を再現 |
| 7 回帰テスト | ○ | ベンチマーク固定あり |
| 8 実ブラウザー | △ | Chromium のみ |

分野判定：**充足（基準8のみ一部）**。高 Ra・共役は dev のみの位置づけが正しく維持されている（A2-2）。

| 基準 | 判定 | 根拠 |
|---|---|---|
| 1 支配方程式 | ○ | ネットワーク法・形態係数（2D／3D）・表面交換の定式化を確認 |

| 4 操作機能 | ○ | 形態係数→ネットワーク接続を含む操作を確認 |
| 5 日本語説明 | ○ | 放射3モデルの §21 説明書をアプリ内反映 |

| 7 回帰テスト | ○ | ベンチマーク固定あり |
| 8 実ブラウザー | △ | Chromium のみ |

分野判定：**充足（基準8のみ一部）**。長ダクト放射は dev のみ（A2-1）。

## 6. Phase 4（高度解析）

| 基準 | 判定 | 根拠 |
|---|---|---|
| 1 支配方程式 | ○ | 3D 直方体熱伝導・キャビティ CFD・乱流平均流の定式化と適用範囲を確認 |
| 2 数値計算の正しさ | ○ | 3D 直方体は積解照合・観測次数 2.06／2.02。CFD は Ghia 照合（Marchi et al. 2021 との照合整理済み：x=0.8594 の v は Ghia 転記が正しく、0.005 予算は Marchi に対して 64 格子で達成） |
| 3 動的可視化 | ○ | 3D 表示・場の描画を確認 |
| 4 操作機能 | ○ | GPU 経路（Worker）と CPU 代替の両方を確認 |
| 5 日本語説明 | ○ | 適用範囲と限界を日本語で明示 |
| 6 独立検証 | ○ | DNS（Moser–Kim–Mansour、Reτ 実測 178.12）等の外部ベンチマークと照合 |
| 7 回帰テスト | ○ | ベンチマーク固定あり |
| 8 実ブラウザー | △ | Chromium のみ |

分野判定：**充足（基準8のみ一部）**。乱流は Cess 定常平均流を「平均流」と明示した限定公開であり、瞬間場と偽っていないことを確認した。
