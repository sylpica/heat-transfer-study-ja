# 問題集 作業解レベル独立検証 — Muse 第2回（R1-P2-01 継続）

実施：2026-11-08。対象ツリー：`audit/integration-loop1` 先端 `bec84fc`（監査ブランチ `audit/muse-round-02` の起点）。検証は読み取り専用で実施し、データの変更は裏取り済みの欠陥1件（R2-01）のみ。

## 1. 対象範囲の定義（第1回の数え方の再現不可能性と、本回の操作定義）

第1回台帳は「`reviewStatus` を集計すると、作業解レベルの独立検証済み（source_checked 367問＋needs_review 9問）は376問、残り375問」と記録したが、現行データの `reviewStatus` は自由文の日本語ステータス（30種）であり、第1回の集計区分（source_checked／needs_review という語彙）は問題集のステータスには存在せず（source_checked は8問のみ）、367＋9 の内訳を現行データから一意に再現することはできなかった。個々の問題の「検証済み／未検証」の対応表も記録に残っていない。

このため第2回では、第1回の「残り375問」を下回らない、より弱い側の操作定義を採用した：

- **本回の検証対象（422問）**：`reviewStatus` が作業解レベルの独立再計算を自ら謳っていない4区分＋1区分の問題全件。
  - 「執筆原稿・基本算術と構造を確認／包括的品質監査待ち」268問
  - 「執筆原稿・最低限の算術と構造を確認／包括的品質監査待ち」20問
  - 「AI作問・論理構造照合済み」76問
  - 「AIによる内部照合済み」57問
  - 「概念と適用条件の内部確認済み」1問
- 対象外（329問）：ステータス自体が独立再計算・独立手計算・別式検算等を謳う問題群。第1回が検証済みとした376問の大部分はこの群に属すると考えられるが、上記のとおり厳密な対応は再現できない。本回で422問を検証したことにより、「第1回の残件」とみなし得る集合はいずれの合理的な再構成でも本回の対象に含まれる（弱い側に広く取ったため）。

対象 ID 一覧と区分は本ラウンドの作業ファイル（チャンク分割）に記録し、結果 JSON を `docs/audit-round2/results/chunk-1.json` 〜 `chunk-8.json` に保存した。

## 2. 方法

- 422問を章バランスを取って8チャンク（52〜53問）に分割し、並行検証ライン8本で独立検証した。
- 各問の検証水準（第1回の検証済み群と同水準）：(1) 解説・正解を見ずに prompt から独立に解く（数値問題は計算ツールで途中式つきで計算）。(2) 保存された正解選択肢と照合（提示された有効数字・丸めの範囲）。(3) 一意性（他の選択肢が正解になり得ないか）。(4) explanation・solutionSteps の数値・式・引用の一致。(5) 単位・定数・丸めの整合、相関式・モデルの適用条件の明示。(6) 概念問題は教科書水準の物理としての正誤と、2つ目の擁護可能な答えの有無。
- 確定済み論点（第15章）は検証者に事前に共有し、誤検出を防いだ（式 (9.29) の係数、球の Nu_D=2、CHF の 0.131／0.149 の使い分け等）。
- 本体（監査担当）は並行ラインの結果を鵜呑みにせず、(a) 全チャンクの件数突合（422問全件が verified／issues／uncertain／notDone のいずれか1つにちょうど1回現れることを機械確認）、(b) 無作為標本13問（約35問ごと、数値7問・概念6問）の独立再検算、(c) 指摘1件の実物裏取り、を行った。標本13問は全件、保存された正解・解説と一致した（再計算値：光学的厚さ 1.00、質量流束 +5.0×10⁻⁶ kg/(m²·s)、混合物 c_p 1903.2 J/(kg·K)、平板壁 Q̇ 120 W、平均温度からの放出割合 32%、Ec=1.0、対流 Q̇ 6.8531 W 等）。

- **誤答（保存された正解が誤り）は0件**。正解が複数成立する問題も0件。単位誤り・条件不足による不正解も0件。
- 唯一の指摘 R2-01：`supp-transient-gap-one-term-initial-overshoot-v1` の正答選択肢の文言「高次項を省いた短時間近似の限界として扱う」は、一項近似自体が短時間近似であるかのように読める（実際は一項近似は長時間側＝Fo が大きい側で有効で、t=0 へ外挿すると Θ₀=A₁=1.119>1 の非物理値になる、という話）。解説本文は正しい。本体が実物で裏取りし、選択肢文言を「一項近似を短時間へ外挿した限界として扱う」へ訂正した（`data/questions.json` のみ。同問題は他の原稿ファイルに複製なし）。なお訂正文言は、長さ手がかりのゲート（tests/answer-cues.test.mjs：正解が単独最長・単独最短であってはならない）にも適合させるため、「高次項を省いた」を含む長い案から調整した最終形であり、意味は変わらない（一項近似は高次項を省いた近似であることが前提）。
