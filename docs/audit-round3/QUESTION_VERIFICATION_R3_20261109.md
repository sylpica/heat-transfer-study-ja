## 1. 対象範囲

ループ2照合（`docs/audit-collation/LOOP2_COLLATION_20261109.md` §4）で明文化した数え方——「保存キーを見る前に独立に解いた作業解の記録（問題 ID を特定できる記録）が監査記録に実在すること。ステータス文言だけでは数えない」——の下で、記録のなかった残件 **289問**（第2回請求422問と Codex レシート41問の和集合 462 問の補集合。全件がステータス上で何らかの内部検証を謳う側）を対象とした。対象 ID はカバレッジ CLI と同条件で機械的に確定した（751 − 462 = 289、 supplement 288問＋book 1問）。

## 2. 方法

- 対象289問をラウンドロビンで8チャンク（36〜37問）に分割し、並行検証ライン8本で独立検証した。パケット（`docs/audit-round3/packets/`）は id・prompt・choices・figure・field のみで、正解・解説・誤答理由・ヒント・解法ステップを含まない。
- フェーズ1（ブラインド解題）：検証者は `data/questions.json` 等の正解を含むファイルを一切開かず、prompt から独立に解いた（数値問題は計算ツールで途中式つきで計算。相関式・定義の確認に教科書テキストの参照は許可）。独立解・途中式・計算結果・他選択肢の検討を結果ファイル（`docs/audit-round3/results/chunk-*-phase1.json`）に先に保存した。
- フェーズ2（解説整合チェック）：フェーズ1の保存後に限り正解側を開き、explanation・distractors・solutionSteps・hints の数値・式・引用の整合を確認した（`chunk-*-phase2.json`）。フェーズ1の回答は変更していない。
- 確定論点（指令書 第15章）は検証者に事前共有し、誤検出を防いだ（式 (9.29)、Nu_D=2、CHF の 0.131／0.149 の使い分け、Re_c の競合定義、例題の印刷値保持 等）。
- 本体（監査担当）は結果を鵜呑みにせず、次を行った：(a) 全チャンクの件数突合（289問全件が過不足なく1回ずつ現れること、未知 ID・重複・空の working がないことを機械確認）、(b) 標本9問（各チャンクから等間隔）の独立再検算——全件、検証ラインの計算と一致（Ra = 7.848×10⁶、膜厚 1.251×10⁻⁴ m、補正潜熱 2.51×10⁶ J/kg、傾斜板 h ≈ 1.0×10⁴ W/(m²·K)、管群 h ≈ 5.0×10³ W/(m²·K) 等）、(c) フェーズ2の指摘11件すべての実物裏取り（再計算・原典ページ画像・コードポイント確認）、(d) concerns 5件の裁定。
