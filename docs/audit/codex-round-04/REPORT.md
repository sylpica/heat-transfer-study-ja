### 新規所見 R4-Q01（P3、監査記録の説明）

### 新規所見 R4-S01（P1）：式(8.43b)の指数位置・係数の転記誤り

箇所：`data/sections/8-4-ja.json`、blocks[26]、number=8.43b。

- 現行：`NuL = [0.73·Ra*_L/(1 + (0.492/Pr)^(9/16))]^(16/45)`。
- 原典PDF452：`NūL = 0.73·(Ra*_L)^(1/5)/[1 + (0.492/Pr)^(9/16)]^(16/45)`。

原典では16/45乗は分母括弧だけに掛かり、Ra*の指数は1/5、0.73は全体の係数である。現行は三者をまとめて16/45乗している。原典の印刷不整合ではなく、明確な転記誤り。

独立確認：同じページの(8.43a)でNu≫0.68とすれば、Nu^(5/4)=0.67(Ra*)^(1/4)/D^(4/9)、D=1+(0.492/Pr)^(9/16)。従ってNu=0.67^(4/5)(Ra*)^(1/5)/D^(16/45)。係数0.67^(4/5)=0.72587166を原典が0.73とした形と整合する。

Ra*=1e8、Pr=.7では、現行 **505.09197935**、原典の表示近似式 **23.48795489**（比21.5043）。(8.43a)の0.68を残した独立二分法は23.90069011。近似と係数丸めの小差と、現行の指数の誤りを混同しない。

修正案：上記の原典形へ8.43bだけを訂正する。Ra*の1/5乗、分母の16/45乗を表示式から評価する回帰確認を加え、固定PrでのRa*に対する1/5スケーリングも検査する。8.43a・8.42はこのページで原典と一致しているため、一括書換えしない。確定済み8.44aの論点も再開しない。原典式の0.73を独立導出の0.72587166へ勝手に置換しない。
