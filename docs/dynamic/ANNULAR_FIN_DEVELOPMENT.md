# 開発専用：環状フィン（管外周円盤フィン）の半径方向1D非定常モデル

2026-11-07（Asia/Tokyo）。対象 `dynamic/dev/annular-fin.mjs`。公開allowlist外、releaseApproved=false。フェイリス側の並行実装であり、Codex本線（`codex/dynamic-heat-simulation`）の成果物ではない。Phase 3「フィン・ヒートシンク」（正本プロンプト §7）で丸ごと欠落していた環状フィンの動的モデルを、以下の限定範囲で新規実装した。GUI・Worker接続・公開候補化は今回の範囲外で、数値コア＋独立検証＋本文書まで。

## 現象・仮定・支配式

管（外半径 r1）の外周に取り付けた厚さ t 一様の円盤フィン単体。フィンは r1 ≤ r ≤ r2、温度は半径方向のみに変化し、厚さ方向は一様と仮定する。両側面は同一の指定 h で周囲 T∞ へ対流する。物性 k・ρ・cp は一定、放射なし、内部発熱なし、管壁の熱抵抗や基部の熱拡がりは解かない。

θ = T − T∞、m² = 2h/(kt) として、定常の支配方程式は Bessel 型

(1/r) d/dr (r dθ/dr) − m²θ = 0

であり、解は θ(r) = A I₀(mr) + B K₀(mr)。非定常は ρcp ∂T/∂t = (k/r) ∂/∂r (r ∂T/∂r) − (2h/t)(T − T∞) を解く。

境界条件：基部 r = r1 は指定温度 Tb に固定。先端は2方式を選択できる。

- `convection`：先端面（面積 2π r2 t）自体が同じ h で対流する厳密な先端条件 −k dθ/dr = hθ（r = r2）。
- `corrected`：修正半径 r2c = r2 + t/2 まで領域を延長し、先端を断熱とする Schmidt/Gardner の古典的近似。解く形状自体が実フィンより半径で t/2 大きい近似であり、その旨を assumptions と mesh に明記する。

出力は基部熱流量 [W]、基部熱流束（基部断面積 2π r1 t で割った値）[W/m²]、側面・先端の対流損失、蓄熱変化と収支誤差、効率 η と有効度 ε。η・ε の定義は既存の学習モデル（FIN_LEARNING.md）と同じく**表面損失ベース**：η = Q_surface / (h A_fin θb)、ε = Q_surface / (h · 2π r1 t · θb)。過渡中は基部流入と表面損失が蓄熱の分だけ異なるため、基部流入をそのまま効率と呼ばない。定常では両者が一致し、下記の Bessel 参照値と一致する。A_fin は convection では両側面＋先端面、corrected では r2c までの両側面。h = 0 または θb = 0 では η・ε は定義できないため null を返す（数値の創作をしない）。

厚さ方向一様の1D仮定の開発範囲として、横方向 Bi = h(t/2)/k ≤ 0.1 を生成時に検査し、超える条件は拒否する。未知キー・非有限・範囲外・初期配列の長さ不一致は日本語エラーで原子的拒否（heat-sink.mjs と同じ流儀）。

## 数値法・保存・再生

有限体積、セル中心は環状セルの面積重心 rc = (2/3)(a² + ab + b²)/(a + b)。面コンダクタンスは重心間の対数抵抗 2πkt / ln(rc′/rc)（円筒伝導の厳密抵抗）、基部は ln(rc₀/r1) を使う。側面対流は両面分 2hπ(r_{i+1}² − r_i²)。陽 Euler、安定刻みは最大流出率の0.8倍の逆数。累積外部熱（基部流入 − 表面損失）には補償和を使い、受理前に有限値・正温度・監視上限・熱収支予算を検査し、失敗時は受理状態を変更しない。復元は law/条件署名/配列/時計/収支を検査する。

効率・有効度は表面損失から各スナップショットで計算する診断量であり、過渡初期（初期温度一様・基部だけ Tb）は 0 から始まって定常値へ近づく。「過渡中の η」は定常効率そのものではない。

## 独立検証

`scripts/dynamic-annular-fin-reference.py` が `docs/dynamic/ANNULAR_FIN_REFERENCE_20261107.json` を生成（生成スクリプトの SHA-256 を JSON に記録し、試験が照合）。手法は JS ソルバーと独立：

- 定常：50桁 mpmath の Bessel 解。基部の微分熱量 −2π r1 t k θ′(r1) と、閉形式の面積分による表面放熱が両ケースとも 1e-35 W 未満（実測 3.4e-49 / 1.7e-49 W）で一致することを生成器内で確認。セル平均温度の配列は同じ閉形式積分を float64（scipy）で評価し、最粗格子で50桁値と 1e-9 K 未満の一致を生成器内で確認済み（float64 の丸め ~1e-13 K は測定対象の離散化誤差より桁違いに小さい）。
- 過渡：Python 側で保存式から独立に組み直した有限体積ネットワークを行列指数（scipy）で厳密伝播し、JS の陽 Euler と照合。ネットワークの組み立て式は参照側で別途記述しており、JS の更新コードは流用していない。

基準条件：r1 = 0.01 m、r2 = 0.03 m、t = 0.002 m、k = 200 W/(m·K)、ρ = 2700 kg/m³、cp = 900 J/(kg·K)、h = 150 W/(m²·K)、Tb = 400 K、T∞ = 初期 300 K（仮想値であり実在材料の保証値とは呼ばない）。m = 27.386 m⁻¹、断面 Bi = 7.5e-4。

### 実測結果（2026-11-07、Node 試験の診断出力と参照 JSON から）

定常 Bessel 参照値：convection で η = 0.840173、ε = 36.1274、q_base = 68.0986 W。corrected で η = 0.839925、ε = 36.1588、q_base = 68.1577 W。修正半径近似は対流先端の厳密解に対して η で 2.5e-4、q で 0.06 W の差であり、この条件では近似として妥当な水準。

- 定常温度場 vs Bessel セル平均（RMS、K）：convection は n=16/32/64 で 0.02319 / 0.005907 / 0.001528、観測次数 1.97 / 1.95。corrected は 0.02471 / 0.006190 / 0.001548、次数 2.00 / 2.00。JS 定常は Python 離散定常（同一格子の線形解）と RMS 1e-7 K 未満で一致。
- 基部熱流量の格子収束（離散定常 vs Bessel q）：corrected は誤差 7.34e-2 / 1.84e-2 / 4.61e-3 / 1.15e-3 / 2.88e-4 W（n=8…128）、次数ほぼ正確に 2.00。convection は 6.03e-2 / 1.43e-2 / 3.15e-3 / 5.78e-4 / 3.88e-5 W と単調減少するが、細格子側の見かけ次数は 2.45 / 3.89 と乱れる（誤差の符号消し合いの影響であり、次数2を主張しない）。先端セル温度の誤差は両ケースとも単調減少し次数は約 1.8〜2.0。
- 過渡（t = 2 s、n=16、dt = safeDt/2）：行列指数参照との最大差は convection 0.01705 K、corrected 0.01611 K。固定格子の時間精細化は RMS 0.02598 / 0.01299 / 0.006495 K、時間次数 1.000 / 1.000（陽 Euler の1次と一致）。
- エネルギー収支：全ステップで内部予算検査を通り、試験範囲で |energyError| ≤ 1e-8 J。定常到達時は基部流入と表面損失が 1e-6 W 未満で一致。
- 極限チェック：(1) 長さ消滅（r2 = 0.011、L = 0.001 m）で η = 0.998903（Bessel 0.998905）と 1 へ近づく。(2) 大半径では直線フィン tanh(mLc)/(mLc)（Lc = L + t/2）へ近づき、η の差は r1 = 0.5 m で 0.01159、r1 = 2.0 m で 0.00310 と L/r1 に応じて縮小する（Python Bessel 側の差 0.01143 / 0.002934 とも整合）。環状フィンの η が同長さの直線フィンより小さいのは、外側ほど面積が増え温度の低い領域の重みが増すためであり、符号も含めて物理と整合する。

新規 Node 試験 8 件（`tests/dynamic-annular-fin.test.mjs`）が成功。失敗ステップ・不正復元の原子性、無効入力の拒否（Bi 超過・未知物理キー含む）も含む。試験1件（定常収束）だけで約1分を要する重さは既存の熱シンク試験と同程度であり、削減はしていない。
