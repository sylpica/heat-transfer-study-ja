## 実装境界

- dynamic/thermal.mjs：セル中心の保存型FVM、直交2D格子、面の調和平均/接触抵抗、境界半セルの抵抗、顕式時間更新と正値/安定性検査。CPU倍精度。流体速度は解かない。
- dynamic/geometry.mjs：閉多角形の検証と格子中心の領域判定。曲面は階段状境界で、境界適合FEMと同等とは扱わない。形状を変える補修は明示し、自己交差/未解像の細部/非連結は拒否する。
- dynamic/worker.mjs：計算所有者。要求ID、取消、状態版、まとまった進行を分割してUIから独立。旧実験の遅れた応答を捨てる。
- dynamic/lab.mjs / index.html / lab.css：図、条件、時間操作、測定点、グラフ、2条件比較、3段階の説明。実験状態はメモリのみ。巻き戻しは保存状態の再生で、逆熱伝導ではない。
- 動的表示の追加と既存公式計算は独立して共存。単独ページの入口でapp.js/guide/翻訳との競合を抑える。

最初の公開候補は検証済みの熱伝導条件だけ。自由形状、フィン、放射連成、CFD、GPU等は個別の品質ゲートを通し、未実装/未検証と検証済みを分ける。自由形状を描けるだけで一般解析可能とはしない。CPUで教育用実験を成立させてからGPU経路を検証する。

## 検証計画

熱伝導：一様場/断熱、既知正弦モードの解析解、一定熱流束の全体収支、Dirichlet境界の定常線形分布、複合壁+接触抵抗の直列抵抗解、対流境界の半セル抵抗、格子/時間刻みの細分化。エネルギーはΣρcpV(T−T_ref)と累積境界熱/内部発熱を別計算して照合。残差（反復無し）と空間/時間の誤差を同一視しない。

フィン：軸方向FVM+側面対流とcosh解析解、基部流量と側面損失。放射：K、相反/総和、等温ゼロ、孤立二面収支。CFD：投影等を選定後、Poiseuilleとlid-driven cavity、自然対流は条件一致したde Vahl Davis型の文献値を取得して比較。文献値は推測しない。乱流は代表検証に限定。GPUは同じ条件のCPU解と比較。これら未実施項目はテスト成功と呼ばない。

格子と時間の収束は少なくとも3段階の解析誤差を比較し、保存誤差は浮動小数点の丸めと規模に応じて評価。形状誤差/物性近似と離散化誤差を区別。実機Safari/Android/支援技術は未実施で、Chromium/WebKitは代替試験として記録する。

## 共通化後の構成と限定流路

Experiment→Actor→Workerで時間/比較/履歴と非同期輸送、個々の物理計算を分離。thermal（k(T)/cp(T)を含む）、radiation-network、developed-channelの3モデル種別を選ぶ。発達流路は1D運動量＋周期2D温度で、一般CFDとは別。field-frameの物理縦横比、field-analysis/plotsの抽出と断面、trace-plot、term-panelを再利用する。入力パネル/可視化は単独ページとし既存20モード/翻訳データを変えない。dev/cavity.mjsは公開allowlist外、dev/channel.mjsは移動後のテスト互換re-exportのみ。各モデルの適用条件・独立検算は専用文書を参照。
