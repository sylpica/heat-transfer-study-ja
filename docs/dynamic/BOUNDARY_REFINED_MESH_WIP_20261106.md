# 境界係数を非負にするメッシュ分割：独立検証前

2026-11-06、基点c9911af。元の凸Delaunayメッシュを変更せず、別の開発factoryを追加した。PDE・GUI・公開へ未接続。負の境界cotangentを持つ区間へ実際の境界中点を追加して三角形を分割し、局所Delaunayを再構成する。係数を0へ切り捨てたり、元の節点を移動・削除したりしない。全境界係数非負が得られた場合だけ結果を返す。

600節点/1024要素、32分割段階、辺交換回数の上限を守る。鋭角等で収束・解像・予算を満たさなければ明示的に拒否し、一般的な終了保証を主張しない。物理座標が潰れる中点や最終要素も拒否。元の輪郭への距離/面積の丸め予算を守り、元の輪郭辺の位相IDを追加小辺へ引き継ぐ。境界小辺数は初期分割数とは別に記録する。

予備例：2×1矩形で初期分割1/2/4/8に対し、2/4/8/16点の境界追加、計7/17/49/161節点、6/20/72/272要素。標準P1演算子の負係数は0になった。ただし独立の幾何/物理座標演算子/PDE検証はまだ行っていない。

## 独立検証前の予算

- 元の全節点と角を保持し、全三角形/物理向き正、頂点/辺/要素の円板Euler関係、各輪郭辺の被覆を確認。正の面積を黙って削除しない。
- 独立のFraction幾何で全内部辺のDelaunay符号と全境界dot>=0を確認する。物理座標のP1基底勾配による全行列を独立組立し、全未知の非正off-diagonal/定数消去/アフィン熱収支を丸め範囲で照合する。
- 元輪郭の解析面積/辺長/法線モーメント/Gauss則、境界の位置誤差を照合し、4096EPS×面積または無次元長さの既存予算を維持する。回転矩形/三角形/多角形を複数分割で検査する。
- 既存メッシュとモデルの挙動は変えない。未完了/上限/未解像は拒否し、一般精度や全境界モデル対応と数えない。両ブラウザーで幾何互換を確認してから、別モデルへの接続と連続PDEの独立検証へ進める。
