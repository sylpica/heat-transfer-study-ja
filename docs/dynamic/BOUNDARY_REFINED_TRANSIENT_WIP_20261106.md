# 境界分割を伴う線形混合境界P1：接続後・独立検証前

2026-11-06、基点2690425。boundaryRefinement:trueを明示した場合だけ、幾何検証済みの別メッシュ生成を線形混合境界コアと回復factoryへ接続した。既定値/falseは元のメッシュと数値経路を保ち、負係数の拒否も維持する。GUIや公開へ未接続。

境界小辺数が初期分割数から増えることを、既知のgenerator・実区間数・追加節点/要素数とともに検査する。単に個数検査を外さず、元のメッシュでは従来どおり各辺n区間を要求する。新生成方式はモデル署名へ入れて異なる方式の復元を拒否する。回復も同じ生成方式から幾何を再構成し、既知境界熱を保つ。

予備例：2×1矩形・初期分割4・全断熱・体積発熱100、k15/ρ1000/cp1000/D.03で、49節点/72要素、25s後T300.0025K、源6W、蓄熱150J、収支差0。これは1例であり連続PDEの検証は未完了。従来の境界/過渡/回復13Nodeは成功。

## 独立検証前に固定する予算

- 旧メッシュ既定値とfalseの同一性、追加分割不要の正方形の温度軌道同一性を確認。新方式との署名/復元の区別、個数改ざん/上限/負係数を検査する。
- 2:1矩形の全断熱発熱と、底面入熱/上面Robin/側面断熱の線形定常場を手計算で照合する。一般凸多角形のアフィン初期場とそれに整合する各辺Neumann熱流束のpatch testも実施する。
- .4×.2m、回転.37rad、中心(.53,.47)、k15/ρ1000/cp1000/D.03、振幅50K、t200s、初期分割1/2/4/8。法線座標yのsin(πy/2H)（下側固定300K・他面断熱）とcos(μy/H)（上側h15/T∞300K、他面断熱、μtanμ=hH/k）について連続全P1場・熱・境界熱を独立積分し、最細RMS<.25K、境界熱相対差<2%、最終空間次数>1.5を目標とする。
- 別の物理座標P1 K/C/固定節点消去と重み付き行列指数へ固定格子を照合。初期分割4、dt2.5/1.25/.625sで最細最大時間差<.001K、最終時間次数1.8〜2.2。刻みが安全上限内であることを別に検査。
- 両ブラウザーの実Worker・復元・取消再開、追加分割方式を持つ回復の独立辺熱/状態不変、既存のGUI回帰を確認。未達は結果を残し、基準を緩めない。一般形状/境界の科学的承認は別工程。
