# 3次元直方体形態係数の放射ネットワークへの接続（2026-11-07、フェイリス並行実装）

検証済みの3次元形態係数核 `dynamic/dev/view-factor-3d.mjs`
（`createBoxViewFactors3D`）を、検証済みの過渡放射ネットワーク
`dynamic/radiation-network.mjs`（`createRadiationNetwork`）へ接続する
開発モジュール `dynamic/dev/box-radiation-3d.mjs`
（`createBoxRadiation3D`）を実装した。**両核の計算本体は変更していない**
（接続層とテストの追加のみ）。対象は軸平行な直方体エンクロージャー
（6面）に限定し、一般形状・曲面・開口・参加性媒体は対象外として
明示的に拒否する。開発専用（releaseApproved=false、公開 allowlist 外）
を維持する。

## API

`createBoxRadiation3D({dimensions, faces, integration?, maxTemperature?})`

- `dimensions`：直方体の内法 `{x, y, z}` [m]。核へそのまま渡す。
- `faces`：面の順序（核の定義どおり bottom, top, front, back, left,
  right）に6件。各面は `{temperature [K], emissivity, capacity [J/K],
  power [W]? , heatFlux [W/m²]?}`。外部入力は power か heatFlux の
  どちらか一方（heatFlux は核が計算した面積で power へ換算する）。
  面積と面IDは核の値を採用し、呼び出し側からは指定できない。
- 返り値は長ダクト接続（`createLongDuctRadiation`）と同じ形：
  `geometry`（形態係数核の結果＋接続診断）、`config`、`safeDt`、
  `time`、`snapshot()`、`step(dt)`、`restore(state)`。
  スナップショットには面ごとの正味放射熱流束 `faceOutwardFlux`
  [W/m²]（outwardPower ÷ 面積）を追加する。

## 受入管理（接続層の責務）

ネットワーク核は閉鎖系の受入条件として、素朴和による行和の1からの
ずれ ≦ 1e-12 と、相反則の相対残差 ≦ 1e-12 を要求する。一方、形態係数
核自身の保証は残差 1e-9 以下（未達は核が拒否）である。この隙間を接続層
が埋める：

- 接続層はネットワークと**同一の式**（素朴和・大きな方の交換面積で
  割る相反残差）で受入可否を事前に判定する。
- `integration` が未指定なら、核の解像度を既定 → (20, 32, 7) →
  (32, 48, 8) → (48, 64, 8) → (64, 64, 8) と段階的に上げ、最初に
  受入を満たした解像度を採用する（採用解像度と `resolutionEscalated`
  は geometry の diagnostics に記録する）。
- `integration` が指定された場合はその解像度を厳密に使い、受入未達なら
  拒否する（呼び出し側の指定を黙って変えない）。
- どの解像度でも受入に届かない形状は、実測残差を示して拒否する。
- **総和則による再正規化・クリッピングは一切しない**（両核の方針を
  維持）。受入判定に使う残差は geometry の
  `diagnostics.networkAdmission` に実測のまま残る。

実測（受入判定）：立方体・2×1×3・1×1000×1 は既定解像度で受入
（行和残差 1e-13 級以下）。扁平箱 1×1×0.001 は既定解像度では行和残差
2.92e-11 で受入未達となり、一段のエスカレーションで 1.92e-14 まで
解像して受入れた。

## 独立検証

参照生成 `scripts/dynamic-box-radiation-3d-reference.py`
（生成器の SHA-256 を参照 JSON に固定）は、製品コードと共有しない
独立経路で参照値を作る：形態係数は教科書 *A Heat Transfer Textbook*
6th ed. Table 10.3 の解析式（場合1：平行矩形、場合2：共通辺を持つ
垂直矩形）を mpmath 50桁で評価し（行和・相反則の自己検査誤差
1e-38 未満）、射度系 J_i = ε_i σT_i⁴ + (1−ε_i) Σ_j F_ij J_j を
mpmath の LU で解く。σ は製品と同じ 5.670374419e-8（SI厳密値）。

記録ケース（`docs/dynamic/BOX_RADIATION_3D_REFERENCE_20261107.json`）：

| ケース | 射度 J の最大相対差 | 照射 G | 正味出力 Q | 面間 pair |
|---|---|---|---|---|
| 灰色箱 2×1×3（T・ε は面ごとに異なる） | 3.0e-14 | 4.7e-14 | 3.6e-13 | 5.5e-13 |
| 黒体立方体（底面600 K、他300 K） | 9.9e-16 | 3.0e-15 | 1.2e-15 | 1.2e-15 |
| 灰色立方体＋再放射側面（ε=0） | 6.1e-16 | 1.0e-15 | 9.4e-13 | 9.1e-14 |

（相対差の分母は max(1, |参照値|)。再放射ケースの Q の差は側面の
参照値 0 に対する絶対差 9.4e-13 W が支配的。）

その他の検証（いずれもテスト `tests/dynamic-box-radiation-3d.test.mjs`）：

- **等温黒体立方体**：全表面 400 K・ε=1 で全ての面間交換・正味出力が
  厳密に 0、放射収支 0。
- **正準ケースとの整合**：接続層経由のスナップショットは、同じ形態
  係数・面条件を素の `createRadiationNetwork` へ直接与えた結果と
  全項目一致（deepEqual）し、接続層が数値的な偏差を加えないことを
  確認。ネットワーク核自体の正準2面ケース（3594.524305609565 W）は
  既存テストで固定済み。
- **2次元極限**：長さ L の箱（1×L×1）の側壁4面の単位長さ当たり
  正味出力を、長ダクト核（crossed-string）の正方形ダクト解と比較。
  相対差は L=20 → 100 で全壁とも単調に減少し（底面 1.01e-2 →
  2.05e-3、最も大きい右壁でも 1.29e-1 → 2.60e-2）、端面の影響が
  1/L で消えることを実測で確認。L=100 での端面への形態係数は
  2.50e-3。
- **過渡と収支**：灰色箱 2×1×3 を外部入力なしで safeDt 刻み 3000
  コマ進行。放射収支は各コマ |Σ Q| ≦ 1e-9 W、全体系のエネルギー
  保存は相対誤差 2.0e-14（テストでは 1e-12 未満を要求）、最終温度は
  熱容量重み付き平衡 2600/6 = 433.33… K へ広がり 4.8e-12 K まで
  一致。
- **復元**：巻き戻し→再進行でスナップショットが完全一致。破損した
  復元データ（時計・累積入力・蓄熱の不整合）は原子的に拒否し、
  状態は不変。
- **全反射箱**：ε=0 のみの閉鎖系は射度レベルが一意でないため、
  ネットワークが特異として拒否するか、物理的に正しいゼロ交換を
  返すかのどちらかであり、非ゼロの交換は返らない（立方体では
  特異検出で拒否、一般箱では右辺が厳密に 0 のためゼロ解）。

## 範囲と残件

- 対象外（拒否）：一般形状・曲面・開口・参加性媒体・面内伝導・
  面内の温度分布。面は等温・拡散・灰色・不透明のみ。
- GUI は未実装（開発モジュールの範囲）。公開ビルドの allowlist には
  含めていない（dist の dynamic エントリ数 47 は不変を別途確認）。
