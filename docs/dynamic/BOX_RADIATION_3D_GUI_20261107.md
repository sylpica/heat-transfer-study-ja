# 3次元直方体放射（形態係数＋ネットワーク接続）の開発画面（2026-11-07、フェイリス）

検証済みの接続モジュール `dynamic/dev/box-radiation-3d.mjs`
（`createBoxRadiation3D`、ブランチ `feiris/viewfactor3d-network`
b4cacd9 で接続済み）に対する開発画面を作成した。**接続モジュールと
両核（形態係数核・放射ネットワーク）の計算本体は一切変更していない**
（画面・画面用設定層・テスト・本記録の追加のみ）。画面は開発専用で、
公開ビルドの allowlist には入れていない。

## 作成ファイル

- `dynamic/dev/box-radiation-3d.html`：画面本体（共通CSS `cavity.css`
  ＋画面固有の最小限のスタイル）。
- `dynamic/dev/box-radiation-3d-ui.mjs`：入力収集・時間操作・履歴
  復元・表示。モデルのエラー文は `e.message` をそのまま表示する。
- `dynamic/dev/box-radiation-3d-ui-config.mjs`：DOM 非依存の設定層。
  面定義（核の順序 bottom/top/front/back/left/right）、プリセット、
  解像度選択肢、入力ビルダー `buildBoxRadiationInput`（接続モジュールが
  受けるキーだけを渡す）、1コマの細分 `frameSteps`。
- `dynamic/dev/box-radiation-3d-view.mjs`：各面を同じ大きさのタイルで
  示す模式図（SVG、面温度で色分け）。寸法比は数値表で確認する設計。
- `tests/dynamic-box-radiation-3d-gui.test.mjs`：画面用 Node テスト8件。
- `tests/dynamic-box-radiation-3d-browser.mjs`：Playwright 実ブラウザー
  テスト。

## 操作項目

- 検証済みプリセット：手入力／灰色箱 2×1×3（参照ケース）／等温黒体
  立方体／扁平箱 1×1×0.001（選択で即計算）。
- 寸法 x・y・z [m]、監視上限温度 [K]、形態係数の積分解像度
  （自動＝受入まで自動引上げ／明示：低・中・高・最高）。
- 6面それぞれの条件編集：温度 [K]、放射率、熱容量 [J/K]、外部入力
  （なし／power [W]／heatFlux [W/m²]）と値。
- 時間操作：1コマの物理時間、再生／一時停止／1コマ進める／1コマ
  戻す／時刻0へ戻す。1コマは安定刻み safeDt 以下へ自動で細分する。
  戻す・時刻0は接続モジュールのスナップショット復元を使う。
- 表示：面タイル図（温度で色分け）、各面の温度・射度・照射・正味
  放射 [W]・正味熱流束 [W/m²] の数値読み出しと表、放射収支 ΣQ、
  形態係数行列（6×6）と受入判定・熱収支の診断（折りたたみ）。
  一般的な説明・理論・適用限界は画面下部に集約した。

## 画面値とモジュールの一致確認（Chromium、実ブラウザー）

検証方法：画面の数値読み出し（面ごとの T・J・G・Q・q″ と ΣQ を
有効数字10桁で整形した文字列）が、Node 側で接続モジュールを直接
計算したスナップショットの同じ整形と**完全一致**することを照合した。

- 灰色箱プリセット：初期状態で完全一致。放射収支 |ΣQ| ≦ 1e-9 W。
  60 s の1コマ（safeDt=85.69 s のため細分1回）後も完全一致。
  1コマ戻す・時刻0へ戻すで初期の読み出しが正確に復帰する。
- 等温黒体プリセット：全6面の正味放射が 1e-12 以下、ΣQ は厳密に
  0（読み出しに「ΣQ = 0 W」と表示される）。
- 外部入力：下面へ power 100 W を与えた条件でも、画面とモジュール
  （ビルダー経由の入力）が完全一致する。
- 拒否表示：扁平箱＋明示の低解像度では、接続層の理由
  「指定された積分解像度では、形態係数の総和則・相反則を放射
  ネットワークの受入精度（1e-12）まで解像できません…」をそのまま
  表示し、受理済みの表示は不変。放射率 1.5 ではネットワーク核の
  理由「放射率は0〜1です。」をそのまま表示する。
- 扁平箱プリセット（自動解像度）は受入が自動引上げで成立し、
  画面の要約にも「解像度の自動引上げあり」と表示される。

## レイアウト確認

- 幅 375／390／1280／1920 px × ライト／ダーク（計8条件）で、文書の
  横はみ出しなし、読み出し・図の文字切れなし、pageerror 0件。
  390px ダークと 375px ライトのスクリーンショットを目視確認した
  （`work/boxrad-gui-chromium-390-dark.png`、同 `375-light.png`）。
- 作成過程で見つけて直した2件：(1) 長い選択肢を持つ select が
  fieldset の旧来の最小幅（min-content）にはまって 375px で文書が
  538px にはみ出した → `fieldset{min-width:0}` と、長い select を
  行全体の flex 行にして縮小可能にした。(2) 面タイルの SVG 文字が
  タイル幅を超えた → 実測（getComputedTextLength）に基づいて
  文字サイズと熱流束の短い指数表記（タイルのみ。読み出しは常時
  有効数字10桁）を調整し、最長でもタイル内幅 272 単位に対し
  250 単位に収めた。
- WebKit は本環境で起動できず未実施（MiniBrowser の起動失敗。
  従来ラインと同じ環境制約）。「両エンジン確認済み」とは記録しない。
