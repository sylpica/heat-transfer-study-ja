# 自然対流の開発用画面

2026-11-05。dynamic/dev/cavity.htmlからの開発検証用。一般公開のモデル・公開アプリの新メニューではなく、distからdevディレクトリ全体を除外する。公開承認やmainへのマージは行っていない。既存20モード、教材・問題・用語データは変更しない。

10 mm角の閉じた矩形内で、300 K近傍の空気のBoussinesq自然対流を計算する。ρ=1.177 kg/m³、cp=1006 J/(kg K)、k=0.0264 W/(m K)、ν=1.575×10⁻⁵ m²/sは既に参照した付録A.6（書籍755/PDF769）。α=k/(ρcp)、β=1/300 K⁻¹は理想気体近似。温度依存物性ではない。ΔT=10 K、浮力9.81/300 m/(s² K)、Ra=931.18873016、Pr=0.706400625。全壁静止/滑りなし、上下断熱、左右壁300±ΔT/2 K、初期300 K、奥行き1 mあたり。逆向きの浮力も扱う。既存のRa≤1000・Boussinesq・Pe・熱収支・発散停止条件を維持する。

格子は12/16/24/32、既定16。運動量conservative2、温度central、圧力MG-PCG、時間Euler。高次polynomial4の選択はこの画面に入れない。壁を急に加熱/冷却する初期のNuは半セル近似と格子に依存する（16格子では初期Nu=16）。連続体の有限の最大値とは扱わず、同じ正の時刻の比較が必要。ΔT=0のNuは未定義と表示する。

## 表示と操作

Workerの実計算から、セル温度・平均0のゲージ圧力・補間速度の大きさを色で表示。A/Bの共通色範囲、共通の速度矢印スケール、固定時刻の瞬間流線。流線はCFD_FIELD_INSPECTION.mdの補間/RK4で、粒子の時間軌跡ではない。クリック/矢印キーの測定点、物理時間の再生・一時停止・取消・コマ送り・戻し・時刻0、保存コマ、壁平均Nuの履歴、数値の収支/Poisson診断を備える。

条件をBへ固定後にAを変えられる。比較の開始/条件変更は両方を時刻0へ戻す。表示する条件は受理済みの結果に対応するものを別に保持する。初期化中に新しいconfigと古い2条件の結果を混ぜない。条件が未適用なら前回受理した結果と明示する。履歴はメモリー内のみ。回答・学習記録のlocalStorageへ書き込まない。

## Workerの共通化と公開側の保護

worker-runtime.mjsへ既存の取消/巻き戻し/進捗/時間上限/熱収支処理を移し、通常worker.mjsが従来4モデルだけを登録する。開発cavity-worker.mjsは別の固定URLでcavityだけを登録する。Actorは開発者が固定Worker URLを指定でき、既定URLと公開4モデルは従来どおり。コード文字列や製造解callbackを画面/Workerポートから受け入れない。公開側は共通runtimeをallowlistとAPP_SHELLへ追加し、公開ビルドが依存閉包を検査する。

履歴グラフの縦軸名は任意指定でき、従来画面は既定の「温度 [℃]」を保持する。開発画面のNuを温度として表示しない。幅変更でグラフを描き直し、390/412 pxの明暗両方で横はみ出しと文字の縮小を検査した。

キャッシュ移行試験は13b0d1eのworker/actor/trace/SWソースを使用し、その他の公開資産を固定した制御された旧版fixture。公開ビルドと同じpublicCacheName/pdfCacheName/stampServiceWorkerで版名を構成する。ソースのv12/v13を配信時のキャッシュ名と取り違えない。新runtimeをbytesで照合し、旧appキャッシュ削除、PDF用キャッシュ内の小さな検査データ保持、localStorage保持、更新後のオフラインWorker計算を両エンジンで確認した。32 MB PDFを再取得せず、実PDF全体の保存をこの試験の結果としては主張しない。WebKitはサーバー停止によるSW fallback、Chromiumはブラウザーofflineを利用した。
