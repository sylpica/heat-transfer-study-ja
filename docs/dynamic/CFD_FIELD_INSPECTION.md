# 開発用MAC速度場の補間と瞬間流線

2026-11-04、13b0d1e後続。dynamic/dev/cavity-fields.mjsは一般CFDと同じく公開allowlist外。新しい流体方程式を解くものではない。当初は画面へ未接続。2026-11-05にCFD_DEVELOPMENT_UI.mdの開発専用画面へ接続したが、一般公開ビルドには含めない。

セル中心へ一旦平均してから流線を作らず、u/vそれぞれのずれたMAC位置から各軸に線形補間する。壁から最寄りの半セルまでの接線速度は、実際の壁速度（上壁lidVelocity、他の壁0）と内部値から補間する。壁外へ外挿しない。移動壁と静止壁が接する上端の角は境界値が一意でないため、架空の速度を返さず拒否。配列の寸法/有限性/測定範囲を検査し、場を複製するので呼出し元の配列変更によって既存の表示場は変わらない。

流線はその物理時刻で固定した速度場の接線方向を、長さを独立変数とするRK4で積分する。入力stepLengthはm、出力lengthはm。粒子の時間積分や流跡線ではなく、速度場の時間変化を追っていない。線形の表示用補間の誤差と、元のPDE解の誤差は残る。

境界外へ出る中間点、よどみ、閉じた線、点数/長さの上限、浮動小数点で進めない場合に停止理由を返す。外側点を境界へ貼り付けて架空の線を足さない。正/逆方向を扱い、最大5000点。今後ブラウザー側では少数の始点から描き、過剰な積分で操作を止めない。

今回のNode 4試験：長方形格子上の線形場を正確に補間、境界値/異常値/元配列からの隔離、円形の解析速度場で刻み半減による半径誤差の低下、正逆方向、よどみ/境界/閉曲線/点数上限。すべて成功。円形場は補間と積分の数学的検査であり、閉キャビティの実在流体ケースとしては扱わない。実際のCFD場とブラウザー表示との整合性検査は次工程。
