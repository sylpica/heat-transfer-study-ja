# 流体側の全点・細格子検証：開始前の範囲と予算

2026-11-06、基点c68d3e5。P1表面境界の局所検証に続き、既存conservative2 MAC/多重格子のRe100/Ra1000だけを精細化する。Re400/1000、高Ra、自由形状/一般乱流へ未検証のまま範囲を広げない。

旧Ghia Re100の全17点u/17点vは32格子で最大差約.002041/.008421。旧4点uゲート.005をvへ転用して合格とはしない。今回の追加目標は64格子で全34点の各成分最大絶対差<.005（速度はlid速度1で正規化）。16/32の未達は保持する。時刻30だけを定常と決めつけず、5時間単位の全速度差<1e−8を確認し、最大時刻100までに未達なら保存して不合格とする。圧力/熱/質量の旧ゲートは維持。

自然対流は正方形Ra1000/Pr.71、16/32/64、t1。壁面Nu_0は1.117、体積/中央面Nuは1.118へ定義を対応させる。追加64格子の目標は壁面Nu絶対差<.002、局所最大Nu差<.01、中心線正のu/v最大値差各<.02。極値は区分線形MAC再構成のnative節点と壁から抽出し、参照位置差は1セル幅＋参照印刷.0005以内。最後の区間の変化も記録し、残差だけで全場精度と呼ばない。既にフェイリスからNuの格子値を受領しており、この追加計画を盲検とは呼ばない。

自然対流のt1値は保存し、最後の区間の全速度/温度変化が1e−8を超えた場合はt1.5/2まで延長して区別する。最大t2で定常条件を満たさなければ精度承認を保留。各格子/ケースを別実行・別ファイルへ保存し、長い実行の前に完了分をコミットする。

## Nuの読み取り専用診断

既存snapshot.nusselt/更新式は変えず、実FVの各垂直断面で伝導＋移流の熱、質量流量、Nuを読む別helperを追加する。左壁/中央面/体積平均を別ラベルにする。体積はnative面の台形積分、中央面はnative断面（奇数分割では隣接断面の線形補間）。移流は選んだcentral/upwindと同じ面温度を使う。温度基準を引くが、質量流量が0でないデータを基準に依存しないと偽らない。等温や固定両壁なしにはNuを偽装しない。

解析的な線形伝導場、正x方向/高低温反転、非零移流、断面質量/基準の相殺、不正状態と入力不変更を先に検査する。細格子の実測と独立検証が済んだ範囲だけを後でGUIへ接続する。保存則・全場MMS・文献中心線/極値の違いを保持し、正式公開や全CFD承認とは扱わない。raw提供表は再配布せず、own計算値/集約差/出典hashを保存する。

先行helperは3Node成功、旧キャビティ7件と合わせ10成功。偶数/奇数断面と温度反転の解析線形場、central/upwindの実数値流束、質量が相殺しない断面の基準依存、Nu未定義/不正状態と元モデル不変更を確認した。移流項は数値面フラックスであり、upwindの数値拡散を含み得る。定常FVでは断面熱が保存されるため3つの離散Nuが一致し得るが、原論文の有限格子推定値が同じ丸め値になることを保証しない。helper/細格子のGUI接続と全場精度は未完了。

専用driverはケース/格子を1個ずつ逐次実行し、5秒ごとと各評価時刻に再開用のown状態をignored workへ原子的に保存する。完成JSONは上書きせず別tagを要求する。途中再開はソースhash/条件/状態署名を照合する。各時刻の全速度/温度の変化と旧4点を含む全点集約差を保持し、64格子だけの追加目標と粗い格子の未達を分ける。数値基盤/精度ゲートを変更するdriverではない。実測前に保存し、未実行を成功とは記述しない。

## lidの粗い格子を新たに計算

ced5b91のdriverで16/32格子を別々に実行。両方t40で直前5時間単位の全速度差<1e−8となり、質量/熱の既存予算を満たした。16格子は全17点u/v最大差.01882547/.01390364で旧4点も未達。32格子は.00204098/.00842102でu/旧4点は.005内、vは未達。t30→40の全速度変化は1e−7未満まで減衰する一方で、vの.0084級の差は維持される。1e−8級の変化を浮動小数点の丸め級とは呼ばず、このv不一致を時間不足として閉じない。

結果とown全場はCFD_FINE_LID_N16_20261106_v1.json、同N32へ保存した。これは64格子目標の合格ではなく、粗い格子の未達を含む実測。64実行前に保存し、raw提供表は追加しない。
