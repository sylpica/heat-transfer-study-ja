# 離散運動エネルギーと圧力補正の診断

2026-11-05、6f8db09後続。開発専用の閉じた矩形MACモデルを読むだけの診断。cavity.mjsの運動方程式・時間更新・既定方式は変更しない。kinetic-energy.mjsと画面はdist外。科学的な連続圧力の精度は別の製造解/ベンチマークで確認する。

## 量と単位

MACの自由なu/v面速度に対してK=ρΔV Σ(u²+v²)/2 [J]を計算する。ΔV=ΔxΔy depth。閉境界の法線速度は0。境界にある法線速度の値はエネルギーへ寄与しない。このKは格子の離散内積であり、補間画像から推定した速度積分ではない。

セル圧力の勾配G、速度発散Dに対して、閉境界の離散部分積分は〈u,Gp〉=−〈Du,p〉。圧力仕事は−ΔVΣu Gp [W]とΔVΣp Du [W]を別々のループで評価し、その差も表示する。密度は圧力力を速度更新へ変換する際と質量の積で相殺され、この仕事率へ二重に掛けない。圧力に定数を加えても閉じた場の結果は変わらない。

最後の刻みΔtと保存された物理圧力からδu=Δt Gp/ρを求め、補正前の予測速度u*=u+δuを再構成する。K*−K=ρΔVΣ(u δu+|δu|²/2)。投影後にDu=0なら交差項は0で、減少量はρΔVΣ|δu|²/2≥0。直接の再構成とこの直交投影値との差、さらにセルのp Duを使う恒等式の差を残す。小さい残差を丸めて0へ置き換えない。

再構成した圧力補正の減少量を、物理的な粘性散逸とは呼ばない。動く壁や浮力の仕事・粘性散逸の全力学収支を、この圧力補正だけで承認しない。温度式は低速Boussinesqの近似で、粘性散逸や圧縮仕事を熱源へ戻していない。画面にEc=U²/(cp ΔT)も参考表示し、Uは表示セル中心の最大速度、ΔT=0は未定義とする。顕熱J、運動エネルギーJ、仕事率W、1回の補正Jを区別する。

## 読取りと状態保護

snapshotと受理済みの設定だけを読み、Worker/履歴/時刻/成績を変更しない。現在編集中で未適用のフォーム値は使わない。A/Bは別に算出し、巻き戻した状態の最後のΔt/圧力を用いる。診断の有限範囲を超えた場合は表示不可と示し、0のエネルギーを作らない。閉境界以外や不正な配列/密度/単位寸法を拒否する。

## 独立した検査

Node4件：2×2の手計算でΔV=1 m³、ρ=3、K=45 J、圧力仕事−9.5 W、補正減少1.9566667 Jと直交値.0566667 Jを確認。発散が0ではない例なので両者を無条件に等しいとは扱わない。圧力の定数移動と奥行きの比例も検査する。

実際のprojectFacesへ別の予測速度を与え、補正前後のKを独立に計算して減少量へ照合する。さらに離散curlから作る発散ゼロの場では、任意の圧力で仕事が0となることを確認。不正/開境界入力の拒否と呼出元データ不変更を検査する。

Chromium/WebKitの隔離した開発画面試験は、実Workerの0.1秒状態から別の直接和で求めたKへ表示値を照合。A/B、真の巻き戻し、浮力反転、取消/不正刻み、温度差0のKとEcの扱い、390/412/1280 pxと明暗、localStorage不変更を確認する。オフラインや実機の結果とは数えない。
