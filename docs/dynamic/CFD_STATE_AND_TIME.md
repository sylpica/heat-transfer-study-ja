# 開発用CFD：復元・時間収束・奥行き

対象は `dynamic/dev/cavity.mjs` の矩形閉容器のみ。一般向けの配信allowlistには追加しない。移動壁Re≤100・自然対流Ra≤1000等の制限を保持する。

## 受理済み状態の復元

`snapshot()` は速度面・セル温度/ゲージ圧力・物理時刻・ステップ数・直近刻み/熱入力・反復情報を保持し、`restore(snapshot)` で戻す。モデル、格子、物性、境界、解法設定と初期顕熱基準が同一であることをsignatureで確認する。専用製造解は後続の[PRESSURE_SENSITIVITY.md](PRESSURE_SENSITIVITY.md)で安定law IDと宣言パラメーターの照合も追加した。識別子なしの任意関数は同じインスタンス内の復元だけを受理する。任意の関数を復元データから実行しない。

配列長、有限値、正の絶対温度、時刻/回数、閉壁の法線速度、連続の式、圧力の平均ゼロ、顕熱/時間尺度の有限性、Boussinesq近似範囲を検査してからまとめて反映する。不正な復元では現在の場を変更しない。配列はコピーし、復元元の後変更を参照しない。圧力を再度正規化せず、受理済み状態からの次の計算を同じ丸め順で再現する。

Jacobi/多重格子の両方について移動壁・浮力・全場製造解の次の状態が全項目で一致することをNodeで検査。別モデルへの復元、破損した場、流入壁、非ゼロ発散/ゲージなどの拒否と原子性も確認した。署名は利用者認証や悪意あるデータへの暗号署名ではない。実験状態の恒久保存機能は追加していない。

圧力反復の停止だけでは連続の式を保証できないため、更新前にも `max|∇·u| ≤ 1e−8 max(1 s⁻¹, |u|max/min(L,H), |v|max/min(L,H), |Uwall|/min(L,H))` を確認する。意図的に緩い圧力許容値では残差基準を通っても、この検査で状態を更新せず停止する。製造解の離散化誤差や物理モデルの正しさを保証する検査ではない。

## 奥行きと熱収支

奥行きは既定1 m、正の有限値のみ。2D場に一様な奥行きとして、セル熱容量・内部面/壁の熱移動率・体積発熱を同じ係数で換算する。奥行き方向の速度、温度勾配、横壁の損失は追加しない。0.2 mと1 mで場が一致し、顕熱/熱入力が0.2倍になることを検査した。顕熱は273.15 K基準。粘性散逸や機械仕事まで含む全エネルギー保存とは呼ばない。

## 独立した時間細分化

`node scripts/dynamic-cavity-time-benchmarks.mjs --full`。格子32²と最終時刻0.025 sを固定し、256/512/1024/2048ステップ（Δt、Δt/2、Δt/4、Δt/8）で全場を計算する。**空間誤差の混じる連続解との差ではなく、同じ格子上の隣接刻みの差**のRMS/最大値を記録する。圧力は各計算の直近の投影が返す同じ平均ゼロゲージを比較する。

`CFD_TEMPORAL_BENCHMARKS_20261104.json` の観測次数は速度1.0020→1.0010、圧力1.0010→1.0005、温度1.0005→1.0003。陽的Eulerと分離更新の約1次の自己収束を確認した。これは独立な半離散厳密解を用いた時間誤差評価ではなく、時空間誤差の厳密な加法分離でもない。圧力の約6.85%の連続場誤差が解決したとは扱わない。32²の4計算はクラウドCPU約24秒、実機性能ではない。

結果は保存前ツリーの測定で、基点a49ceb6、sourceTreeDirty=trueとソースSHA-256を保持。Nodeには小さい固定格子で同じ時間自己収束を追加。CIでもCLIを実行する。

## 保存済みソースのCI再現

`CFD_CLEAN_CI_A49CEB6_20261104.json` は [CI 41868021403](https://github.com/sylpica/heat-transfer-study-ja/actions/runs/41868021403) の完了ログから、数値を変えず4結果を抽出したもの。a49ceb6のJacobi/多重格子それぞれの標準キャビティと16/32/64全場製造解。製造解のsourceTreeDirty=false、ファイルSHA-256と保存Gitソースの一致を照合した。artifact取得が環境側403のため完了ジョブログを用いた。過去の未保存測定は履歴として保持する。同SHAのNode/公開ビルド・Chromium/WebKitの3動的画面も成功。今回の復元/時間収束差分を同CIで検証済みとはしない。

一般CFDの公開承認、圧力の精度改善、他境界/自由形状、原文一次文献、専門家・実機検査は残る。
