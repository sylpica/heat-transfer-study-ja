# 有限厚固体壁＋指定発達流：限定した共役温度モデルの事前計画

2026-11-07（Asia/Tokyo）、平板GUI 22a8612保存後。Q11/48とPhase3強制対流/Phase4連成の残量に対して、まずdevの別コアを作る。フェイリスの定常Graetz/CWT（壁温/熱流束を指定する流体のみ、別ブランチ）とは別で、有限厚固体の温度・蓄熱も時間発展させ、界面の同一熱を固体損失/流体入力へ等大逆向きに使う。

## 限定モデル

2Dの平行平板。両側に同じ厚さ・一定物性の固体、間に一定物性流体。定常Poiseuille速度を指定、流体のx移流＋y伝導と、固体のx/y伝導を計算する。流体x伝導・非定常運動量・浮力・粘性仕事・形状変化・側壁・3D・乱流は省略。Re_Dh≤1000、Pe_Dh≥100、L/H≥5。流体入口は指定行平均T、出口は対流流出、固体左右端は断熱。外側上下は指定の内向き熱流束。接触抵抗R''≥0を両界面に設定可能。完全接触はR''=0だが格子中心間の伝導抵抗は残す。

同じx格子で下固体/流体/上固体の3層セル中心FV。y界面のG=A/(dy1/(2k1)+R''+dy2/(2k2))、固体xのG=kA/dx。同一の界面熱を両セルへ逆符号で適用し、hを別入力して熱を二重計上しない。指定の空間セル平均体積源も受け付ける。流速は行平均Poiseuille、風上移流、SSPRK2、非負係数から全領域の安定上限を決める。

基準温度からの保持θ、固体/流体/全体の蓄熱、外側上下/体積源（固体・流体）/入口/出口/2界面の積算熱、正味外部熱を別管理。界面は内部熱で全系正味に含めない。絶対温度・有限値・全成分と3収支・時計を受理前に検査し、不正step/restoreで旧状態を変えない。内部未知の平均温度・熱・右辺を補正して収支を作らない。公開allowlist/SWに追加せずreleaseApproved=false。

## 実行前の検証予算

1. 等温＋源/外熱0で温度/熱0を保つ。任意の有限界面温度差で界面熱の固体/流体作用が等大逆向き。未知キー/無効物性/格子/監視温度/上限刻みをloud拒否。負の外熱を冷却として保持。
2. 一定上向きqの連続3層線形場を手計算する。流体の入口にも同じ横断場を与えると移流項0、固体x伝導0。外熱は下+q/上−q。完全接触/有限接触の両方で温度差・界面温度ジャンプqR''・各界面総熱qLDを確認。固定点温度ドリフト<1e−10 K、界面熱相対差<1e−10。これは連続線形場の検証で、任意共役場の空間精度とは呼ばない。
3. 独立Pythonで物理寸法・各材料K/C・入口/源/外熱・接触Rから疎行列を別組立し、9熱積算行を含むアフィン指数と照合。非一様初期/入口/源/外熱を含める。固定16×(2+8+2)、t=.5 s、safeDtの1/.5/.25/.125/.0625の5水準。最細の全セル最大差<.001 K、全積算成分最大差<1e−4 J、最後の時間次数1.8〜2.2、全ケースの3領域収支が丸め予算内。JS作用素/SSPRK2を参照へ流用しない。
4. 連続製造定常場T=300+2 cos(πx/L) f(y)も別段階で検証する。fは材料ごとの熱抵抗座標で線形、接触面で指定ジャンプを持つ。固体x/yと流体移流/yに対応する既知体積源、外側熱と流体入口を独立積分。8/16/32/64のx/横断格子系列でセル平均の体積重みRMS<.15 K（最細）・最終次数>.7を要求する。別疎行列定常解に加え製品ソルバーの同じ状態の残差/時間発展も区別して記録。非一様場の検証が終わるまで一般空間精度済みとしない。
5. 数値段階後に専用Workerの実復元/取消/不正初期化、両ブラウザー、限定GUIを接続。GUI前に数値結果をコミットし、外部専門家/実機/専用オフライン/実公開/全Phase3・4完成は別に残す。
