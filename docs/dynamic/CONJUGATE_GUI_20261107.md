# 自然対流・共役（加熱体）モデルの画面（GUI）：記録

2026-11-07（Asia/Tokyo）。ブランチ `feiris/conjugate-gui`（基点＝共役モジュール先端
221cb53）。検証済みの共役モデル `dynamic/dev/conjugate-cavity.mjs`（記録：
CONJUGATE_MODEL_JS_20261107.md）を画面で操作できるようにする。モデル本体は
変更していない（本ブランチの差分に conjugate-cavity.mjs は含まれない）。

## 作成物

- `dynamic/dev/conjugate-cavity.html`：開発画面。cavity.css を共有し、
  ページ内 style でモバイル幅のはみ出し対策（後記）だけを足す。
- `dynamic/dev/conjugate-cavity-ui-config.mjs`：純粋ヘルパー。検証済み
  プリセット5件（主ケース／伝導のみ／固体発熱／固体支配／等温壁極限）、
  入力ビルダー（モジュールが受けるキーちょうど7個をそのまま渡す）、
  表示温度範囲、前進ヘルパー `advanceModelBy`（モジュールの runToSteady と
  同じ刻み規則）、定常判定ヘルパー `intervalChanges`（モジュールと同じ基準）。
- `dynamic/dev/conjugate-cavity-ui.mjs`：DOM 配線。履歴フレーム方式
  （再生／一時停止・計算取消／1コマ進める／1コマ戻す／時刻0へ戻す／
  定常まで進める）。前進は約25ステップごとに制御を返し、ページを固めない。
- `dynamic/dev/conjugate-cavity-view.mjs`：固体＋流体を1つの場として
  実形状（固体 x∈[−0.25, 0]、流体 x∈[0, 1]）で描く。界面位置に線を引く。
- `tests/dynamic-conjugate-cavity-gui.test.mjs`：Node テスト6件。
- `tests/dynamic-conjugate-cavity-browser.mjs`：Chromium 実測スクリプト
  （node --test の対象外。cylinder 画面の同名スクリプトと同じ作法）。

## 画面構成

- 条件：プリセット、格子数 n（16／24／32）、Ra、Pr、熱伝導率比 K、
  体積熱容量比 C、固体の体積発熱 S、初期無次元温度 θ0。モジュールの
  主要パラメータはすべて画面から与えられる。δ=0.25 はモジュールの
  固定仕様として条件欄と注意書きに明示した。
- 時間操作：1コマの無次元時間 Δτ（既定0.1）、再生、一時停止・計算取消、
  1コマ進める、1コマ戻す、時刻0へ戻す、定常まで進める、無次元時刻表示。
  定常の探索は Δτ=0.1 区間ごとに `intervalChanges` が連続2区間
  合格するまで進め、上限はモジュールの既定と同じ τ=40。
- 表示：温度場（固体＋流体を1つの場）、界面熱 Q（瞬間・高さ平均）、
  界面平均温度（最小／最大つき）、固体・流体の平均温度、背面熱・
  冷壁熱・発熱（瞬間）。診断（details 内）：法則と releaseApproved、
  ステップ数・刻み・safeDt、発散、最大面速度、最大セルPe、圧力投影の
  反復、蓄熱3種、積算熱4種、収支誤差3種と相対最大、実効熱伝達比と Bi_s。
  説明文は画面下部（details）に置いた。
- 拒否：モジュールの拒否理由は画面側で書き換えず、そのまま日本語で
  表示する（例：Ra=2000 → 「共役キャビティの検証範囲はRa≤1000です。」）。
  失敗した適用では、直前に受理された状態が画面に残る。
- 計算量：既定格子は16。1コマ（Δτ=0.1）は Node 実測で366ステップ・
  約3.5秒、定常探索の全行程は Chromium 実測で約45〜70秒。格子32は
  1コマに数十秒かかる旨を画面に明示した。

## 検証実測

### Node スイート
- GUI テスト新規6件：全合格。内容は、HTML 配線と公開ビルド
  allowlist 非混入、入力ビルダーのキー集合と数値検証、プリセット
  5件すべてのモジュール受理と拒否の素通り（Ra=2000・θ0=2）、
  表示範囲、主ケース τ=0.1 の実測アンカー（界面熱 0.548530400268694、
  界面平均温度 0.6174993519840419、最大面速度 2.314465339142153 と
  1e-12 級で一致）、定常判定ヘルパーの基準どおりの合格／不合格。
- 全 Node スイート：1,685 件 = 1,680 合格 / 0 失敗 / 5 スキップ
  （基点 1,679 = 1,674/0/5 から新規6件増、失敗0を維持）。
  注記：全スイートの実行後に加えた変更は conjugate-cavity.html の
  ページ内 style と class 属性のみで、そのファイルを参照する
  スイート成員は GUI テストだけであることを grep で確認し、
  GUI テストは最終形で再実行して6件全合格を得た。

### 公開ビルド・dist
- 公開ビルド成功。dist は基点クローンの dist とバイト単位で同一
  （diff -rq で差分0）。日本語節76件、dynamic 47エントリ、
  conjugate の混入0件（grep 0件）。

### Chromium 実レンダリング（tests/dynamic-conjugate-cavity-browser.mjs）
- 主ケース τ=0.1：画面の界面熱・界面平均温度・固体平均温度・
  流体平均温度が、Node で計算したモジュール値と表示桁（10桁）
  まで一致（許容 1e-9 以内）。
- 戻す／進める／時刻0へ戻す：初期フレーム（界面熱0）を正確に復元。
- 拒否表示：Ra=2000 でモジュールの理由がそのまま表示され、
  既存の状態が保持されること。空欄フィールドではビルダーの
  「数値ではありません」が表示されること（フォームの required に
  よる送信阻止を外して到達）。
- 定常探索：主ケースで τ=2.7 に定常到達（モジュールの記録と同じ
  到達時刻）。画面の定常値は界面熱 0.6964472716、界面平均温度
  0.6517763914 で、記録値 0.6964472716362966／0.6517763913916443 と
  1e-6 以内で整合し、表示10桁はすべて一致した。診断の収支相対
  最大誤差は 1e-10 台（丸め誤差級）であることも確認した。
- 追加の実操作（使い捨てスクリプトで実施）：再生で時刻が進み、
  一時停止で進行中フレームが取り消されて時刻が止まること。
  格子32（Δτ=0.01）でも受理され前進すること。pageerror は全行程0。

### レイアウト（幅 375／390／1280／1920 × ライト／ダーク）
- 初回測定で 375px・390px に横はみ出しを検出し、2件修正した。
  (1) fieldset の min-content 幅（最長プリセット選択肢の select が
  原因）：ページ内 style で `fieldset{min-width:0}` と、放射GUIの
  前例に倣いプリセット行へ `.wide`（select を flex で縮小可能に）。
  (2) 詳細段落内の長い英字トークン（記録ファイル名など）：
  `p{overflow-wrap:anywhere}`。
- 修正後の再測定：8組合せすべてで横はみ出し0、操作要素の
  文字切れ0、canvas のはみ出し0、pageerror 0。
  1280px と 375px のスクリーンショットを目視し、温度場（固体の
  勾配と流体の発達、界面の線）と操作系の配置を確認した。
