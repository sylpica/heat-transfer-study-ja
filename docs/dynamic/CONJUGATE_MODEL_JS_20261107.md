# 自然対流・共役（加熱体）モデルの本線 dev 実装：記録

2026-11-07（Asia/Tokyo）。ブランチ `feiris/conjugate-model-js`（基点＝統合先端 34b84ad）。
Codex サポート依頼2（`codex/support-natconv-conjugate` @cc932b7）が Python で検証した
「有限厚固体壁＋閉キャビティの双方向共役」を、本線の既存基盤の系譜で JS の dev モジュール
`dynamic/dev/conjugate-cavity.mjs` として実装し、Codex 記録値と突き合わせる。
公開側の受入範囲（既存キャビティ Ra≤1000 等）は変更しない。GUI は本作業の範囲外。

## 物理と定式化（Codex FORMULATION.md と同一）

- 固体 Ωs：−d<x<0、0<y<H（δ=d/H=0.25）。流体 Ωf：0<x<H、0<y<H の閉正方形。
- 固体背面 x=−d は θ=1、流体右壁 x=H は θ=0、上下は断熱、流体は全壁 no-slip。
- 界面 x=0 は接触抵抗0で温度・法線熱流が連続。固体だけに一様体積発熱 S を任意に与える。
- 無次元化：θ=(T−Tc)/(Th−Tc)、長さ H、時間 H²/αf、速度 αf/H。
  固体 `C ∂τθs=K∇²θs+S`、流体温度 `∂τθf+U·∇θf=∇²θf`、
  運動量 `∂τU+U·∇U=−∇Π+Pr∇²U+Ra·Pr(θf−.5)e_y`。
  主条件は Ra_nom=1000、Pr=0.71、K=ks/kf=0.5、C=(ρcp)s/(ρcp)f=2、δ=0.25、S=0。
- Ra_nom は背面温度差基準であり、非一様な界面温度の主ケースを等温壁の de Vahl Davis
  条件そのものとは扱わない（Codex の線引きを継承）。

## 離散化（本線基盤への対応）

- 温度：全領域セル中心 FVM。流体 n×n＋固体 (n/4)×n、Δx=Δy=1/n。
  面コンダクタンスは半セルの直列抵抗（調和型）で、界面でも独立の h を挿入せず、
  同じ界面熱を固体から差し引き流体へ加える（Codex FVM と同じ構成）。
  背面・冷壁は半セルコンダクタンス 2K・2。固体源はセル当たり S/n²。
- 流体温度の移流：保存形中心差分（Codex と同じ）。セル Pe≤2 を監視し、超えたら受理しない。
- 運動量：MAC 保存形2次（本線 cavity.mjs の conservative2 と同じ系譜。隅 uv の扱いは
  Codex プロトタイプの隅差分形を採る）、浮力は v 面で流体セル温度の平均。
- 圧力投影：流体格子の Neumann グラフラプラシアン（本線 cavity.mjs の projectFaces と
  同じ作用素・同じ零平均ゲージ・許容 1e-10）に対し、多重格子 V サイクルによる
  欠陥修正反復（毎サイクル真の残差で収束判定）をモジュール内の型付き配列実装で
  行う。本線共有実装は実測で 46ms/回（n=16）と全過渡の検証が不可能な速度だった
  ため、作用素と収束条件を変えずに実装だけを替えた（PCG 駆動で停滞・破綻が
  実測された経緯を含む詳細は実測結果に記録）。Codex の DCT 直接解との違いは
  反復解法の差であり、投影後の発散で監視する。
- 時間：全未知 SSPRK2（Heun）。段ごとに投影し、圧力は段平均を保存する。
  刻みは Codex と同じ規則：min(0.35/最大対角率, min(0.12/n², 0.2/(2n·最大速度)))。
- 熱収支：背面・冷壁・体積源・界面の4積算を段の台形則＋Kahan 補償で積分し、
  固体/流体/全体の3収支を毎ステップ監視する（尺度は実蓄熱・積算の和、床なし）。

## 定常判定（Codex run_case.py と同じ）

Δτ=0.1 ごとに、全温度の最大変化 <1e-7、全速度の相対変化 <1e-6、
界面熱の相対変化 <1e-6 を、連続2区間満たしたら定常とする。
16格子は冷スタート（θ=0.5 一様・静止）、32/64 は自方式の粗格子定常場を補間して初期化し、
同じ定常基準まで再計算する（暖スタートを冷スタートの検証へ再計数しない）。

## 受理基準（測定前に固定。後付けで緩めない）

Codex の事前予算（PLAN.md）と FVM/P1 間差の実測を根拠に、測定前に次を固定する。

### A. Ra=0 解析伝導
- A1（S=0、K=0.01/0.5/10、n=16）：解析の区分線形セル平均場で温度 RHS の最大残差 ≤1e-9。
  時間発展で到達した定常の界面熱が解析 Q=1/(1+δ/K) と相対差 ≤1e-6。
- A2（S=1、K=0.5）：界面熱の解析値 Q=17/24 へ相対差 ≤1e-5 で到達。
  温度の正確なセル平均との RMS 差が 16→32→64 で単調減少し、64 で ≤2e-3
  （Codex の事前予算は最細 <.002、FVM 実測 3.64e-5）。

### B. 等温壁極限（n=16、Ra=1000、C=K/8）
- B1（K=256）：|界面平均温度 − 0.99890144| ≤2e-3（Codex 共役値 1−0.00109856）。
  あわせて 1−界面平均温度 ≤0.005（Codex の事前目標）。
- B2（K=16）：|界面平均温度 − 0.9827421514| ≤3e-3。

### C. 固体支配（Ra=1000、K=C=0.01、n=16）
- C1：界面熱が Codex 記録 0.0384619642 と相対差 ≤0.1%。
- C2：固体の平均温度降下が全体の 95% 以上（Codex 実測 96.1549%）。

### D. 主ケース（Ra=1000、Pr=0.71、K=0.5、C=2、S=0、定常）
Codex FVM 記録：界面熱 16:0.6964472716 / 32:0.6948715158 / 64:0.6944727170、
界面平均温度 16:0.6517763914 / 32:0.6525642190 / 64:0.6527636161、
最大面速度 16:2.4952162624 / 32:2.4928453175 / 64:2.4923150880。
- D1：界面熱の相対差 ≤0.5%（16）/ ≤0.2%（32）/ ≤0.1%（64）。
- D2：界面平均温度の絶対差 ≤2e-3（16）/ ≤1e-3（32）/ ≤5e-4（64）。
- D3：最大面速度の相対差 ≤1%（16）/ ≤0.5%（32）/ ≤0.5%（64）。
- D4：自方式の界面熱が格子細分で単調に近づく（|Q32−Q64| < |Q16−Q32|）。
- D5（場の照合、検証スクリプトで実施）：64格子の温度場と Codex FVM 保存場との
  RMS 差が固体・流体とも ≤1e-3（参考：FVM/P1 間は固体 7.82e-6・流体 3.35e-5）。

### E. 熱収支・不変条件（全ケース）
- E1：3収支の相対誤差 ≤1e-9（Codex の基準と同じ。尺度に床を置かない）。
- E2：Ra=0 では速度が全時刻で厳密に 0。閉壁の法線速度は厳密に 0。
  投影後の発散は 1e-8 以下（物理発散、無次元）。
- E3：温度が監視範囲 [−1e-9, 1+S(δ+δ²/(2K))+1e-9] を出る候補は受理せず、
  例外時に受理済み状態は不変。

## 実測結果

検証ドライバ：`scripts/dynamic-conjugate-cavity-verify.mjs`（ケース別に実行し、
定常シークは凍結流れの熱前進＋短い結合ブロックで行い、定常の宣言は必ずモジュール
自身の結合 runToSteady 基準（Codex プロトコル）通過後に限る）。
単体テスト：`tests/dynamic-conjugate-cavity.test.mjs`。

### 圧力投影の実装経緯（実測に基づく変更）

- 本線共有の projectFaces は n=16 で 46ms/回（PCG 9反復）と実測され、全過渡の
  検証が不可能だった。作用素（Neumann グラフラプラシアン）・零平均ゲージ・相対
  許容 1e-10 を同一に保ち、型付き配列の幾何多重格子に実装を替えた。
- 当初 PCG 駆動では、再帰残差のドリフトにより相対残差 1e-10 近傍で停滞・破綻が
  実測されたため、欠陥修正（Vサイクル反復、毎回真の残差で判定）に替えた。
  V(2,1) の非対称サイクルは停滞し、V(2,2) 対称サイクルで全合成右辺に収束した。
- 実測速度（同一 VM、参考値）：結合ステップ 11.3ms（n=16）/ 約40〜60ms（n=32, 64）、
  熱のみステップ 0.77ms / 1.68ms / 約7〜15ms。投影の発散は全ケースで 1.4e-11 以下。

### A. Ra=0 解析伝導

- A1 残差（n=16、正確なセル平均場での温度 RHS 最大値）：K=0.01 で 8.88e-16、
  K=0.5 で 2.84e-14、K=10 で 2.84e-14。基準 ≤1e-9 を満たす。界面熱は解析値と
  相対差 9.0e-16 / 1.8e-15 / 2.7e-15。
- A1 行進（K=0.5、冷スタート）：定常 t=2.2（8,052 ステップ）、界面熱の相対誤差
  1.59e-7（基準 ≤1e-6）。熱収支相対誤差 1.97e-16。
- A2（S=1、K=0.5）：界面熱の解析値 17/24 への相対誤差は行進定常で
  16: 1.71e-7 / 32: 1.20e-7 / 64: 1.20e-7（基準 ≤1e-5）。
  正確なセル平均との RMS 差：16: 5.823e-4 / 32: 1.456e-4 / 64: 3.641e-5

  64 で 3.63943e-5（本実装 3.64117e-5）とほぼ一致する。
  64 は 32 の自方式定常場からの暖スタートで t=1.7・99,484 ステップで定常。

## 残件・範囲外

- 流体内の孤立加熱体・障害物、他厚さ（δ≠0.25）、接触抵抗、変物性、他 Pr の体系検証、
  Ra>1000 との共役、3次元・放射・相変化は本モジュールの検証範囲外。
- GUI・Worker 化は今回の範囲外（モジュールと検証まで）。
- 運動量/投影は本線基盤と共通であり、完全に独立した別 CFD ソルバーによる承認ではない
  （Codex 側も運動量/DCT を FVM/P1 で共有していた。独立性は熱離散化と投影解法の差にある）。
