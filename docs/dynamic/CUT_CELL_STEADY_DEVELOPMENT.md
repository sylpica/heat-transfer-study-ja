## 保存則と未知温度の解き方

セルiの定常式は、外向きの全面熱移動率の和 = qvol_i V_i [W]。V_i=A_i D、qvol [W/m³]、k [W/(m K)]。壁片平均温度は geometry.wallFragments 順、熱源は一定値または全セル順の配列とし、未知セル温度の厳密値は入力しない。

既存の数値配列流束APIを、ゼロ場と実際の単位基底で評価して全体演算子Aと壁寄与bを組み立て、A θ=qvol V−bを解く。`twoPoint` と `corrected` は同じ条件を用いる。温度基準は最初の壁温度とし、温度差θを保持する。任意の遠い基準値を渡して微小な温度差を失わせるAPIは提供しない。

線形解法は行ごとの正規化と部分ピボット付きGaussian消去。有限値、ピボット、相対後退誤差、面流束へ戻した各セル/全境界の熱収支を検査する。丸め予算は実際の係数×温度差と境界/熱源のスケールから作り、一律1 Wの下限を入れない。正の絶対温度への復元も検査し、微小なθが絶対温度への加算で失われる件数/丸め差を明示する。熱収支を丸めた絶対温度から再計算しない。

条件数はこの実装のピボット/後退誤差だけでは保証しない。最大セル数は密行列の開発範囲であり、一般形状に対する解析保証ではない。

## 独立した解析解と線形代数

`scripts/dynamic-cut-cell-steady-reference.py` を実行し、`CUT_CELL_STEADY_REFERENCE_20261106.json` に結果を保存した。参照は独自の製造解 T=310−x²−y² K、qvol=4k=60 W/m³、k=15、D=.03 m。0.4×0.2 mの矩形を角度.37 rad回転し、中心(.53,.47)に置く。

Python Fractionで各クリップ頂点を正確な二進有理数として扱い、三角形の多項式積分からセル平均、線分積分から壁片平均を求める。重心評価や壁中点の点値を二次関数の平均と混同しない。製品側の勾配/モーメント/温度解を参照値生成に使わない。ただしクリップ頂点は製品側の幾何から取得しており、幾何そのものの独立検査は既存の幾何試験で行う。

さらに輸出した離散行列にSciPyの汎用LAPACK solve/eigvals、NumPyのSVD条件数を適用した。これは別の線形解法との照合であり、独立した第二のPDE離散化ではない。単独運用に合わせてBLASも1スレッドに固定した。

## 単調性が成立しない具体例

補正行列は非対称で、正の非対角成分を持つ。12×12のセル68/56に A_68,56=.4993695086 W/K がある。壁と他セルの温度差を0、セル56だけ+1 Kとすると、セル68の外向き熱移動率が正となり、その初期温度差の時間微分は負となる。容量密度を1 J/(m³ K)に正規化し行和から選んだ正の試行刻みでは、セル68のEuler代数値は−3.676833e−5 Kになる。

これは時間ソルバーを実装して承認した結果ではなく、演算子の最大・最小原理を破る反例である。刻みを小さくするだけで符号の問題を解消することはできない。最細格子では容量正規化拡散行列に虚部約46.71 s⁻¹を持つ固有値も観測した。4個の有限行列の固有値の実部が正だったことを、一般形状の安定性・正値性・非対称性の解消へ転用しない。

補正方式の時間発展接続は保留する。次の自由形状過渡解析には、保存と単調性を検査できる離散化/制限処理、小セルの扱い、独立過渡参照が必要。既存2点法の単調性と今回の空間誤差も別に扱う。
