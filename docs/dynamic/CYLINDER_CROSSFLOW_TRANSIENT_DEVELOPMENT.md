# 円柱横流れの動的（過渡）モデル（2026-11-07、フェイリス並行実装）

Phase 3「強制対流」分野の残項目（円柱の動的モデル）への対応。流れに置かれた
固体円柱が加熱・冷却される過渡を解く開発専用モジュール
`dynamic/dev/cylinder-crossflow-transient.mjs` を新設した。既存資産の結合で
あり、新しいソルバーは書いていない：

- 円柱内部の放射方向非定常伝導：本線の `dynamic/radial.mjs`
  （`createRadial`、geometry='cylinder'、セル中心有限体積＋陽的進行、
  表面は半セル伝導抵抗と対流の直列抵抗で処理）を無変更で使用。
- 表面の熱伝達率 h：風速→h推定モジュール
  `dynamic/dev/wind-heat-transfer.mjs`（フェイリス側 feiris/fin-wind-h
  adaa7ff から SHA-256 d631f47b… でハッシュ一致取り込み。教科書§7.6の
  相関で検証済み）による推定、または直接指定のどちらか一方。
- 本モジュールは条件の検証・hの決定・放射モデルの生成と、平均温度等の
  診断量の付与だけを行う薄い結合層である。

開発専用（releaseApproved=false、公開 allowlist 外）を維持する。GUIは
今回の範囲外。

## 設計上の仮定（モジュール冒頭にも明記）

- 固体：固体円柱、一定物性（k・ρ・cp）、発熱なし、軸方向・角度方向の
  温度変化なし。熱交換は側面のみで、端面は解かない（面積は与えた長さに
  対する 2πRL）。
- 流れ：一様・一定温度の自由流。h は教科書§7.6相関の周方向平均値で、
  表面一様・時間一定とする。局所 h の周方向分布（よどみ点〜剥離・後流）
  と流れ場そのものは解かない。
- 物性は膜温度での利用者供給値で固定し、h は過渡の間一定に保つ。膜温度の
  表面温度は flow.filmSurfaceTemperature（省略時は固体の初期温度）で
  評価する（h の値自体は供給物性から決まり、表面温度は膜温度の記録に
  のみ効くのは風速→hモジュールと同じ流儀）。
- Bi の開発範囲上限：Bi=hR/k ≤ 10。Bi が大きいと局所 h の周方向非一様が
  内部の角度方向温度分布として現れ、「1次元放射＋周方向平均 h」の前提が
  崩れるため、上限を超える条件は理由を表示して拒否する。これは教科書の
  限界ではなく本モデルの適用上限として明示したものである。
- 対象外：放射、浮力・混合対流、温度依存物性、相変化、粗さ、管群。

## 検証（実測、tests/dynamic-cylinder-crossflow-transient.test.mjs）

参照値は独立生成器 `scripts/dynamic-cylinder-crossflow-reference.py`
（生成器 SHA-256 をテストで固定）による
`docs/dynamic/CYLINDER_CROSSFLOW_REFERENCE_20261107.json`。

1. **h の一致**：例題7.8の順方向評価条件（ν=1.602e-5、k_f=0.0265、
   Pr=0.712、D=0.1 mm、U=73.2114 m/s）で、モジュールの h =
   2833.9817356038657 W/(m²K) が風速→h側の50桁参照値
   2833.981735603865 と相対差 1e-12 以内で一致。相関は式(7.66)。
2. **集中定数極限**：Bi=0.00125（k=400、h=50、R=0.01）の条件で、
   時定数 τ=ρcpR/(2h)=342.65 s は解析値と一致。体積平均温度の
   減衰比 (T̄−T∞)/(T0−T∞) は t=τ で解析値 e⁻¹ と相対差 3.2e-4、
   t=2τ で e⁻² と 6.3e-4（テスト予算は実測の約3倍：1e-3／2e-3）。
3. **内部勾配ケースの独立照合**：Bi=1/3（k=15、h=500、R=0.01、
   T0=400 K、T∞=300 K）で、独立な Python 参照（セル中心放射 FV を
   独自に組み立て、行列指数関数で厳密に時間伝播、格子512。格子256との
   自己差は最大 8.6e-5 K）と照合。JS 側の誤差（中心・表面・平均の
   最大値、t=2/5/10/20 s）は格子 32→64→128 で単調に減少し、
   格子128では中心 4.1e-4 K・表面 7.9e-4 K・平均 8.2e-5 K
   （テスト予算：1e-3／2e-3／2e-4 K）。
4. **定常到達と収支**：同ケースを t=600 s まで進め、平均温度は
   流体温度の 0.01 K 以内、表面熱流束は 0.5 W/m² 未満まで減衰。
   相対エネルギー誤差（表面積算熱量と内部エネルギー変化の差）は
   1.2e-14（テスト予算 1e-12）。
5. **拒否の実証**：Re_D>10⁷（風速→h側の拒否が伝播）、Bi>10、
   h の二重指定・未指定、h≤0、未知キー（flow 内も）、セル数範囲外、
   非正の直径、負の時間刻みをテストで確認。

## 限界

- GUI・ブラウザー確認・公開判定は未実施（数値コア＋検証＋文書まで）。
- h は周方向平均の一定値であり、局所分布・時間変化（物性の温度依存を
  含む）は扱わない。流れが変わる条件では呼び出し側が作り直す前提。
- 陽的進行のため、細格子・長時間では内部ステップ数が増える
  （step(dt) は safeDt 以下へ自動分割する）。
