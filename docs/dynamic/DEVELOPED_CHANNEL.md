# 発達流路の始動と熱の移動：限定モデル

2026-11-04開始の動的実験ライン。`developed-channel.mjs` / `channel.html` / `channel-ui.mjs`。以前の開発用`dev/channel.mjs`は互換re-exportへ変更した。一般2DのMACキャビティは引き続き開発用・公開allowlist外。

## 範囲

平行平板間の1D過渡運動量u(y,t)と、周期x・断熱yの2D温度移流拡散。一定ρ/cp/k/ν、非圧縮、v=0、両壁no-slip。圧力差からgₚ=Δp/(ρL)を指定する。圧力表示は既知の直線であり、圧力Poissonを解いた一般CFDの圧力場とは呼ばない。発散0もuがxに依存しない仮定の帰結。

左右は温度の周期境界で、流出した温度分布が再び流入する。有限の入口/出口・助走・障害物・側壁・浮力・乱流・粘性発熱は対象外。奥行きは評価体積の係数だけ。壁が断熱なので加熱壁からのh/Nuは求めない。温度から流れへの浮力/物性のフィードバックもない。このモードを、平板外部/円柱/管/フィン間の強制対流全体の完成としない。

## 解法と監視

保存型の温度面流束、1次風上移流、中心拡散、前進Euler。壁の速度は半セルghost。定常Re_Dh（平均速度、水力直径2H）≤1000を保守的に制限し、初期速度＋駆動の速度上界にも別の制限を持つ。これらは任意実流路の層流保証ではない。

移流速度の上界は初期最大速度と1.1倍の解析定常最大速度の和。非ゼロ初期分布が駆動で初期最大値を超える場合も考慮する。拡散とCFLから安全側の刻みを決定。最終更新で使用した速度によるCFLと、初期状態からの最大CFL、セルPe/その上界を保存する。正の絶対温度、有限の体積/熱容量/拡散率/速度/エネルギー/力積、再生時の範囲を確認する。失敗前の状態へ戻せる。

内部面の熱量は等量逆符号、周期境界で顕熱収支は閉じる。運動量は圧力による駆動力＋壁せん断の力積と別計算で比較する。粘性発熱を省いた顕熱の保存であり、運動エネルギーを含む完全な全エネルギー収支ではない。安定計算でも風上の数値拡散は残る。低Mach/連続体・一定物性等の物理的適用条件は別に確認が必要で、任意の手動値へ無条件に適用しない。

## 物性と手計算

空気300 K・101325 Paの4数値事実を、許諾済み原本のTable A.6（書籍755/PDF769頁）で抽出文字とページ画像の両方から確認。ρ=1.177 kg/m³、cp=1006 J/(kg K)、ν=1.575e−5 m²/s、k=0.0264 W/(m K)。原表やページ画像/抽出本文は配信しない。一定の参考値であり、温度依存の実物性曲線として扱わない。

既定のΔp=0.02 Pa、L=0.04 m、H=0.01 mでは、μ=ρν=1.853775e−5 Pa s、α=k/(ρcp)=2.22961297635e−5 m²/s。定常Ū=Δp H²/(12μL)=0.22476658 m/s、最大速度1.5Ū=0.33714987 m/s、Re_Dh≈285.417879。参照表のμ/α/Prの丸め値を混ぜず、独立入力から一貫して計算する。
