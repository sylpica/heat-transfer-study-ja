# de Vahl Davis の Nu 定義：照合解決

記録日：2026-11-06。基点8875733の実装を確認。所有者からこのタスクへ届いたフェイリス検証ラインの一次資料照合報告を採用した。実装担当自身が原論文スキャンを直接再閲覧した記録ではない。

## 受領した照合証拠

de Vahl Davis (1983), Table V, p.256（Ra=10³、Pr=.71）には、全体平均Nu=1.118、垂直中央面平均Nu_1/2=1.118、高温壁x=0平均Nu_0=1.117が併記される。「WHICH NUSSELT NUMBER?」pp.262–263はNu_1/2を代表値として推奨する、との報告。フェイリスはScribd上の原論文スキャンを直接読取り、Allen & Reis (Oxford OCCAM Preprint 13/34), Table 7、およびBarakos & Mitsoulis (1994), Table IIIと一致を確認したと報告した。

Ra=10⁶のNu=8.800 / Nu_1/2=8.799 / Nu_0=8.817も定義別の値として報告された。ただし現ソルバーの許容範囲はRa≤1000であり、高Raの実測・検証へ流用しない。原論文のRa=1000における推定誤差0.1%という報告は、現実装の合格幅を変更する根拠にしない。

## 実装との対応

cavity.mjsのsnapshotは、各高温壁隣接セルで2k(T_left−T_cell)/dxを計算し、高さ方向の算術平均を取り、H/[k(T_left−T_right)]を掛けている。等間隔壁面積に対する平均であり、Nu_0に対応する。体積平均・中央面平均を計算したものではない。参照長さはH（ベンチマークではL=H=1）。計算式を変えず、snapshotへ定義メタデータを追加した。

既存32格子t=2の記録値1.1199427644252182は、Nu_0=1.117との差+0.0029427644252182、相対差約+0.2634525%。t=1から2の差約−4.55e−13ではこの空間・境界離散化差を説明できない。収支一致・定常化を全場精度承認としない。

旧ゲート参照1.117、絶対幅.006は変更しない。所有者資料の1.118も全体／中央面の定義ラベル付きで保持する。将来のドライバーは定義の合う壁面参照だけと誤差を取り、過去のJSONにあるprovidedMeanDifferenceは異なる定義間の差として履歴保存する。
