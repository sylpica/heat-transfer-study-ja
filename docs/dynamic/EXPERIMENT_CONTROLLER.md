# 共通の時間操作・比較トランザクション

2026-11-04。`dynamic/experiment.mjs`を熱伝導/フィンと複数面放射の両画面へ接続。Actorは1モデルの非同期通信、Workerはそのモデルの計算/取消時の復元、Experimentは最大2モデルの同時操作と履歴を担当する。可視化・用語・教材データへ依存しない。

## 不変条件

- 条件の初期化は両側の成功を確認してから準備完了とする。失敗した状態で古い計算を再生できない。
- advanceの前に表示スナップショットを両側へ復元する。片側だけ先に計算を終えてから停止しても、未表示の未来を次の計算へ混ぜない。
- 一方が失敗したら両側を表示前の状態へ復元する。復元にも失敗した場合は再生を無効にする。成功側だけを受け入れない。
- 結果の物理時刻が要求した時刻と合い、両側でも一致することを浮動小数点の丸め幅で確認してから表示する。
- epochで古い非同期応答を無効化する。停止・初期化・巻き戻しが新しい操作を上書きしない。
- 履歴は最大500コマ、初期状態と合計200万数値以下。初期状態を別に保持し、古いコマが脱落しても「最初へ/停止」は本当のt=0へ戻る。過去から進めた場合はその先の履歴を切って分岐する。履歴は端末メモリーだけで恒久保存しない。

停止の表示は最後の受理済み状態。保存状態を読み終えたら「表示中」とし、復元処理が続いているように案内しない。新しいモデル画面も同じプロトコルへ接続できるが、この共通化だけで流路/一般CFDを公開したことにはしない。

## 検査

`tests/dynamic-experiment.test.mjs`は実際の熱モデルを非同期トランスポートへ接続し、片側更新後の失敗、片側だけ完了した後の停止と再開、初期化失敗、履歴上限後の巻き戻し/分岐/t=0復帰、誤った物理時刻、メモリー/Worker障害を確認する。Workerの失敗だけに依存せず、成功したモデルも実際に元の状態へ戻ったことを検査する。

Workerの時間ループは1e−12 sの固定打切り幅を除き、要求時刻まで進める。元の処理では正の1e−13 sを要求しても0 sのまま成功応答を返した。専用ブラウザー試験で、1e−13 s後の時間と一様発熱による1e−7 Kの変化を確認した。時間刻みが現在時刻の浮動小数点尺度で区別できない場合は、空の進行を続けず停止する。これは任意の微小刻みに温度精度を保証するという意味ではない。
