# 格子・等温線・温度断面の読み取り

2026-11-04。新しい物理モデルを作らず、保存済みのセル中心温度を検査する表示。検出/数値抽出は`dynamic/field-analysis.mjs`、断面描画は`field-plots.mjs`、操作は`lab.mjs`へ分離した。

## 等温線と格子

格子の重ね表示で、実際の有効セルと階段境界を示す。等温線はA/B共通の温度色範囲の25/50/75%の温度で描き、数値を℃で表示する。四つの有効セルの中心を結ぶ四辺形を対角線で二つの三角形に分け、区分線形補間から線分を得る。これは壁面温度の再構成、滑らかな曲面近似、双線形鞍点の厳密な接続判定ではない。対角線の選び方の影響を伴う。

4中心のうち一つでも物体外ならその四辺形では線を描かず、穴を横切らない。セル中心の外側へは外挿しない。共有辺の重複やゼロ長の線分は除く。一様場や1Dフィンに架空の2D等温線を足さない。白い線の下へ暗い縁取りを重ね、温度色に埋もれにくくする。

## 断面

測定点に最も近いセルの横列/縦列を抽出し、各セル中心の実座標[m]と温度[℃]を示す。断面の実際の固定座標と時刻も表示する。クリック位置そのものを通る連続場だと偽らない。物体外は欠測で線を切り、断面全体が物体外なら値を作らず案内する。

A/Bで寸法が違っても横軸は共通の実座標とし、各モデルの長さから個別に座標を算出する。数値表は各モデルに別の座標列を持ち、同じ行の値が同じ座標とは限らない。色範囲と同様に温度軸は両モデル共通。1Dの1セル断面は点として描く。各列の数値表を用意し、スマートフォンでは表だけ横スクロールできる。図の文字は端末画素比と実表示幅で描き直し、800pxのグラフを単純縮小しない。
