# フィン間流れモデル 開発画面（GUI）

2026-11-08。ブランチ `feiris/fingap-flow-gui`、基点＝フィン間流れモジュール先端 `3ca3710`。
dev モジュール `dynamic/dev/fin-gap-flow.mjs`（「フィン間流れ（発達チャンネル流れ）の
dev 実装」で受理基準 A1〜A8 合格済み）を画面で操作できるようにした記録。
モジュール本体は無変更（git diff 0行）。

## 画面構成

新規ファイル（すべて `dynamic/dev/` 配下、公開ビルドの allowlist には入れない）：

- `fin-gap-flow.html` — 画面本体。他の開発画面と同じ `cavity.css` を使用。
- `fin-gap-flow-ui.mjs` — DOM 配線。核の解法は流れ方向の x-marching で高速
  （受理格子で実測 31〜36 ms）なため、ヒートシンク連成画面のような Worker は
  使わず同期実行する（Worker 化の理由だった十数秒級の計算が存在しない）。
  核の拒否理由は書き換えずそのまま表示する。
- `fin-gap-flow-ui-config.mjs` — プリセット、単位換算（画面表示単位→コアの SI キー）、
  表示フォーマッタ。
- `fin-gap-flow-view.mjs` — 流れ方向プロファイルのグラフ（canvas）。横軸は無次元長
  x* の対数（格子点が等比配置で熱入口が decade にわたるため）。上段はバルク温度・
  下壁温度・上壁温度（線形軸）、下段は局所 Nusselt 数（入口特異性 O(100) と発達値
  O(10) を両方見るため縦軸も対数）。

入力（編集可能）：プリセット（発達極限・一定熱流束（A1）／発達極限・一定壁温（A2）／
短い流路・入口効果（A6）／圧力差駆動（A4）／体積流量・一定壁温（A3））、フィン間隔
（隙間）s・フィン高さ（流路幅）W・流路長さ L [mm]、流体の密度・比熱・熱伝導率・
動粘度、入口温度、駆動条件（平均流速 [m/s]／体積流量 [L/min]／質量流量 [g/s]／
圧力差 [Pa] のいずれか1つ、値ラベルは種別に追随）、壁条件（一定熱流束 q″／
一定壁温 Tw のどちらか一方、両フィン面同一）、格子 nx・ny・dxGrowth。

表示：平均流速と流量換算（体積流量・質量流量）、Re_Dh・Pr・Pe_Dh・出口の無次元長、
圧力損失 Δp・圧力勾配・Darcy f・f·Re_Dh、出口バルク温度（入口からの変化つき）、
出口局所 Nu・平均 Nu・平均熱伝達率 h、総熱移動率・流体の熱量増加・収支の相対残差、
プロファイルグラフ、診断（法則・格子・断面積と加熱壁面積・平均 Nu の定義・圧力
法則・入口発達長の目安・実測計算時間）。

対象外は画面下部の「理論・仮定・適用限界」にモジュール記録の線引きどおり明示：
速度の入口発達、有限幅側壁・先端・底面を含む3次元フィン配列（有限幅 Dh の代入
による「補正」は名乗らない）、フィン内伝導との共役・フィン効率、入口／出口／
分岐の局所圧力損失、複数流路の流量配分とファン作動点、バイパス流、乱流、物性の
温度依存、浮力・混合対流。

## 画面値とモジュール値の一致（実測）

ブラウザーテスト `tests/dynamic-fin-gap-flow-browser.mjs`（Playwright/Chromium）で、
Node 側で計算したコア結果と画面表示を同じフォーマッタで突き合わせ、全件合格：

- 発達極限・一定熱流束プリセット（A1）：出口局所 Nu **8.235294**、
  出口バルク温度 **806.7302 K**、圧力損失 **33.3680 Pa**、総熱移動率 **30.00000 W**
  が表示桁まで一致。
- 発達極限・一定壁温プリセット（A2）：出口局所 Nu **7.540486**、
  出口バルク温度 **316.5639 K**、平均流速 **0.500000 m/s** が表示桁まで一致。
- 数値の出所はモジュール記録（FINGAP_FLOW_JS_20261107.md）の実測値と同一
  （A1 の出口局所 Nu は独立検算値 8.235294109 と絶対差 2.3×10⁻¹⁰）。

## 拒否表示の確認

コアの拒否理由を画面が書き換えずそのまま表示することを、ブラウザーテストで
コア側の例外メッセージと文字列一致まで確認：

- 平均流速 3 m/s（隙間10 mm）→ 「層流域の目安として設定したRe_Dh上限2300を超えます。」
- フィン間隔 0 mm → 「フィン間隔[m]が数値範囲外です。」
