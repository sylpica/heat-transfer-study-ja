# 開発専用：フィン間流路（発達チャンネル流れ）の限定モデル

2026-11-07（Asia/Tokyo）。Muse 本線の残開発として、Codex サポート依頼3・件Bの定式化（`codex/support-forced-pressure-fingap` @1836092、`docs/dynamic/support-forced/FIN_GAP_FORMULATION.md`）に基づき、ヒートシンクのフィン間流路を扱う dev モジュール `dynamic/dev/fin-gap-flow.mjs` を新規実装した記録。公開 allowlist 外、releaseApproved=false。GUI は今回の範囲外。

## 定式化（依頼3の線引きをそのまま採用）

隣接2フィンの間の流路1本を、全隙間 s・流れ方向長さ L・幅（フィン高さ）W の平行平板流路と理想化する。W≫s を前提とし、側面・先端・底面の影響は解かない。2次元・定常・非圧縮・Newton流体・一定物性。

- 速度は発達した平面 Poiseuille 分布 u=6U z(1−z)（z=y/s、原書式(7.62)）を既知とし、解くのは軸方向熱伝導を省いた熱入口の Graetz 問題 rho cp u(y) T_x = k T_yy のみ。温度場の計算は既存の `dynamic/dev/graetz-channel.mjs`（`solveGraetzChannel`）へ委譲し、二重実装をしない。本モジュールは、フィン間流路としての形状解釈（隙間 s＝平板間隔、フィン高さ W＝奥行きスパン）、駆動条件の換算（流量／圧力差→平均流速 U）、圧力損失の組み立て、平均熱伝達率の提示を担う。
- 壁条件は両フィン面同一の (a) 一定壁温 Tw、または (b) 一定流入熱流束 q″ のどちらか一方。同時指定はしない。
- 水力直径は無限幅理想化の Dh=2s で一貫させる。有限幅の Dh=2sW/(s+W) だけを代入しても無限幅の速度・Nu は矩形管の解にならない（依頼3の警告）ため、本モジュールでは有限幅補正を名乗らない。
- 圧力損失は発達層流の解析のみ：p_x=−12μU/s²、Δp=12μUL/s²、等価に Darcy f=96/Re_Dh（Dh=2s）。入口・出口・分岐の局所損失は含まない。圧力差駆動ではこの発達摩擦則を逆算して U を決める（入口損失を含む実圧損の予測ではない）。
- 平均 Nusselt 数は基盤ソルバーの定義（定義区間にわたる局所 Nu の流れ方向長さ平均）をそのまま返し、h_mean=Nu_mean·k/Dh とする。全体熱量／LMTD から定義する h とは定義が異なるため、総熱移動率と出口バルク温度も併せて返し、混同しないようにする。
- 入力域は基盤ソルバーに従う：層流の目安 Re_Dh≤2300、軸方向熱伝導省略の前提 Pe_Dh≥100。範囲外は基盤の日本語エラーをそのまま拒否理由とする。

### 対象外（依頼3の線引きどおり、今回も扱わない）

速度入口発達（圧力連成の運動量解法）、有限幅側壁・3次元フィン列、フィン効率・固体共役（フィン内伝導との連成）、入口／出口／分岐の圧損、複数流路の流量配分とファン作動点、バイパス流、乱流、物性の温度依存、浮力・混合対流。8.235／7.541 をこれらの条件へ無条件に当てはめない。

## 受理基準（事前登録：実装前に本節を固定し、後付けで緩めない）

照合条件は依頼3と同一の空気参照物性（rho=1.177 kg/m³、cp=1006 J/(kg K)、k=0.0264 W/(m K)、nu=1.575e-5 m²/s、U=0.5 m/s、s=W=0.01 m、入口 300 K）を用いる。

- A1（発達極限・一定熱流束）: q″=50 W/m²、L=30 m、nx=400、dxGrowth=1.03、ny=128 で、出口局所 Nu が依頼3の独立検算値 8.235294109 と絶対差 1e-6 以内、かつ解析値 140/17 との相対差 1e-8 以内。
- A2（発達極限・一定壁温）: Tw=320 K、L=0.5 m、nx=512、dxGrowth=1.02、ny=128 で、出口局所 Nu が依頼3の独立検算値 7.540485607 と絶対差 1e-6 以内、教科書印刷値 7.541（原書式(7.63)）との絶対差 1e-3 以内、厳密な第1モード値 7.540700874 との絶対差 3e-4 以内。
- A3（圧力損失）: 受理した全ケースで Δp が発達解析 12μUL/s² と相対差 1e-9 以内、Darcy f·Re_Dh=96 と相対差 1e-9 以内。
- A4（圧力差駆動）: Δp を与えた場合、復元される圧力損失が入力 Δp と相対差 1e-9 以内で一致し、U=Δp·s²/(12μL) を満たす。
- A5（流量駆動）: 体積流量 Q を与えた場合 U=Q/(sW)、質量流量=rho·Q が相対差 1e-12 以内。
- A6（入口効果と平均 Nu）: 一定熱流束・L=0.05 m では平均 Nu が発達値 140/17 より大きく、L を伸ばすにつれ平均 Nu は発達値へ単調に近づき（減少し）、出口バルク温度は解析直線則 Tin+2q″L/(rho cp U s) と 1e-6 K 以内で一致する。
- A7（収支）: 全ケースでエネルギー収支の相対残差が 1e-9 未満（基盤ソルバーの収支保証をラッパーが壊さない）。
- A8（拒否）: 未知キー、駆動条件の重複指定・欠落、非正の寸法・流量・圧力差、壁条件の欠落・混在、Re_Dh／Pe_Dh の範囲外は日本語エラーで拒否し、結果オブジェクトを返さない。

## 実測結果（2026-11-07、基点 34b84ad 上で実施）

新規テスト `tests/dynamic-fin-gap-flow.test.mjs`（8件）は A1〜A8 をそのまま符号化し、全件合格した。

- **A1**：出口局所 Nu = **8.235294109226304**。依頼3検算値 8.235294109 との絶対差
  2.3×10⁻¹⁰（予算 1×10⁻⁶）。解析値 140/17 との相対差 **1.02×10⁻⁹**（予算 1×10⁻⁸）。
- **A2**：出口局所 Nu = **7.540485606848578**。依頼3検算値 7.540485607 との絶対差
  1.5×10⁻¹⁰（予算 1×10⁻⁶）。教科書丸め値 7.541 との差 5.14×10⁻⁴（予算 1×10⁻³）。
  厳密な第1モード値 7.540700874 との相対差 **2.855×10⁻⁵（0.00285%）**——依頼3が独立に
  報告した 0.00285% と一致する（予算：絶対差 3×10⁻⁴）。
- **A3**：3ケース（平均速度／体積流量／質量流量の各駆動、異なる流路寸法）を通じ、
  Δp と解析式 12μUL/s² の相対差は最大 **2.04×10⁻¹⁶**、f·Re_Dh と 96 の相対差は最大
  **1.48×10⁻¹⁶**（予算はいずれも 1×10⁻⁹）。
- **A4**：Δp=0.1 Pa、L=0.1 m で U = **0.44953315981353364 m/s**（=Δp·s²/(12μL)）。
  復元した圧力損失と入力 Δp の相対差 **0**（予算 1×10⁻⁹）。
- **A5**：体積流量・質量流量の換算は予算 1×10⁻¹² 内で一致（テスト合格）。
- **A6**：一定熱流束、L = 0.05／0.5／5／30 m の平均 Nu は
  **13.457512 / 8.884941 / 8.300247 / 8.246109** と単調に発達値 8.235294 へ近づき、
  L=30 m でも相対差は 0.131%（予算 3%）。短流路の出口バルク温度は解析直線則と
  1×10⁻⁶ K 内で一致。
- **A7**：全ケースで熱収支相対残差 < 1×10⁻⁹（基盤解法の実測は概ね 1×10⁻¹² 級）。
- **A8**：不正入力15パターン全てを日本語エラーで拒否（結果オブジェクトは返さない）。
  テスト作成時に判明した2件の失敗（A4 の Δp=250 Pa が Re 上限超過で正しく拒否された件、
  A5 の期待値計算に上書き前の寸法を使った件）はいずれもテスト側の条件設計ミスであり、
  受理基準・モジュールには触れていない。

### 対象外と残件（依頼3の線引きどおり）

- 速度の入口発達（水力学的発達区間）：解いていない。速度は発達済み Poiseuille を所与とする。
- 有限幅の側壁・先端・底面を含む3次元フィン配列：解いていない。Dh=2s の無限幅理想化のみで、
  矩形 Dh への置換による「修正」は行っていない（置換だけでは矩形ダクト解にならないため）。
- フィン固体導伝・フィン効率との共役連成：解いていない。壁面条件は直接与える。
- 入口・出口の局所圧力損失、複数流路間の流量配分、ファン動作点：含めていない。
- 乱流・遷移域：基盤の適用範囲（Re_Dh ≤ 2300、Pe_Dh ≥ 100）外は拒否する。
- GUI・公開投入：本件の範囲外（dev 限定、releaseApproved=false）。
