# 直線フィン対流先端モデル（開発専用）FIN_CONVECTIVE_TIP_DEVELOPMENT

Phase 3「フィン・ヒートシンク」分野の残作業（締め可能性監査 2026-11-07 の §7 残作業・項目4）への対応として、フェイリス側の並行実装を別ブランチ `feiris/fin-convective-tip` に新規追加した。既存ファイルは変更していない。対象は §7.4 検証リストの「フィン先端境界条件」で、これまで断熱先端のみだった動的モデルに、対流先端と解析解照合を追加するものである。

## モデル

`dynamic/dev/fin-convective-tip.mjs`（`createStraightFin`、law: `straight-fin-convective-tip-1d-v1`）

- 一定断面（厚さ×奥行きの矩形断面）の直線フィンの軸方向1D非定常伝導。物性は一定（k, ρ, cp）。
- 支配方程式：ρcp ∂T/∂t = k ∂²T/∂x² − (hP/Ac)(T − T∞)、ただし P は周長、Ac は断面積。
- 境界条件：基部 x=0 は指定温度 Tb。側面は一様な h で周囲 T∞ と熱交換。先端 x=L は `tipCondition` で切替可能：
  - `convection`：先端面が同じ h で周囲と熱交換する（−k ∂T/∂x|_L = h (T(L) − T∞)）。
  - `insulated`：断熱（∂T/∂x|_L = 0）。
- 離散化：セル中心有限体積、陽 Euler。基部面は半セル抵抗（G0 = kAc/(dx/2)）、内部面は Gi = kAc/dx、側面損失はセルごとに Gs = hP·dx、先端損失は対流時のみ Gt = h·Ac を最終セルへ課す。安定刻み safeDt は全セルの流出率最大値から 0.8 倍で与え、超過する刻みは拒否する。
- エネルギー収支：外部熱量の累積は Kahan 補償付きで積算し、各ステップで蓄熱変化との差が丸め誤差予算（128·EPSILON 基準）以内であることを検証する。失敗したステップ・復元は受理状態を変更しない（原子的拒否）。
- 入力検証：未知キーは「未対応の物理条件を暗黙に無視しません」として拒否。非有限・範囲外も日本語エラーで拒否。断面一様の開発範囲として断面 Bi 数 h(Ac/P)/k ≤ 0.1 を検査する（既存学習モデル `steadyFinPrediction` の crossSectionBi と同じ定義）。
- η・ε の定義は既存学習モデル（`fin-learning.mjs` の観察量、`fin-efficiency.mjs`）に揃えた：η = 実損失 / (h·A_s·θb)、ε = 実損失 / (h·Ac·θb)。ここで A_s は対流に触れる全表面積で、断熱先端では側面積 PL、対流先端では PL + Ac（先端面を含む）。過渡中の η・ε は瞬時損失ベースの診断量であり、定常到達時に古典値と一致する。
- 先端温度の出力 `tipCellTemperatureK` は最終セルの代表値であり、先端面 x=L への外挿値ではない（環状フィンモデルと同じ扱い）。解析的な先端面温度は参照 JSON に別途記録している。
- `releaseApproved: false`、公開 allowlist 外。assumptions に未対応範囲（放射なし、2D 伝導・基部熱拡がりなし、流体連成なし、修正長さ近似ではないこと）を明示する。

## 独立検証（FIN_CONVECTIVE_TIP_REFERENCE_20261107.json）

参照生成器 `scripts/dynamic-fin-convective-tip-reference.py` は製品コードを一切再利用していない。

- 定常解析解（mpmath 50桁）：θ(x)/θb = [cosh(m(L−x)) + H sinh(m(L−x))] / [cosh(mL) + H sinh(mL)]、H = h/(mk)（対流先端）／H = 0（断熱先端）。基部微分熱と閉形式の表面積分（側面＋先端）が全ケースで 1e-35 W 未満（実測 ~1e-50 W）で一致。
- 正準条件（k=200, h=25, P=0.04, Ac=1e-4, ΔT=60, L=0.1）の断熱先端は、既に照合済みの閉形式値 q = 5.1663430295 W、η = 0.861057172、ε = 34.4422869 と生成器内で assert 一致。
- 過渡参照は独立組立した有限体積ネットワークを行列指数（scipy expm）で伝播したもの（陽 Euler ではない）。

### 実測値

正準条件（L=0.1 m、厚さ・奥行き 0.01 m、k=200、ρ=2700、cp=900、h=25、Tb=353.15 K、T∞=293.15 K）：

| 項目 | 対流先端 | 断熱先端 |
|---|---|---|
| m | 7.071068 /m（共通） | 同左 |
| H = h/(mk) | 0.017678 | 0 |
| 定常 q（解析） | 5.2597314113 W | 5.1663430295 W |
| 定常 η（解析） | 0.855240880 | 0.861057172 |
| 定常 ε（解析） | 35.0648761 | 34.4422869 |
| 先端面温度（解析） | 340.239853 K | 340.746691 K |
| 定常場 RMS 誤差（n=16/32/64、対セル平均） | 0.015835 / 0.003982 / 0.001007 K | 0.015770 / 0.003944 / 0.000986 K |
| 空間観測次数 | 1.992 / 1.984 | 2.000 / 2.000 |

- JS 定常解と独立ネットワークの離散定常解は全格子で RMS 1e-7 K 未満で一致。定常時の基部流入と全損失の差は 1e-6 W 未満。
- 断熱帰着：n=64 の JS 定常で η = 0.8610408（照合済み値との差 1.6e-5）、q = 5.1662450 W（差 9.8e-5 W）、ε = 34.4416（差 6.5e-4）。
- 過渡（n=16、正準条件、t=20 s、行列指数参照との比較）：刻み safeDt/2 で最大差 0.0213 K・RMS 0.0140 K、safeDt/4 で最大差 0.0106 K・RMS 0.00702 K。時間精細化の観測次数は 0.9985 / 0.9990（陽 Euler の1次と一致）。
- エネルギー収支：実行範囲で |energyError| ≤ 丸め誤差予算（実測はテスト内で assert、収支自体は全ステップ検証済み）。

### 先端対流の効果と修正長さ法

短フィン条件（L=0.02 m、厚さ 0.002 m、奥行き 0.05 m、他は正準と同じ）では、先端対流により定常熱流量が断熱先端比で +4.6336%（解析）／ +4.6338%（JS 実測、n=32）増加し、先端損失は 0.14583 W だった。正準条件でも +1.81% の増加がある。

修正長さ法 Lc = L + Ac/P の断熱近似と対流先端の厳密解との差（解析同士の比較）：

| 条件 | 断熱式（L のまま）の相対誤差 | 修正長さ法の相対誤差 |
|---|---|---|
| 正準（L=0.1） | 1.7755% | 0.00018% |
| 短フィン（L=0.02） | 4.4284% | 0.00018% |

本条件範囲では修正長さ法は厳密解を非常によく近似するが、これは近似であって動的モデルの先端条件そのものではない。本モジュールは修正長さを使わず、先端面の対流を直接離散化している（assumptions の `correctedLengthApproximation: false`）。

## 未実施・限界

- GUI・Worker 接続・ブラウザー確認・公開可否は未実施（今回は数値コア＋検証＋文書まで）。
- 先端の熱伝達率は側面と同じ h のみ（先端だけ別の h、軸方向に変化する h は未対応）。
- 変断面フィン、温度依存物性、放射、基部の2D熱拡がり・接触抵抗、複数フィン／フィン間流れ、風速→h 推定は未対応で、入力は原子的に拒否されるか assumptions に明示している。
- η・ε は過渡中は瞬時診断量であり、定常効率そのものではない。
- テスト実行時間：新規テスト10件で約35秒（定常到達まで陽 Euler を回すため）。全 Node スイート・公開ビルドの結果は STATUS.md の追記を参照。
