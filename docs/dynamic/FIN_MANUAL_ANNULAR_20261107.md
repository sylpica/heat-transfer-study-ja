# モデル別説明書：環状フィン（管外周円盤フィン）

- 日時：2026-11-07（Asia/Tokyo）
- 対象モデル：開発専用モジュール `dynamic/dev/annular-fin.mjs`（`createAnnularFin`、法則識別子 `annular-fin-radial-1d-v1`）。フェイリス側ブランチ `feiris/annular-fin`（起点 `7968146`、コミット `ffe7c25`）の成果物で、統合ツリーの `dynamic/dev/` に開発画面（GUI）を含む。Worker はなく、数値コアとそのスナップショット、および開発画面が対象である。
- 位置づけ：正本 §21.2 がモデルごとに求める16項目の説明書。数値・検証値の正は開発文書 `docs/dynamic/ANNULAR_FIN_DEVELOPMENT.md` と参照記録 `docs/dynamic/ANNULAR_FIN_REFERENCE_20261107.json` であり、本書はそれらと矛盾しない要約と、独立項目として不足していた使用例・誤解・読み方を補う。η・ε の定義は既存の学習モデル（`docs/dynamic/FIN_LEARNING.md`）と同じ表面損失ベースである。
- 読み分け：項目1〜2・9〜10・13 は初心者向け、それ以外は専門寄りの記述を含む。

## 1. 現象の概要

管（外半径 r1）の外周に取り付けた厚さ t 一様の円盤フィン1枚について、温度が半径方向にだけ変化しながら時間とともに伝わっていく現象を計算する。フィンの両側面は同一の指定 h で周囲 T∞ へ対流する。基部（管との接合面）は指定温度 Tb に固定される。先端の扱いは、対流する厳密な先端面と、修正半径による断熱近似の2方式から選べる。

## 2. 現実世界での使用例

- 空冷式熱交換器やラジエータのフィン付き管で、1枚の円盤フィンがどれだけ放熱を受け持つかの学習・概算。
- 円形フィンを持つ発熱体の冷却で、フィン外縁まで温度がどれだけ下がるかの見通し。
- 修正半径近似（項目6）が実務でどの程度の誤差を持つかの確認。
いずれも一定物性・指定 h・半径方向1Dの仮定が成り立つ範囲の学習・概算のためであり、実設計の保証には使わない（項目12）。

## 3. 支配方程式

θ = T − T∞、m² = 2h/(kt) として、定常の支配方程式は Bessel 型

(1/r) d/dr (r dθ/dr) − m²θ = 0

であり、解は θ(r) = A I₀(mr) + B K₀(mr)（I₀・K₀ は変形 Bessel 関数）。非定常は

ρcp ∂T/∂t = (k/r) ∂/∂r (r ∂T/∂r) − (2h/t)(T − T∞)

を解く（出典：`ANNULAR_FIN_DEVELOPMENT.md`）。

## 4. 記号と単位

| 記号 | 意味 | 単位 |
|---|---|---|
| T | 温度（絶対温度で入力・出力） | K |
| r1, r2 | 管外半径（フィン基部）、フィン外半径 | m |
| r2c = r2 + t/2 | 修正半径（`corrected` 方式でのみ解く半径） | m |
| t | フィン厚さ（一様） | m |
| k, ρ, cp | 熱伝導率、密度、比熱（一定物性） | W/(m·K), kg/m³, J/(kg·K) |
| h | 熱伝達率（入力値。流れから予測しない） | W/(m²·K) |
| Tb, T∞ | 基部温度、周囲流体温度 | K |
| m = √(2h/(kt)) | フィン定数 | 1/m |
| Bi = h(t/2)/k | 厚さ方向のビオ数（1D仮定の開発範囲の検査に使う） | — |
| Acb = 2π r1 t | 基部断面積 | m² |
| A_fin | 対流に触れる全表面積（`convection` では両側面＋先端面、`corrected` では r2c までの両側面） | m² |
| η = Q_surface/(h A_fin θb) | フィン効率（表面損失ベース） | — |
| ε = Q_surface/(h Acb θb) | フィン有効度（表面損失ベース）。θb = Tb − T∞ | — |

## 5. 初期条件

一様な初期絶対温度（スカラー）か、セルごとの初期温度配列を与える。配列の長さはセル数と一致しなければならず、不一致は拒否される。温度値は各セルの代表値であり、点温度ではない（項目9・13）。

## 6. 境界条件

- 基部（r = r1）：指定温度 Tb に固定。
- 両側面：同一の指定 h で周囲 T∞ へ対流。
- 先端（r = r2）：2方式を選択できる。
  - `convection`：先端面（面積 2π r2 t）自体が同じ h で対流する厳密な先端条件 −k dθ/dr = hθ（r = r2）。
  - `corrected`：修正半径 r2c = r2 + t/2 まで領域を延長し、先端を断熱とする Schmidt/Gardner の古典的近似。解く形状自体が実フィンより半径で t/2 大きい近似であり、その旨は assumptions と mesh に明記される。

## 7. 数値計算法

- 環状セルの有限体積法。セル中心は環状セルの面積重心 rc = (2/3)(a² + ab + b²)/(a + b)。面コンダクタンスは重心間の対数抵抗 2πkt / ln(rc′/rc)（円筒伝導の厳密抵抗）で、基部は ln(rc₀/r1) を使う。側面対流は両面分を各セルに課す。
- 時間積分は前進 Euler で、安定刻みは最大流出率の0.8倍の逆数（`safeDt`）を上限とし、超過する刻みは拒否する。
- 累積外部熱（基部流入 − 表面損失）には補償和を使い、受理前に有限値・正温度・監視上限・熱収支予算（128·EPS 基準）を検査する。失敗したステップ・復元は受理状態を変更しない（原子的拒否）。
- 入力検証：未知キー・非有限・範囲外は日本語エラーで拒否する。セル数は 4〜256。厚さ方向一様の1D仮定の開発範囲として Bi = h(t/2)/k ≤ 0.1 を生成時に検査し、超える条件は拒否する。監視温度上限は既定 10000 K。

## 8. 計算過程

1. 形状（r1・r2・t）・材料・h・Tb・T∞・初期温度・先端条件・セル数を指定して生成する。
2. `safeDt` 以下の刻みで時間を進め、スナップショットの温度配列・基部熱流量・表面損失・収支誤差で応答を確認する。
3. 定常の検算は Bessel 参照値（項目10）と比べる。

手計算による検算の例（出典：`ANNULAR_FIN_DEVELOPMENT.md` の基準条件）：r1 = 0.01 m、r2 = 0.03 m、t = 0.002 m、k = 200 W/(m·K)、ρ = 2700 kg/m³、cp = 900 J/(kg·K)、h = 150 W/(m²·K)、Tb = 400 K、T∞ = 初期 300 K（仮想値であり実在材料の保証値ではない）では、m = 27.386 m⁻¹、断面 Bi = 7.5e-4、定常 η = 0.840173（`convection`）／0.839925（`corrected`）。

## 9. グラフの読み方

- 公開画面はないが、開発画面（公開ビルドには含まれない）にはグラフ表示がある。公開側で結果を読む場合はスナップショットの数値配列を使う。
- `temperature` はセル重心半径 `radii` における代表値の配列であり、その半径の点温度ではない。`outerCellTemperature` は最終セルの代表値で、先端面 r2 の表面温度への外挿値ではない。
- η・ε は各スナップショットで表面損失から計算する診断量で、過渡初期（初期温度一様・基部だけ Tb）は 0 から始まって定常値へ近づく。時系列で読む場合は「定常効率そのものではない」ことに注意する（項目13）。
- `energyError` は収支の検査量であり、温度の離散化誤差とは別の量である。

## 10. 結果の解釈

- 検証の実測（出典：`ANNULAR_FIN_DEVELOPMENT.md`、参照は50桁 mpmath の Bessel 解と行列指数による独立伝播）：
  - 定常 Bessel 参照値：`convection` で η = 0.840173、ε = 36.1274、q_base = 68.0986 W。`corrected` で η = 0.839925、ε = 36.1588、q_base = 68.1577 W。
  - 定常温度場と Bessel セル平均の RMS 差は、`convection` で n=16/32/64 のとき 0.02319 / 0.005907 / 0.001528 K（観測次数 1.97 / 1.95）、`corrected` で 0.02471 / 0.006190 / 0.001548 K（次数 2.00 / 2.00）。
  - 基部熱流量の格子収束は `corrected` で次数ほぼ正確に 2.00。`convection` では誤差は単調減少するが細格子側の見かけ次数が乱れる（誤差の符号の消し合い）ため、次数2を主張しない。
  - 過渡（t = 2 s、n=16、dt = safeDt/2）の行列指数参照との最大差は `convection` 0.01705 K、`corrected` 0.01611 K。時間精細化の観測次数は 1.000（前進 Euler の1次と一致）。
  - エネルギー収支は試験範囲で |energyError| ≤ 1e-8 J。定常到達時は基部流入と表面損失が 1e-6 W 未満で一致する。
  - 極限チェック：長さ消滅（r2 = 0.011、L = 0.001 m）で η = 0.998903（Bessel 0.998905）と 1 へ近づく。大半径では直線フィンの tanh(mLc)/(mLc)（Lc = L + t/2）へ近づき、η の差は r1 = 0.5 m で 0.01159、r1 = 2.0 m で 0.00310 と縮小する。
- 環状フィンの η が同長さの直線フィンより小さいのは、外側ほど面積が増え温度の低い領域の重みが増すためであり、符号も含めて物理と整合する。

## 11. モデルの仮定

- 半径方向1D（厚さ方向は一様）。スナップショットの assumptions に明記：一定物性、指定の一様 h、基部温度固定、放射なし。
- 管壁の熱抵抗・基部の熱拡がりは解かない。内部発熱なし。
- `corrected` 方式では修正半径近似を使う（assumptions の `correctedRadiusApproximation`）。
- η・ε は表面損失ベースで、既存の学習モデルと同じ定義である。h = 0 または θb = 0 では η・ε は定義できないため null を返す（数値の創作をしない）。

## 12. モデルの限界

- Worker 接続・公開可否は未実施。GUI とそのブラウザー確認（Chromium）は開発画面で実施済み。`releaseApproved:false`、公開 allowlist 外。
- フィン付き管としての管内流体・管壁抵抗との連成、複数フィンとフィン間流れ、基部の熱拡がり／2D伝導、温度依存物性、放射、実在材料での実測照合、外部専門家の承認は未実施。
- 先端条件は対流と修正半径の2方式のみ。実先端温度は最終セルの代表値であり、先端面への外挿値は提供しない。
- 開発範囲は Bi ≤ 0.1、セル数 4〜256 で、範囲外は推定値を返さず拒否する。

## 13. よくある誤解

- **「修正半径で解いた結果は実フィンの厳密解」** — 誤り。解く形状自体が半径で t/2 大きい近似であり、基準条件では対流先端の厳密解に対して η で 2.5e-4、q で 0.06 W の差がある。この条件では近似として妥当な水準だが、近似であることに変わりはない。
- **「過渡中の η がそのまま定常のフィン効率」** — 誤り。過渡中は基部流入と表面損失が蓄熱の分だけ異なり、η は表面損失ベースの瞬時診断量として定義される。初期には 0 から始まる。
- **「基部熱流量と表面損失は常に等しい」** — 誤り。定常でのみ一致し、過渡中は差が蓄熱になる。
- **「最終セルの温度が先端面の温度」** — 誤り。セル代表値であり、面への外挿値は提供していない。

## 15. 関連問題

対応付けは棚卸し記録 `docs/dynamic/MODEL_PROBLEM_MAP_20261107.md`（第4.2節・第8節）に基づく。

**現行の問題バンク（751問）に、本モデル（環状フィン）に対応する問題はない。** バンク全体を「環状」「円形フィン」で棚卸ししても該当は 0 件であり、環状フィンの効率・有効度を扱う問題は存在しない。推測で埋めず、その事実をここに明記する。

最も近いのは、直線フィンの効率・有効度の基礎を扱う次の問題である（いずれも主掲載は直線フィンの説明書の項目15。環状フィンの大半径極限が直線フィンに帰着することの基礎になる）。

- `supp-chapter-ch4-fin-eta` — 先端断熱の直線フィンの効率 η=tanh(mL)/(mL)。
- `supp-deep-fin-effectiveness-v1` — 基部放熱量からフィン有効度 ε を求める。
