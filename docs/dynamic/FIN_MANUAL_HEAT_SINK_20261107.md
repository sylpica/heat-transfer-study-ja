- 位置づけ：正本 §21.2 がモデルごとに求める16項目の説明書。数値・仮定の正は開発文書 `docs/dynamic/HEAT_SINK_DEVELOPMENT.md`（2026-11-07 追補を含む）と画面内「理論・仮定・適用限界」（`heat-sink.html`）であり、本書はそれらと矛盾しない要約と、独立項目として不足していた使用例・誤解・グラフの読み方・参考文献を補う。

## 1. 現象の概要

一様温度の基部に発熱 P [W] を与え、N 本の同一の矩形フィンと、フィンのない露出上面から、指定 h で対流放熱する系を計算する。基部は有限の熱容量を持ち、温度が時間とともに変化する。各フィンは長さ方向だけを計算し、同一条件の対称性から代表1本を解いて、全容量・全交換・全放熱には本数を掛ける。基部とフィンの接触部には接触熱抵抗を置ける。

## 2. 現実世界での使用例

- CPU やパワー半導体のヒートシンクで、発熱に対して基部温度がどこまで上がり、どれくらいの時間で落ち着くかの学習・概算。
- フィン本数・接触抵抗・発熱量を変えたときの基部温度応答の比較（画面の A/B 比較）。
- 接触抵抗や露出上面の寄与が全体の放熱にどう効くかの確認。
いずれも一様基部温度・代表フィン・指定 h の仮定が成り立つ範囲の学習・概算のためであり、任意の実ヒートシンクの性能保証ではない（項目12、画面内「理論・仮定・適用限界」にも明記）。

## 3. 支配方程式

基部幅 W、奥行 D、厚さ b、フィン長 L、厚さ t とし、根元断面 Ac = tD、周長 Pf = 2(t + D)、露出上面 Ab = D(W − Nt)、基部体積 WDb とする（出典：`HEAT_SINK_DEVELOPMENT.md`）。

- Cb = ρcp WDb、Cf = ρcp Ac dx、G0 = Ac/[Rc″ + dx/(2k)]、Gi = kAc/dx、Gs = hPf dx、Gb = hAb（Rc″ は接触熱抵抗 [m² K/W] で、1本につき Rc″/Ac [K/W]）。
- 基部：Cb dTb/dt = P − Gb(Tb − Ta) − N G0(Tb − T1)。
- 各フィンセル：Cf dTj/dt = 隣接セル／基部からの流入 − Gs(Tj − Ta)。先端の外向き伝導は 0。
- 全体：dE/dt = P − Gb(Tb − Ta) − N Gs Σ(Tj − Ta)。基部からフィンへの交換熱は内部量で、全収支へ二重に加えない。

## 4. 記号と単位

| 記号 | 意味 | 単位 |
|---|---|---|
| Tb, Ta | 基部温度（モデル内は一様）、周囲流体温度 | K |
| P | 基部への発熱 | W |
| W, D, b | 基部の幅、奥行、厚さ | m |
| L, t | フィンの長さ、厚さ（フィン断面は厚さ×基部奥行 D） | m |
| N | フィン本数（0〜64） | — |
| Ac = tD, Pf = 2(t + D) | フィン根元断面、周長 | m², m |
| Ab = D(W − Nt) | 露出した基部上面の面積 | m² |
| gap | フィン間隔（均等配置の派生量：W = N·t + (N + 1)·gap） | m |
| k, ρ, cp | 熱伝導率、密度、比熱（一定物性） | W/(m·K), kg/m³, J/(kg·K) |
| h | 熱伝達率（入力値。風速から計算しない） | W/(m²·K) |
| Rc″ | 接触熱抵抗（面積あたり） | m² K/W |
| Cb, Cf | 基部とフィンセルの熱容量 | J/K |
| G0, Gi, Gs, Gb | 基部―フィン間、フィン内部、フィン側面、基部上面のコンダクタンス | W/K |
| Bi = h(Ac/Pf)/k | フィン断面のビオ数（断面一様の開発範囲の検査に使う） | — |

## 5. 初期条件

基部とフィンの初期温度を与える。カーネルは基部（`initialBase`）とフィン（`initialFin`）を別々に指定でき、画面では基部・フィン共通の初期温度として設定する。周囲温度 Ta は別に指定する。

## 6. 境界条件

- フィン側面と露出した基部上面：指定 h で周囲 Ta へ対流。
- フィン先端と基部の他面：断熱。
- 基部とフィンの接合：接触熱抵抗 Rc″ と最初の半セル伝導抵抗を直列に置く。
- 発熱 P は基部へ一様に与える。基部の温度分布そのものは解かない（項目11）。

## 7. 数値計算法

- 有限体積の面コンダクタンスと前進 Euler。安定刻みは基部／フィンの最大流出率の0.8倍の逆数を上限とする。
- 受理前に有限値・正温度・監視上限・熱収支・時計を検査し、累積外部熱には補償和、蓄熱は初期状態との差から別計算する。復元は law／条件署名／配列／時計／収支を検査し、失敗時は受理状態を変更しない。
- 断面 Bi = h(Ac/Pf)/k ≤ 0.1 を開発範囲として検査する。ただし基部の一様温度は別の仮定であり、フィンの Bi 検査が基部の熱拡がり抵抗を保証するわけではない。
- N = 0 は露出上面全体で対流する有限容量基部に退化し、フィン温度配列は空になる。h = 0 の対流寄与は厳密に 0。
- 画面からの入力範囲（UI 側の検証、日本語理由つき）：フィン長さ 1〜500 mm、厚さ 0.1〜50 mm、基部幅・奥行 5〜1000 mm、基部厚さ 0.5〜100 mm、本数 0〜64、セル数 8／16／32／64／128（カーネルの受理範囲は本数 0〜64、1本の格子 4〜256）。本数×厚さが基部幅を超える形状は寸法入りの理由を表示して受理しない。

## 8. 計算過程

1. 画面で条件（本数・h・発熱・接触抵抗・形状・材料・周囲／初期温度・セル数）を設定し、「初期状態から計算」で適用する。
2. 再生／1コマ進める／戻すで時間を操作し、基部温度の履歴・立体図の温度・診断（各部の熱流と全熱収支）で応答を確認する。「現在の条件をBへ固定」で A/B 比較ができる。
3. 検算は独立参照との照合値（項目10）と比べる。

検証に使われた相似則（出典：`HEAT_SINK_DEVELOPMENT.md`）：寸法 λ・h/λ・Rc″λ・入力 Pλ・時刻 λ² の相似変換で解が対応する。材料の選択肢は既定の仮想一定物性（k=200、ρ=2700、cp=900。実在合金の保証値とは呼ばない）と、`dynamic/presets.mjs` の MATERIALS（純銅 k=398／アルミニウム 6061-T6 k=167／純鉄 k=80、いずれも教科書付録A・Table A.1 の20℃参考値を一定とする教育近似）である。

## 9. グラフの読み方

- 立体図は、計算した1Dセル温度を N 本のフィン形状へ配置した表示であり、3Dの温度場を解いた結果ではない（画面内にも明記）。回転・傾き・拡大は表示だけを変え、計算条件や時計を変えない。
- 測定位置（プローブ）の読み値は、フィン内の所属セルの平均温度である。基部温度はモデル内一様値として表示される。
- 履歴グラフは実際に計算した基部温度の履歴で、A は実線、B は破線。保存した温度場へ戻すことができる（履歴はメモリーだけに保持し、再読み込みで消える）。
- 診断の「基部からフィンへの熱」は内部交換であり、全収支へ二重に加えられていない。発熱と放熱の差が基部と全フィンの蓄熱になる。

## 10. 結果の解釈

- 検証の実測（出典：`HEAT_SINK_DEVELOPMENT.md`。独立参照は N 本の物理枝を別々に持つ容量／コンダクタンス行列による定常 solve と拡大行列指数で、JS の対称縮約・Euler を流用していない）：
  - 定常の容量加重 RMS 差は 8/16/32/64 セルで 0.00715376 / 0.00178865 / 0.000447177 / 0.000111795 K（連続解への空間次数 約2）。
  - 各固定格子の過渡を独立行列指数へ照合し、最細の最大差は 0.000277984 K。16セル固定の刻み精細化では RMS 0.00561928 / 0.00280850 / 0.00140397 K（時間次数 約1）。
  - 外部放熱の独立積分／全容量、断熱時の加熱、相似則、N=0、接触の SI 単位、原子的失敗／復元、無効域を確認済み。
- 画面拡張後の確認（出典：同文書 2026-11-07 追補）：形状・材料（純銅）・周囲／初期温度 300 K を変えた条件で、実 Worker の基部／所属セル温度が同条件のカーネル計算と 6e-8 K 以内で一致。間隔 10 mm の編集で基部幅が 58 mm へ連動し、診断の均等間隔と一致。全入力を既定へ戻すと従来検証済みの既定結果（t = 5 s）に一致する。
- 基部温度は「一様という仮定のもとでの値」であり、実物の基部内の温度分布（熱源近くの局所的な高温）は表れない（項目11・13）。

## 11. モデルの仮定

- スナップショットの assumptions に明記：基部一様温度、同一フィン、フィン断面一様温度、指定の一様 h、先端断熱、基部の他面断熱。一方で、流体相互作用・基部熱拡がり・放射・3D伝導は解かない（各フラグ false）。
- 一定物性・指定 h のみで、風速から h を計算しない。フィン間の空気流れ・相互遮蔽・h の本数依存は解かない。
- フィンの奥行は基部奥行と同一で、フィン断面は厚さ×基部奥行である。間隔は均等配置として基部幅から決まる派生量である。

## 12. モデルの限界

- 実ヒートシンクの h／流れの相互作用、基部の熱拡がり／3D伝導、放射、異なるフィン間の相互作用は未対応。
- 開発専用で `releaseApproved:false`、公開 allowlist 外。オフライン・実機・支援技術・公開 URL での動作は未検証（画面内にも明記）。外部専門家の承認はない。
- 数値上の正有限と、連続体モデルの物理的適用は別である。基部の一様温度とフィン断面の一様温度の妥当性は、実物の寸法・熱源位置・物性・Bi 数などから別途判断が必要である。

## 13. よくある誤解

- **「立体図が立体的に解いた 3D 解析結果」** — 誤り。同じ1D解の繰返し表示であり、先端／根元／基部の未計算の3D分布は創作していない。
- **「基部が一様温度になるのは計算結果」** — 誤り。モデルの仮定そのものであり、フィンの Bi 検査が基部の熱拡がりを保証するわけでもない。
- **「N 本のフィンを1本ずつ全部解いている」** — 誤り。対称性で代表1本を解き、本数を掛けて全体量にしている。全フィンが同じ温度分布という仮定を含む。
- **「h は風速から予測された値」** — 誤り。入力値であり、風速→h 推定は別モジュール（`wind-heat-transfer.mjs`）の担当で、本画面には接続していない。
- **「基部からフィンへの熱を全収支に加えると放熱が二重に数えられる」** — そのとおり二重計上になるため、診断表示でも内部交換として分けてある（項目9）。

## 15. 関連問題

対応付けは棚卸し記録 `docs/dynamic/MODEL_PROBLEM_MAP_20261107.md`（第4.3節・第8節）に基づく。

**現行の問題バンク（751問）に、本モデル（ヒートシンク）に直接対応する問題はない。** バンク全体を「ヒートシンク」で棚卸ししても該当は 0 件であり、複数のフィンと基部・接触部を一体で扱う問題は存在しない。推測で埋めず、その事実をここに明記する。

最も近いのは基部の接触抵抗を扱う `supp-existing-fin-contact-loss-v1`（主掲載は直線フィンの説明書の項目15）であり、放熱の基礎は直線フィンの問題一式（同・項目15）である。ヒートシンク固有の問題として断定できるものはない。
