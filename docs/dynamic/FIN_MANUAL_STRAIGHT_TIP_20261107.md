# モデル別説明書：直線フィン（対流先端／断熱先端）

- 日時：2026-11-07（Asia/Tokyo）
- 対象モデル：開発専用モジュール `dynamic/dev/fin-convective-tip.mjs`（`createStraightFin`、法則識別子 `straight-fin-convective-tip-1d-v1`）。フェイリス側ブランチ `feiris/fin-convective-tip`（起点 `f9bdfef`、コミット `9f7f267`）の成果物で、本線への統合は未実施。GUI・Worker はなく、数値コアとそのスナップショットが対象である。
- 位置づけ：正本 §21.2 がモデルごとに求める16項目の説明書。数値・検証値の正は開発文書 `docs/dynamic/FIN_CONVECTIVE_TIP_DEVELOPMENT.md` と参照記録 `docs/dynamic/FIN_CONVECTIVE_TIP_REFERENCE_20261107.json` であり、本書はそれらと矛盾しない要約と、独立項目として不足していた使用例・誤解・読み方を補う。既存の学習モデルは断熱先端のみだったところへ、対流先端と解析解照合を追加したモデルである。
- 読み分け：項目1〜2・9〜10・13 は初心者向け、それ以外は専門寄りの記述を含む。

## 1. 現象の概要

一定断面（厚さ×奥行きの矩形断面）の直線フィンについて、軸方向1Dの非定常伝導を計算する。基部は指定温度 Tb に固定され、側面は一様な h で周囲 T∞ と熱交換する。先端は、同じ h で対流する条件と断熱条件を切り替えられる。先端が実際には対流しているのに断熱で近似すると、短いフィンほど熱流量を過小評価する（項目10）。

## 2. 現実世界での使用例

- ヒートシンクの板フィン1本について、先端の放熱を無視してよいかどうかの判定。
- 空冷フィンの概算で、教科書の修正長さ法（項目13）を使ってよい条件かどうかの確認。
- 断熱先端の古典解（tanh 型）と対流先端の厳密解の差が、フィン長さでどう変わるかの学習。
いずれも一定物性・指定 h・断面一様の仮定が成り立つ範囲の学習・概算のためであり、実設計の保証には使わない（項目12）。

## 3. 支配方程式

ρcp ∂T/∂t = k ∂²T/∂x² − (hP/Ac)(T − T∞)　（P は周長、Ac は断面積、m² = hP/(kAc)）

定常の解析解（θ = T − T∞、θb = Tb − T∞、H = h/(mk)）：

θ(x)/θb = [cosh(m(L−x)) + H sinh(m(L−x))] / [cosh(mL) + H sinh(mL)]

対流先端では H = h/(mk)、断熱先端では H = 0 で古典解に帰着する（出典：`FIN_CONVECTIVE_TIP_DEVELOPMENT.md`）。

## 4. 記号と単位

| 記号 | 意味 | 単位 |
|---|---|---|
| T | 温度（絶対温度で入力・出力） | K |
| x, L | 基部からの軸方向座標、フィン長さ | m |
| thickness, depth | 断面の厚さ、奥行き | m |
| Ac | 断面積（thickness × depth） | m² |
| P = 2(thickness + depth) | 周長 | m |
| k, ρ, cp | 熱伝導率、密度、比熱（一定物性） | W/(m·K), kg/m³, J/(kg·K) |
| h | 熱伝達率（入力値。流れから予測しない） | W/(m²·K) |
| Tb, T∞ | 基部温度、周囲流体温度 | K |
| m = √(hP/(kAc)) | フィン定数 | 1/m |
| H = h/(mk) | 先端対流の無次元パラメータ（断熱先端では 0） | — |
| Bi = h(Ac/P)/k | 断面ビオ数（断面一様の開発範囲の検査に使う。既存学習モデル `steadyFinPrediction` の crossSectionBi と同じ定義） | — |
| A_s | 対流に触れる全表面積（断熱先端では PL、対流先端では PL + Ac） | m² |
| η = 実損失/(h·A_s·θb) | フィン効率 | — |
| ε = 実損失/(h·Ac·θb) | フィン有効度 | — |

## 5. 初期条件

一様な初期絶対温度（スカラー）か、セルごとの初期温度配列を与える。配列の長さはセル数と一致しなければならず、不一致は拒否される。温度値は各セルの代表値であり、点温度ではない（項目9・13）。

## 6. 境界条件

- 基部（x = 0）：指定温度 Tb に固定。
- 側面：一様な h で周囲 T∞ と熱交換。
- 先端（x = L）：`tipCondition` で切替可能。
  - `convection`：先端面が同じ h で周囲と熱交換する（−k ∂T/∂x|_L = h (T(L) − T∞)）。
  - `insulated`：断熱（∂T/∂x|_L = 0）。

## 7. 数値計算法

- セル中心有限体積法。基部面は半セル抵抗（G0 = kAc/(dx/2)）、内部面は Gi = kAc/dx、側面損失はセルごとに Gs = hP·dx、先端損失は対流時のみ Gt = h·Ac を最終セルへ課す。
- 時間積分は前進 Euler で、安定刻み `safeDt` は全セルの流出率最大値の0.8倍を上限とし、超過する刻みは拒否する。
- 外部熱量の累積は補償和（Kahan）で積算し、各ステップで蓄熱変化との差が丸め誤差予算（128·EPSILON 基準）以内であることを検証する。失敗したステップ・復元は受理状態を変更しない（原子的拒否）。
- 入力検証：未知キーは「未対応の物理条件を暗黙に無視しません」として拒否する。非有限・範囲外も日本語エラーで拒否する。セル数は 4〜256。断面一様の開発範囲として断面 Bi = h(Ac/P)/k ≤ 0.1 を検査する。監視温度上限は既定 10000 K。

## 8. 計算過程

1. 形状（L・厚さ・奥行き）・材料・h・Tb・T∞・初期温度・先端条件・セル数を指定して生成する。
2. `safeDt` 以下の刻みで時間を進め、スナップショットの温度配列・基部流入・側面／先端損失・収支誤差で応答を確認する。
3. 定常の検算は解析解（項目3・10）と比べる。

手計算による検算の例（出典：`FIN_CONVECTIVE_TIP_DEVELOPMENT.md` の正準条件）：L = 0.1 m、厚さ・奥行き 0.01 m、k = 200、ρ = 2700、cp = 900、h = 25、Tb = 353.15 K、T∞ = 293.15 K では m = 7.071068 /m、H = 0.017678（対流先端）、定常 q = 5.2597314113 W（対流先端）／5.1663430295 W（断熱先端）。

## 9. グラフの読み方

- 本モデルには画面・グラフはない（開発専用、GUI 未実施）。結果はスナップショットの数値配列で読む。
- `temperature` はセル中心位置 `positions` における代表値の配列である。`tipCellTemperatureK` は最終セルの代表値であり、先端面 x = L の温度ではない。解析的な先端面温度は参照記録に別途ある（正準条件で対流先端 340.239853 K、断熱先端 340.746691 K）。
- η・ε は過渡中は瞬時損失ベースの診断量であり、定常到達時に古典値と一致する（項目13）。

## 10. 結果の解釈

- 検証の実測（出典：`FIN_CONVECTIVE_TIP_DEVELOPMENT.md`、参照は50桁 mpmath の解析解と行列指数による独立伝播。正準条件）：
  - 定常解析値：対流先端で q = 5.2597314113 W、η = 0.855240880、ε = 35.0648761。断熱先端で q = 5.1663430295 W、η = 0.861057172、ε = 34.4422869（断熱側は既に照合済みの閉形式値と生成器内で一致を確認）。
  - 定常場の RMS 誤差（対セル平均、n=16/32/64）：対流先端 0.015835 / 0.003982 / 0.001007 K（空間次数 1.992 / 1.984）、断熱先端 0.015770 / 0.003944 / 0.000986 K（次数 2.000 / 2.000）。JS 定常解と独立ネットワークの離散定常解は全格子で RMS 1e-7 K 未満で一致する。
  - 断熱帰着：n=64 の JS 定常で η = 0.8610408（照合済み値との差 1.6e-5）、q = 5.1662450 W（差 9.8e-5 W）。
  - 過渡（n=16、t = 20 s）：行列指数参照との最大差は刻み safeDt/2 で 0.0213 K、safeDt/4 で 0.0106 K。時間次数は 0.9985 / 0.9990（前進 Euler の1次と一致）。
- 先端対流の効果：短フィン条件（L = 0.02 m、厚さ 0.002 m、奥行き 0.05 m、他は正準と同じ）では、先端対流により定常熱流量が断熱先端比で +4.6336%（解析）／+4.6338%（JS 実測、n=32）増え、先端損失は 0.14583 W だった。正準条件でも +1.81% の増加がある。フィンが短いほど先端の寄与は相対的に大きい。

## 11. モデルの仮定

- 一定断面・一定物性。断面内は一様温度（Bi ≤ 0.1 を開発範囲として検査）。
- 側面と先端で同じ h。基部温度は固定。
- スナップショットの assumptions に明記：修正長さ近似ではない（`correctedLengthApproximation:false`）、放射なし、流体連成なし、2D伝導・基部熱拡がりなし。

## 12. モデルの限界

- GUI・Worker 接続・ブラウザー確認・公開可否は未実施。`releaseApproved:false`、公開 allowlist 外。
- 先端だけ別の h、軸方向に変化する h は未対応。変断面フィン、温度依存物性、放射、基部の2D熱拡がり・接触抵抗、複数フィン／フィン間流れは未対応で、入力は原子的に拒否されるか assumptions に明示している。風速→h 推定は別モジュール（`wind-heat-transfer.mjs`）の担当で、本モジュールには含まない。
- 開発範囲は断面 Bi ≤ 0.1、セル数 4〜256 で、範囲外は推定値を返さず拒否する。

## 13. よくある誤解

- **「修正長さ法 Lc = L + Ac/P は厳密解」** — 誤り。断熱近似の一種であり、対流先端の厳密解との差は正準条件で相対誤差 0.00018%、短フィン条件でも 0.00018% と本条件範囲では非常に小さいが、近似であることに変わりはない。本モジュールは修正長さを使わず、先端面の対流を直接離散化している。なお L のままの断熱式では相対誤差 1.7755%（正準）／4.4284%（短フィン）になる。
- **「先端温度の出力が先端面の温度」** — 誤り。最終セルの代表値であり、先端面の解析値は参照記録に別途ある（項目9）。
- **「過渡中の η がそのまま定常のフィン効率」** — 誤り。過渡中は瞬時損失ベースの診断量であり、定常到達時に古典値と一致する。
- **「対流先端では η の分母に先端面を入れてはいけない」** — 誤り。本モデルと既存学習モデルでは、対流先端の場合 A_s に先端面 Ac を含める定義で統一している（項目4）。
