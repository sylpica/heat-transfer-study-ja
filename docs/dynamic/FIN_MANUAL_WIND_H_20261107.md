# モデル別説明書：風速→熱伝達率 h 推定

- 日時：2026-11-07（Asia/Tokyo）
- 対象モデル：開発専用モジュール `dynamic/dev/wind-heat-transfer.mjs`（`estimateWindHeatTransfer`、法則識別子 `wind-heat-transfer-correlation-v1`）。フェイリス側ブランチ `feiris/fin-wind-h`（起点 `0fa3965`、コミット `adaa7ff`）の成果物で、本線への統合は未実施。GUI はなく、相関式の評価器とその返却レコードが対象である。
- 位置づけ：正本 §21.2 がモデルごとに求める16項目の説明書。相関式・式番号・適用範囲の正は開発文書 `docs/dynamic/WIND_HEAT_TRANSFER_DEVELOPMENT.md` と参照記録 `docs/dynamic/WIND_HEAT_TRANSFER_REFERENCE_20261107.json` であり、本書はそれらと矛盾しない要約と、独立項目として不足していた使用例・誤解・読み方を補う。本モデルは時間発展を解くシミュレーションではなく、定常な相関式の評価であるため、項目5（初期条件）など該当しない項目はその旨を明記する。
- 読み分け：項目1〜2・9〜10・13 は初心者向け、それ以外は専門寄りの記述を含む。

## 1. 現象の概要

流速（風速）だけが分かっているときに、平板や円柱の表面の対流熱伝達率 h を、教科書 *A Heat Transfer Textbook*, 6th ed. に印刷された相関式だけから推定する。正本 §7 の要求「風速から熱伝達率を推定する場合は、流れの条件と相関式の適用範囲を確認する」「任意の風速変更に対し、根拠なく熱伝達率を比例変更しない」に対応し、適用範囲外では推定値を返さず理由つきで拒否する。推定した h は、フィン／ヒートシンクの各モデルが受け取る「規定の一様 h」として渡す量である。

## 2. 現実世界での使用例

- ファンで冷やすフィンやヒートシンクについて、風速しか分からない段階で h の概算を得て、各フィンモデルの入力にする。
- 平板状の基板や円柱（管・ピンフィン）が流れの中でどれくらい冷えるかの学習・概算。
- 相関式ごとに適用範囲が違うこと、範囲外では推定できないことの確認。
いずれも相関式の適用範囲内での学習・概算のためであり、範囲外の外挿や実設計の保証には使わない（項目12）。

## 3. 支配方程式

支配方程式に相当するのは、教科書の以下の相関式群である（すべて教科書の式番号つき。物性は膜温度評価）。

平板（等温・板全体の平均 Nu_L）：

| レジーム | 式 | 適用範囲（拒否条件） |
|---|---|---|
| 層流 `laminar` | Nu_L = 0.664 Re_L^{1/2} Pr^{1/3}（式 **6.68**） | Pr ≧ 0.6、Pe_L > 100（境界層近似）、Re_L ≦ 5×10⁵（全体が層流） |
| 液体金属 `liquid-metal` | Nu_L = 1.13 Pe_L^{1/2}（式 **6.69**） | Pe_L > 100。液体のみ |
| 観測遷移 `mixed-observed`（気体） | 式 **6.120**（乱流部＋層流部＋遷移部の3領域平均）、勾配 c は式 **6.115** | 気体のみ。遷移開始 Re_l ≦ 5×10⁵、Re_l < Re_u ≦ Re_L、Pr ≧ 0.6 |
| 急峻遷移 `mixed-abrupt`（気体） | 式(6.120)の例題 **6.11** による縮約 | 0 ≦ Re_trans < Re_L、Pr ≧ 0.6。遷移域省略の近似である旨を警告に明示 |
| 急峻遷移 `mixed-abrupt`（液体） | 乱流部を局所式 **6.113** から展開した形 | 同上。式(6.120)そのものではない導出形であり、識別子 `6.120-abrupt-liquid` と本書で区別する |

円柱横流れ（円周平均 Nu_D、Churchill–Bernstein 系の構成式選択）：

| 条件 | 式 |
|---|---|
| Pe_D ≦ 0.2 | Nu_D = 1/(0.8237 − ln Pe_D^{1/2})（式 **7.67**、Nakai–Okazaki） |
| Re_D < 4000 | 式 **7.66** |
| 40,000 < Re_D < 400,000 | 式 **7.68**（原典に4/5乗はなく、印刷どおりに実装） |
| その他 | Churchill–Bernstein 全体式 **7.65**（既存の静的モデル `cylinder-crossflow.mjs` の実装を共有し、値の drift を構造的に防ぐ） |

h は h = Nu·k/L（円柱では L = D）で得る。フィン付き面は `fin-plate` を平板、`fin-pin` を円柱の代表形状として扱う。

## 4. 記号と単位

| 記号 | 意味 | 単位 |
|---|---|---|
| u∞ | 主流速度（風速） | m/s |
| L, D | 代表長さ（平板の長さ、円柱の直径） | m |
| ρ, μ, cp, k | 密度、粘度、比熱、熱伝導率（膜温度で評価した利用者供給値） | kg/m³, Pa·s, J/(kg·K), W/(m·K) |
| ν = μ/ρ, α = k/(ρcp) | 動粘度、熱拡散率 | m²/s |
| Ts, T∞ | 表面温度、主流温度 | K |
| Tf = (Ts + T∞)/2 | 膜温度（物性評価温度） | K |
| Re, Pr, Pe = Re·Pr | Reynolds 数、Prandtl 数、Péclet 数 | — |
| Nu | Nusselt 数（平板は平均 Nu_L、円柱は円周平均 Nu_D） | — |
| h | 熱伝達率（推定の出力） | W/(m²·K) |
| c | 観測遷移の勾配（式 6.115） | — |
| Re_trans, Re_l, Re_u | 遷移 Reynolds 数、遷移開始／終了 Reynolds 数 | — |

## 5. 初期条件

本モデルは時間発展を解かないため、初期条件は存在しない。代わりに必要な入力は、形状（`flat-plate`／`cylinder`／`fin-plate`／`fin-pin`）、主流速度、代表長さ、膜温度で評価した物性（ρ・μ・cp・k）、表面温度と主流温度（膜温度の報告用）、平板ではレジームと遷移条件である。物性は既存の静的モデルと同じく利用者供給であり、流体データベースや温度補間による推定はしない。

## 6. 境界条件

境界条件に相当するのは相関式の前提である：平板は等温面、円柱は円周平均の扱い、物性は膜温度 Tf = (Ts + T∞)/2 で評価すること（教科書の指定、§6.5・§7.6）。フィン付き面は代表形状（平板／円柱）として扱い、フィン間干渉・バイパス流れ・フィン効率は含まないことが結果に警告として明示される。

## 7. 数値計算法

- 閉形式の評価であり、格子・時間積分はない。入力から Re・Pr・Pe を計算し、項目3の範囲選択で相関式を1つ選び、Nu と h を返す。
- 式(7.65) は既存の静的モデル `cylinder-crossflow.mjs` の `churchillBernsteinNu` をそのまま呼び出し、実装間の値の drift を構造的に防ぐ。式(7.65) が選ばれる範囲では既存モデルと値は完全一致する。
- 拒否条件（推定値を返さない）：Pr < 0.6 の層流、Pe ≦ 100 の平板、レジーム未指定での Re_L > 5×10⁵（外挿禁止）、遷移条件の欠落・逆転・Re_l > 5×10⁵、Re_D > 10⁷（教科書 Fig. 7.11 のデータ範囲と既存静的モデルの教育用制限に合わせた保守的上限）、円柱へのレジーム指定、未知キー、非有限・非正入力。
- 境界の扱い（テストで確認済み）：Pe_D = 0.2 ちょうどは式(7.67)、Re_D = 4000／400,000 ちょうどは式(7.65)。

## 8. 計算過程

1. 形状・速度・代表長さ・物性・温度を入力する（物性は膜温度で評価して用意する）。
2. モジュールが Re・Pr・Pe を計算し、レジーム／構成式を選んで Nu を評価する。範囲外なら理由を表示して推定しない。
3. h = Nu·k/L を返し、警告（遷移が始まり得る領域、圧縮性の確認、代表形状の扱いなど）を確認する。フィン／ヒートシンクへは `heatSinkHFromWind` アダプタで h を渡せる。

手計算による検算の例（出典：`WIND_HEAT_TRANSFER_DEVELOPMENT.md` の例題6.5）：層流平板で Re_L = 384,615.38（教科書印刷値 384,600）、Nu_L = 366.156（印刷値 366.2）、h = 21.3835 W/(m²·K)（印刷値 21.4）、膜温度 65 ℃も一致する。

## 9. グラフの読み方

- 本モデルには画面・グラフはない（開発専用、GUI 未実施）。結果は返却レコードで読む：`nusselt`、`h`、採用された相関の識別子 `correlation`、観測遷移の勾配 `transitionSlope`、`reynolds`／`prandtl`／`peclet`、`filmTemperatureK`、`warnings`。
- `correlation` は「どの式で推定したか」を示す最重要の項目で、値だけを見て式を確認しないと、境界付近での式の切替わり（項目13）に気づけない。

## 10. 結果の解釈

- 検証の実測（出典：`WIND_HEAT_TRANSFER_DEVELOPMENT.md`。参照は mpmath 50桁の生成器で、モジュール値は50桁参照と相対差 10⁻¹² 以内で一致し、教科書の印刷値とは印刷丸めの範囲で一致する）：
  - 例題6.9（観測遷移）：c = 2.54536（印刷値 2.55。印刷値は c を丸めて使用）、Nu_L = 1434.03（印刷値 1433）、h = 18.9292（印刷値 18.92）。差は c の丸め由来と特定されている。
  - 例題6.11（急峻遷移）：Re_trans = 4×10⁵ で Nu = 1759.87（印刷値 1760）、8.7×10⁵ で 1151.71（印刷値 1152）。
  - 例題7.8（円柱、式(7.66) を順方向評価）：Nu_D = 10.6943（印刷値 10.69）、h = 2833.98（印刷値 2833）。
  - 式(7.67) は Pe = 0.1 で Nu_D = 0.506331（印刷値なし、50桁参照と照合）。
  - 式(7.68) と式(7.65) は Re = 10⁵ で 243.952 対 214.126 となり、教科書の「(7.65) は約20%過小評価」という記述と整合する。
- 速度に対する非比例性：層流平板では流速4倍で h は2倍（√比例）であり、線形比例ではない。レジームが変われば比例関係自体が変わる。

## 11. モデルの仮定

- 返却レコードの assumptions に明記：物性は膜温度評価、一定物性、等温面、滑らかな面、非圧縮流。一方で放射・浮力（混合対流）・フィン干渉は含まず、流体そのものは解いていない。
- 平板は等温・板全体の平均の相関であり、局所 h の相関ではない。

## 12. モデルの限界

- GUI・ブラウザー確認・公開可否は未実施。`releaseApproved:false`、公開 allowlist 外。
- 対象外として明示的に扱わないもの：平板の局所 h、一様熱流束平板、非加熱始端、粗さ壁、圧力勾配、管群、球・その他の形状、自然対流との混合対流、放射、物性の温度依存の自動評価。100 m/s 超では圧縮性の確認が必要という警告のみで、圧縮性そのものは解かない。
- 式(7.66) と式(7.65) の間には Re_D = 4000 の境界で構成式由来の段差（約5.5%、Pr に依らず実モジュールで実測）がある。教科書の構成そのまま であり、境界付近の値はどちらの式でも相関のばらつき内とみなすべきである。
- 液体の急峻遷移形は式(6.113) からの導出であり、教科書に印刷された完成形ではない（識別子と本書で区別済み）。Pe_D ≦ 0.2 の領域は既存静的モデルが拒否していた範囲を式(7.67) で拡張したもので、この拡張域に既存モデルの対応値は存在しない。

## 13. よくある誤解

- **「風速を2倍にすれば h も2倍」** — 誤り。層流では √ 比例（流速4倍で h 2倍）、乱流側では 0.8 乗に近い比例で、レジームをまたげば関係自体が変わる。根拠のない比例変更はしない設計である。
- **「式(7.68) と式(7.65) の値が違うのはどちらかのバグ」** — 誤り。教科書自身の構成式選択であり、該当帯域では (7.65) がデータを約20%過小評価すると教科書が述べている。
- **「物性は主流温度や表面温度で評価すればよい」** — 誤り。教科書の指定は膜温度 Tf = (Ts + T∞)/2 である。
- **「フィン面で推定した h にはフィン効率まで含まれている」** — 誤り。推定されるのは表面の対流熱伝達率そのもので、フィン効率・フィン間干渉・バイパス流れは含まない。フィン側の計算は各フィンモデルの担当である。
- **「範囲外でも式をそのまま外挿すれば概算になる」** — 誤り。本モジュールは範囲外では推定値を返さず拒否する。相関式の範囲外の値は根拠を持たない。
