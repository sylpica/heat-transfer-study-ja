## 段階1：定常Blasius流れと質量

一様外流U、零圧力勾配、2D平板、定物性・層流の境界層近似。η=y√(U/(νx))、ψ=√(νUx)f(η)、f‴+f f″/2=0、f(0)=f′(0)=0、f′(∞)=1を別の開発用factoryで解く。u=ψ_y、v=−ψ_x。全Navier–Stokes/運動量の非定常発達/圧力投影を解いた表示はしない。先端x=0はψ=Uyの極限、板上はψ=0。先端角の極限は不連続で、先端近傍の実流れを保証しない。

RK4射撃・二分法でf″(0)を求め、η12までの独自表をHermite補間し、外側はf′=1の漸近形を使う。有限η・補間誤差を別に検証する。流量は格子頂点ψ差から直接作り、MAC面の平均速度へ換算する。セルの離散発散と領域流量を確認し、温度計算で非保存の速度を無断使用しない。Re_L=10⁴〜10⁵、H/L≤.2、η(H,L)=10〜24、横4〜256/縦8〜128に開発範囲を制限。範囲内でも実流れの遷移/乱れを保証しない。

独立Python/SciPy solve_bvpまたはshooting＋DOP853で、η上限16/24の相違を確認し、物理座標の全face流量へ照合する。製品RK4/補間/流量関数を参照へ流用しない。事前予算：f″(0)絶対差<1e−11、全face体積流量のL1流量尺度での最大差<1e−9、離散発散/領域質量の正規化差<1e−12。複数格子/寸法・U/ν相似、板/入口/外側境界、未知条件・範囲外・非有限入力の拒否を試験する。この段階は速度生成の検証で、熱伝達やGUIの承認ではない。
