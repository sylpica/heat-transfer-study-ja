## 実際に計算・表示する範囲

定常Blasius速度を指定し、セル平均温度をFV/SSPRK2で時間発展させる。非定常運動量・圧力・浮力・一般NS・先端の有限な点熱流は解かない。長さ100 mm、換算幅10 mm、入口300 Kの空気参考物性。速度1.575〜15.75 m/s、板温差±30 K、格子32×16〜512×256。遠方計算高さは外端η=12から決まり、板厚や固体上壁ではない。

温度または実面流量から再構成した速さ、実際の板区間平均q″、瞬間の板平均Nu、符号付き4成分の熱・蓄熱・流量・刻みを表示。温度差0ではNuを未定義とする。熱矢印は板から流体へ正。測定は所属セル平均と実セル中心を表示し、クリック/矢印キーで移動。初期の有限Nuは離散格子の値で、先端・瞬間の物理的最大値と呼ばない。

A/Bの色・速度矢印・板熱矢印の基準と物理y縮尺を共通化。Uの異なる条件の計算高さをそれぞれ同じ高さに引き伸ばさない。縦の拡大表示は実倍率を明記し、実寸比にも戻せる。画面の時計・条件・図・全熱・履歴を一致させる。条件draftが不正・未適用でも、前回受理済みの図を新条件の結果と表示しない。

## 操作と数値上限

再生・停止・コマ送り・実復元・再計算、最大2条件。時間入力の空欄刻みはA/B最小safeDtの1/4、表示区間は0超〜.2 s。安定上限と精度は異なる。既定64×32・.01sは独立物理アフィン指数に対しこの1/4刻みで最大差.000462666 K（FLAT_PLATE_AIR_TIME_REFERENCE_20261106_v1.json）。最細1/8の.000115126 KをGUI既定結果に転用しない。空間精度は別のPr.71/1・精細格子の限定測定で、全ての粗格子/速度/空気条件を精度承認したものではない。
