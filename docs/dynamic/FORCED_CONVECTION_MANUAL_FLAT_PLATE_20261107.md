## 1. 現象の概要

一様な流れ U の中に置かれた平板の上では、粘性のために壁近くの流れが遅くなり、境界層が下流へ向かって厚くなる（Blasius の層流境界層）。平板が流れと違う温度に保たれると、温度の境界層も発達する。このモデルは2段構成で、まず定常な Blasius 相似解から質量を保存する面流量を作り（速度段階）、その中で温度だけを非定常に解く（温度段階、受動温度）。圧力や運動量そのものは解かない。

## 2. 現実世界での使用例

- 平板状の電子基板や太陽熱集熱板が風で冷える（または温まる）ときの、平均熱伝達率の見積もりの学習。
- 「先端で局所熱流束が特異的に大きく、全板平均 Nu の収束が遅い」ことの実感。
- Pr 数が変わると温度境界層の厚さと壁勾配 g′(0) がどう変わるか（Pr = 0.71 と 1 の比較）。
いずれも境界層近似の中の学習モデルであり、実在の物体まわりの流れの保証には使わない（項目12）。

## 3. 支配方程式

零圧力勾配・一様外流・2D・定常層流境界層近似。

- Blasius 方程式：f‴ + f f″/2 = 0、η = y√(U/(νx))、ψ = √(νUx) f(η)。板で f = f′ = 0、遠方で f′ = 1。壁曲率 f″(0) = 0.3320573362… が壁せん断と熱伝達の基準になる。
- 温度の相似解：g″ + (Pr/2) f g′ = 0（等温板）。g′(0) が局所熱伝達を決め、平均 Nusselt 数は Nu_L = 2 g′(0) √Re_L（Re_L = 10⁴ の参照では Pr = 0.71 で g′(0) = 0.2941649050 → Nu_L = 58.83298100、Pr = 1 で g′(0) = f″(0) → Nu_L = 66.41146724。出典は項目10）。
- 温度段階の輸送方程式：∂T/∂t + u ∂T/∂x + v ∂T/∂y = α ∂²T/∂y²、α = k/(ρcp)。入口 T∞、板 Tw、上端遠方 T∞、右端と上端は移流流出。
- 軸方向（x 方向）熱伝導・浮力・粘性加熱・圧力仕事・物性変化は省略する。温度は速度へフィードバックしない。

## 4. 記号と単位

| 記号 | 意味 | 単位 |

| U | 一様外流速度 | m/s |
| L | 板長 | m |
| D（スパン） | 奥行き（熱量換算幅。有限側壁ではない） | m |
| x, y | 流れ方向、壁垂直方向の座標 | m |
| η = y√(U/(νx)) | Blasius 相似変数 | — |
| f, f′, f″ | 相似流れ関数とその微分 | — |
| g, g′(0) | 温度相似関数と壁勾配 | — |
| u, v | 速度成分（ψ の差から作る面流量の平均） | m/s |
| ρ, ν, cp, k | 密度、動粘度、比熱、熱伝導率（一定物性） | kg/m³, m²/s, J/(kg·K), W/(m·K) |
| α = k/(ρcp) | 熱拡散率 | m²/s |
| T∞, Tw | 主流温度、板温 | K |
| θ = T − T∞ | 主状態として保持する温度差 | K |
| Re_L, Pr | Reynolds 数、Prandtl 数 | — |
| Nu_x, Nu_L | 局所／全板平均 Nusselt 数 | — |

## 5. 初期条件

温度段階は θ = 0（全域が主流温度）または指定した初期場から開始する。初期の半セル由来の Nu は格子依存値であり、先端の物理的な初期ピークではない（項目13）。速度場は定常で、時間の初期条件を持たない。

## 6. 境界条件

- 板（y = 0）：T = Tw（等温）。板の面速度 v = 0、滑りなしは相似解に含まれる。
- 入口（x = 0）：T = T∞。ただし先端 x = 0 は相似解の特異点であり、角の速度とせん断の点値は有限最大値に置き換えない。
- 上端：有限の計算高さ（外端 η = 10〜24）に T∞ を置き、上端からの移流流出も保持する（勝手にゼロにしない）。遠方 η → ∞ の近似との違いは項目12の限界である。
- 右端：移流流出。

## 7. 数値計算法

- 速度段階：製品は独自の RK4 射撃／二分法で相似 ODE を η ≦ 12・8192区間で解き、f／f′ に Hermite 補間、外側は傾き1へ接続する。面流量は格子頂点の ψ 差 × 奥行き D で構成し、内部流量の発散と入口・流出の一致を検査する。板のせん断は各 x 区間の解析平均として保持し、平均摩擦係数 4f″(0)/√Re_L を照合する。
- 温度段階：一様矩形有限体積、風上移流／中央 y 伝導、正性を保つ SSPRK2。主状態は θ で保持し、板入力・上端伝導入力・右端移流出力・上端移流出力・正味入力の5成分を Kahan 積算で別々に保持する。安全刻みは流出熱容量流量と伝導 G の和から算出する。
- 受理範囲（実コードと開発文書で確認）：速度段階は Re_L = 10⁴〜10⁵、H/L ≦ 0.2、外端 η = 10〜24。温度段階は Pr = 0.6〜2、温度差は T∞ の10%以内。未知の温度条件・範囲外は拒否し、失敗時は旧温度・時計・熱履歴を保持する。`releaseApproved:false`。

## 8. 計算過程

1. 形状（L、スパン D）、物性、U、T∞、Tw、格子（nx × ny）と表示区間を設定する（画面の空気参考条件：L = 100 mm、換算幅 10 mm、入口 300 K、U = 1.575〜15.75 m/s、板温差 ±30 K、格子 32×16〜512×256）。
2. 速度段階が Blasius 解から面流量を作り、温度段階の Worker が SSPRK2 で θ を時間発展させる。
3. 板区間の平均 q″、瞬間の板平均 Nu_L、4成分の熱と蓄熱が表示される。A/B は色・速度矢印・板熱矢印の基準と物理 y 縮尺を共通化して比べる。

検算の例：相似参照では Re_L = 10⁴・Pr = 1 で Nu_L = 66.41146724（項目10）。画面の粗い格子の平均 Nu がこの値と数%ずれるのは欠陥ではなく、先端特異性の解像不足として記録されている（項目10・13）。

## 9. グラフの読み方

- 画面は温度場、再構成した速さ、板の区間平均 q″ の矢印、瞬間の板平均 Nu、4成分の熱・蓄熱・流量・刻みを表示する。縦の拡大表示は実倍率を明記し、実寸比にも戻せる。U の異なる条件の計算高さを同じ高さに引き伸ばすことはしない。
- 測定は所属セルの平均と実セル中心を表示し、クリック／矢印キーで移動する。
- 温度差 0 では Nu は未定義として表示される。初期の有限な Nu は離散格子の値で、先端・瞬間の物理的最大値として読んではいけない。

## 10. 結果の解釈

検証の実測（出典：`FLAT_PLATE_BOUNDARY_FLOW.md`、`FLAT_PLATE_THERMAL.md`、`FLAT_PLATE_UI.md`。予算は実行前に事前登録された）：

- 速度段階：独立参照（SciPy solve_bvp、η = 16／24）で f″(0) = 0.3320573362151983、製品との差 7.49e-14 未満。別 DOP853＋Brent 射撃との補助比較も 2.11e-11 未満。全 face 流量差は流量尺度で最大 1.86e-14 未満、発散と全体流量の予算も成功。
- 温度段階の時間精度：独立参照（別 SciPy Blasius BVP の連続速度求積＋物理座標 FV 疎行列のアフィン行列指数）に対し、16×16・Pr = 0.71・t = 0.5 で最大温度差が刻み細分化により 0.00957256 → 0.00013928 K、最終次数 2.00099。全積算熱成分も同じ2次で近づく。
- 定常の空間精度と**未達の保持**：独立な温度相似 ODE からの実セル平均に対し、元の一様格子系列（32×16 → 256×128）では全板平均 Nu の差が Pr = 0.71 で +2.0467%、Pr = 1 で +2.5112% と、予算 <2% を**未達のまま保持**している。追加格子では Pr = 0.71 の 512×128 で 1.69515%（成功）、Pr = 1 は 512×128 で 2.06369%（未達）、y も増やした 512×256 で 1.44515%（成功）。局所熱流は先端を除けば良好（L2 で 0.24% 級）で、全指標の単調改善は主張されていない。
- フェイリス側の独立検証（検証ノート §24、リポジトリ外）：Blasius 方程式と温度相似 ODE を独立に解き（solve_bvp、η 上限30）、f″(0) = 0.3320573362、g′(0) は Pr = 0.71 で 0.2941649050 → 平均 Nu_L = 58.83298100、Pr = 1 で 66.41146724 と、Codex の事前登録参照値と**全桁一致**した。したがって上記の未達は参照側の問題ではない。また別の離散化（相似速度場を与えるマーチング法）では全板 Nu が参照へ下から単調収束し（Pr = 1、256×128 で −6.00%）、2つの独立した離散化が参照を両側から挟む。Codex 側の正の偏りは、先端セルの半セル固定温度処理による局所熱流の過大評価と整合的と切り分けられている。
- 画面の既定（64×32・0.01 s）は独立物理アフィン指数に対し safeDt/4 で最大差 0.000462666 K。最細刻みの値を GUI 既定結果へ転用することはしない、と画面文書は明記している。

## 11. モデルの仮定

- 境界層近似そのものが仮定である：零圧力勾配、層流、定物性、平板は無限に薄く側壁なし。速度段階の assumptions に明記：定常境界層近似、零圧力勾配、層流、一様外流、一定物性、有限の外端、先端の速度極限は特異、非定常運動量は解かない、全 Navier–Stokes は解かない。
- 温度は受動的で、速度へフィードバックしない。温度段階の assumptions に明記：規定の定常 Blasius 場、軸方向伝導・浮力・粘性加熱の省略、上端の移流を含む、有限の外端温度境界、一般 CFD の精度は検証していない。
- 小温度差という条件だけで浮力の無視が保証されるわけではない（開発文書の注意）。

## 12. モデルの限界

- 開発専用・未公開。実機・支援技術・専用オフライン・外部専門家の確認は未実施。画面のブラウザー確認は Chromium で実施済み（実 Worker・復元・A/B・モバイル明暗・DPR2。WebKit は検証環境で起動できず未実施）。
- 扱わないもの：圧力勾配のある流れ、遷移・乱流、粗さ、圧縮性、浮力・共役伝熱、物性変化、一般形状・3D、非定常運動量。
- 全板平均 Nu の <2% 予算は元の一様格子系列では未達のまま保持されている（項目10）。全入力範囲の科学的誤差保証はない。
- 本分野（強制対流）全体の残作業として、円柱まわりの過渡モデルとフィン間の流れのモデルは開発専用として存在するが公開画面はない。圧力・速度連成 CFD の強制対流形状への接続、流体入口発達（速度助走区間）、温度依存物性も未実施である（締め可能性監査の残作業 #1〜#5）。

## 13. よくある誤解

- **「平均 Nu が参照と2%ずれるのは参照値が間違っている」** — 誤り。参照値は2つの独立解法（本線の SciPy BVP と検証ノート §24 の独立 BVP）で全桁一致しており、ずれは製品側の先端解像の問題と切り分けられている。未達は予算を緩めず保持されている。
- **「先端の熱流束が有限値で表示されるはず」** — 先端 x = 0 の局所熱流は相似解で特異であり、有限最大値に置き換えることはしない。区間平均として積分した量が正しい読み方である。
- **「Blasius 解を使っているから Navier–Stokes を解いている」** — 誤り。解いているのは境界層近似の相似 ODE と、その中での受動温度輸送であり、運動量の時間発展も圧力も解かない。
- **「温度差が小さければ浮力は無視できる」** — 小温度差は必要条件側の目安にすぎず、それだけで浮力無視は保証されない。本モデルは浮力を解かない前提を明記して運用する。
- **「格子を x 方向だけ細かくすれば平均 Nu はすぐに収束する」** — 先端特異性に支配されるため x のみの精細化では誤差はゆっくりしか減らない（独立検証での観測次数は約 0.3）。壁際 y 精細化や先端 x 集積が次の手段と記録されている。
