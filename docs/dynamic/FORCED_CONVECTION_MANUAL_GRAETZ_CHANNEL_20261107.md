## 1. 現象の概要

2枚の平行な板の間に、すでに放物線状に発達した層流（Poiseuille 流）が流れている。入口では流体は一様な温度だが、壁が加熱または一定温度に保たれているため、流れ方向に進むにつれて温度分布が発達していく（熱的入口発達、Graetz 型の問題）。このモデルは**定常**の温度場を、時間発展ではなく流れ方向へのマーチングで直接解く。壁条件は3種から選べる：(a) 両壁一定壁温、(b) 両壁一定熱流束、(c) 片壁（下壁）一定熱流束・他壁（上壁）断熱。

## 2. 現実世界での使用例

- プレート式熱交換器や薄い流路（コールドプレート、マイクロチャネル）の入口付近で、熱伝達率が下流ほど下がって発達値に近づく様子の学習。
- 「壁温一定」と「熱流束一定」と「片側だけ加熱」では発達した Nusselt 数がどう違うか（7.541／8.235／5.385）の確認。
- 入口直後で局所熱伝達率が非常に大きくなる（Lévêque 漸近）理由の理解。
いずれも指定された発達速度場の中の受動温度の学習モデルであり、実際の流路設計の保証には使わない（項目12）。

## 3. 支配方程式

全高さ H、長さ L の平行平板間。速度は発達した Poiseuille 流を**与え**（解かない）、温度だけを定常エネルギー方程式で解く。

- 速度分布（原書式 **7.62**）：u/u_av = (3/2)[1 − 4(y/b)²]（b＝板間隔＝H）。モジュール内では u = 6U z(1−z)、z = y/H と置く。
- エネルギー方程式（軸方向熱伝導を省略）：u(y) ∂T/∂x = α ∂²T/∂y²、α = k/(ρcp)。
- 入口条件：x = 0 で T = T_in（一様）。
- 壁条件（3種）：(a) 両壁 T = Tw、(b) 両壁 q″＝一定（流体へ正）、(c) 下壁 q″＝一定・上壁断熱（∂T/∂y = 0）。
- 水力直径 Dh = 2H。バルク温度の定義は原書 §7.2 式(7.3)〜(7.5)。軸方向の発達の進み具合は、Graetz 数（式(7.26)）に関連する無次元軸距離 x* = x/(Dh·Re_Dh·Pr) で整理する。
- 既知の駆動圧力勾配 dp/dx = −12ρνU/H²、壁せん断の大きさ 6ρνU/H は診断として示すが、圧力場を解いた表示はしない。

## 4. 記号と単位

| 記号 | 意味 | 単位 |
|---|---|---|
| H, L | 板間隔（全高さ）、流路長さ | m |
| depth | 奥行き（熱量換算のスパン。有限側壁ではない） | m |
| U | 平均流速（バルク速度） | m/s |
| u(y) | 発達速度分布（放物線） | m/s |
| ρ, ν, cp, k | 密度、動粘度、比熱、熱伝導率（一定物性、利用者供給） | kg/m³, m²/s, J/(kg·K), W/(m·K) |
| α = k/(ρcp) | 熱拡散率 | m²/s |
| T_in, Tw | 入口温度、壁温（条件(a)） | K |
| q″ | 壁熱流束（条件(b)(c)、流体へ正） | W/m² |
| Tb(x) | バルク（混合平均）温度 | K |
| Dh = 2H | 水力直径 | m |
| Re_Dh, Pr, Pe_Dh = Re·Pr | Reynolds 数、Prandtl 数、Péclet 数 | — |
| x* = x/(Dh·Re_Dh·Pr) | 無次元軸距離（熱的発達のものさし） | — |
| Nu_Dh, Nu_x | 平均／局所 Nusselt 数（Dh 基準） | — |

## 5. 初期条件

定常モデルなので時間の初期条件はない。代わりの「入口条件」が一様温度 T_in であり、流れは入口から発達済み（速度の入口発達は扱わない）と置く。過渡応答は解かない。

## 6. 境界条件

項目3の3種がすべてである。対称性：条件(a)(b) は上下対称、条件(c) は非対称（加熱壁と断熱壁で温度が異なる）。局所 Nu の定義は条件で異なる：(a)(b) は両壁共通の壁−バルク温度差、(c) は原書式(7.63) 第3ケースの定義に合わせ**加熱壁の熱流束と加熱壁−バルク温度差**で定義する（両壁平均は使わない）。q″ = 0 または Tw = T_in では局所 Nu は全区間未定義（null）とし、0除算の値を表示しない。断熱壁の温度は、発達分布で壁面の T_yy = 0 となる性質から隣接セル平均を壁面値として報告する（半セル再構成はしない）。

## 7. 数値計算法

- 流れ方向：有限体積の風上セル収支（流出は自セルのセル平均温度）。x 格子は等間隔、または入口側を細分する幾何格子（増加率 1〜1.25）。
- 横断方向：陰的3重対角（Thomas 法）。速度は放物線の解析セル平均を用いる。
- バルク温度は行の熱容量流量 ρcp·ū_j·dy による重み付き平均（行平均同士の積による断面近似のため、厳密積分との差 O(dy²) を残すことを開発文書に明記）。
- 一定熱流束では壁温をセル平均に q″dy/(2k) を加えて再構成し、一定壁温では壁熱流束を半セル差分 k(Tw − T)/(dy/2) から求める。断熱壁は上端セルの上面に拡散結合を持たせない形で課す。
- 収支：壁からの総熱移動率と流体の顕熱増加（出口バルク−入口）を毎回照合し、残差（絶対・相対）を結果に記録する。実測では照合した全ケースで相対残差 1e-9 未満（概ね 1e-12 台）。
- 受理範囲（実コードで確認）：Re_Dh ≦ 2300、Pe_Dh ≧ 100。未知キー・非有限値・範囲外は日本語エラーで拒否し、結果を返さない（純関数で部分状態は残らない）。計算途中で非有限・非正・監視上限超過の温度が出た場合も受理しない。

## 8. 計算過程

1. 形状（H、L、奥行き）、物性、U、T_in と壁条件（種類と Tw または q″）、格子（nx、ny、幾何格子の増加率）を入力する。
2. ソルバーが入口から下流へ1列ずつマーチングし、各列で横断方向の陰的系を解く。
3. 各 x 位置のバルク温度・壁温・局所 Nu と、出口での収支残差が返る。画面では温度場と分布、測定点の読み値を確認する。

検算の例（出典：`GRAETZ_CHANNEL.md`）：一定熱流束で十分長い流路（L = 30 m、x* ≈ 3.3）では、出口局所 Nu = 8.2352940 となり、厳密値 140/17 = 8.2352941…、原書式(7.63) の 8.235 と一致する。壁−バルク温度差は 4.5995672 K で、quartic 解の (q″H/k)(17/70) = 4.5995671 K と一致する。

## 9. グラフの読み方

- 画面（`graetz.html`、開発専用）は温度場の分布、x 方向のバルク温度・壁温・局所 Nu の変化、測定点の値を表示する。表示値と直接ソルバー計算の一致は Chromium のブラウザー試験で確認されている。
- 入口直後（x* が小さい領域）の局所 Nu は非常に大きく、格子依存のセル平均量である。有限の物理的な「初期最大値」として読んではいけない（項目13）。
- 条件(c) では上下の壁温が非対称に表示されるのが正常であり、断熱壁の出力熱流束は全区間厳密に 0 である。

## 10. 結果の解釈

検証の実測（出典：`GRAETZ_CHANNEL.md`。連続参照と解析限界による裏付け）：

- 連続スペクトル参照との照合（一定熱流束、Python の cosine-Galerkin スペクトル解。JS の有限体積作用素を流用していない）：格子 16×8 → 128×64 で出口 Nu の相対差が 1.6487% → 0.4484% → 0.1335% → 0.04435% と単調減少。全場に単一の収束次数は主張しない（x 風上と y 拡散の寄与混在、入口角の特異性）。
- 発達限界：一定熱流束 Nu = 8.2352940（厳密 140/17）、一定壁温の局所 Nu は x* = 0.202 で 7.54049（原書式(7.63)／Table 7.4 の 7.541 との差 5.1e-4）。片壁熱流束・他壁断熱では出口 Nu が 70/13 = 5.384615… へ下から単調に近づく（ny = 128 で差 −1.8e-9）。加熱壁−バルク差 (13/35)(q″H/k)、両壁温度差 (1/2)(q″H/k)、バルク−断熱壁差 (9/70)(q″H/k) の解析関係も実測で一致し、冷却（q″ < 0）でも同じ発達 Nu になる。
- 入口漸近（Lévêque）：局所 Nu は Nu_Dh,x = C·(12·Gz_x)^{1/3} に従う。定数は相似 ODE の定義から独立に計算されており、一定壁温で C = 1.23255058（θ′(0) = 0.53836605）、一定熱流束で C = 1.49039964（φ(0) = 1.53611717）。ソルバーの帯域平均は漸近値より +0.68%／+0.63%（x* ∈ [1e-4, 5e-4)）で、上から近づく。同じ定数を円管に適用すると原書式(7.28) の Lévêque 枝の係数 1.077 が再現されることも確認されている（形状が違うため平板の値には使わない）。
- フェイリス側の独立参照（検証ノート §22、実装受領前の事前計算。リポジトリ外記録）：独立マーチング解法で、一定壁温（Tw = 350 K）の出口バルク温度 348.42075 K・Nu 7.5407、一定熱流束（q″ = 1000 W/m²）の出口バルク温度 637.82068 K（エネルギー収支 637.82015 K と差 0.0005 K）・Tw − Tb = 91.9917 K・Nu 8.2353 を得ており、実装の結果と一致する。第3境界条件についても独立検算（同 §25）で両壁温度差 9.469697 K が解析値と全桁一致している。
- 過渡ソルバー `heated-channel`（本線）の定常到達点との一致（最大差 約 1.1e-10／2.3e-10 K）は、同一離散系の別解法どうしの整合性であり、連続解への裏付けはスペクトル参照と解析限界が担う、と区別されている。

## 11. モデルの仮定

- 速度は発達した Poiseuille 流を規定し、温度へはフィードバックしない（受動温度）。定物性。
- 軸方向熱伝導を省略する（Pe_Dh ≧ 100 の入力域で運用）。奥行きは一様な 2D 場の熱量換算スパンであり、有限の側壁を持つ矩形管ではない。
- 結果オブジェクトの前提明記どおり、圧力場は解かず、既知の駆動圧力勾配を表示するに留める。

## 12. モデルの限界

- 統合ツリーへ統合済み・開発専用（公開未承認）。`releaseApproved:false`、公開 allowlist 外。ブラウザー確認は Chromium のみ（WebKit はこの環境で起動できず未実施）。実機・支援技術・オフライン・外部専門家の確認は未実施。
- 扱わないもの：速度入口発達、非定常運動量、粘性加熱、浮力、物性の温度依存、側壁・一般形状・3D、乱流、過渡応答。
- Re_Dh ≦ 2300 は層流の目安として設定した上限であり、精度保証の境界ではない。Pe 基準による軸方向伝導の省略は入力域の限定であり、省略誤差の上界を証明したものではない。
- 本線の締め可能性監査の時点では、本モデルは「別ブランチの定常 Graetz 実装（未統合・件数に算入しない）」と位置づけられていた。その後、統合ウェーブ1で開発専用モジュールとして統合ツリーへ統合された（公開は未承認のまま）。

## 13. よくある誤解

- **「入口の局所 Nu が大きいのは入口効果で物理的に正しい最大値」** — 入口直後の値は一様入口と壁条件が角で適合しないことによる格子依存のセル平均量で、x = 0 の特異点そのものは評価しない。物理として読めるのは Lévêque 漸近への近づき方である。
- **「発達 Nu は壁条件によらず同じ」** — 誤り。平行平板では一定壁温 7.541、両壁一定熱流束 8.235、片壁熱流束・他壁断熱 5.385（加熱壁基準）と、条件ごとに異なる（原書式(7.63)）。
- **「片壁条件の Nu は両壁の平均で定義する」** — 誤り。本モデルは原書の定義に合わせ、加熱壁の熱流束と加熱壁−バルク温度差で定義する。定義を変えれば数値は変わる。
- **「定常解は過渡ソルバーを長時間回したものと同じはず」** — 離散系が同じなら定常到達点は一致する（実測 約 1e-10 K）が、それは同一 PDE・同一離散化の範囲の話であり、連続解の正しさの証明はスペクトル参照と解析限界が担う。
- **「奥行きを変えれば側壁のある矩形管になる」** — 誤り。奥行きは熱量換算のスパンで、側壁は存在しない。

## 15. 関連問題

対応付けは棚卸し記録 `docs/dynamic/MODEL_PROBLEM_MAP_20261107.md`（第5.1節・第8節）に基づく。

**現行の問題バンク（751問）に、本モデル（平行平板チャネルの熱発達・Graetz 問題）に直接対応する問題はない。** 「Graetz／グレツ」を名指しする問題は 0 件であり、平行平板チャネルの熱発達・バルク温度の指数減衰そのものを扱う問題はバンクに無い。推測で埋めず、その事実をここに明記する。

最も近いのは、非円形ダクトの発達した流れの Nu と境界条件を扱う次の問題である。

- `supp-geometry-correlation-square-h-v1` — 正方形ダクトの発達層流の Nu_Dh。
- `supp-geometry-correlation-duct-thermal-boundary-v1` — ダクトの周方向の熱的境界条件と Nu。
- `supp-geometry-correlation-duct-dh-not-sufficient-v1` — 水力直径 D_h だけでは Nu が決まらないこと。

入口・助走区間の考え方については、円管・一定壁温の説明書の項目15に主掲載された助走区間の 4 件も近い。
