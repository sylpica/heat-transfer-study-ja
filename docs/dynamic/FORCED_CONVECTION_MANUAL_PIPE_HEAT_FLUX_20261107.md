## 1. 現象の概要

円管の中を、すでに放物線状に発達した層流（Hagen–Poiseuille 流）が流れている。管壁からは一定の熱流束 q″ が与えられ（加熱または冷却）、流体は流れ方向に進みながら一様に温まっていく。十分下流では温度分布の形が固定され（熱的に発達し）、壁温とバルク温度の差が一定値に落ち着いて、その比から Nusselt 数 4.364（= 48/11）が得られる。このモデルは入口から発達までの**非定常**の温度発展を、軸対称の環状セルで解く。熱流束は課すが壁温は結果として計算され、両方を同時に課すことはしない。

## 2. 現実世界での使用例

- 電気ヒーターで管壁からほぼ一定の熱流束が入る管内加熱で、壁温がバルク温度よりどれだけ高くなるかの学習。
- 「一定熱流束では発達 Nu が 4.364、一定壁温では 3.657」と条件で値が違う理由の理解。
- 加熱と冷却（q″ の符号反転）で温度場が対称に振る舞うことの確認。
いずれも指定された発達速度場の中の受動温度の学習モデルであり、実際の配管設計の保証には使わない（項目12）。

## 3. 支配方程式

軸対称の円管（半径 R、長さ L）。速度は発達した Hagen–Poiseuille 流 u(r) = 2Ub(1 − (r/R)²) を**与え**（解かない）、温度だけをエネルギー方程式で解く。

- エネルギー方程式（軸方向流体伝導を省略）：∂T/∂t + u(r) ∂T/∂x = α (1/r) ∂/∂r (r ∂T/∂r)、α = k/(ρcp)。
- 入口条件：x = 0 で T = T_in（一様）。壁条件：r = R で −k ∂T/∂r = q″（一定、流体へ正が加熱）。
- バルク温度 Tb(x) の定義は教科書 §7.2 式(7.3)〜(7.5)。発達領域では壁−バルク温度差が一定となり、Nu_D = q″D/(k(Tw − Tb)) → 48/11 = 4.3636…（教科書 式(7.23) の印刷値 4.364）。
- 発達した温度分布は quartic（4次）型の解析形を持ち、これが独立検証の連続参照に使われている（項目10）。
- 注意：教科書 §7.5 は、Table 7.4 の一定熱流束の値が「周方向に一様な壁温」を仮定した値であることに注意を促している。本モデルの q″ は周方向一様な熱流束であり、条件の取り違えに注意する（項目13）。

## 4. 記号と単位

| 記号 | 意味 | 単位 |
|---|---|---|
| R, D = 2R, L | 管半径、直径、管長 | m |
| Ub | 平均（バルク）流速 | m/s |
| u(r) | 発達速度分布（放物線） | m/s |
| ρ, ν, cp, k | 密度、動粘度、比熱、熱伝導率（一定物性） | kg/m³, m²/s, J/(kg·K), W/(m·K) |
| α = k/(ρcp) | 熱拡散率 | m²/s |
| T_in | 入口温度 | K |
| q″ | 壁熱流束（一定、符号つき） | W/m² |
| Tw(x, t) | 壁温（計算結果） | K |
| Tb(x, t) | バルク温度 | K |
| θ = T − T_ref | 保持する温度オフセット（主状態） | K |
| Re_D, Pr, Pe_D = Re·Pr | Reynolds 数、Prandtl 数、Péclet 数 | — |
| Nu_D | 壁−バルク基準の Nusselt 数（瞬間値／発達値） | — |

## 5. 初期条件

管内は一様温度（入口温度が既定）から開始する。初期の瞬間 Nu（= 4·nr の形で現れる値）は半セル処理による格子依存値であり、物理的な初期最大値ではない（項目13）。

## 6. 境界条件

- 壁：r = R で熱流束 q″ を課す。壁温はセル平均から半セル伝導で再構成して表示する（結果量）。
- 対称軸：r = 0 は断熱壁ではなく軸対称の中心で、軸の熱流は面積 0 のためゼロになる。画面でも対称軸と外周壁を区別する。
- 入口：T = T_in（一様）。出口：移流流出。
- 壁熱は全円周 2πRL で積算し、質量流量は ρUbπR² を使う（矩形モデルの奥行き換算に置き換えない）。
- 一定壁温モデル（別モデル）の snapshot との混用は拒否する。

## 7. 数値計算法

- 空間：円管の環帯有限体積（環帯の体積平均が状態）。軸方向は風上、半径方向は中央差分。
- 時間：SSPRK2。主状態は θ で保持し、微小な熱を絶対温度の丸めで捨てない。
- 収支：壁／入口／出口／正味の4成分の熱、全環帯の蓄熱を保持し、完全復元／取消が可能。壁熱と蓄熱の照合が受理条件に含まれる。
- 精度についての正直な区別：軸方向の風上と入口の平均積の誤差を含むため、**全場が2次精度とは主張しない**（時間積分の次数 2 とは別の話。項目10）。
- 受理範囲（開発文書と事前登録に基づく）：Re_D ≦ 1000、Pe_D ≧ 100、L/D ≧ 5、固定物性・小温度差。`releaseApproved:false`。

## 8. 計算過程

1. 形状（R、L）、物性、Ub、T_in、q″（符号つき）、格子と1コマの物理時間を設定する。
2. Worker が自動刻み（画面の空気参照では事前に選ばれた safeDt/8）で時間発展させ、温度場・壁温・バルク温度・瞬間 Nu と4成分の熱が表示される。
3. A/B 比較では2条件を共通の色尺度で比べられ、巻き戻しは同じ場を再現する。無効入力の後は受理済みの条件と時刻が保持される。

検算の例：十分下流の定常的な断面では壁−バルク温度差が一定になり、Nu_D は 48/11 = 4.3636… に近づく（項目10の最細格子実測 4.36447122）。

## 9. グラフの読み方

- 画面は r ≧ 0 の半径断面を表示するが、これは全円周の環帯平均を塗ったもの。表示は実寸からの半径方向拡大を明記している。測定位置は、選択位置／環帯の面積重心／壁を区別して表示される。
- 壁熱の符号は加熱・冷却で反転し、実熱積算（J）と瞬間率（W）は別々に表示される。
- 瞬間 Nu は過渡の比であり、q″ = 0 や壁−バルク差 0 では未定義になる。定常相関として読んではいけない（項目13）。

## 10. 結果の解釈

検証の実測（出典：`HEATED_PIPE.md` と各参照 JSON。予算は実行前に事前登録された）：

- 時間精度：独立な環帯行列指数（別の物理環帯 C/G・放物線流量の原始関数で構成）に対し、全温度最大差 7.71628e-6 K、全4成分の熱差 1.40220e-5 J、時間次数 2.01776。
- 空間精度：独自の quartic 連続場の環帯体積平均と、別の定常疎行列による参照に対し、4格子で RMS が 0.0137647 → 0.00659505 → 0.00321097 → 0.00158372 K と縮小（最終次数 1.01969。軸方向風上の1次寄与を反映する）。最細格子の Nu は 4.36447122 で、厳密値 48/11 との差は 0.0191321%。
- 実空気寸法の独立指数参照では、既定 32×16・0.01 s・safeDt/8 で最大差 6.41234e-6 K、全熱差 1.69375e-10 J、時間次数 2.00442。ただしこれは固定 300 K 物性の計算であり、空気物性モデル自体の独立測定ではない、と開発文書は区別している。
- 実 Worker の全場・全4熱が時間参照と照合され、完全復元、破損した熱や未知物理の拒否後の状態保持、取消後の再計算、加熱・冷却の対称が Chromium／WebKit の双方で確認されている。
- なお上記の定常比較は「独立な定常ソルバーで解いた場」との比較であり、製品を一様初期条件から時間発展させて定常に到達させた試験ではない、と開発文書は明記している。

## 11. モデルの仮定

- 速度は発達した Hagen–Poiseuille 流を規定し、温度へはフィードバックしない（受動温度）。定物性・小温度差。
- 結果オブジェクトの assumptions に明記：軸対称温度、環帯体積平均が状態、バルクは環帯平均の積、壁温は半セル再構成、軸方向流体伝導・粘性加熱・浮力は省略、入口運動量は解かない、一般 CFD ではない。
- 圧力勾配と壁せん断は既知の解析量として表示するもので、圧力場を解いてはいない。

## 12. モデルの限界

- 開発専用・未公開。実機・支援技術・開発専用オフライン・外部専門家の確認は未実施。画面のブラウザー確認は Chromium で実施済み（WebKit は検証環境で起動できず未実施）。
- 扱わないもの：軸方向流体伝導、速度入口発達・非定常運動量、粘性加熱、浮力、乱流、一般形状・3D、温度依存物性。
- 全場の空間精度は1次寄与を含む（項目7・10）ため、細格子での値だけを見て高次精度と誤解してはいけない。

## 13. よくある誤解

- **「一定熱流束の発達 Nu は 3.657」** — 誤り。3.657 は一定壁温の値（式(7.22)）。一定熱流束では 48/11 = 4.364（式(7.23)）であり、平行平板の 140/17 = 8.235 とも幾何が違う。
- **「Table 7.4 の一定熱流束の値をそのまま使える」** — 教科書 §7.5 の注意どおり、Table 7.4 の一定熱流束の値は周方向一様な壁温を仮定した条件の値であり、本モデルの「周方向一様な熱流束」とは条件が異なる。値の出所の条件を確認すること。
- **「時間次数が2だから場全体も2次精度」** — 誤り。時間積分は2次だが、空間は軸方向風上などの1次寄与を含み、実測の空間次数は約 1.02 である。
- **「初期の Nu が大きいのは入口効果の物理的最大値」** — 初期値（4·nr の形）は半セル処理の格子依存値で、物理的な最大値ではない。
- **「瞬間 Nu を定常相関として設計に使える」** — 誤り。瞬間 Nu は過渡の比であり、q″ = 0 や壁−バルク差 0 では未定義になる。
