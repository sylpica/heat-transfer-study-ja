## 1. 現象の概要

円管の中を、すでに放物線状に発達した層流（Hagen–Poiseuille 流）が流れている。管壁は一定温度 Tw に保たれ、入口から一様温度の流体が入る。流体は壁から熱を受け（または壁へ熱を失い）、下流へ進むにつれてバルク温度が壁温へ指数関数的に近づいていく（教科書 §7.4 の Graetz 型の熱的入口発達）。このモデルはその**非定常**の温度発展を、軸対称の環状セルで解く。壁温は課すが壁の熱流束は結果として計算され、両方を同時に課すことはしない。

## 2. 現実世界での使用例

- 恒温槽や蒸気ジャケットで壁温がほぼ一定に保たれる管内加熱・冷却で、出口温度が壁温へどこまで近づくかの学習。
- 「十分に長い管では発達 Nusselt 数が 3.657 になる」ことと、「入口付近では局所 Nu がそれより大きい」ことの区別。
- 式(7.57) の指数減衰（バルク温度の壁温への接近）を、入口効果を含む数値解と比べる教材。
いずれも指定された発達速度場の中の受動温度の学習モデルであり、実際の配管設計の保証には使わない（項目12）。

## 3. 支配方程式

軸対称の円管（半径 R、長さ L）。速度は発達した Hagen–Poiseuille 流 u(r) = 2Ub(1 − (r/R)²) を**与え**（解かない）、温度だけをエネルギー方程式で解く。

- エネルギー方程式（軸方向流体伝導を省略）：∂T/∂t + u(r) ∂T/∂x = α (1/r) ∂/∂r (r ∂T/∂r)、α = k/(ρcp)。
- 入口条件：x = 0 で T = T_in（一様）。初期条件：管内一様温度（項目5）。
- 壁条件：r = R で T = Tw（一定）。壁熱流束は壁の伝導 G = k·2πR·dx/(dr/2) を介して各段で計算する結果量である。
- バルク温度 Tb(x) の定義は教科書 §7.2 式(7.3)〜(7.5)。十分発達した領域では Nu_D → λ₁/2 = 3.65679…（教科書 式(7.22) の印刷値 3.657）。λ₁ = 7.3135869155… は Graetz 固有問題 (zf′)′ + λz(1 − z²)f = 0 の第1固有値である。
- バルク温度の指数減衰 式(**7.57**) については項目10・13で注意するとおり、h 一定を前提とする関係式であり、発達値 3.657 をそのまま代入すると入口効果の分だけ厳密解とずれる。本モデルは (7.57)＋3.657 で計算してはいない。

## 4. 記号と単位

| 記号 | 意味 | 単位 |

| u(r) | 発達速度分布（放物線） | m/s |
| ρ, ν, cp, k | 密度、動粘度、比熱、熱伝導率（一定物性） | kg/m³, m²/s, J/(kg·K), W/(m·K) |
| α = k/(ρcp) | 熱拡散率 | m²/s |
| T_in, Tw | 入口温度、壁温 | K |
| Tb(x, t) | バルク温度 | K |
| θ = T − T_ref | 保持する温度オフセット（主状態） | K |

## 5. 初期条件

管内は一様温度（画面の実空気条件では入口温度と同値が既定）から開始する。初期の瞬間 Nu（= 4·nr の形で現れる値）は半セル処理による格子依存値であり、物理的な初期最大値ではない（項目13）。

## 6. 境界条件

- 壁：r = R で T = Tw を課す。壁熱は半セル伝導で計算し、壁の G を安定刻みの上限にも含める。
- 対称軸：r = 0 は断熱壁ではなく軸対称の中心であり、軸の熱流は面積 0 のため自動的にゼロになる。画面でも対称軸と外周壁を区別して表示する。
- 入口：T = T_in（一様）。出口：移流流出。
- 一定熱流束モデル（別モデル）の snapshot や同時 q 入力は拒否する（壁温と熱流束を同時に課さない）。

## 7. 数値計算法

- 空間：円管の環帯有限体積（環帯の体積平均が状態）。軸方向は風上、半径方向は中央差分。
- 時間：SSPRK2（正性を保つ2段 Runge–Kutta）。主状態は θ（基準温度からのオフセット）で保持し、絶対温度の丸めで微小な熱を捨てない。
- 収支：壁／入口／出口／正味の4成分の熱、全環帯の蓄熱、収支の丸め予算を保持し、完全復元／取消（巻き戻し）が可能。質量流量は ρUbπR² の解析値と照合される。
- 受理範囲（実コードで確認）：Re_D ≦ 1000、Pe_D ≧ 100、L/D ≧ 5。この範囲外、未知キー、別モデルの snapshot は日本語の理由つきで拒否し、受理済み状態を保持する。`releaseApproved:false`。

## 8. 計算過程

1. 形状（R、L）、物性、Ub、T_in、Tw、格子（nx × nr）と1コマの物理時間を設定する（画面の実空気プリセット：300 K 参考空気、L = 50 mm／R = 5 mm、Ub 0.24〜1.5 m/s、Tw と入口／初期 280〜330 K、格子 32×16／64×32／128×64）。
2. Worker が自動刻み（事前登録では safeDt/16）で時間発展させ、温度場・壁熱流束・バルク温度・瞬間 Nu が表示される。
3. A/B 比較では2条件を共通の色尺度で比べられ、巻き戻しは bit 単位で同じ場を再現する。

検算の考え方：定常に近づいた出口バルク温度は、Graetz 級数解（項目10）で独立に検算できる。安易に式(7.57) へ発達 Nu 3.657 を代入した値とは一致しないのが正しく、その理由は項目10・13にある。

## 9. グラフの読み方

- 画面は r ≧ 0 の半径断面を表示するが、これは全円周の環帯平均を塗ったもので、管を切り開いた半分の実像ではない。測定位置は、選択位置／環帯の面積重心／点としての壁温を区別して表示される。
- 壁熱の矢印は各断面の実計算結果の符号だけを示す（加熱と冷却で向きが反転する）。
- 瞬間 Nu は過渡の比であり、Tw = Tb では未定義、q = 0 かつ Tw ≠ Tb では比 0 を保持する。定常相関の値として読んではいけない。

## 10. 結果の解釈

検証の実測（出典：`PIPE_WALL_TEMPERATURE.md` と各チェックポイント。予算は実行前に事前登録された）：

- 時間精度：独立な環帯行列指数（別の物理環帯 C/G・放物線流量の原始関数・壁面 Dirichlet G で構成）に対し、元の刻み safeDt×1〜1/16 では全熱差 9.93e-4 J が予算 1e-4 J を**未達**だった記録が、閾値を緩めずそのまま保存されている。事前に追加された 1/32・1/64・1/128 では熱差が 2.46e-4 → 6.14e-5 → 1.53e-5 J、最細温度差 1.94e-7 K、時間次数 2.00380 で達成した（v1 の未達は書き換えられていない）。
- 発達限界の独立照合：80桁べき級数から λ₁ = 7.31358691552658…、Nu_D = λ₁/2 = 3.65679345776329… を求め、別 IVP と Gauss 積分で照合（場差 8.13e-15、Nu 差 2.5e-14）。定常場の4格子系列は RMS 0.0122028 → 0.00149266 K と縮小し（最終次数 0.99418、入口の風上1次を反映）、最細格子の Nu は 3.65620038 で固有値解との差 0.0162186%。
- 式(7.57) との関係：(7.57) は h 一定を前提とするため、発達値 3.657 を代入すると出口バルク温度は 302.783 K となり、級数解とは入口効果の分だけずれる（画面条件 L/D = 5、x* = 0.0223 では熱的に発達途上で、出口局所 Nu は約 4.09）。正しい長さ平均 Nu（級数解で約 5.64、Hausen 相関でも約 5.60 と裏付けられる）を使えば (7.57) は級数解・本モデルと一致する。画面の理論欄は 3.6568 を「十分熱的発達の検算値」と明示し、瞬間 Nu を定常相関として使うなと警告しており、製品側に不整合はない。
- フェイリス側の独立検証（本線外の作業記録）：自前の50桁 Graetz 級数で λ₁ = 7.3135869155265847、Nu∞ = 3.6567934578 が画面の理論欄と一致。定常出口バルク温度は級数解 303.9534 K に対し、数値核が格子 32/64/128 で 303.9406／303.9454／303.9490 K と単調に収束（最細で差 −0.0043 K、駆動温度差 10 K の 0.043%）。画面表示値と数値核の直接計算も表示桁まで一致し（t = 0.01 s で 300.0121896 K 対 300.01218959 K）、質量流量は解析値と全桁一致、収支差は 1.7e-18 J だった。
- 画面の既定条件（Tw 310／Tin 300／Ub 0.5、0.01 s）は別の行列指数参照に対し全場最大差 2.64e-5 K、時間次数 2.00685。
- なお上記の定常比較は「独立な定常ソルバーで解いた場」との比較であり、製品を一様初期条件から定常まで時間発展させた試験ではない、と開発文書は区別している。

## 11. モデルの仮定

- 速度は発達した Hagen–Poiseuille 流を規定し、温度へはフィードバックしない（受動温度）。定物性。結果オブジェクトの assumptions に明記：軸対称温度、環帯体積平均が状態、バルクは環帯平均の積、壁熱は半セル伝導、軸方向流体伝導・粘性加熱・浮力は省略、入口運動量は解かない、一般 CFD ではない。
- 圧力勾配と壁せん断は既知の解析量として表示するもので、圧力場を解いてはいない。

## 12. モデルの限界

- 開発専用・未公開。実機・支援技術・専用オフライン・外部専門家の確認は未実施。画面のブラウザー確認は Chromium で実施済み（実 Worker・A/B・巻き戻し再現・モバイル明暗・DPR2。WebKit は検証環境で起動できず未実施）。
- 扱わないもの：非定常運動量、速度入口発達、軸方向流体伝導、粘性加熱、浮力、温度依存物性、乱流、非円形・周方向非一様・3D。
- 受理範囲は Re_D ≦ 1000、Pe_D ≧ 100、L/D ≧ 5 の受動温度の限定であり、この範囲外の精度は主張しない。

## 13. よくある誤解

- **「式(7.57) に Nu = 3.657 を入れれば出口温度が出る」** — 誤り。(7.57) は h（したがって Nu）が一定という前提の式で、入口発達の途中では局所 Nu は 3.657 より大きい。発達値をそのまま入れると入口効果の分だけ出口バルク温度がずれる（項目10の実測：302.783 K 対 級数解 303.9534 K）。長さ平均の Nu を使えば (7.57) は正しく使える。
- **「3.657 は 3.66 と書いても同じ」** — 検算値としては 3.6567934578… が固有値 λ₁/2 であり、平板の 7.541 や円管一定熱流束の 48/11（= 4.364）と取り違えてはいけない。
- **「瞬間 Nu が表示されているから定常の熱伝達率が分かる」** — 誤り。瞬間 Nu は過渡の比で、Tw = Tb では未定義になる。定常相関として使うものではない。
- **「初期の Nu が大きいのは入口効果の物理的最大値」** — 初期値（4·nr の形）は半セル処理の格子依存値で、物理的な最大値ではない。
- **「壁温を課せば壁熱流束も同時に指定できる」** — 誤り。壁温を課した系では熱流束は結果である。同時指定の入力は拒否される。
