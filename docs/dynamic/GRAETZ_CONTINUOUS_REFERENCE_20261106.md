## 独立解法と入口角

z=y/H、Q=qH/k、g=2q/(ρcpUbH)、f=Q(17/70−z+2z³−z⁴)とし、T=Tin+gx+f+wへ分離する。wはu(y)∂xw=α/H² ∂zzw、横断Neumann境界、入口w=−fを満たす。

`scripts/dynamic-graetz-reference.py` は対称cosine基底からPoiseuille速度重みの平均を引き、既知のゼロ重み平均を正確に分離する。重み行列は解析積分、別のGauss積分へ照合し、正の横断拡散との対称一般化固有分解を使う。x方向の指数解とx/yセル積分は閉形式。JS有限体積/数値ネットワークは流用しない。

x=0で一様入口と非ゼロ壁勾配は角で適合しない。入口は速度重み付きL2で与え、角の点wise勾配や有限初期Nuを保証しない。正のxと有限xセル平均を照合する。半セル壁再構成の初期Nu4nyとは別である。

64/128、256/512、512/1024の試行では一部セル平均のモード精細化差が1e-7 Kを超えた。閾値を変えず768/1024対称モードへ精細化し、全4格子の差は最大約3.36e-8 K。4096/6144/8192積分点での精細化差は約3.5e-12 K以内。解析重み行列と数値積分の差/重み平均の残差もJSONへ記録。参照/ソースhash/環境はGRAETZ_CONTINUOUS_REFERENCE_20261106.jsonに保持する。
