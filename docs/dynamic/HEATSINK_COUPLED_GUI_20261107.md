# ヒートシンク連成モデル 開発画面（GUI）

2026-11-07。ブランチ `feiris/heatsink-coupled-gui`、基点＝連成モジュール先端 `c940d4b`。
連成モデル `dynamic/dev/heat-sink-coupled.mjs`（「ヒートシンク連成モデルの本線 dev 実装」で
検証済み）を画面で操作できるようにした記録。モデル本体は無変更（git diff 空）。

## 画面構成

新規ファイル（すべて `dynamic/dev/` 配下、公開ビルドの allowlist には入れない）：

- `heat-sink-coupled.html` — 画面本体。他の開発画面と同じ `cavity.css` を使用。
- `heat-sink-coupled-ui.mjs` — DOM 配線と Worker クライアント。
- `heat-sink-coupled-ui-config.mjs` — プリセット、単位換算（画面表示単位→コアの SI キー）、表示フォーマッタ。
- `heat-sink-coupled-worker.mjs` — Worker 入口。定常連成解は1回が重い（r=4 で十数秒級）ため
  メインスレッドでは解かず、`solveHeatSinkCoupled` をそのまま呼び、結果から
  温度場と添字関数を除いた plain データだけを返す。
- `heat-sink-coupled-view.mjs` — 流路ごとの流量配分の棒グラフ（canvas）。

入力（編集可能）：プリセット（標準条件／放射なし ε=0／高発熱・大流量）、フィン本数・
フィン厚さ・フィン間隔・フィン高さ・流路長さ・ベース厚さ、固体の熱伝導率、空気の
密度・比熱・熱伝導率・動粘度、周囲・入口温度、総流量 [L/min]、発熱量、放射率 ε、
発熱パッチ長さ・幅、格子細分化 r（1/2/4）、速度副格子細分化（1/2）。

表示：発熱面平均温度・圧損・放射（開口）・流体への熱とエンタルピー増加・フィン端面の
対流・基部セル最大／発熱面最大／基部体積平均温度・全熱収支の残差・平均流速と Re/Pe、
流路ごとの流量（棒グラフ＋数値）と出口バルク温度、診断（法則・未知数・反復履歴・
残差最大・流量係数の級数差・形態係数閉包誤差・境界温度近似の注記・実測計算時間）。

## 画面値とモジュール値の一致（実測）

ブラウザーテスト `tests/dynamic-heat-sink-coupled-browser.mjs`（Playwright/Chromium）で、
Node 側で計算したコア結果と画面表示を同じフォーマッタで突き合わせ、全件合格：

- 標準条件プリセット（r=4・速度副格子2・ε=0.8）：発熱面平均 **316.6867 K**、
  圧損 **3.0417 Pa**、放射 **0.22714 W**、基部セル最大、流路1の流量 5.4000 L/min、
  出口バルク温度が表示桁まで一致。
- 放射なしプリセット（ε=0）：発熱面平均 316.9890 K、放射 0.00000 W が画面に出ることを確認。
- 数値の出所はモジュール記録（HEATSINK_COUPLED_JS_20261107.md）の JS 実測値と同一
  （参照計算との差は最大でも 5×10⁻⁸ K）。

## 拒否表示の確認

コアの拒否理由を画面が書き換えずそのまま表示することを、ブラウザーテストで
コア側の例外メッセージと文字列一致まで確認：

- 総流量 0 → 「流量0または逆流は自然対流モデルが必要であり、この強制対流参照では解きません。」
- 発熱パッチ幅 50 mm（ベース幅超過）→ 「発熱パッチが基部下面の外に出ています。」

## 途中で見つけて直した不具合

- 初版は 375px で横はみ出し 159px。原因はプリセット select の長い選択肢ラベル
  （select が 484px に広がり fieldset ごと押し出した）。対策：選択肢ラベルを短縮し、
  ページ内スタイルで `fieldset{min-width:0}` と `select{max-width:calc(100vw - 4rem)}` を追加。
  修正後に同条件で再測定し、はみ出し 0 を確認（ブラウザーテストの幅検査にも組み込み済み）。
- ブラウザーテスト側の待機マーカーの取り違え（圧損は放射率に依らないため ε=0 の
  旧表示で待機が即通過した）を、発熱面温度マーカーへ修正。画面側の不具合ではない。
