## モデル（Python 参照と同一の離散化）

- ベース: 3D 定常有限体積伝導。下面中央のパッチ（標準 30×9 mm）から一様流入、
  他の外側面は断熱。フィン根元・流体への界面は半セル抵抗の直列
  `G=A/[ds/(2ks)+df/(2kf)]` で内部交換として1回だけ組む。
- フィン: 厚さ方向一様、流れ方向 x と高さ z の 2D 伝導。先端断熱。
  前後の薄い端面だけは学習用モデルと同じ規定 `h_ref` で周囲へ対流（流体解には含めない）。
- 流れ: 断面の発達 Stokes/Poisson 解（側面・底面 no-slip、上面 free-shear）から
  共通圧力差の並列流量配分。速度は温度と独立（一定物性・浮力なし）。
  v2 方式として速度 Poisson だけを各方向2倍に細分化し、セル平均で温度格子へ制限する。
- 流体温度: 指定速度による受動輸送。x 方向は保存的1次風上、軸方向拡散なし、
  横断・高さ方向は拡散。入口は周囲温度。
- 放射: 各 x 列の長ダクト断面について交差弦法の形態係数と射度法。
  遮蔽・相互反射・上部開口（黒体）・ガード流路外壁の拡散反射（ε=0）を含む。
  放射は隣接固体セル温度で評価し、独立の表面節点は解かない（Python 参照と同じ近似）。
- 非線形: 温度差 θ=T−Tamb を未知数とし、`(Tamb+θ)^4−Tamb^4` を展開形で計算、
  線形行列を固定した放射 Picard 反復。収束条件は Python と同じ
  （更新差 <1e-10 K かつ全残差最大 <1e-10 W、60 反復以内、温度は (0, 500] K 予算内）。
- 線形解法だけが Python（疎直接法 LU）と異なる: JS では CSR + ILU(0) 前処理付き
  BiCGSTAB を使う。解く離散系は同一であり、最終判定は真の非線形残差で行う。

標準条件（Python `Conditions` と同一）: 長さ 120 mm、フィン 7 本・厚さ 1 mm・
高さ 30 mm、隙間 3 mm×8 流路、ベース厚さ 3 mm（幅 31 mm）、固体 k=167 W/(m·K)、
空気 ρ=1.177 kg/m³・cp=1006 J/(kg·K)・k=0.0264 W/(m·K)・ν=1.575e-5 m²/s、
周囲・入口 300 K、総流量 7.2e-4 m³/s（43.2 L/min）、発熱 10 W、ε=0.8。
`h_ref = 7.5407008740694379 · k_air/(2s) = 33.17908384590553 W/(m²·K)`。

格子（細分化 r）: Nx=8r、基部 Ny=31r（隙間 3r＋フィン足跡 r の交互）/Nz=r、
フィン Nz=4r、流体 Ny=3r/Nz=4r。未知数は r=1: 1,240、r=2: 9,024、r=4: 68,608。

## 受理基準（測定前に固定。後付けで緩めない）

Python 側 PLAN.md の事前基準と、本線 JS の参照値突き合わせ基準を併記する。

1. 熱収支: 全収支の相対残差 <1e-8。固体‐流体内部交換の差（界面熱と流体エンタルピー増の差）
   および放射内部収支の差は絶対値 <1e-8 W。
2. 流量係数: 最細格子で連続級数（鏡像矩形級数）に対する相対差 <2%。
   圧力指定→流量の往復は相対 1e-12 以内。
3. 格子収束: r2→r4 の発熱面平均温度上昇の変化 <3%、基部セル最大温度上昇の変化 <3%。
4. 参照値突き合わせ（r=4、ε=0.8、速度副格子2）: Python 参照
   発熱面平均 316.6866687041174 K に対し |Δ| ≤0.05 K、
   圧損 3.0416976229211974 Pa に対し |Δ| ≤0.005 Pa、
   放射（開口）0.2271442670380633 W に対し |Δ| ≤0.001 W。
   r=1/r=2 の発熱面平均（317.4943819436352 K / 316.8991015011487 K）も同 tolerance で照合する。
5. 放射オフ帰着（ε=0、r=4）: 放射は厳密に 0 W、発熱面平均は Python 参照
   316.98898894367477 K に対し |Δ| ≤0.05 K。線形系のみへ帰着し Picard は1反復で収束すること。
6. 無発熱: 全場が厳密に 300 K（θ≡0）。
7. 停止流: 流量 0 以下は自然対流と呼ばず明確に拒否する。
8. 既存学習用モデル・公開側は無変更。全 Node スイートは基点
   1,671 件＝1,666 合格／0 失敗／5 スキップに対し失敗 0 を維持し、
   公開ビルド成功、dist 棚卸し（節 76 件・dynamic 47 エントリ・開発モジュール混入 0）を不変とする。

### 収支・収束（基準1・2・3・6）

- 全収支の相対残差: r=1 で 7.9e-11、r=2 で 2.1e-10、r=4 で 3.4e-9（いずれも <1e-8）。
  Python（直接法）は r=4 で相対 1.45e-12 であり、JS の残差が大きいのは反復法の
  残差（方程式あたり最大 ~1e-11 W）が出口エンタルピー等の総和に蓄積するためで、
  基準内であることを記録する。界面熱−流体エンタルピー増の差は r=4 で −3.0e-10 W、
  放射内部収支の差は −1.9e-16 W（ともに |差| <1e-8 W）。
  最終解の非線形残差最大は固体 9.9e-12 W・流体 5.3e-12 W（予算 1e-10 W 内）。
- 流量係数: 最細格子の相対差 0.685% <2%。圧力指定→流量の往復は相対 1e-12 以内
  （テストで確認）。断面 Poisson 残差最大 ~1e-19（rhs 規模比で実質零）。
- 格子収束 r2→r4: 発熱面平均の上昇変化 1.27307%、基部セル最大の上昇変化 0.56607%
  （ともに <3%。Python 整理値 1.27307%／0.566069% と一致）。
- Picard 反復: r=4・ε=0.8 で 6 反復（Python は 7。初期解と線形解法の経路差による）、
  ε=0 で 1 反復。線形反復（BiCGSTAB）の総数は r=4 で 553 回。
- 無発熱: θ は厳密に 0（全場 300 K）。
- 形態係数の閉包誤差最大 3.6e-14、射度演算子の相反性（相対）3.1e-16。

## 対象外・残件

- 停止流の自然対流（Boussinesq 連成・開口/圧力境界の別検証が必要。本モデルは流量 0 を拒否）。
- 完全な 3 次元 CFD（速度の入口発達・3D 運動量・剥離/再循環・乱流・ファン曲線・マニホールド損失）。
- 全方向放射（x 方向の非局所放射、端部/外面/先端の 3D 形態係数、鏡面・参加気体）。
- 温度依存物性、接触抵抗の未知値、実測による性能認定、専門家の承認。
- 放射の表面節点（対流界面温度と放射評価温度の厳密一致）は Python 参照でも残件であり、本実装も同じ近似を採る。
- GUI は今回の範囲外（dev モジュール＋テスト＋本記録のみ）。
