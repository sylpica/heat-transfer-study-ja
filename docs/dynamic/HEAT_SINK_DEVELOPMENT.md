# 開発専用：有限熱容量基部と複数の同一フィン

2026-11-06（Asia/Tokyo）。対象 `dynamic/dev/heat-sink.mjs` と専用UI/Worker。公開allowlist外、releaseApproved=false。Phase 3のフィンとPhase 4の連成・立体表示を、以下の限定したモデルで進める。実ヒートシンク全般・3D温度場・流体相互作用の承認ではない。

## 現象・仮定・支配式

一様温度の基部に発熱P [W]を与え、N本の同一矩形フィンと露出上面から指定hで対流放熱する。各フィンの断面温度は一様、長さ方向だけを計算。同一の初期/境界条件という対称性で代表1本を解くが、全容量/全交換/全放熱には必ず本数を掛ける。

基部幅W、奥行D、厚さb、フィン長L、厚さt。根元断面Ac=tD、周長Pf=2(t+D)、露出上面Ab=D(W−Nt)、基部体積WDb。先端と基部の他面は断熱。接触抵抗Rc'' [m² K/W]は1本につきRc''/Ac [K/W]。隙間を均等に取る配置は図のためで、隙間流動やhの本数依存を解かない。

Cb=ρcp WDb、Cf=ρcp Ac dx、G0=Ac/[Rc''+dx/(2k)]、Gi=kAc/dx、Gs=hPf dx、Gb=hAbとする。

- Cb dTb/dt=P−Gb(Tb−Ta)−N G0(Tb−T1)。
- 各フィンセル：Cf dTj/dt=隣接セル/基部からの流入−Gs(Tj−Ta)。先端の外向き伝導は0。
- 全体：dE/dt=P−Gb(Tb−Ta)−N Gs Σ(Tj−Ta)。基部からフィンへの交換熱は内部量で、全収支へ二重に加えない。

断面Bi=h(Ac/Pf)/k≤0.1を開発範囲として検査する。**基部の一様温度は別の仮定**で、フィンのBi検査が基部の熱拡がり抵抗を保証するわけではない。一定物性/指定hのみで、風速からhを計算しない。放射、流動、温度依存物性、基部内温度分布、接触の空間不均一は未対応。未知の物理入力を無視しない。

## 数値法・保存・再生

有限体積の面コンダクタンスと陽Euler。安定刻みは、基部/フィンの最大流出率の0.8倍の逆数。受理前に有限値・正温度・監視上限・熱収支・時計を検査。累積外部熱には補償和、蓄熱は初期状態との差から別計算。復元はlaw/条件署名/配列/時計/収支を検査し、失敗時は受理状態を変更しない。

N=0は露出上面全体で対流する有限容量基部に退化し、フィン温度配列は空。h=0の対流寄与は厳密0（符号付き負ゼロを表示しない）。数値上の正有限と連続体モデルの物理的適用は別である。

## 前回失敗の原因と修正

前回の無効入力試験は厚さ1e-300 mを必ず拒否すると仮定していた。しかし、基部容量5.80608e-297 J/K、safeDt=3.8034092105e-297 sは正有限で、1刻みの温度も正有限だった。任意の最小厚さを追加して試験へ合わせず、**実際に無効な数値域**へ試験を具体化した。

- Number.MIN_VALUE：入力は正でも基部体積が0へunderflowして既存の検査が拒否。
- 1e-320：体積/容量から計算した基部流出率がoverflowして既存の検査が拒否。

元の誤った仮定と再現値を保存し、無効入力の保護そのものは維持する。別の独立QAはh=0・周囲より冷たいフィンで−0を検出したため、有限検査後に熱流のゼロを正規化。科学的な許容差や正値の基準は緩めていない。
