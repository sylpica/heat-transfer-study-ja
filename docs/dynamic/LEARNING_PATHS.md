# 熱伝導のチュートリアルと予想実験

公開候補の熱伝導画面に追加した学習経路。体験/自由実験/専門解析という表示設定とは別に、「自由に試す」「操作チュートリアル」「予想して確かめる」を選ぶ。現在の対象は左面加熱の1実験のみで、全モデルの学習経路が完成したとは扱わない。

## 条件と流れ

0.1×0.05×0.005 m、一定物性のアルミニウム6061-T6（k=167 W/(m K)、ρ=2700 kg/m³、cp=896 J/(kg K)、20℃の参考値を一定とする教育近似）。初期20℃、左面60℃、他面断熱、内部発熱なし。5 sの過渡伝導を通常のCPU Workerで解く。流速/自然対流を描かない。

専用の準備ボタンでA/Bと一時履歴を初期化することを事前に明示する。PC32×16、600 px以下24×12。測定点を実際に移動し、5 sまで数値計算し、2点のセル平均温度を観察し、初期状態に復帰する。巻き戻し後の観察結果には「観察した状態 t=5 s」と記し、現在の図が0 sであることと区別する。

予想では実行前に左右の温度関係を選び確定する。選択を固定してから実計算し、予想・観察・温度差・物理的な理由を示す。左右差0.01 K以内は「ほぼ同じ」という表示上の分類で、ソルバーの誤差基準ではない。正答率/成績へ加算しない。未確定で時間を進めた場合や条件を再設定した場合は、古い予想/結果を無効化してやり直す。沸騰模式へ切り替えた場合も無効化する。

測定値は x/L=0.25、0.75、y/H=0.5 に近いセルの計算値で、実際のセル中心座標を表示する。連続体の厳密な点温度とは呼ばない。自由経路へ切り替えても実験の場は変更しない。予想/ガイドの状態はメモリーのみで、localStorageや回答/復習履歴へ書かない。

## 独立した数値照合

初期温度一様、x=0で温度固定、x=Lで断熱の連続解を別の級数で計算する。θ=(T−60)/(20−60)、λj=(j+1/2)π/L として、θ=Σ[2/(λj L)]sin(λj x)exp(−αλj²t)、α=k/(ρcp)。セル区間のsinを積分したセル平均と比較する。有限体積の面コンダクタンスやEuler更新式を参照計算へ流用しない。t=5 sでは200項で十分に減衰する。

単体試験の許容値0.07 Kは初期境界温度差40 Kの0.175%。観測される左右差約12 Kに比べて小さい教育用比較の許容幅で、任意条件の精度保証ではない。最初の16×8で左誤差約0.0949 Kが生じて失敗したため、**許容幅を広げず、この専用実験の格子を増やした**。通常のスマホ用16分割の自由実験は維持した。

格子ごとに「近いセル」の実座標も変わるため、行どうしの温度差をそのまま同一点の格子誤差としない。各行はそのセル区間の独立参照解との照合である。時間と空間を独立に細分化する一般伝導の検証は既存ベンチマークと区別する。

## 操作と検査範囲

`learning-path.mjs` は学習経路/観察判定、`learning-ui.mjs` はDOM操作、物理計算は既存Experiment/Workerのまま。チュートリアル用の偽の温度やアニメーション時間は作らない。予想のラジオ群・ボタンはネイティブ要素。準備後に次の操作へ、計算後に結果へ、巻き戻し後に状態説明へフォーカスする。結果中の用語も同じパネルで開閉し、Escapeで元へ戻る。準備/予想/計算の失敗は現在の物理場の扱いと区別して伝える。

Node4試験は実モデルの移動/観察/復帰、予想の実行前固定と物理状態不変、上の独立解、条件変更時の無効化。Chromiumの配信物試験はチュートリアル、誤った予想と理由、変更/未確定時のやり直し、モバイル24分割、キーボードと結果フォーカス、用語パネル、390/412/1280 px・明暗・オフラインでの予想と実計算を含む。実機/支援技術の実機確認は未実施。
