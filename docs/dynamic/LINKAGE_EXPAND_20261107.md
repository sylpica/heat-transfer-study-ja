## P5-8：問題→シミュレーションの条件引き継ぎ拡張（1問 → 5問）

### 選定基準

1. 問題文だけで数値条件が完結する（形状寸法・物性・境界の h／ε・温度が数値で与えられている）。
2. 公開ラボの熱伝導実験（板・フィン・対流／放射境界）の構成で同じ物理を再現でき、
   不足分が「設問にない補足条件」として明示できる範囲に留まる。
3. 引き継ぐのは条件のみ。解答・解説、および m・tanh(mL) のような答えに直結する中間量は
   引き継がない。実験側の説明文にも答えの数値を書かない（テストで機械的に確認）。
4. 問題のリビジョンとフィンガープリントで固定し、問題文・選択肢・答えが変われば
   導線は自動で消える（既存の仕組みを全ケースに拡張）。

### 選ばなかった問題の類型

- 相関式への数値代入型（境界層・管内対流・自然対流・沸騰・凝縮）：実験側に流れ・相変化の
  計算がなく、引き継ぐ対象の物理がない。
- 無次元量だけが与えられる問題（mL、θ、τ、η のみ）：形状・物性・温度を復元できず、
  補足条件の発明が条件引き継ぎの範囲を超える。時定数 τ だけの集中熱容量問題は
  h と ρcp と形状を分離できないため同じ理由で外した。
- 両面の温度を固定する平板問題：現行の板実験は左面のみ条件指定（他面は断熱）で再現できない。
- 先端対流フィンの問題：実験のフィンは先端断熱のみ。
- 断面を矩形で再現できないフィン（P と Ac の組合せが矩形断面を持たない）、
  および L・温度差のないフィン問題。
- 二面間の放射交換・放射ネットワークの問題：放射ネットワーク画面にケース引き継ぎの
  受け口がない（節対応のみ）。
- 既存ケースの結果を前提にする派生問題（フィン有効度など）：条件の重複引き継ぎになる。
- 相似変数だけを与える半無限問題：時間・長さの尺度を復元できない。
