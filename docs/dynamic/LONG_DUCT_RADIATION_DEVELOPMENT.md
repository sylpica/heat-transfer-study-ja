# 開発専用：長い凸多角形ダクトの放射

2026-11-06（Asia/Tokyo）。root単独・逐次実行。`dynamic/dev/long-duct-radiation.mjs`。全壁が見通せる3〜12辺の厳密な凸多角形断面、軸方向に無限、各壁は等温・灰色・拡散・不透明、内部は非参加媒体に限る。既存の射度/有限熱容量ネットワークを利用し、形態係数を実際の断面形状から計算する。開発専用であり公開登録しない。専用の動的UIはまだない。

## 幾何・形態係数

各辺iの長さL_i [m]、形態係数F_ijは無次元。交差弦法から共有の交換長 G_ij=L_i F_ij=L_j F_ji [m]を一度求める。平面壁の自己形態係数は0。厳密凸なので障害物/遮蔽/凹形状の可視判定を省略できる範囲である。

座標を原点移動・長さで正規化し、弦長の差は平方差を因数分解して評価する。隣接壁では三角形の Li+Lj−diagonal を有理化し、小さい曲がり角はsin²/(1+cos)を使う。短い壁からの寄与を長い弦同士の差で失わせない。初期式では幅1e−6の矩形を総和精度不足で明示拒否していたが、有理化後は幅1e−6/1e−12/1e−100と高さ1の対向短壁Fを安定な平行帯板式へ相対照合できた。相反積そのものがunderflowする条件は拒否する。

非有限/ゼロ辺/重複/一直線/凹/交差/数値的に未解像な形状は拒否。同じ閉終点の除去だけを明記し、壁の入力順と時計回り/反時計回りを保持する。Fをクリップしたり行和で正規化したりして誤差を隠さない。総和則と面積相反則は1e−12以内を要求する。これらは実装の受理条件であり、一般形状の誤差証明ではない。

## 熱容量と動的応答

`span` [m]は一様な軸方向の熱量換算長で、有限長の端面を追加しない。面積A_i=L_i span [m²]、入力熱容量C_i=C'_i span [J/K]、外部入力P_i=P'_i span [W]。C'は各壁のダクト軸長さ1 m当たり熱容量[J/(m K)]であり、断面辺長さ当たりという意味ではない。薄い一様壁ならC'=ρ cp δ L_iなどで別途設定できる。

既存ネットワークで射度/照射/正味交換を求め、C_i dT_i/dt=P_i−Qout_iをHeun法で積分する。各壁が均一温度という集中熱容量近似であり、壁内伝導/端面冷却/気体の放射吸収/自然対流を解かない。返却するW/mは総Q/span。換算スパンを変えても温度応答は同じで、容量/入力/蓄熱だけが比例する。

無効刻み/出力の非有限/復元失敗は旧状態へ戻す。復元時は安全な整数回数、時間と最終刻み/上限、既知の定常外部入力積分、蓄熱差を確認する。初期時刻は初期温度だけを受理。完全な過去軌道の証明ではなく、時間・入力・エネルギーの必要条件である。返したgeometry/configを編集しても内部状態は変わらない。
