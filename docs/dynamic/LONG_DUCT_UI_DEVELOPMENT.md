# 開発専用：幾何から計算する長いダクト放射の画面

2026-11-06（Asia/Tokyo）。root単独で作成・検証。`dynamic/dev/long-duct.html`、`long-duct-ui.mjs`、`long-duct-view.mjs`、`long-duct-worker.mjs`。先に検証したLONG_DUCT_RADIATION_DEVELOPMENT.mdの物理モデルを接続した。公開allowlist/公開Workerへの登録は行わない。

## 実際の入力と計算

三角形/矩形/六角形の凸断面プリセット、全幅/全高さ、壁1と他壁の初期℃/放射率、全壁に共通の面積あたり熱容量[J/(m² K)]を指定する。C_i=面積あたり熱容量×辺長L_i×軸方向1 m。外部入力は0 W、各壁内は一様温度の仮定。壁内伝導/対流/有限長の端面は解かず、自由な凹形状/障害物も追加しない。画面上の線幅は壁厚ではない。

専用Workerは既存のトランザクション/取消を利用し、既存Experimentで最大2条件の同時刻比較・履歴・実状態への巻戻し・取消・再計算を扱う。条件変更時は未適用の前回状態と明示し、計算を無効化する。AをBへ固定してからAの放射率等を変えると、両条件を時刻0から計算する。戻す操作は図の再描画だけでなく全温度/時計/累積入力をモデルへ戻す。

計算の開発・Node試験・ブラウザー確認はすべてrootの単独・逐次実行。既存アプリ内のA/B用Worker/共有controllerの仕様は維持し、サブエージェントを再開/委譲しない。

## 図と数値

実際の断面頂点を縦横同じpx/mで配置し、A/Bも共通の物理範囲/倍率/温度凡例を使う。各辺は解いた実壁温度、番号、℃を表示。選択壁との正味交換Q_ijは、計算した射度差の符号から方向を決める。反射を含むため温度差だけから方向を代入しない。矢印は模式表現であり光線軌跡/個数ではない。

rootがWebKit390px暗色の実画像を見て、対称な冷壁間の約−4.55e−13 W/mが見える矢印になっていた点を修正した。描画だけで128 EPS×選択壁の最大|Q_ij|以下の矢印を省略し、その閾値/省略数を診断表示する。元の熱流は変更せず、微小な非ゼロ値を指数表記で残す。物理的に全交換が小さい場合には相対スケールが一緒に小さくなる。一律の絶対W下限は置かない。丸め差の描画省略と物理的な0 Wは区別する。

壁温度K/℃、射度W/m²、正味放射W/m、全F行列、総和/相反残差、顕熱/外部入力/収支差、射度残差、容量/面積、時間/刻みを表示。壁番号selectはキーボードでも操作でき、温度履歴は実際の保存コマの値。表は狭い画面で内部を横スクロールし、図文字は実描画幅のSVG座標で保持する。画像はアプリ自身の図だけを保存した。
