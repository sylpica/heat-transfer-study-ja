# 長い凸ダクト放射：自由頂点編集UI（2026-11-07、フェイリス並行実装）

締め可能性監査（放射分野の残作業・項目6）への対応。カーネル
`dynamic/dev/long-duct-radiation.mjs` は凸多角形3〜12頂点に既に対応していたが、
画面はプリセット3種（正三角形・矩形・正六角形）しか選べなかった。本作業で
`long-duct.html` / `long-duct-ui.mjs` に自由頂点編集を追加した。カーネル・
Worker・描画（view）は無変更。開発専用（releaseApproved=false、公開
allowlist外）を維持する。フェイリス側の並行実装であり、統合は後段で行う。

## 編集操作の仕様

- 断面セレクタに「自由編集（頂点）」を追加。編集欄（fieldset「断面の頂点編集
  （条件A）」）は常時表示され、現在の輪郭（プリセット由来を含む）を保持する。
- 頂点のドラッグ：編集図の丸ハンドルをポインターで掴み、候補位置を毎回
  カーネルで検証しながら移動する。不正な位置では最後の正常位置に留まり、
  理由をその場に表示する。ドラッグ中はフィット倍率を固定する（輪郭の
  バウンディングボックス変化による倍率再計算がポインター下の物理点を
  ずらすフィードバックを避けるため）。終了時に再フィットする。
- 座標の数値入力：頂点ごとの x / y 入力（change で確定）。受理時は入力した
  値をそのまま保持し、表示用の丸めで書き戻さない（編集中の行を丸め値で
  上書きすると確定座標がずれるため）。拒否時は直前の輪郭へ入力を戻す。
- 追加：最も長い壁の中央を外向き法線方向へ少し出した位置に挿入し、カーネル
  検証を通る最初の候補を採用する。12個で追加ボタンを無効化する。
- 削除：3個では全削除ボタンを無効化する。削除候補もカーネル検証を通す。
- 範囲：断面の幅・高さは各 0.05〜5 m（UI側チェック）。カーネル側の検証
  （厳密凸・自己交差禁止・重複/同一直線上の頂点・辺長>0、総和則と相反則の
  残差 1e-12 以下）に反する編集は理由（カーネルの日本語エラー文）を表示して
  受理せず、直前の正常な輪郭・プレビューを保持する。壊れた形状で計算には
  進まない。
- 即時反映：受理のたびに編集図・辺長・形態係数 F（5桁）・総和/相反残差・
  初期（t=0）の壁別正味放射（現在の温度・放射率・熱容量入力による試算）を
  再計算して表示する。本計算への反映は従来どおり「初期状態から計算」。
  プリセットを選び直すと、その形状と全幅・全高さから頂点を作り直す。
- 壁の割当ては従来どおり（壁1が高温・他は低温、面積あたり熱容量×新辺長×
  軸1 m で再計算）。編集は条件Aのみ。

## 拒否動作の確認（Chromium実測）

- 凹化：正方形の頂点3を (0.4,1) へ（台形として受理）→ 続けて y=0.4 を入力
  すると「凹形状・自己交差・障害物は長い凸ダクトの対象外です。」を表示して
  拒否。入力は (0.4,1) に復帰し、プレビューは台形のまま不変。
- 自己交差：頂点2を (0.2,0) へ（受理）→ 続けて y=1.2 を入力すると同じ理由で
  拒否。入力は (0.2,0) に復帰。
- ドラッグ：正方形の頂点1を対角線の向こう (0.75,0.75) へドラッグすると、
  対角線上で同一直線となり検証に落ちるため頂点は約 (0.4375,0.4375) で
  止まり、理由表示が残る（実測：x<0.6、エラー表示あり）。
- 個数：3個で削除不可、追加を繰り返して12個で追加不可。いずれもエラーなし。
