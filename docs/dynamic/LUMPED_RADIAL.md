# 条件を限定した集中熱容量の軽量モデル

2026-11-05、5a3e0ed後続。内部一様の温度1個を扱う、明示的に選ぶ近似モデル。詳細な半径方向PDEを粗い1セルで解く方法とは異なる。既存20モードの集中冷却計算を置換しない。数値基盤の後に既存の動的画面への接続を進める。

対象は中実球、または端面断熱/長さ方向一様の円筒。一定k/ρ/cp、一様初期温度、発熱なし、一定の指定hと一定流体温度だけ。自由輪郭、複合材、温度依存物性、固定表面温度/熱流束/放射・同時境界は拒否する。流体速度を解いたり、hを相関式で予測したりしない。機器が遅いという理由で、成立しない近似へ自動で切り替えない。

## 式と適用判断

ρcpV dT/dt=hA(T∞−T)。T(t)=T∞+(T0−T∞)exp[−hAt/(ρcpV)]を解析的に更新する。表面温度も内部温度と同じと近似するので、細かな内部勾配や中心/表面差は計算しない。熱流は表面でのhA(T−T∞)だけを表示し、内部のFourier熱流を描かない。

Lc=V/Aは球R/3、円筒R/2（側面のみ）。Bi=hLc/k≤0.1を選択の基準とし、超える場合は分布を解くモデルを選ぶよう案内して拒否する。この条件は全時刻の特定の誤差を保証するものではない。ρとcpは応答時間、kは近似の適用判断に使う。

更新は前進Eulerではなく固定条件の指数解。安定刻み制限はない。物理時間と表示コマ/再生倍率は従来どおり別で、巻き戻し/再開は本当に計算状態を復元する。h=0なら断熱で一定温度。熱量の収支を温度変化ρcpVΔTで追跡し、異なる境界/物性のsnapshotや改変温度/熱量は復元しない。

## 独立した連続PDEとの比較

scripts/dynamic-lumped-reference.pyはSciPyで球/円筒のRobin固有値を求め、128項の連続級数を体積平均へ解析積分する。64項との差も保存。JSの指数解・FVMをPDE参照へ流用しない。LUMPED_RADIAL_REFERENCE_20261105.jsonに保存。

球の固有値はζcosζ+(Bi_R−1)sinζ=0、円筒はζJ1(ζ)−Bi_R J0(ζ)=0。Bi_R=hR/kとBi_Lcは異なり、球はBi_R=3Bi_Lc、円筒は2Bi_Lc。Fo=αt/R²=.1/.5/1/2/5/10、Bi_Lc=.01/.05/.1を比較。差は初期の温度超過(T0−T∞)で正規化し、消えていく末期の温度超過を分母にした相対誤差と混同しない。

この標本内の最大誤差は球で.002188/.010776/.021133、円筒で.001332/.009080/.017353。Biが小さいほど近似誤差が減る。単に指数解に一致することと、連続PDEへ正確であることを別に検査する。初期50 K差なら最大約1.06 Kの誤差が残る例であり、保存則が小さいから正確という説明をしない。

Nodeは指数解の加熱/冷却、各幾何/長さ尺度、PDE平均への差、適用拒否、h=0、長時間平衡、刻み分割、真の再生と不正復元を検査する。最初のh=0試験で符号付き負ゼロの出力が見つかり、ゼロの表示を正規化した。外部専門家校閲や工学利用承認ではない。画面・実機・一般GPU/CFDへの代替は別の工程。
