# §21 説明書のアプリ内 #manual 反映 記録（2026-11-07）

ユーザー決定（2026-11-07、保留事項の解消）に基づき、`docs/dynamic/` 配下の §21 16項目説明書を、動的シミュレーション画面（`dynamic/index.html`）のアプリ内マニュアル `#manual` で読めるようにした記録。ブランチ `feiris/manuals-inapp`（基点＝統合先端 34b84ad）。

## 反映方式

- 正本は Markdown の説明書のままとし、`scripts/generate-model-manuals.mjs` が使う Markdown 部分集合（段落、`###` 小見出し、1階層までの箇条書き、パイプ表、`**太字**`、`` `コード` ``）を構造化ブロックへ変換して `dynamic/model-manuals.mjs` を生成する。生成は決定的で、再実行してもバイト一致することを確認した。生成器は未対応の記法（HTML・コードフェンス・引用・画像・想定外の見出しレベル・区切り行のない表）に出会うと黙って落とさずエラーで停止する。
- 画面側（`dynamic/lab.mjs`）は `#manual` 末尾の「モデル別説明書」で、選択したモデルのみを描画する。16項目はすべて初期状態で閉じた `<details>` とし、開閉式のためマニュアルを開いても作業領域を押し下げない。各項目の本文には既存の用語リンク機構（`linkTermTextNodes`）を適用し、用語から用語集パネルへ飛べる（実測で1モデル表示あたり最大105件の用語リンクを確認）。
- モデルごとに「対象画面」行（該当する実験画面へのリンク、または「この画面」）と「正本：`docs/dynamic/…`」行を示し、文書側の正本への導線を残した。開発専用モデルは「対象画面：開発専用（公開ビルドには含まれません）」と明示する。
- `dynamic/model-manuals.mjs` は公開ビルドの allowlist と `sw.js` のアプリシェルに追加した（学習者がオフラインでも読めるようにするため）。

## 未反映項目と理由

- 各説明書の冒頭リードのうち「日時」「位置づけ」の2種は反映していない。これらは日付・ブランチ名・コミット SHA を含む文書管理用のメタデータであり、学習者向けの内容ではないため。学習者向けのリード（対象モデル／対象範囲／注意／状態／読み分け）は全て反映した。
- 16項目の本文については未反映はない。数値・式番号・適用範囲は正本どおりに転記し、テストで代表値（例：σ = 5.670374419×10⁻⁸、環状フィン項目15の「対応する問題はない」、風速→h 項目5の「初期条件は存在しない」）が無変更で残ることを固定した。
