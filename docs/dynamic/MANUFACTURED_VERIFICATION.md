# 製造解による2D CFD全場の検査

単位正方形の既知の速度・圧力・温度から、連続の運動量/熱の方程式が成り立つ外力と体積発熱を逆算するコード検証。実在流体・自然対流の新しいプリセットではない。`dynamic/dev/cavity.mjs`と`manufactured-cavity.mjs`は公開ビルドに含めない。

## 既知の場と境界

長さ1 m・時間尺度1 sの数学的な例。ψ=sin²(πx)sin²(πy)e⁻ᵗからu=∂ψ/∂y、v=−∂ψ/∂x。p=0.1cos(2πx)cos(2πy)e⁻ᵗ Pa（平均ゼロのゲージ）、T=300+sin(πx)cos(πy)e⁻ᵗ K。全壁でu=v=0、左右T=300 K、上下面は断熱、圧力の法線微分は0。密度/比熱/動粘度等は検査用の仮定値。

外力は加速度[m/s²]としてf=∂u/∂t+(u·∇)u+∇p/ρ−ν∇²u、体積発熱はq=ρcp[∂T/∂t+u·∇T−α∇²T] [W/m³]。連続の式で∇·u=0。コードは格子の離散式から外力を作らず、この連続式から独立に導出する。

専用の検証引数で初期場と外力を与える。通常の移動壁/浮力ケースの既存経路を保持し、検証引数とそれらの同時使用は拒否する。外力/発熱にNaN等があれば温度・速度・圧力・時刻を更新しない。顕熱の入力へ体積発熱も加え、収支を別に確認する。

## 独立した式の照合

`python3 scripts/check-manufactured-sources.py`は開発者向け。SymPyでψ/p/Tから別に微分し、3組のρ/cp/ν/αと3座標（9組）でJSの場・外力・発熱を検査。差の最大は2.84e−14、発散と各壁条件は記号的に0。結果は`MANUFACTURED_SYMBOLIC_CHECK_20261104.json`。Python/SymPyはWebアプリの利用者には不要。CIは別の数値微分によるPDE照合をNode試験で行う。

`tests/dynamic-manufactured.test.mjs`は速度/圧力/温度の3格子、独立差分の連続PDE、一定体積力からの線形ゲージ圧力と偽の流れ0、異常な外力/発熱の原子性を確認する。一定体積力の検査はρ=0.3/1/7でもPaの圧力勾配が一致する。CGの離散圧力問題が正確に解けることと、連続場の空間誤差は別の検査。

## 全場の数値記録

`node scripts/dynamic-manufactured-benchmarks.mjs --full`で16/32/64格子を再計算。t≈0.025 s、ν=1、α=0.2、中心移流、格子に伴い刻みも小さくなる。全速度面/全圧力・温度セルのサンプルRMSと最大誤差を保存し、特定の点だけを選ばない。圧力は同じ平均ゼロのゲージで比べる。記録は`MANUFACTURED_FIELDS_BENCHMARKS_20261104.json`。

|格子|u RMS [m/s]|p RMS [Pa]|T RMS [K]|圧力の相対RMS|
|---|---:|---:|---:|---:|
|16²|0.0122852|0.0530298|0.000619922|108.74%|
|32²|0.00310271|0.0133285|0.000153304|27.33%|
|64²|0.000780707|0.00333868|0.0000382337|6.85%|

全場の誤差は約2次で減る。64²の最大発散2.84e−14、顕熱収支誤差2.48e−14 J。参照圧力のRMSは約0.0487655 Paで、**粗い格子の圧力相対誤差は大きい**。64²の最大圧力誤差も約0.0124175 Pa。反復残差や発散が小さいことだけで、連続圧力の高精度を主張しない。この例は粘性と外力が大きく、指定した圧力は小さい条件である。誤差の改善や他条件の確認を後続課題とする。

この表は保存前の開発ツリーでの計測で、JSONの`sourceTreeDirty=true`と基点07d39ff、ソースファイルSHA-256で識別する。記録したハッシュと同じ内容を保存する。後の最新CIが同じ保存SHAで再現した結果はSTATUS/PR #18へ別記し、未保存ツリーの結果をクリーンな07d39ffの結果とは呼ばない。64²の単独計測はクラウドCPUで約99.5秒、実機やGPUの性能ではない。
