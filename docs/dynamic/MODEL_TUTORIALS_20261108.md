## 対象モデルと構成

アプリ内説明書がある **全15モデル**（過渡3：矩形／径方向／三角形、フィン4：直線先端／環状／ヒートシンク／風速→h、強制対流4：平板境界層／Graetz／円管一定熱流束／円管一定壁温、自然対流1：閉キャビティ、放射3：ネットワーク／長ダクト／表面交換）に、各1件の手順案内を作成した。

- データは新規 `dynamic/model-tutorials.mjs`（`MODEL_TUTORIALS`、手書きデータ。説明書のような生成元 Markdown は持たない）。
- 各チュートリアルは共通の3段構成：**1. まず触る**（最初に操作するプリセット・条件・ボタン）／**2. 観察する**（何が起きるか、表示の読み方）／**3. 確認する**（検証済みの数値・極限との照合）。各段2項目、1項目は240字以内に絞った。
- 内容の根拠は各モデルの §21 説明書（特に項目9 グラフの読み方・項目10 結果の解釈）と開発記録のみで、新しい物理の主張は作っていない。「確認する」の数値は説明書・検証記録の値をそのまま使った（例：直線フィン先端面温度 340.239853 K／340.746691 K、Graetz 発達限界 Nu 8.235294・5.384615、円管一定壁温 Nu∞ 3.6567934578、キャビティ Nu₀ 64格子 1.118329、表面交換の Kirchhoff 厳密解 Ts = 498.4157 K・q = 6087.01 W/m²、長ダクト正方形 F = √2 − 1）。
