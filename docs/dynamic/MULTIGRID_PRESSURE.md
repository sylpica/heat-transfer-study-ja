# 圧力PCGの対称Galerkin多重格子前処理

開発用`poisson-multigrid.mjs`。元の細格子Neumannラプラシアンを外側PCGで解き、前処理だけを切り替える。圧力をp/ρで解いてからPaへ戻す正規化は保持。既定のJacobiは残し、`pressurePreconditioner: 'multigrid'`で選ぶ。CFD・この前処理とも公開ビルド外。

## 構成と不変条件

セル中心の双線形補間P、制限R=Pᵀ、粗演算子A_c=PᵀA_fP。端ではNeumannに対応して一定値を保つ補間、奇数格子も対応する。丸め後は粗演算子の対称性と定数の零空間を保つ。細格子の外側演算子は元のまま。

V-cycleは前後とも固定2回の減衰Jacobi。重みは行の絶対和/対角から得るGershgorin上界に基づく。小さい粗格子（16セル以下）は1自由度を固定したCholesky解を平均ゼロへ戻す。固定の対称サイクルとしてPCGの平均ゼロ部分空間で線形/正定値の前処理を構成。階層/分解はモデル初期化時に一度作り、各内部刻みで再利用する。

ゼロの圧力残差では前処理を呼ばない。残差ノルム/内積のオーバーフローや悪条件は明示的に停止する。旧処理は各要素が有限でも二乗和がInfinityになると、Infinity同士の比較で反復0回の成功になり得た。有限速度1e200の専用試験で検出し、成功応答を返さないようにした。

## 一致と反復数

`tests/dynamic-multigrid.test.mjs`：線形性・双対積の対称性・平均ゼロ部分空間の正定値、定数成分0、奇数/長方形、入力を変更しないこと、元演算子の既知圧力との一致、移動壁/浮力/製造解の全軌道の一致、異常値とゼロ残差。

`scripts/dynamic-multigrid-benchmarks.mjs`と`MULTIGRID_BENCHMARKS_20261104.json`。同じ許容値1e−11、同じ細格子混合モードの圧力問題：

|格子|Jacobi PCG反復|多重格子PCG反復|解の最大差[Pa]|
|---|---:|---:|---:|
|16²|58|9|約8.5e−13|
|32²|120|9|約7.3e−13|
|64²|236|10|約7.8e−13|

64²の前処理作成は約111 ms、PCG部分はJacobi約199 ms/多重格子約41 msというローカル計測。セットアップは一度だけ。32²の製造解の全軌道では圧力反復合計18715→1813、同じプロセス内の逐次測定で約3.96→1.52 s。全場の差は速度約4.4e−16、圧力約1.0e−13 Pa、温度約5.7e−14 K。測定環境と正確な数値はJSONが優先。実機/GPUや普遍的な速度保証ではない。

## 全場・標準ケースの再計算

- `dynamic-manufactured-benchmarks.mjs --full --multigrid`：16/32/64格子の全場収束を再現。64²で約21.0秒という別計測、最大発散約3.6e−14。圧力相対RMS約6.85%は残る。前処理が離散化誤差を改善したとは呼ばない。記録は`MANUFACTURED_MULTIGRID_BENCHMARKS_20261104.json`。
- `dynamic-cavity-benchmarks.mjs --full --multigrid`：移動壁16/32、自然対流16/32/48、半時間刻みを再現。Nuは1.126318692908 / 1.119942764429 / 1.118748501461。既存Jacobi CI記録との差は最大約1.9e−11、lid参照点の差は最大約1.9e−12。別の実行環境との比較なので、これだけからCPU加速比を主張しない。新しいローカル全計測は約177秒。記録は`CFD_MULTIGRID_FULL_REPRODUCTION_20261104.json`。

これらはe1e93d1後の保存前ツリーの測定で、dirtyフラグとソースSHA-256を保持する。元コミットの未変更コードの結果と混同しない。新保存SHAのCIでは両前処理・全場・標準ケースを再現し、JSONをartifactへ保存する。コード検証の成功を公開承認/専門家校閲へ転用しない。
