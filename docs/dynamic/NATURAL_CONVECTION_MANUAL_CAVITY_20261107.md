## 1. 現象の概要

左右の壁に温度差をつけた、密閉された矩形（画面では正方形）の中の流体に生じる自然対流を計算する。温かい左壁に沿って流体が上昇し、冷たい右壁に沿って下降して、内部に1つの大きな循環ができる。駆動力は重力と温度による密度変化（浮力）だけであり、ファンやポンプのような外部の流れはない。画面の条件（温度差最大10 K、10 mm角の空気）では流れは層流で、熱の移動は伝導に流れの寄与が加わった比較的弱い対流である。時間を進めると過渡を経て、やがて定常な循環と温度分布に落ち着く様子を観察できる。

## 2. 現実世界での使用例

- 二重ガラスの間の空気層で、ガラス間の熱の伝わり方が空気の循環でどう変わるか。
- 建物の壁の中の空気層や、断熱材のない中空壁の内部で起きる熱移動の考え方。
- ファンのない電子機器の筐体の中で、部品の熱が空気の循環でどう逃げるか。
- 保温・保冷容器の内部で、温度の偏りが時間とともにどう均されるか。
- 室内で窓際の冷気が下降し、暖房側の空気が上昇する局所循環の定性的な理解。

いずれも閉じた空間内の浮力駆動流れという共通性に基づく学習・概算のためであり、寸法・温度差・流体が異なる実物への数値の直接適用はしない（項目11・12）。

## 3. 支配方程式

非圧縮・層流・Boussinesq 近似のもとで、以下の式を解く（実装の構成は `docs/dynamic/CFD_DEVELOPMENT.md`、本書の記述は `dynamic/dev/cavity.mjs` の更新則に基づく）。

連続の式：

∂u/∂x + ∂v/∂y = 0

運動量（保存型で離散化する）：

∂u/∂t + ∂(uu)/∂x + ∂(uv)/∂y = −(1/ρ) ∂p/∂x + ν∇²u
∂v/∂t + ∂(uv)/∂x + ∂(vv)/∂y = −(1/ρ) ∂p/∂y + ν∇²v + gβ(T − T_ref)

エネルギー（顕熱のみ）：

∂T/∂t + u ∂T/∂x + v ∂T/∂y = α∇²T、ただし k = ρc_p α

- 浮力は Boussinesq 近似として、密度変化を鉛直運動量の項 gβ(T − T_ref) にだけ入れる。実装では積 gβ を1つの入力 `gravityBeta` として与える。
- エネルギー式は顕熱と境界からの熱量だけを扱い、粘性散逸や圧縮の仕事を熱源へ戻す完全な全エネルギー方程式ではない（`docs/dynamic/CFD_DEVELOPMENT.md` に明記）。
- 圧力 p は平均ゼロのゲージ圧（相対値）であり、絶対圧ではない（項目9・13）。

## 4. 記号と単位

| 記号 | 意味 | 単位 |
|---|---|---|
| x, y | 水平・鉛直座標（原点は左下） | m |
| u, v | x・y 方向の速度（MAC 配置ではセルの面に置く） | m/s |
| T | 温度（内部計算は絶対温度、画面の色表示は ℃） | K |
| T_ref | 浮力の基準温度（画面では300 K） | K |
| p | ゲージ圧（平均ゼロに正規化した相対値） | Pa |
| ρ, c_p | 密度、定圧比熱（一定物性） | kg/m³, J/(kg·K) |
| ν, α | 動粘度、熱拡散率 | m²/s |
| k = ρc_pα | 熱伝導率（独立には与えず ρc_pα で決まる） | W/(m·K) |
| β | 体積膨張係数 | 1/K |
| g | 重力加速度（画面では向きの符号を含め変更可） | m/s² |
| gβ | 浮力の係数（実装入力 `gravityBeta`） | m/(s²·K) |
| H, L | キャビティの高さ、幅（画面では両者とも10 mm） | m |
| ΔT | 左右壁の温度差 T_left − T_right | K |
| Ra = gβΔT·H³/(να) | レイリー数（基準長さは高さ H） | — |
| Pr = ν/α | プラントル数 | — |
| Nu₀ | 左壁の伝導熱流束の高さ平均を kΔT/H で割った値（「高温壁平均Nu」） | — |
| Nu₁/₂ | 鉛直中央面 x = L/2 の全熱流束（伝導＋移流）の高さ平均を kΔT/H で割った値 | — |
| 体積平均Nu | 全鉛直断面の全熱流束Nuを x 方向に台形平均した値 | — |
| Ec = U²/(c_pΔT) | エックルト数（画面ではセル中心最大速度からの参考表示のみ） | — |

Nu の3定義は測定する場所と量が異なる別々の量であり、同一視しない。定義の正確な対応は `dynamic/dev/cavity-heat-flux.mjs` の定義メタデータと、項目10の照合経緯に基づく。なおソルバーの `snapshot` が返す `nusselt` は Nu₀ であり、定義メタデータ（quantity: 'Nu_0', location: 'hot-wall x=0'）が併記される。

## 5. 初期条件

- 画面：一様な初期温度300 K、速度ゼロ。左右の壁温は時刻0で段差状に設定される（左壁 300＋ΔT/2 K、右壁 300−ΔT/2 K）。
- このため計算開始直後の壁面 Nu は大きな値を取りうるが、これは壁温の段差と半セル近似に依存する離散化上の見かけであり、物理的な有限の最大値として扱わない。格子を変えて比較するときは、同じ正の物理時刻で比べる（画面「理論・物性・適用範囲」に明記。例：16格子では初期値16）。
- ベンチマーク設定（項目8）でも初期場は一様温度・静止で、壁温を時刻0に与える同型の設定である。

## 6. 境界条件

- 左壁・右壁：温度固定（Dirichlet）。壁からの熱流束は、壁と隣接セル中心の間の半セルの伝導抵抗で評価する（2k(T_wall − T_cell)/dx）。
- 上壁・下壁：断熱（熱流束ゼロ）。
- 全ての壁：静止・滑りなし。法線速度はゼロ、接線速度は壁のゴースト値で no-slip を与える。
- 浮力の向きは画面の重力入力で反転できる（−9.81〜＋9.81 m/s²。正の浮力設定では温かい空気への浮力が上向き）。
- 本モデルに存在しない境界条件：熱流束指定、対流境界、開境界（入口・出口）。加熱・冷却の位置も変更できない（項目12）。

## 7. 数値計算法

- 空間配置：MAC（マーカー・アンド・セル）配置の保存型有限体積法。速度はセル面、温度と圧力はセル中心に置く。
- 運動量：保存型の2次中心差分（既定 `conservative2`）で拡散と移流を評価し、前進 Euler で予測する。実験用の高次差分（`polynomial4`）は本画面では選べない。
- 圧力投影：予測速度の発散を右辺として Neumann 型 Poisson 方程式を解き、速度を発散ゼロへ投影する。反復は前処理付き共役勾配法（前処理は Jacobi または多重格子）で、圧力は平均ゼロに保つ。反復の既定は計算核が許容値（相対）1e-10・上限2000回、開発画面が許容値1e-11・上限4000回と異なる。収束しない場合は元の状態を変更せず停止する。
- 連続性の検査：投影後の発散最大値が速度尺度に対する許容（1e-8×尺度）を超えると、更新前の状態のまま停止し、その旨を表示する。
- 温度：面を通る熱流束（伝導＋移流）を隣接セルへ等量・逆符号で計上する保存型で更新する。移流の面温度は風上（既定）または中心差分（中心差分ではセル Pe 数が2を超えると例外で拒否）。熱量の基準温度は273.15 K。
- 時間刻み：拡散と CFL の制限から決まる安定刻み `safeDt` 以下だけを受け付ける。画面では1コマの物理時間と刻み上限を指定し、内部で刻みを刻む。
- 格子：各方向4〜96（ソルバー API）。画面では正方形の 12／16／24／32／64 のみ。
- 失敗時の原子性：不正な入力・収束失敗・範囲超過は例外として返され、受理済みの状態は変更されない。
- 製造解検証モード：既知の連続場（ψ・p・T）から SymPy で独立に導出した外力・発熱を注入し、離散化の実装そのものを照合する専用経路。通常の自然対流計算では使わず、浮力や移動壁との併用は拒否される（項目10）。

## 8. 計算過程

画面での手順：

1. 条件Aで左右壁の温度差、鉛直浮力の向き、格子数を設定し、「初期状態から計算」を押す。
2. 再生／1コマ進める／1コマ戻す／時刻0へ戻すで時間を操作し、履歴スライダで保存したコマへ戻る。
3. 表示量（温度／速度の大きさ／ゲージ圧）を切り替え、速度の矢印と瞬間流線を重ねる。計算場をクリックまたは矢印キーで測定点を動かす。
4. 「現在の条件をBへ固定して比較」で条件Bを固定し、色スケール共通のまま並べて比べる。
5. 詳細パネルで断面熱流束の3定義、運動エネルギーと圧力補正、計算条件・収支・収束を確認する。

手計算で確認できる検算：

- Ra の再計算（ベンチマーク設定、`scripts/dynamic-cfd-fine-grid.mjs` と同一）：1 m角、ρ = c_p = 1、α = 1、ν = 0.71、gβ = 710、ΔT = 1 K とすると Ra = gβΔT·H³/(να) = 710×1×1/(0.71×1) = 1000。
- 画面条件の上限：10 mm角・300 K の空気（項目11の物性）・ΔT = 10 K で Ra ≈ 931 となり、ソルバーの上限1000の内側にある（締め可能性監査の記録値）。
- 純伝導の極限：流れが止まれば3定義とも Nu = 1 に戻る。対流の寄与は「伝導限界からの超過」として読む（項目10のアスペクト比ケースの解釈も同じ考え方である）。

## 9. グラフの読み方

- 色表示：温度 [℃]、速度の大きさ [m/s]、圧力（平均0のゲージ）[Pa] の3種を切り替える。A/B 比較では色の範囲は両条件で共通である。
- 速度の矢印：MAC 位置から補間した速度の方向と大きさ。間引いて描かれる。
- 瞬間流線：その時刻の速度場を凍結して追跡した線である。**流線は粒子の移動軌跡ではない**（画面にも明記）。粒子の軌跡表示は実装されていない。
- 測定点の読み値：温度と圧力は指定点が属するセルの中心値、速度は MAC 位置からの補間値である。点の厳密値ではない。
- Nu の履歴グラフ：瞬間の左壁平均 Nu（Nu₀）の履歴である。定常相関の値ではなく、過渡中は変動し、初期には項目5の見かけの大きな値を取る。
- 詳細パネルの熱流束表示：Nu₀／Nu₁/₂／体積平均Nu は瞬間値であり、過渡中は互いに一致しない。一致するのは定常に限る（項目10）。
- 運動エネルギーの表示：MAC 速度から積分した離散運動エネルギーと、圧力補正で減る量の診断である。顕熱の収支とは別の量であり、混同しない（画面「運動エネルギーと圧力補正」）。

## 10. 結果の解釈

検証は「どの量を、どの条件で、どの参照と比べたか」を分けて読む。本モデルの検証の中心は、Ra = 1000・Pr = 0.71・正方形キャビティの定常ベンチマークである。

### 標準ベンチマークとの照合（de Vahl Davis 1983）

論文 Table V は3つの異なる Nu を併記する：全体平均 Nu = 1.118、中央面平均 Nu₁/₂ = 1.118、高温壁平均 Nu₀ = 1.117（論文自身の推定精度は約0.1%）。本ソルバーの格子系列（保存場の Python 再集計、`docs/dynamic/CFD_FINE_NATURAL_SUMMARY_20261106.json`）：

| 格子 | Nu₀ | 局所Nu最大 | u_max（位置 y） | v_max（位置 x） |
|---|---|---|---|---|
| 16 | 1.126319 | 1.541528 | 3.638743（0.84375） | 3.719344（0.15625） |
| 32 | 1.119943 | 1.515194 | 3.646848（0.828125） | 3.707512（0.171875） |
| 48（中心移流） | 1.118749 | — | — | — |
| 64 | 1.118329 | 1.508583 | 3.649077（0.8203125） | 3.700381（0.1796875） |

- 64格子の Nu₀ = 1.118329 は、対応する定義の論文値 Nu₀ = 1.117 との差が +0.00133 で、照合の予算0.002の内側にある。
- 格子系列の観測次数は約1.98、Richardson 外挿は Nu₀ ≈ 1.11778（`docs/dynamic/CFD_DEVELOPMENT.md`）。
- 最大速度（α/L で尺度した無次元値）：論文は u_max = 3.649（y = 0.813）、v_max = 3.697（x = 0.178）。64格子は u_max = 3.649077、v_max = 3.700381 で、値・位置とも近い。局所Nu最大は論文 1.505 に対して 1.508583。
- 定常では3定義がほぼ一致する（N64 での定義間の広がりは 1.06e-10）。これは閉キャビティの定常では全断面の全熱流束が一様になる保存則の帰結であり、定義が同一という意味ではない。
- 論文側には中面プロファイルの全点表が存在しないため、温度・速度の全分布の論文照合は最大値と位置で代表させる（プロファイル同士の照合は下記の独立ソルバーとの間で行った）。

### Nu の定義をめぐる照合の経緯（記録に基づく）

当初、ソルバーの出力 Nu と論文値の差の解釈で混乱があった。論文 Table V には 1.118 と 1.117 という近い値が異なる定義で併記されており、ソルバーの `snapshot` が計算しているのは高温壁の伝導流束の平均、すなわち **Nu₀** である。壁の Nu₀（32格子の記録値 1.1199427644252182）を、論文が代表値として推奨する中央面 Nu₁/₂ の 1.118（全体平均も同じ 1.118）と直接比べると、差の一部は定義の違いであり、誤差そのものではない。一次資料の直接読取り（原論文スキャン、Allen & Reis の OCCAM Preprint 13/34 Table 7、Barakos & Mitsoulis (1994) Table III との相互確認）によって定義の対応が確定し、現在は `snapshot` に定義メタデータが併記され、照合は常に対応する定義同士で行う。確定した対応と旧記録の扱いは `docs/dynamic/DE_VAHL_DEFINITIONS_20261106.md` に記録されている。この経緯のため、本書でも文献の Nu を引用するときは必ず定義を併記する。

- Pr・アスペクト比ケース（`~/workspace/dev/heat-sim-benchmarks/natural-convection-cases-20261107.md`）：API 経由で Pr = 0.1／0.71／1／7（Ra = 1000、正方形）と、アスペクト比 AR = 2／0.5（Pr = 0.71）の計12ケースを定常まで実測した。Richardson 外挿の Nu₀ は Pr ≥ 0.71 で ≈1.1178 に揃い、Pr = 0.1 では約0.16%低い。AR = 2 では Nu（H基準）は伝導限界0.5に対して +21.4%、AR = 0.5 では伝導限界2.0に対して +0.44%で、幅基準の Ra（AR = 2 で8000、AR = 0.5 で125）で単調に説明できる。全ケースで定常時に3定義が7桁目まで一致し、発散最大 3.3e-11 以下、相対エネルギー誤差 1.3e-14 以下であった。Pr ≠ 0.71 向けの外部ベンチマーク表は用いていない（一般的な多 Pr ベンチマークは Ra ≥ 10⁴ で、本モデルの受理範囲外）。

### 解釈上の限定

- 検証が外部参照と照合できているのは、Ra = 1000・Pr ≈ 0.71・正方形の定常量が中心である。過渡過程そのものの外部参照照合と、圧力場のベンチマーク照合は未実施である。
- Pr の複数値と非正方形は API 経由のケース測定と独立検証があるが、画面（UI）では変更できない。

## 11. モデルの仮定

- 2次元、非圧縮、層流。奥行きは評価用の長さ（既定1 m）であり、奥行き方向の端面はモデル化しない。
- Boussinesq 近似：密度変化は浮力項のみ。|β(T − T_ref)| ≤ 0.1 を保守的な監視範囲として生成時と各ステップで強制し、超える条件は拒否する。これは精度の普遍的な保証ではない（`docs/dynamic/CFD_DEVELOPMENT.md`）。
- 一定物性（温度依存なし）。画面の物性は300 K の空気の参照値：ρ = 1.177 kg/m³、c_p = 1006 J/(kg·K)、k = 0.0264 W/(m·K)、ν = 1.575×10⁻⁵ m²/s、β = 1/300 K⁻¹（理想気体の近似）。出典は教科書付録 A.6（書籍755／PDF769）（画面「理論・物性・適用範囲」）。このとき α = k/(ρc_p) ≈ 2.23×10⁻⁵ m²/s、Pr ≈ 0.71。
- エネルギーは顕熱のみ。放射との連成、相変化は含まない。
- 圧力は相対値（ゲージ）であり、絶対圧の水準は決まらない。

## 12. モデルの限界

- Ra > 1000 は仕様として例外で拒否する。したがって de Vahl Davis の Ra = 10⁴〜10⁶ のケースは照合できず、高 Ra の流れ（多セル化・乱流への遷移を含む）は対象外である。
- 開放領域の鉛直加熱壁に沿う外部自然対流（温度境界層型）の動的モデルはない。本モデルで扱えるのは閉キャビティの熱壁の内面だけである。静的な相関の学習モデル `natural-convection-vertical.mjs` は別物であり、本モデルの検証には数えない。
- 発熱体の周囲の自然対流は解けない。ソルバーは障害物・自由形状を明示的に拒否する。内部熱源は製造解検証専用で、浮力とは併用できない。
- 境界条件は等温壁と断熱のみ。熱流束・対流境界、加熱／冷却位置の変更はできない。画面では流体（空気）・形状（10 mm角の正方形）・物性は固定で、アスペクト比も変えられない（API では矩形と Pr の変更を受け付けるが、画面の機能ではない）。
- 温度境界層の定量表示、熱流束の場表示、粒子軌跡の表示はない。
- 3次元、乱流、固体との共役伝熱、圧縮性、開境界は未対応である。
- 開発専用・公開承認前であり、公開URL・オフライン・実機での動作は未検証である（`docs/dynamic/CAVITY_UI_CHECKPOINT_20261105.json` に mainPublished:false、offlineVerified:false、realDeviceVerified:false の記録）。

## 13. よくある誤解

- **「Nusselt 数は1つだけ」** — 誤り。本モデルには測定場所の異なる3定義（Nu₀／Nu₁/₂／体積平均Nu）があり、論文 Table V にも 1.117 と 1.118 が定義別に併記されている。壁の Nu₀ を論文の代表値 1.118 と比べて誤差と判断するのは定義の取り違えである（項目10の経緯）。
- **「流線は粒子の軌跡」** — 誤り。瞬間流線はその時刻の速度場に接する線であり、粒子がたどる経路ではない。
- **「圧力の色が絶対圧を表す」** — 誤り。平均ゼロのゲージ圧（相対値）である。また Poisson 残差や発散が小さいことは、連続圧力の精度の保証ではない。
- **「計算開始直後の Nu の大きなピークが物理現象」** — 誤り。壁温の段差と半セル近似による離散化上の見かけであり、格子数に依存する（項目5）。
- **「過渡中に3定義が食い違うのは異常」** — 誤り。断面ごとに熱の流れ方が異なる過渡では当然食い違う。一致するのは定常だけであり、その一致は保存性の確認になる。
- **「64格子でベンチマークと合ったから一般の CFD として正確」** — 誤り。検証は限定された条件（Ra = 1000・Pr ≈ 0.71・正方形・定常量）に対するもので、一般 CFD の精度承認ではない（画面とチェックポイントにも明記）。
- **「温度差を大きくすれば高い Ra の様子が見られる」** — 誤り。Ra > 1000 は拒否され、Boussinesq の監視範囲 |βΔT| ≤ 0.1 もある。乱流や高 Ra の対流は本モデルでは扱えない。
- **「運動エネルギーと熱の収支は同じ収支」** — 誤り。運動エネルギーは圧力投影の整合性を調べる診断であり、顕熱の収支とは別である（項目9）。

## 15. 関連問題

対応付けは棚卸し記録 `docs/dynamic/MODEL_PROBLEM_MAP_20261107.md`（第6.1節）に基づく。記載した ID はすべて問題バンク `data/questions.json` の実在 ID であり、アプリの演習（`../index.html#quiz`）でそのまま検索できる。

**現行の問題バンク（751問）に、本モデル（密閉キャビティ内部の自然対流）に直接対応する問題はない。** 「キャビティ」「閉空間」「密閉（容器）」で棚卸ししても該当は 0 件であり、バンクの自然対流問題は外部自然対流と膜状凝縮が中心である。

対応表では、次の 12 件が本節に主掲載されている。これらは本モデルの前提（Ra の定義と尺度、Boussinesq 近似）そのものに対応する基礎問題であり、いずれも外部自然対流の文脈で書かれているため、キャビティ固有の問題として断定はしない。

- `supp-chapter-ch8-ra` — Ra=gβ|ΔT|L³/(να) の計算。
- `supp-chapter-ch8-length` — 代表長さを2倍にしたときの Ra の変化（Ra∝L³）。
- `supp-chapter-ch8-gr-pr` — Gr と Pr から Ra=Gr・Pr を求める。
- `supp-section-8-2` — Gr が温度差のほかに依存する長さの因子（第8.2節の学習ノート）。
- `supp-section-8-3` — L を2倍にしたときの Ra の比例変化（第8.3節の学習ノート）。
- `supp-advanced-ch8-calc` — L と ΔT をともに2倍にしたときの Ra の変化。
- `supp-applied-8-3-v1` — 物性値を与えた自然対流の Ra の計算。
- `supp-natural-rayleigh-v1` — 一定物性の仮想流体での Ra の計算。
- `supp-buoyancy-film-rayleigh-from-gr-v1` — Gr_L と Pr から Ra_L を求める。
- `supp-buoyancy-film-vertical-ra-v1` — 垂直面の自然対流における Ra_L。
- `supp-buoyancy-film-boussinesq-check-v1` — 密度変化を浮力だけに残す Boussinesq 近似の適用判断。
- `supp-buoyancy-film-zero-gravity-limit-v1` — g→0 の極限における浮力自然対流モデルの解釈。
