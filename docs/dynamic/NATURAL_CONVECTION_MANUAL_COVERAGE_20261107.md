## 検証済み範囲と未実施範囲の区別（項目10・12の根拠）

- 外部照合あり：Ra = 1000・Pr = 0.71・正方形の定常ベンチマーク量（Nu の3定義、最大速度と位置、局所Nu最大）。格子系列 16／32／48／64 と Richardson 外挿 ≈1.11778 まで記録がある。
- 独立検証・ケース測定あり（リポジトリ外のフェイリス記録）：定式化の異なる ω–ψ 独立ソルバーによる再計算（Richardson 外挿の相互一致 7e-6、全プロファイル照合）、Pr = 0.1〜7 とアスペクト比 0.5／2 の12ケース実測。
- 未実施・対象外：Ra > 1000（仕様として例外拒否。de Vahl の 10⁴〜10⁶ は照合不可）、開放領域の鉛直加熱壁の動的モデルなし、発熱体・障害物まわりなし、圧力場のベンチマーク照合なし、過渡過程の外部参照照合なし、熱流束・対流境界なし、公開URL・オフライン・実機の確認なし。これらを新規説明書の項目12に限界として明記し、検証済みと混同しないようにした。
