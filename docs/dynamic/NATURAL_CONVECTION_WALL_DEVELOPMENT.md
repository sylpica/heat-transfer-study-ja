# 鉛直等温平板の自然対流（相似解モデル）開発記録

開発専用・未公開（releaseApproved=false、公開ビルドの allowlist 外）。
対象は Phase 3「自然対流」分野の未実施項目だった**開放された鉛直加熱壁**
（外部の静止流体に置かれた鉛直平板）の層流自然対流である。密閉キャビティ
（`cavity.mjs`、de Vahl Davis 照合済み）とは別のモデルである。

根拠は A Heat Transfer Textbook, 6th ed. (Lienhard) 第8章。式番号・係数は
原典テキストと印刷ページ画像で確認したものだけを使う。

## 採用した定式化と式

### 等温壁（主モデル）

境界層方程式 (8.8) と連続式の相似変換 (6.40) から導かれる Ostrach 型の
相似方程式を解く。教科書は Schmidt–Beckmann の厳密計算（空気、Fig. 8.4）を
参照しており、相似方程式そのものの組立ては (8.8) からの導出で確認した。

- η = (y/x)(Gr_x/4)^{1/4}、ψ = 4ν(Gr_x/4)^{1/4} f(η)、θ = (T−T∞)/(Tw−T∞)
- f''' + 3 f f'' − 2 (f')² + θ = 0
- θ'' + 3 Pr f θ' = 0
- 境界条件 f(0)=f'(0)=0、θ(0)=1、f'(∞)=θ(∞)=0
- 局所 Nu_x = −θ'(0)·(Gr_x/4)^{1/4}、平均 Nu_L = (4/3)·Nu_x（x=L）
- 速度 u = (4ν/x)(Gr_x/4)^{1/2} f'(η)
- Ra_L = Gr_L·Pr = gβ∆T L³/(να) …… (8.11)、定義 (8.9)

数値解法は**台形コロケーション＋Newton 反復**（格子逐次細分化と Pr の
継続法を併用）。単純な射撃法は採用しない：初期値問題として積分すると、
解から外れた初期値で有限 η の発散（blow-up）が起き、特に低 Pr で
収束域が狭いことを実測したためである。代表スカラー（θ'(0)、f''(0)、
f'max、f(∞)）は2つの最細格子から Richardson 外挿する（台形法は2次）。

比較相関式（モデル記録に併記し、独立照合にも使う）：

- Churchill–Chu 層流平均 Nu_L = 0.68 + 0.670·Ra_L^{1/4}·[1+(0.492/Pr)^{9/16}]^{−4/9}
  …… (8.13a)、Ra_L ≲ 10^9、全 Pr、物性は膜温度
- Squire–Eckert 積分法の平均 Nu_L = 0.678·Ra_L^{1/4}·[Pr/(0.952+Pr)]^{1/4}
  …… (8.27)、局所 (8.26)

### 等熱流束壁（相関式のみ）

相似解は使わず、教科書が印刷する相関式と温度分布だけで構成する。

- 修正 Rayleigh 数 Ra*_x = Ra_x·Nu_x = gβq_w x⁴/(kνα) …… (8.42)
- Raithby–Hollands 平均 Nū_L = (6/5)·[Ra*_L·Pr/(4+9√Pr+10Pr)]^{1/5} …… (8.44b)
  （全 Pr、Nū_L ≳ 5 で適用。平均温度差 ∆T̄ 基準）
- 温度分布 ∆T = C·x^{1/5} …… (8.40)、平均 ∆T̄ = (5/6)·C·L^{1/5} …… (8.41)
  から、頂部 ∆T = (6/5)∆T̄、中点 ∆T = 頂部×2^{−1/5}、頂部局所 Nu = (5/6)Nū_L
- 比較として Churchill–Chu (8.43b) を平均温度差基準へ換算
  （係数 (6/5)·2^{−1/5} を掛ける）して併記する

## 式 (8.44a) の不整合（記録）

印刷された局所式 (8.44a) Nu_x = 0.630·(Ra*_x·Pr/(4+9√Pr+10Pr))^{1/5} は、
(8.44b) と (8.40)/(8.41) の組合せと**ちょうど自らの先行係数 0.630 の分だけ**
食い違う（実測：両者の比は全 Pr で 0.630000…）。一方 (8.44b) は独立な
(8.43b)（換算後）と Pr = 0.1〜100 で 0.8〜2.1% 以内で一致する。よって本
モジュールは (8.44b)＋(8.40)/(8.41) の内部整合した系だけを計算に使い、
(8.44a) は計算経路に使わず、印刷形と実測した不整合率を参照 JSON
（`ratioPrinted844aToProfile`）に記録する。これは本プロジェクトの既存方針
（書籍側の印刷不整合は記録し、黙って直さない）に従う。

## 受付範囲と拒否

- Pr = ν/α ∈ [0.1, 100]：相似解を独立検証した範囲。範囲外は理由を表示して拒否。
- Ra_L ∈ [1e4, 1e9]：上限は教科書の層流域（§8.3、Ra_L ≲ 10^9）。乱流式
  (8.13b) は実装しない。下限未満は境界層近似の妥当性ノート（§8.3、低 Gr で
  境界層近似が劣化）に基づく検証範囲外として拒否する。
- 遷移近傍の警告：Ra_L·[1+(0.492/Pr)^{9/16}]^{16/9} > 1e8（p.419 の整理で
  乱流的振る舞いの始まる領域）では警告を付けて層流値として返す。
- 等熱流束：Nū_L < 5 は (8.44b) の適用条件外（低 Nu の式は文献 [8.11] に
  委ねられており教科書に再掲がない）として拒否。平均温度差基準の
  Ra_L = Ra*/Nū_L > 1e9 も乱流域として拒否する。なお等熱流束側では
  Ra の下限は設けていない（教科書の適用条件は Nū_L ≳ 5 であり、それが
  実効的な下限になる）。
- 物性は膜温度 Tf = (Tw+T∞)/2 での利用者供給（教科書の処方どおり）。
  未知のキーは「未対応の物理条件を暗黙に無視しません」と明示して拒否。
- 冷たい壁（Tw < T∞）は流れの向きを反転させて扱う（速度は符号付き、
  h は |∆T| で同じ値）。
- 相似領域 ηmax の既定値は Pr<1 で 40、Pr≧1 で 30。それ未満の明示指定は
  「相似領域が不足します」として拒否する（切り詰めた領域では裾の条件が
  解を黙って歪めるため）。

## 検証（実測）

参照値：`docs/dynamic/NATURAL_CONVECTION_WALL_REFERENCE_20261107.json`
（生成：`scripts/dynamic-natural-convection-wall-reference.py`、SHA-256 を
テストで固定）。中身は3系統の独立計算の照合である。

1. **mpmath 50桁の射撃法**（Taylor 法積分、tol 1e-30、射撃 Newton は
   尾部残差 1e-12 未満で停止）。findroot の初期値は JS コロケーション値
   （別手法・倍精度）を種に使ったが、記録値は収束した50桁の射撃解であり、
   初期値の出所は JSON に明記した。
2. **scipy solve_bvp**（コロケーション、解析的初期プロファイルのみ使用）：
   θ'(0) と f''(0) は全 Pr で mpmath と相対差 3e-15 以下で一致。
   f'max の相対差は 8e-8〜5.8e-7（scipy 側は 20001 点評価グリッドの
   argmax で読むため、その抽出分解能が支配的）。
3. **本モジュール（JS）** vs mpmath：θ'(0) の相対差は最大でも Pr=0.1 の
   3.4e-8（JS の ηmax=40 と参照の 60 の差を含む）、他は 1e-8 級以下。
   Pr=0.72 で −θ'(0) = 0.5046341858（文献の Ostrach 表値 0.5046 と整合）。

- 収束次数：Pr=1 で生の θ'(0) の誤差は格子 400→800→1600→3200 で
  1.225e-4 → 3.065e-5 → 7.664e-6 → 1.916e-6、実測次数 1.998〜2.000
  （台形コロケーションの2次）。Richardson 外挿値は細分化で 1e-10 まで安定。
- ηmax 感度（参照側、1.5倍の領域で再計算）：θ'(0) の変化は Pr=0.1 で
  1.5e-12、Pr=7 で 1.1e-12、Pr=100 で 9.3e-8（高 Pr では速度の裾が
  ゆっくり減衰するため最も大きい。それでも 1e-7 級）。
- 相関式との一致：相似解の平均 Nu 係数 / (8.13a) の漸近係数 =
  0.9966〜1.0028（全 Pr で ±0.35% 以内）。/ (8.27) Squire–Eckert =
  0.923〜1.025（積分近似の精度として教科書の記述と整合）。
- 例題 8.1（書籍入力、g=9.8）：Ra_L = 6.7828e7（印刷 6.78e7）、(8.13a) の
  式評価 Nu_L = 47.346（印刷 47.33）、相似解 Nu_L = 46.797、h = 4.168
  （印刷 4.22 は (8.13a) 由来）。
- 例題 8.3（書籍入力、g=9.8）：(8.27) の式評価 Nu_L = 61.247（印刷 61.25）、
  相似解 Nu_L = 57.614、h = 3.778、q = 98.23（印刷 104 は (8.27) 由来）。
- **問題 8.29 の u_max = 0.35 m/s の出所**：(8.19)/(8.23)/(8.24) の
  Squire–Eckert 経路で計算すると 0.34532 m/s となり印刷値と一致する。
  厳密相似解では 0.32274 m/s（約7%低い）。教科書自身が Squire–Eckert の
  速度プロファイルは温度より粗い旨を述べていることと整合する記録として
  残す（相似解側の欠陥ではない）。
- 等熱流束の照合ケース（例題8.3の流体、q_w=100 W/m²、L=0.40 m）：
  Ra* = 9.1206e9、(8.44b) Nū_L = 61.2776、∆T̄ = 24.886 K、頂部 29.864 K、
  (8.43b) 換算値との比 1.0110。Pr スイープでも両式の比は 0.992〜1.021。

## 限界・未実施

- GUI は今回の範囲外（開発モジュールと検証のみ）。公開 allowlist 外、
  releaseApproved=false を維持する。
- 乱流域 (8.13b)、傾斜板・水平板、鉛直円筒、エンクロージャは対象外。
- 一様な物性（膜温度で評価）と Boussinesq 近似の範囲。温度依存物性・
  放射との連成は扱わない。
- 等熱流束は相関式 (8.44b) のみで、相似解による裏付けはない（教科書が
  等熱流束の相似解を示していないため）。局所分布は (8.40) の x^{1/5} 形を
  平均量から構成するものに限る。
- 実機・支援技術での操作確認は未実施（本モジュールに画面がないため
  統合フェーズで判断する）。
