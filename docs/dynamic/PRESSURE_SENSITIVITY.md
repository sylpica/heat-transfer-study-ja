# 開発用CFDの圧力誤差：粘性・速度・時間

感度調査であり、空間離散化を改善したものではない。一般CFDは配信物外、pressureAccuracyApproved=false。元の64²圧力相対RMS約6.85%を取り消さない。

単位正方形、ρ=cp=1、α=0.2、最終時刻0.025 s、16/32格子、256/512等分刻み。圧力は全て同じ0.1cos(2πx)cos(2πy)e⁻ᵗ Paで、RMS約0.0487655 Pa。参照圧力の振幅/ノルムを変更して誤差を小さく見せない。ψ=A sin²(πx)sin²(πy)e⁻ᵗの速度振幅A=0/0.1/1とν=0.01/0.1/1を独立に変える。連続PDEからの外力/発熱を合わせ、FVM式から参照外力を作らない。実在流体の物性プリセットではない。

同じ刻みで格子を変える比較と、同じ格子の刻み半減を分ける。時間/空間誤差を完全に分解したとは扱わない。全36ケースのRMS/最大圧力誤差・速度RMS・発散・収支を保存。passedは計算完了と保存則ガードのみで、圧力精度の承認ではない。

32²・512刻みの圧力相対RMS [%]：

|ν|A=0|A=0.1|A=1（元の速度振幅）|
|---:|---:|---:|---:|
|0.01|0.16571|0.58254|47.1464|
|0.1|0.16571|0.57897|43.0982|
|1|0.16571|0.70886|27.3176|

ν=1、A=1で16²→32²の絶対RMSは0.0528959→0.0133216 Pa。同じ32²の256→512刻みでは0.0133285→0.0133216 Pa。刻み半減の効果は小さく、格子と速度に強く依存する。「粘性を小さくすれば減る」という仮定は支持されなかった。次は移流/拡散の各離散演算子と圧力への勾配成分を分けて調査する。

A=0は既知の圧力勾配を体積力で釣り合わせる検査。面の連続圧力勾配とセルcosの中央差分の係数はz/sin(z)、z=π/nだけ異なる。この係数を回復し、偽の速度が10⁻¹³ m/s未満であることを別のNode試験で照合。外力は陽的ステップ直前の時刻なので、最終時刻の連続圧力との比較には1次時間誤差も含む。元の大きな誤差をこの単純な検査の結果へ置き換えない。

PRESSURE_SENSITIVITY_BASE_20261104.jsonは最初のνのみ12ケース。その未保存driverはsource-snapshotsへ正確なbytes/hashで保全。PRESSURE_AMPLITUDE_SENSITIVITY_20261104.jsonは36ケースで、scripts/dynamic-pressure-sensitivity.mjsとCI artifactで再現する。基点SHA/dirty状態/正確なソースhashを保持する。

## 製造解と復元の識別

旧復元signatureは「製造解あり」のboolだけで、同じ初期温度/物性なら異なる外力lawを同一と扱い得た。製造解へ安定IDとρ/cp/ν/α・領域/壁温の宣言を付け、条件不一致を拒否。異なる振幅の復元は原子的に拒否、同じlaw/条件の別モデルでは受理する。識別子のない開発用関数は各インスタンス固有とする。IDは信頼された開発者の宣言で、暗号認証ではない。通常の物理ケースへ関数を持ち込まない。

check-manufactured-sources.pyを拡張し、A=0/0.1/1も含む27条件をSymPyで独立微分。最大差2.84×10⁻¹⁴、発散と全壁が記号的に成立。MANUFACTURED_AMPLITUDE_SYMBOLIC_20261104.jsonに記録。専門家の承認ではない。
