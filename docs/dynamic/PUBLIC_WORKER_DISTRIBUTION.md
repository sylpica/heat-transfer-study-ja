# 公開Workerの自己完結した配信

2026-11-05、2e8f80c後続。動的実験室の公開ビルド専用。一般利用者は公開URLだけで利用し、Node/npm/ビルド操作を要求しない。

WebKit 26.0 build2215の新しいオフライン文書で、キャッシュ済みmodule Workerのエントリーから相対importだけがネットワークに出る失敗を再現した。今回のフィン画面で初めて訪れるクエリ付きURLを使い、サーバーを停止して検査した。pageerrorはImporting a module script failed、5依存のrequestfailedはconnection refused。キャッシュ/SW支配済みでも失敗していた。

scripts/public-worker-bundle.mjsはesbuild 0.25.12で公開4モデルのWorkerを自己完結したESモジュール1ファイルにまとめる。定数・Float64演算・通信・取消/ロールバックは元の実装を使い、minifyはしない。各メタデータ入力がdynamic内の明示した公開allowlistにある.mjsか検査し、dev/や許可外の依存と外部importを拒否してから配信物を置き換える。ビルド/試験ツールをブラウザーへ配信しない。

原ソースは分割したままで、distだけを変換する。生成後のWorkerを含む配信物のハッシュからSWキャッシュ名を計算し、旧利用者にも更新を検出させる。PDFのキャッシュ名は原本のハッシュを保ち、アプリ更新で無条件再取得しない。新旧キャッシュ試験はWorker/runtimeの正確なバイト一致、旧アプリキャッシュの廃棄、PDFキャッシュとlocalStorageの保持、更新後のオフライン計算を調べる。

ビルド依存esbuildと既存の試験依存Playwright 1.56.1をdevDependencies/lockへ固定した。Node20以上でnpm ciを先に実行する。動的CIおよび公開ビルドを実行する該当ワークフローはnpm ciを使う。手動デプロイの対象は別の旧開発ブランチのままで、この変更では実行・対象変更・権限変更を行わない。

新規Node試験は、生成Workerを実際のworker_threadsで起動し、初期と前進後の全温度・時刻・収支を分割版のモデルと完全一致させる。未登録cavityの拒否も確認。許可外依存では既存の出力を上書きしない別試験もある。各公開モデルのブラウザー試験は実際の生成Workerを使う。

分割ソースをそのまま開発サーバーで配信する場合、このビルド変換は入らない。一般CFDの開発専用Workerは未公開で、同じオフライン保証を主張しない。実機Safari/Android、旧端末の実キャッシュ、実公開URLへの動的版配信は別途未実施。
