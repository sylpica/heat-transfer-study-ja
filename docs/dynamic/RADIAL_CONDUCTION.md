# 円筒・球の半径方向熱伝導：数値コア

`dynamic/radial.mjs` は半径方向1Dの保存型有限体積法。現在は数値検証段階で、公開ビルドのallowlist/Worker/画面へは未登録。既存の円の輪郭を使う直交2D平板モデルとは別の支配式・体積/面積を使う。

## 対象と式

単一の中実円筒または球、均質で一定のk・ρ・cp、半径R、半径方向にのみ変化する温度、一様体積発熱。円筒は長さLを与え、端面断熱・軸方向/周方向変化なし。球も角度方向の変化を解かない。中空/複合材料/相変化/物性の温度依存/流体との連成は対象外。

ρcp ∂T/∂t = k r^(1−d) ∂[r^(d−1) ∂T/∂r]/∂r + q‴。円筒d=2、球d=3。実装はこの式の1/rを直接計算せず、各殻の積分保存則を使う。

|量|円筒|球|
|---|---|---|
|面積A(r)|2πrL|4πr²|
|殻体積|πL(r₊²−r₋²)|4π(r₊³−r₋³)/3|
|熱容量Cᵢ|ρcp Vᵢ|ρcp Vᵢ|

等間隔の面rᵢとその中点に温度を置く。殻体積は差の安定な積の形で計算し、内部面の熱量をGᵢ(Tᵢ₊₁−Tᵢ)、Gᵢ=kA(r面)/Δrとして両隣へ等量・逆符号で計上。中心は面積0・熱流0の対称条件で、特別な架空セルやr=0の除算をしない。過渡/発熱のセルに、熱流が半径によらず一定という定常のlog/1/r抵抗を無条件に使わない。温度値は殻平均の代表値で、勾配再構成の離散化誤差を持つ。

## 境界と時間積分

外表面は温度固定、断熱、内向き熱流束、指定hの対流、灰色面→大きな黒い周囲への放射。表面までの半セルの勾配抵抗Δr/(2kA)を使い、対流では1/(hA)と直列にする。これは曲面半セルの離散勾配近似で、連続解との格子検証を必要とする。hを流速から推定したり自然対流を解いたりしない。

放射では表面温度を正のKの範囲で二分法により解き、半セル伝導とεσA(T面⁴−T周囲⁴)を一致させる。σ=5.670374419×10⁻⁸ W/(m² K⁴)、差の4乗は積に分解する。放射率0とh=0は断熱の極限。内向き表面熱流束の正負と、診断の外向き熱流束の符号を分ける。

前進Euler。Δt ≤ 0.8 min[Cᵢ/ΣGᵢ]。放射も表面までの伝導Gを上界として含める。発熱/冷却による0 K以下、非有限値、無効な面温度、時間/カウンターの保存範囲超過では更新前の状態で停止する。顕熱は273.15 K基準、外部入力は体積発熱＋境界入力。復元ではモデル/物性/初期場の署名と場・時刻を確認し、配列をコピーする。公開したconfig/meshを後から書き換えても内部の体積/物性は変わらない。

## 独立した連続参照解

`scripts/dynamic-radial-reference.py` は開発者用。利用者にはPython/SciPyを要求しない。SciPyのBessel関数/根、50桁mpmathでのJ₀最初の根の照合を使い、連続の球/円筒固有関数級数を**各殻体積で積分**する。FVM更新式から参照値を生成しない。表面温度固定の球のsin級数と円筒J₀級数、Bi=hR/k=0.5のRobin境界の根/係数を扱う。

各殻平均を体積で重み付けして、別の解析的な全体平均級数と2×10⁻¹⁴以内で一致することも確認。32項、Fo=0.1では高次項が指数的に減衰する。数学的な参考条件はR=0.01 m、k=10、ρ=1000、cp=1000、初期373.15 K、表面/周囲293.15 K、t=1 s。これを実在材質の物性プリセットと呼ばない。生成時刻/ライブラリ版/スクリプトhashと未保存状態の識別は `RADIAL_CONTINUOUS_REFERENCE_20261104.json` に保持。
