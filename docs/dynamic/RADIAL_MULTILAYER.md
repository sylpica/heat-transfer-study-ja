# 径方向多層（複合材料）・中空 非定常熱伝導モデル

`dynamic/dev/radial-multilayer.mjs`（法則識別子 `radial-multilayer-conduction-v1`）の仕様と検証記録。
Phase 3「非定常熱伝導」の締め可能性監査（2026-11-07）で最大の実装ブロッカーとされた
「径方向複合材（多層）＋中空モデル」の実装である。フェイリス側の並行実装であり、
既存の単一材料モデル `dynamic/radial.mjs` は変更していない。
**開発専用**（`dynamic/dev/` 配下、公開ビルドの allowlist 外）で、`releaseApproved=false`。
画面（GUI）は今回の範囲外で、数値コアと検証記録のみである。

## 1. 物理モデル

同心の層が最大 8 層まで積層した円筒（長さ `length` 必須）または球について、
層ごとに異なる定物性（熱伝導率 `k`、密度 `rho`、比熱 `cp`、体積発熱 `source` [W/m³]）を持つ
1 次元径方向の非定常熱伝導を解く。

- 支配方程式（層 j 内）: `rho_j cp_j ∂T/∂t = (1/r^m) ∂/∂r ( r^m k_j ∂T/∂r ) + source_j`
  （円筒 m=1、球 m=2）
- 内半径 `innerRadius >= 0`。`0` は中実（中心は対称条件で自動処理）、`>0` は中空で内面に境界条件を持つ。
- 層界面では温度と熱流束の連続を基本とし、界面ごとに面積当たり接触熱抵抗
  `contactResistance` [m²K/W]（スカラーまたは界面ごとの配列、既定 0）を置ける。
  接触抵抗がある界面では温度ジャンプ `ΔT = q'' · Rc''` が生じる。
- 内面・外面の境界条件は既存 `radial.mjs` と同じ 6 種
  （`insulated` / `temperature` / `flux` / `convection` / `radiation` / `convection-radiation`）を
  `dynamic/surface-exchange.mjs` の共通評価で処理する。
  中実形状の内面境界は `insulated` 以外を拒否する。

## 2. 離散化

- 層ごとに等分格子（`cells`、層内で一様）のセル中心有限体積法。セル体積は殻体積の厳密式
  （球 `(4π/3)(r₂³−r₁³)`、円筒 `π(r₂²−r₁²)L`）を安定な積の形で評価する。
- セル間のコンダクタンスは面面積と中心間距離から `G = k·A/dr`。
- **界面コンダクタンス**は、界面面積 A と両側の半セル抵抗・接触抵抗の直列として
  `G_if = A / ( (dr_L/2)/k_L + Rc'' + (dr_R/2)/k_R )` とし、
  左セルから界面までの温度降下と接触ジャンプを分けて復元する
  （`flux()` が界面ごとに外向き熱量、両側表面温度、温度ジャンプを返す）。
  これにより定常では熱抵抗網の解析解へ 2 次で収束する（§4.1）。
- 境界は半セル抵抗 `dr/(2k)` 越しの表面交換として既存モデルと同一に扱う。
- 時間積分は前進オイラー。安定上限 `safeDt = 0.8 · min_i C_i / ΣG_i`
  （境界の安定化コンダクタンスの扱いも既存モデルと同一）を超える刻みは原子的に拒否する。
- エネルギーは 273.15 K 基準で会計し、境界熱量は台形積分で蓄積する。
  スナップショットには `energyError`（蓄熱変化と収支の残差）が常に入る。
- 入力検証は既存モデルの流儀どおり厳格:未知キー（トップ／層／境界条件の各レベル）、
  非有限・範囲外の値は日本語エラーで原子的に拒否する。損傷した復元データも原子的に拒否し、
  正しい復元は完全再生する。公開された `config` / `mesh` を書き換えても内部状態は変わらない。

## 3. 検証の構成

参照値は製品コードと独立に生成した。

- 定常解析解:熱抵抗網（円筒 `ln(r)` 抵抗、球 `1/r` 抵抗、接触抵抗 `Rc''/A`、

## 4. 実測検証値（2026-11-07、基底コミット 7968146 上で計測）

### 4.1 定常解析解との照合（熱抵抗網）

製品モデルを境界熱量の相対不均衡が 1e-8 未満になるまで行進させた定常値と解析解の差。

| ケース | 解析 Q [W] | セル/層 | Q 相対誤差 | 界面温度 最大誤差 [K] |
|---|---|---|---|---|
| 3層円筒（k=10/1/5、内面400K・外面300K固定） | 97.758423 | 8 / 16 / 32 / 64 | 8.81e-4 / 2.21e-4 / 5.52e-5 / 1.38e-5 | 2.55e-2 / 6.41e-3 / 1.61e-3 / 4.01e-4 |
| 2層球＋外面対流（k=5/0.5、h=100） | 5.438174 | 8 / 16 / 32 | 1.15e-3 / 2.88e-4 / 7.21e-5 | 1.50e-2 / 3.77e-3 / 9.43e-4 |
| 2層円筒＋接触抵抗 Rc''=0.005 | 42.764956 | 8 / 16 / 32 | 2.61e-4 / 6.53e-5 / 1.63e-5 | 8.05e-3 / 2.02e-3 / 5.04e-4 |

- 誤差比はいずれも 3.99〜4.00 で、**観測次数は約 2.0**。
- 接触抵抗ケースの解析温度ジャンプは 56.7188 K。製品モデルはこのジャンプを
  界面の両側表面温度として分離して再現する（32 セル/層でジャンプ誤差 0.01 K 未満、テストで固定）。
- 球ケースの外面表面温度誤差は 8/16/32 セル/層で 4.12e-2 / 1.03e-2 / 2.58e-3 K。
- 定常行進中のエネルギー収支残差 `|energyError|` は全ケースで 4.4e-9 J 以下。

### 4.2 過渡の独立参照との照合

| ケース | 参照自己収束（格子 / 時間）RMS [K] | 製品 RMS 誤差（8 / 16 / 32 セル/層）[K] |
|---|---|---|
| 2層球（中実、k=10/2、外面対流冷却、t=1 s） | 2.7e-5 / 1.1e-4 | 4.69e-2 / 1.16e-2 / 2.70e-3 |
| 2層中空円筒（k=5/0.8、内面360K固定・外面対流、t=2 s） | 7.0e-5 / 3.6e-4 | 1.35e-1 / 3.35e-2 / 8.24e-3 |

- 誤差比は約 4.0〜4.3 で単調減少し、観測次数は約 2.0。32 セル/層での最大シェル誤差は
  球 4.77e-3 K、円筒 2.25e-2 K。
- 過渡行進中のエネルギー収支残差は全ケースで 3.2e-12 J 以下（相対 2.9e-15 以下）。
- 参照側の自己収束誤差（最大 3.6e-4 K）は製品側の 32 セル/層誤差より 1 桁以上小さい。

### 4.3 界面熱流束の整合性（プロンプト §6.4 項目 8）

ソルバー内部の界面移動量は保存型で両側共通（定義上一致）であるため、独立な照合として、
各層の界面近傍 3 セルの温度から 2 次片側外挿で求めた界面熱流束を両側それぞれ計算し、
保存型の移動量と比較した（相対差）。

| ケース・時刻 | セル/層 | 左側（高 k 側） | 右側（低 k 側） | 左右の差 |
|---|---|---|---|---|
| 中空円筒 t=2 s（Q=86.24 W） | 32 | 1.60e-3 | 2.29e-3 | 6.93e-4 |
| 中空円筒 t=2 s | 64 | 4.05e-4 | 5.13e-4 | 1.08e-4 |
| 2層球 t=1 s（Q=0.905 W） | 32 | 5.45e-3 | 2.21e-2 | 1.66e-2 |
| 2層球 t=1 s | 64 | 1.40e-3 | 5.48e-3 | 4.07e-3 |

- 時刻が進み格子を細分するほど全ケースで単調に減少する。
- **正直な留保**:界面熱流束そのものがほぼ 0 の初期時刻（球ケース t=0.25 s、Q≈5e-4 W）では
  相対差が大きくなる（32 セル/層で右側 4.9e-1）。これは熱前線が未発達な低 k 側での
  外挿誤差が支配的であり、絶対量としては微小である。初期の微小流束の相対精度が必要な
  用途では格子細分が必須である。

### 4.4 単層帰着と既存モデルとの一致

- 1 層・中実に帰着させた設定（対流境界・固定温度境界、球・円筒、発熱あり）では、
  既存 `createRadial` と温度場の最大差 **0**（ビット同一水準）、エネルギー一致、
  安定上限 `safeDt` の比 1（円筒で 1+2e-16）を確認した。
- 幾何量（殻体積・面面積・界面半径）は解析式と相対 1e-14 未満で一致する。
- 断熱した多層体の一様温度場は厳密に保存され、界面ジャンプは 0 になる。
- 層ごとの発熱を熱容量比例に選ぶと全層一様に昇温し、収支は厳密に閉じる。

## 5. 適用範囲と限界（未実施を含む）

- 物性は層ごとに定数。**温度依存物性 k(T)・cp(T) は未対応**（既存の矩形・径方向モデル側の課題と共通）。
- 相変化・移動境界・流体との連成は扱わない。形状は同心の円筒・球のみで、偏心・軸方向変化は対象外。
- 接触熱抵抗は界面ごとに定数（温度・圧力依存は扱わない）。
- 時間積分は前進オイラーのため、定常への行進や高熱伝導率の薄層ではステップ数が多くなる
  （検証では最大約 7.1e5 ステップを要したケースがある）。陰解法化は今後の課題。
- 過渡参照は閉形式解ではなく細格子数値参照である（自己収束値を §4.2 に併記）。
  定常側は閉形式の熱抵抗網と照合している。
- 画面（GUI）・Worker・ブラウザ確認・実機確認は今回の範囲外（数値コアのみ）。
  §21 の日本語モデル説明文も未作成で、公開判定は `releaseApproved=false` のままである。
