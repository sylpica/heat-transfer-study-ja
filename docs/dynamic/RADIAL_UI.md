## 表示と操作

殻平均温度を円の断面へ配置する半径方向1D解。中心の点温度を推測せず、殻中心/外表面も区別する。矢印は実際の面熱流束で外向き正、ゼロなら描かない。比較では共通の物理半径・温度・矢印尺度を使う。測定はドラッグ/クリック・左右キー・スライダーで、比較の同じr/Rに対応する実際の殻中心rを各条件に表示する。円筒は端面断熱・軸方向一様で、長さは全熱量を変え、半径方向の温度を変えない。

時間履歴と半径断面のグラフは別。断面は0から最大Rの共通実座標、殻中心/外表面の種別付き数値表を提供する。共通グラフの目盛りと軸名を別行にし、短い時間では表示桁数/指数表記を使う。小さい時刻/半径を単に0へ丸めない。

共通Experimentの最大2条件の同期再生・初期状態・メモリー履歴・巻き戻しを使用。体験/自由/専門、温度色の自動/初期固定/手動、テーマ、用語と焦点復帰、形状/寸法・材料/境界/発熱を設定する。CPU Workerで進捗/中断し、実験をlocalStorageへ保存しない。物性は既存の3金属の20℃参考値または手動の一定値で、他温度の実物性を保証しない。画面内の説明書に式・SI単位・境界・Fo/Biの長さ定義・検算・限界・オフラインを記す。

## 回帰で見つけた問題と修正

全モデルで初期化時にflux()も評価する試作では、既存k(T)表の範囲外ケースが「1コマで停止」から「初期化で停止」へ変わり、既存熱伝導ブラウザー回帰が失敗した。操作順/基準を変えず、安全に初期診断を返せるモデルだけが任意のinitialFlux()を提供する方式へ修正。球/円筒は提供し、既存の診断タイミング/停止順を保持。新しいsnapshot/初期診断を作り終えてからWorkerのモデルを入れ替える。

無効な手動の色範囲で描画だけ失敗し、裏で物理時間を進めないよう、初期化/前進の前に範囲を検査する。直すと同じ受理済み時刻の表示を回復する。
