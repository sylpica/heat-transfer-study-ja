# モデル別説明書：長い凸ダクト放射

- 日時：2026-11-07（Asia/Tokyo）
- 対象モデル：数値核 `dynamic/dev/long-duct-radiation.mjs`（`createLongDuctViewFactors`／`createLongDuctRadiation`）。本線の開発専用画面は `dynamic/dev/long-duct.html`、自由頂点編集 UI は統合ツリーの `dynamic/dev/long-duct-ui.mjs` に実装済み（開発画面のみ）。数値核の詳細は `docs/dynamic/LONG_DUCT_RADIATION_DEVELOPMENT.md`、本線画面は `docs/dynamic/LONG_DUCT_UI_DEVELOPMENT.md`、頂点編集は同ブランチの `docs/dynamic/LONG_DUCT_VERTEX_UI_20261107.md`。
- 位置づけ：正本 §21.2 の16項目の説明書。本モデルは開発専用（`releaseApproved:false`、公開 allowlist 外）であり、公開画面の説明書ではない。Phase 3 締め可能性監査（`phase3-closure-audit-20261107.md`、熱放射の残作業 #8）を受けた整備である。
- 読み分け：項目1〜2・9〜10・13 は初心者向け、それ以外は専門寄りの記述を含む。

## 1. 現象の概要

軸方向に無限に長い凸多角形ダクトの断面で、壁同士が放射だけで熱をやり取りする現象を計算する。放射ネットワークモデルとの違いは、形態係数 F を入力ではなく実際の断面形状（3〜12頂点の輪郭）から幾何計算する点である。各壁は等温で、軸方向 1 m あたりの熱容量を持ち、温度が時間発展する。熱の出入りは断面内の放射のみで、端面は存在しない。

## 2. 現実世界での使用例

- 長い炉内流路やダクトの断面で、壁面同士の放射交換を見積もる学習・概算。
- 正方形・矩形・正多角形など、形態係数の既知値がある断面での形態係数の学習と検算。
- 断面形状を変えたとき（例：矩形のアスペクト比）に、対向壁の見え方がどう変わるかの確認。
いずれも無限長・厳密凸・等温壁の仮定が成り立つ範囲に限る（項目12）。

## 3. 支配方程式

- 形態係数：2次元閉鎖系の交差弦法による。共有の交換長 Gᵢⱼ = LᵢFᵢⱼ = LⱼFⱼᵢ [m] を、交差する弦と交差しない弦の長さの差から一度だけ求める：LᵢFᵢⱼ =（交差弦の和 − 非交差弦の和）/ 2。平面壁の自己形態係数は 0（出典：`docs/dynamic/LONG_DUCT_RADIATION_DEVELOPMENT.md`、教科書 §10.3 の交差弦法の条件は Problem 10.14／§10.3 を参照）。
- 放射収支と温度発展：放射ネットワークと同じ式を使う。Gᵢ = ΣⱼFᵢⱼJⱼ、Jᵢ = εᵢσTᵢ⁴ + (1−εᵢ)Gᵢ、Qᵢ = AᵢΣⱼFᵢⱼ(Jᵢ−Jⱼ)、Cᵢ dTᵢ/dt = Pᵢ − Qᵢ。ここで Aᵢ = Lᵢ × span、Cᵢ = C′ᵢ × span、Pᵢ = P′ᵢ × span と換算する。

## 4. 記号と単位

| 記号 | 意味 | 単位 |
|---|---|---|
| (x, y) | 断面の頂点座標（3〜12頂点、厳密凸） | m |
| Lᵢ | 壁 i の辺長 | m |
| span | 軸方向の熱量換算長。端面を追加する物理的な長さではない | m |
| Aᵢ = Lᵢ × span | 壁 i の面積 | m² |
| C′ᵢ | 軸方向 1 m あたりの熱容量（断面辺長さあたりではない） | J/(m·K) |
| P′ᵢ | 軸方向 1 m あたりの外部入力 | W/m |
| Qᵢ / span | 軸方向 1 m あたりの正味放射出力 | W/m |
| Fᵢⱼ, Gᵢⱼ = LᵢFᵢⱼ | 形態係数、相反交換長 | —, m |
| εᵢ, Tᵢ, σ | 放射率、絶対温度、ステファン・ボルツマン定数 5.670374419×10⁻⁸ W/(m²·K⁴) | —, K, W/(m²·K⁴) |

## 5. 初期条件

壁ごとに初期絶対温度を与える。復元（巻き戻し）では、時刻 0 の温度は初期値と一致することが核側で要求され、一致しない復元データは拒否される。

## 6. 境界条件

断面は閉じた輪郭であり、各辺が 1 つの壁（等温面）になる。軸方向の端面はモデルに存在しない（無限長）。開口、障害物、外部への漏れは扱わない。壁以外の境界条件（対流・伝導との連成）はこのモデルにはない。

## 7. 数値計算法

- 形態係数：座標を原点移動と長さスケールで正規化し、弦長の差は平方差の因数分解で評価して桁落ちを避ける。隣接壁では三角形の Lᵢ+Lⱼ−対角線 を有理化し、小さい曲がり角は sin²/(1+cos) を使う（出典：`docs/dynamic/LONG_DUCT_RADIATION_DEVELOPMENT.md`、`dynamic/dev/long-duct-radiation.mjs`）。
- 受理条件：総和則と面積相反則の残差 1e-12 以内を要求する。F を切り取ったり行和で正規化したりして誤差を隠すことはしない。非有限・ゼロ辺・重複・一直線・凹・自己交差・弦長差から正の形態係数を解像できない形状は拒否する。同じ閉終点の除去だけが自動で行われ、その旨が記録される。
- 温度発展：放射ネットワーク核（`createRadiationNetwork`）の Heun 法と刻み上限をそのまま使う。無効な刻み・非有限な出力・復元失敗時は旧状態へ戻す（原子性）。

## 8. 計算過程

1. 断面を選ぶ。本線画面ではプリセット（正三角形／矩形／正六角形）と全幅・全高さの指定のみ。フェイリス側ブランチの画面では頂点のドラッグ・数値入力・追加・削除（3〜12個）による自由編集が可能で、編集のたびに核の検証を通し、不正な形状は理由を表示して受理しない。
2. 壁1と他壁の初期温度・放射率、全壁共通の面積あたり熱容量を指定して初期化し、再生／巻き戻し／A・B比較で応答を確認する。

形態係数の検算値（出典：`docs/dynamic/LONG_DUCT_RADIATION_REFERENCE_20261106.json` の照合形状と解析値。フェイリス側スポットチェック 2026-11-07、先端 `c52f2a7` で全て再現）：
- 正方形 1×1：対向壁 F = √2−1 = 0.41421356…、隣接壁 F = 1−1/√2 = 0.29289321…
- 矩形 2×1：長壁の対向 F = (√5−1)/2 = 0.61803398…、短壁の対向 F = √5−2 = 0.23606797…
- 正五角形：隣接 F = (3−√5)/4 = 0.19098300…、第二隣接 F = (√5−1)/4 = 0.30901699…
- 正三角形：全ペア F = 0.5

例題 10.9 の扱い（出典：`docs/dynamic/EXAMPLE_10_9_DISPOSITION_20261106.md`）：教科書の印刷値 Q = 46.53 W/m は、教科書自身の丸めた節点式の算術と一致しない（丸めない条件での式評価は 46.62819046 W/m）。本モデルの瞬間値は式評価に一致する。印刷値を式のオラクルにしないこと（項目13）。

## 9. グラフの読み方

- 本線画面の図は実際の断面頂点を縦横同じ px/m で配置する（放射ネットワーク画面の模式配置とは異なる）。各辺に解いた実壁温度・番号・℃ を表示する。
- 矢印は選択壁との正味交換 Qᵢⱼ の符号から方向を決める模式表現であり、光線の軌跡や本数ではない。反射を含むため温度差だけから方向は決まらない。
- 描画上の省略：丸め差水準の矢印（128 EPS × 選択壁の最大 |Qᵢⱼ| 以下）は図だけ省略し、省略数と閾値を診断に表示する。元の熱流の数値は変更されず、微小な非ゼロ値は指数表記で残る（出典：`docs/dynamic/LONG_DUCT_UI_DEVELOPMENT.md`）。
- 画面の線幅は壁厚ではない。全 F 行列、総和／相反残差、顕熱／外部入力／収支差、射度残差が数値で表示される。

## 10. 結果の解釈

- 検証の実測（出典：`docs/dynamic/LONG_DUCT_RADIATION_DEVELOPMENT.md`）：5形状（正方形、1×2.4 矩形、正三角形、正五角形／八角形）を 80桁 mpmath の弦式へ照合し、独立な放射角度核の線積分とも最大差 約 2.44e-15 で一致。等しい ε=0.8 の正三角形の冷却を1変数 ODE（DOP853）へ縮約して照合し、時間誤差の観測次数は 約 2.01/2.00。
- 総和／相反の残差表示は形状の解像度の指標であり、残差が小さいこと自体は一般形状の誤差証明ではない（受理条件は項目7）。
- span を変えても温度応答は同じで、容量・入力・蓄熱だけが比例する。W/m の値は span=1 m 換算の値として読む。

## 11. モデルの仮定

- 軸方向に無限長で、断面形状は一様。端面の効果はない。
- 断面は厳密な凸多角形（3〜12辺）。全壁が見通せるため遮蔽の判定を省略できる範囲である。
- 各壁は等温・灰色・拡散・不透明。内部の媒質は非参加。
- 壁内伝導・壁の厚み方向の温度分布は解かない（集中熱容量近似）。

## 12. モデルの限界

- 凹形状・障害物による遮蔽、有限長・端面、一般 3D は対象外（監査の残作業 #1）。
- 自由頂点編集は統合ツリーの開発画面に実装済み（公開ビルドには含まれない）。
- 開発専用であり、公開ビルドには含まれない。開発画面のオフライン確認と公開候補への登録判断は未完了（監査の残作業 #7）。
- 気体の放射吸収（参加媒体）、自然対流との連成は解かない。

## 13. よくある誤解

- **「span はダクトの実際の長さで、端面も計算される」** — 誤り。span は熱量換算のためだけの量で、有限長の端面は追加されない。
- **「形態係数の行和が 1 にならない形状は自動で補正される」** — 誤り。正規化も切り取りもしない。解像できない形状は拒否される。
- **「例題 10.9 の印刷値と合わないのはソルバーの誤り」** — 誤り。印刷値側に算術の不一致があり、式評価（46.62819046 W/m）が照合の基準である（項目8）。
- **「壁の温度が一様に描かれるのは計算結果」** — 誤り。一様性は集中熱容量の仮定そのものである。
- **「矢印は光線の経路」** — 誤り。射度差による正味交換の模式表現である。

## 15. 関連問題

対応付けは棚卸し記録 `docs/dynamic/MODEL_PROBLEM_MAP_20261107.md`（第7.2節・第8節）に基づく。

- 教科書側では Problem 10.14／§10.3 が交差弦法の条件の参照として開発文書に記録されている。
- **現行の問題バンク（751問）に、本モデル（長ダクトの形態係数）に直接対応する問題はない。** ダクトの放射文脈や交差弦（crossed-string）法を扱う問題は 0 件である。推測で埋めず、その事実をここに明記する。

最も近いのは、形態係数の基礎を扱う次の問題である（いずれも主掲載は放射ネットワークの説明書の項目15）。

- `supp-chapter-ch10-reciprocity` — 相反則 A₁F₁₂=A₂F₂₁。
- `supp-chapter-ch10-enclosure` — 閉じた囲いの総和則。
- `supp-batch2-closed-view-sum-v1` — 閉じた三面囲いの総和則。
- `supp-batch2-convex-self-factor-v1` — 凸面の自己形態係数が0であること。
