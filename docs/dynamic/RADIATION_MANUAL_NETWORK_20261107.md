# モデル別説明書：複数面の放射ネットワーク

- 日時：2026-11-07（Asia/Tokyo）
- 対象モデル：数値核 `dynamic/radiation-network.mjs` と学習モデル `dynamic/radiation-learning.mjs`。画面は `dynamic/radiation.html`（複数面の動的放射実験）。数値核の詳細は `docs/dynamic/RADIATION_NETWORK.md`、学習モデルの詳細は `docs/dynamic/RADIATION_LEARNING.md`。
- 位置づけ：正本 §21.2 がモデルごとに求める16項目の説明書。アプリ内の既存説明（`dynamic/radiation.html` の #manual「使い方と理論」）を正として参照し、独立項目として不足していた現実世界での使用例・よくある誤解・参考文献を本書で補う。数値・式の出典は各項に併記する。本書は Phase 3 締め可能性監査（`phase3-closure-audit-20261107.md`、熱放射の残作業 #8）を受けた整備である。
- 読み分け：項目1〜2・9〜10・13 は初心者向け、それ以外は専門寄りの記述を含む。

## 1. 現象の概要

閉じた囲い（閉鎖系）の中にある 2〜12 個の面が、放射だけで熱をやり取りしながら温度を変えていく現象を計算する。各面は温度が一様（等温）で、面同士の見え方は形態係数 F の行列で与える。形態係数は入力であり、このモデルは形状から F を計算しない（形状から F を計算するモデルは「長い凸ダクト放射」の説明書を参照）。画面には、同じ数値核を使う学習コース（等面積2面の予想実験）も含まれる。

## 2. 現実世界での使用例

- 炉の内壁同士が放射で熱を移し合い、壁温が均されていく様子の見積り。
- 宇宙機のパネルや電子機器の筐体内部で、部品面同士が放射交換する学習・概算。
- 建物の室内で、壁・床・天井の面同士が放射で影響し合う感覚の確認。
- 2つの面の間で、熱容量の違いが最終温度をどう決めるか（項目13）の確認。
いずれも等温・拡散灰色・閉鎖系の仮定が成り立つ範囲の学習・概算のためであり、実設計の保証には使わない（項目12）。

## 3. 支配方程式

教科書第10章（§10.3 黒体間の交換、§10.4 灰色体間の熱伝達）の放射収支を、面ごとにそのまま連立させる（出典：`docs/dynamic/RADIATION_NETWORK.md`、アプリ内 #manual「法則・単位・計算」）。

- 照射量：Gᵢ = Σⱼ Fᵢⱼ Jⱼ
- 射度：Jᵢ = εᵢσTᵢ⁴ + (1−εᵢ)Gᵢ（自己放出と反射の和）
- 正味出力：Qᵢ = Aᵢ Σⱼ Fᵢⱼ (Jᵢ − Jⱼ) = Aᵢ (Jᵢ − Gᵢ)（正は面からの正味流出）
- 温度発展：Cᵢ dTᵢ/dt = Pᵢ − Qᵢ

閉鎖系では相反関係 AᵢFᵢⱼ = AⱼFⱼᵢ により面間の交換が相殺し、全 Q の和は 0 になる。

## 4. 記号と単位

| 記号 | 意味 | 単位 |
|---|---|---|
| Tᵢ | 面 i の絶対温度（入力・表示の ℃ は 273.15 を加えて換算） | K |
| εᵢ | 放射率（0〜1） | — |
| Aᵢ | 面積 | m² |
| Cᵢ | 熱容量（一定） | J/K |
| Pᵢ | 一定の外部入力（正は加熱、負は冷却） | W |
| Fᵢⱼ | 形態係数：面 i から出た拡散放射が面 j へ届く割合（0〜1） | — |
| Jᵢ, Gᵢ | 射度、照射量 | W/m² |
| Qᵢ | 正味放射出力（外向き正） | W |
| σ | ステファン・ボルツマン定数 5.670374419×10⁻⁸ | W/(m²·K⁴) |
| T_max | 監視上限温度（既定 2000 K）。物性が有効な温度という意味ではない | K |

## 5. 初期条件

面ごとに正の絶対温度を与え、監視上限 T_max を超える初期温度は受理されない。外部入力 Pᵢ は時間に対して一定である。

## 6. 境界条件

このモデル自体が閉鎖系の収支であり、外部との境界は「閉じている」ことそのものである。各行の総和 ΣⱼFᵢⱼ = 1（開口なし）を要求し、開口・外部への放射漏れは扱わない。外部とのエネルギーの出入りは外部入力 Pᵢ（W、一定）のみ。対流・伝導との連成はこのモデルにはない（単一面の連成は「表面交換」の説明書、一般連成は未実装。項目12）。

## 7. 数値計算法

- 射度の線形連立方程式は、同温度近傍の桁落ちを避けるため、共通の黒体射出能 σT₁⁴ からの偏差の形で解く。T⁴ の差は (a−b)(a+b)(a²+b²) と因数分解して評価する。解法は行スケーリングつき部分ピボット選択の消去法で、残差が許容範囲（右辺ノルム比 1e-10）を超えれば受理しない（出典：`dynamic/radiation-network.mjs`）。
- 時間積分は Heun 法（2次）。刻みの上限は safeDt = 0.2 × minᵢ [Cᵢ / (4σAᵢT_max³)] で、予測・修正の両状態が正の絶対温度と監視上限を満たすことを確認してから状態を確定する（失敗時は状態を変更しない原子性）。
- 入力検証：F は 0〜1、各行の総和 1 との差 1e-12 以内、相反関係 AᵢFᵢⱼ = AⱼFⱼᵢ の相対差 1e-12 以内を要求し、違反は拒否する。閉じた完全反射面だけの独立部分系は射度が定まらないため、初期化時点で拒否する。

## 8. 計算過程

1. プリセット（内面を外面が完全に包む2面／等面積の2面（端部を無視）／等面積の3面閉鎖系）または面数 2〜12 の再構成から始め、面ごとの温度・ε・A・C・P と F 行列を入力する。
2. 「条件を適用して最初から」で初期化し、再生／1コマ／巻き戻し（最大500コマの履歴）で応答を確認する。比較は最大2条件（A/B）。

手計算による検算の例（出典：アプリ内 #manual「手計算・検算」、`docs/dynamic/RADIATION_BENCHMARKS_20261104.json`）：
- 等面積 1 m²、ε₁=0.8、ε₂=0.6、T₁=600 K、T₂=300 K なら、2面抵抗式 Q₁ = σ(600⁴−300⁴)/(1/0.8+1/0.6−1) ≈ 3594.5243 W、Q₂ = −Q₁。ベンチマーク記録の瞬間交換は 3594.5243056095646 W で、フェイリス側のスポットチェック（2026-11-07、先端 `c52f2a7`）でも数値核から 3594.524305609565 W を再現し、差は約 4.55e-13 W で記録と一致した。
- C₁=C₂=100 J/K なら初期の dT₁/dt ≈ −35.945243 K/s（瞬間の傾き。直線外挿はしない。項目13）。
- 学習コースの専用条件（等面積1 m²、ε=0.8/0.6、C₁=200/C₂=400 J/K、初期 200℃/20℃、P=0）では、20秒後の独立参照値は面1 = 126.8639445166℃、面2 = 56.5680277417℃、その時点の正味出力は約 ±407.819 W（出典：`docs/dynamic/RADIATION_LEARNING.md`、独立参照は SciPy DOP853）。

## 9. グラフの読み方

- 画面の図は接続の模式配置である。線の本数・面の位置・円の大きさは、エネルギー量・距離・面積を表さない（アプリ内 #manual と図の注記に明記）。数値は表の J・G・Q を正とする。
- 矢印は面間の AᵢFᵢⱼ(Jᵢ−Jⱼ) の符号と W の注記で読む。4面以上では注目面につながる矢印だけを表示する。
- 温度履歴グラフは実験Aが実線、比較Bが破線。時間バーや「戻る」操作は保存した前進解の再生であり、逆向きの放射計算ではない。
- Q が正ならその面から正味流出、負なら正味流入。診断には射度残差、放射出力の総和、外部入力と顕熱の収支が表示される。

## 10. 結果の解釈

- 外部入力 0 の閉鎖系では全体の顕熱 ΣCᵢ(Tᵢ−273.15) が保存し、最終温度は容量平均 ΣCᵢTᵢ(0)/ΣCᵢ に近づく。収支誤差（フェイリス側スポットチェックでは50コマ進行後も 7.3e-12 J）と温度の離散化誤差は別の量であり、混同しない。
- 検証の実測（出典：`docs/dynamic/RADIATION_NETWORK.md`、`docs/dynamic/RADIATION_BENCHMARKS_20261104.json`）：別実装の2面抵抗式 RK4 解との比較で、時間誤差の観測次数は約 2.00（内部刻み 0.04/0.02/0.01 s で温度誤差 約 0.00066374/0.00016540/0.00004129 K）。これは滑らかな2面例での次数であり、任意の行列・物性の万能精度を証明しない。
- 正本 §10.4 の検証リスト9項目（絶対温度の扱い、放射率の範囲、形態係数、相反関係、総和則、正味放射交換、エネルギー保存、温度差ゼロ条件、複数面の放射収支）は、実装済みモデルの範囲で全て実施済みである（出典：締め可能性監査 §5）。放射関連テストはフェイリス側検証記録 `radiation-closure-verification-20261107.md` 項目10で再計測され全件成功し、本パッケージでも先端 `c52f2a7` の全 Node スイート（1501件＝1496成功／0失敗／5スキップ）で回帰がないことを確認した。

## 11. モデルの仮定

- 各面は不透明・拡散灰色・等温。放射率・熱容量・外部入力は一定。
- 媒質は非参加（放射を吸収・散乱しない）。閉鎖系で開口はない。
- 形態係数は与えられるものであり、幾何から計算しない。プリセットと面数変更で作る F は理想閉鎖系の数学的な例である。

## 12. モデルの限界

- 入力 F が総和則・相反関係を満たしても、任意の実形状が存在する証明にはならない。実形状への適用は別途照合が必要（アプリ内 #manual「仮定・形態係数」にも明記）。
- 鏡面反射、波長依存性（非灰色）、気体放射（教科書 §10.5）は対象外で未実装。
- 面の位置関係から F を作る仕組みはこの画面にはない（幾何計算は長い凸ダクトのみ。監査の残作業 #2）。
- 伝導・対流との双方向の一般連成は未実装（監査の残作業 #4）。単一面の連成は表面交換モデルが担う。
- 内部温度分布は解かない。等温近似は内部熱抵抗が十分小さい場合などに限る。

## 13. よくある誤解

- **「放射で近づく温度は単純平均になる」** — 誤り。外部入力 0 の閉鎖系の最終温度は熱容量で重み付けした容量平均である。学習コースの例（200℃・200 J/K と 20℃・400 J/K）では単純平均 110℃ ではなく 80℃ へ近づく。
- **「低温の面は放射を出していない」** — 誤り。低温面も自己放出しており、矢印と Q は正味の交換を示す。
- **「矢印の向きは温度の高低だけで決まる」** — 誤り。射度 J には反射が含まれるため、各線の向きは温度だけでは決まらない。
- **「模式図の面を動かせば F が求まる」** — 誤り。図は接続の模式配置であり、F は入力値である。
- **「初期の温度変化の傾きで長時間を外挿できる」** — 誤り。傾きは瞬間の値で、T⁴ の非線形により変化する。
- **「完全反射面（ε=0）は温度が変わらない面として自由に置ける」** — 誤り。ε=0 の面自体は放射で温度を変えないが、閉じた完全反射面だけの部分系は射度が定まらず拒否される。
