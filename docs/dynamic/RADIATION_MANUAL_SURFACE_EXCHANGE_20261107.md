# モデル別説明書：表面交換（対流＋放射の同時境界）

- 日時：2026-11-07（Asia/Tokyo）
- 対象モデル：共有カーネル `dynamic/surface-exchange.mjs`（`surfaceExchange`）。接続先は矩形 FVM `dynamic/thermal.mjs` と径方向モデル `dynamic/radial.mjs` で、画面は伝導画面 `dynamic/index.html` と径方向画面 `dynamic/radial.html` の境界条件「対流＋放射」。基盤の詳細は `docs/dynamic/SURFACE_EXCHANGE.md`。
- 位置づけ：正本 §21.2 の16項目の説明書。放射分野では「単一面と周囲」のモデルに当たり、Phase 3 締め可能性監査（`phase3-closure-audit-20261107.md`、熱放射の残作業 #8・#11）を受けた整備である。宿主モデル自体の説明は、矩形 FVM・径方向の各説明書（非定常熱伝導の説明書群）を正とする。
- 読み分け：項目1〜2・9〜10・13 は初心者向け、それ以外は専門寄りの記述を含む。

## 1. 現象の概要

固体の 1 つの表面が、流体への対流と大きな黒い周囲への放射を同時に行う境界を計算する。対流と放射は別々の表面温度で評価して足すのではなく、共通の表面温度 Ts を 1 つ解いて両方を同時に満たす。流体温度 T∞ と放射周囲温度 Tr は別の値として与えるため、対流では加熱されながら放射では冷える、という同時発生も起こる。流体側や囲いの形態係数は解かない。

## 2. 現実世界での使用例

- 空気中で冷える板・球・円柱の表面温度と放熱量の見積り（対流だけ／放射だけでは足りない温度域の確認）。
- 電子機器の筐体や配管の表面が、自然対流と放射のどちらで主に冷えるかの内訳確認。
- 高温面で放射の寄与（Ts⁴）が対流に匹敵する条件の学習。
いずれも周囲が「大きな黒い囲い」とみなせる範囲の学習・概算のためであり、実設計の保証には使わない（項目12）。

## 3. 支配方程式

表面には熱容量も熱源も置かず、表面収支が各瞬間に釣り合う（出典：`docs/dynamic/SURFACE_EXCHANGE.md`）。

G (Tc − Ts) = hA (Ts − T∞) + εσA (Ts⁴ − Tr⁴)

- 左辺はセル中心温度 Tc から表面までの半セル伝導（コンダクタンス G。矩形 FVM では G = 2kA/dist、径方向では半セルの勾配抵抗 Δr/(2kA) を含む形）。
- 物体への流入は G (Ts − Tc)。対流と放射をセル温度へ別々に掛けて単純加算しない。
- 宿主側の支配方程式は各宿主のもの（熱伝導方程式は教科書 §2.1、過渡応答は第5章）。放射収支の考え方は教科書 §10.4（灰色体間の熱伝達）に基づく。

## 4. 記号と単位

| 記号 | 意味 | 単位 |
|---|---|---|
| Tc | 表面に接するセルの中心温度（絶対温度） | K |
| Ts | 共通表面温度（解く量） | K |
| G | セル中心から表面までの伝導コンダクタンス | W/K |
| A | 表面積 | m² |
| h | 熱伝達率（入力値。流れから予測しない） | W/(m²·K) |
| ε | 放射率（0〜1） | — |
| T∞ | 流体温度（絶対温度） | K |
| Tr | 大きな黒い放射周囲の温度（絶対温度。T∞ とは独立） | K |
| σ | ステファン・ボルツマン定数 5.670374419×10⁻⁸ | W/(m²·K⁴) |

## 5. 初期条件

カーネル自体は状態を持たない（Tc を与えるたびに Ts と各熱流を返す）。初期条件は宿主モデル側の初期温度場であり、初期化の時点でも面収支の診断が行われる（過大な h などは初期化時に拒否される。出典：`docs/dynamic/SURFACE_EXCHANGE.md`）。

## 6. 境界条件

このモデル自体が宿主の境界条件（型 `convection-radiation`）である。

- 流体温度と放射周囲温度は独立した入力（画面では流体は主たる境界温度、放射周囲は独立した ℃ 入力から K へ変換）。
- 特別な場合：h=0 は放射のみ、ε=0 は対流のみ、h=ε=0 は断熱に戻る。
- 拒否される組合せ（項目12）：自由輪郭の面、温度依存物性 k(T)/cp(T) との同時使用、フィン選択中の同時境界（分布対流へ放射を足す機能ではないため）。

## 7. 数値計算法

- 未知量は絶対温度 Ts ではなく偏差 δ = Ts − Tc とする。G が非常に大きい場合、物理的な δ が絶対温度の ULP 以下でも、G×δ として熱流を保持できるためである（丸めて Ts=Tc になったことだけを根拠に熱流 0 と扱わない）。
- 解法は保護つき Newton 法（残差の微分は −G − hA − 4εσATs³ < 0 で単調）。Newton 更新が正の温度の括り区間を出れば二分法に戻す。4乗差は εσA (Ts−Tr)(Ts+Tr)(Ts²+Tr²) と因数分解して近接温度の桁落ちを避ける（出典：`dynamic/surface-exchange.mjs`、`docs/dynamic/SURFACE_EXCHANGE.md`）。
- 収束条件：残差が各熱流項の最大値に対する 64 機械イプシロン以内。収束しなければエラーとして状態を更新しない。
- 宿主の陽的積分では、境界勾配の上限 |dq_in/dTc| ≤ G を従来の半セル伝導 G による刻み上限へ算入する。対流と放射の面を二つとして数えない。

## 8. 計算過程

1. 宿主モデル（板または球／円筒）で境界に「対流＋放射」を選び、流体温度・放射周囲温度・h・ε を指定する。
2. 各面の表面温度と対流／放射の内訳、合計の流入が診断に表示される（板は面ごとの集計と表面温度の最小／最大、球／円筒は外面の値）。

検算の例：
- カーネル単体（フェイリス側スポットチェック、2026-11-07、先端 `c52f2a7`）：Tc=500 K、G=100 W/K、A=1 m²、h=20 W/(m²·K)、T∞=300 K、ε=0.8、Tr=350 K に対して、JS カーネルは Ts = 455.99527258993413 K、流入 −4400.47 W（正味流出）、対流の外向き 3119.91 W、放射の外向き 1280.57 W を返し、独立な Python brentq 解と表面温度が全桁一致した。h=ε=0 では流入 0（断熱）に戻ることも確認した。
- 平板の定常（出典：`docs/dynamic/SURFACE_EXCHANGE.md`、`docs/dynamic/SURFACE_EXCHANGE_REFERENCE_20261105.json`）：左面 600 K、k=5 W/(m·K)、L=0.1 m、h=20、流体 300 K、放射周囲 350 K、ε=0.8 の定常表面温度は Ts = 487.4297292963 K。線形な連続定常解の体積平均との比較で、前進後の温度ドリフト < 1e-10 K、全表示熱流束の誤差 < 1e-8 W/m² を要求している。

## 9. グラフの読み方

- 画面表示は宿主側の温度場・断面表示に従う。本モデルの固有の読み取りは診断欄である：対流・放射の各寄与は外向き正、合計は物体への流入正と明記される。符号の向きを取り違えないこと。
- 瞬間出力 [W] と累積入力 [J] は別の量であり、混同しない。
- 表面温度 Ts はセル中心温度 Tc とは別に表示される（板では最小／最大、径方向では外面の値）。Ts と Tc の差が半セル伝導の効き具合を示す。

## 10. 結果の解釈

- 検証の実測（出典：`docs/dynamic/SURFACE_EXCHANGE.md`）：独立参照（Python/SciPy、絶対表面温度への Brent 法）との照合で、発熱する球／円筒の定常体積積分温度との RMS は 8/16/32 殻で球 0.0104005/0.00260315/0.000650978 K、円筒 0.01171875/0.00292969/0.000732422 K（約2次）。時間積分だけの検査（1制御体積の ODE を DOP853 で別積分）では、JS の前進 Euler の温度誤差は刻み 2/1/0.5/0.25 s で 0.860805/0.428490/0.213771/0.106767 K（約1次）。保存則誤差と離散化誤差を混同しない。
- 変物性との組合せの切り分け（出典：フェイリス側検証記録 `radiation-closure-verification-20261107.md` 項目5）：連成カーネルは温度依存コンダクタンスでも独立根と表面温度で最大 5.7e-14 K まで一致し、変物性を入れた有限体積の定常解は Kirchhoff 変換の厳密解（Ts = 498.4157 K、q = 6087.01 W/m²）へ空間2次（観測次数 1.99）で収束した。物理・離散化の水準で組合せに不整合は見つかっていない。一方で変物性の効きは大きく、一定物性（300 K 評価）との比較で定常表面温度に +33.6 K、全熱流束に +28.6% の差があるため、一定物性で代替できる大きさではない。

## 11. モデルの仮定

- 表面は熱容量・熱源を持たず、収支は瞬時に釣り合う。
- 放射周囲は大きな黒い囲い（形態係数 1、温度 Tr 一様）。有限の囲いの形態係数は扱わない。
- 流体温度は規定値で、流体側は解かない。h は入力値。
- 表面は灰色・拡散。宿主は一定物性（同時境界を使う場合）。（2026-11-07 追記：変物性との組合せは同日受理へ移行した。下記 §12 の追記を参照。）

## 12. モデルの限界

- 温度依存物性 k(T)/cp(T) と同時境界の組合せは、検証待ちとして生成時点で拒否される（`dynamic/thermal.mjs` のガード。フェイリス側スポットチェックでも先端 `c52f2a7` で再確認：kTable のみ・cpTable のみ・両表とも拒否、放射のみ／対流のみとの組合せは受理）。受理に必要な残条件は、ガードを外した JS 本体での直接回帰テスト、刻み上限への放射接線勾配 4εσTs³ の影響の実測、物性表範囲と表面温度の関係の明示であり、フェイリス側検証記録に列挙されている。本書の項目10の検証は独立実装同士の比較であり、JS 実装の組合せ経路を直接実行した検証ではない。
  **（2026-11-07 追記：受理済み）** 上記の残条件4件は同日に全て充足し、組合せは thermal.mjs の矩形FVM（自由輪郭なし）に限り受理へ移行した。JS 本体の定常は Kirchhoff 厳密解と表面温度 2.7e-10 K 以内・熱流束相対差 2e-12 以内で一致し、刻み上限は放射接線が半セル伝導の最大 90.7 倍の条件でも dt=safeDt で安定だった。受理範囲は表面温度も物性表の範囲内にある条件に限り、範囲外では刻みが外挿拒否で停止する。直接検証の過程で snapshot 診断のコンダクタンス不整合が見つかり修正済み。詳細と実測値は SURFACE_EXCHANGE.md の「変物性との組合せの受理（2026-11-07）」と tests/dynamic-surface-exchange-variable.test.mjs を参照。
- 自由輪郭（階段輪郭）では表面積・法線の検証が未了のため拒否される。矩形の外周面と輪郭でない内縁面が対象である。
- 有限囲いとの放射交換（形態係数つき）は放射ネットワーク／長い凸ダクトの担当であり、本カーネルは周囲を黒体とみなす。
- 三角形表面系（`dynamic/dev/triangle-surface-transient.mjs`）にも対流＋放射の表面境界があるが、一定物性のみ・物性表の入力自体がない別モデルであり、本書の対象外とする。

## 13. よくある誤解

- **「対流と放射は、セル温度で別々に計算して足せばよい」** — 誤り。両者は共通の表面温度 Ts を共有し、Ts は半セル伝導と釣り合うよう解かれる。単純加算とは結果が異なる。
- **「流体温度と放射周囲温度は同じもの」** — 誤り。独立した入力であり、対流加熱と放射冷却が同時に起きる条件も作れる。
- **「表面温度はセル温度と等しい」** — 誤り。Ts と Tc の間には半セルの伝導抵抗があり、診断では別々に表示される。
- **「変物性と使えないのは物理的におかしいから」** — 誤り。拒否は検証待ちの措置であり、独立検証では物理・離散化の不整合は見つかっていない（項目10・12）。受理には JS 本体側の直接検証が残っている。（2026-11-07 追記：その直接検証を含む残条件は全て充足し、矩形FVMに限り受理済み。§12 の追記を参照。）
- **「h が大きいほど表面温度は流体温度に近づくので、放射は無視できる」** — 誤り。放射の寄与は Ts⁴ で増え、h の大小とは独立に効く。内訳は診断で確認する。

- `supp-audit-radiation-same-delta-different-level` — 温度差が同じでも温度水準が違えば正味放射が変わること。
- `supp-advanced-ch10-calc` — 広い黒体周囲へ向いた灰色拡散面の正味放射。
- `supp-deep-rad-netflux-v1` — 大きな黒体囲いを完全に見込む灰色面の単位面積当たり正味放射流束。
