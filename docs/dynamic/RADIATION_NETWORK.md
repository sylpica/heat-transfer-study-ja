# 複数面の動的放射：実装範囲と検証

2026-11-04。一般的な放射収支から独自に記述。原書の文章・図・外部実装は複製していない。既存の静的20モードは維持し、`dynamic/radiation.html`を新しい動的実験として追加した。実公開サイトへの配備はしていない。

## 方程式とモデル

閉鎖系の2〜12面。不透明・拡散灰色・等温、各面の放射率ε・面積A・熱容量Cを一定とする。媒質は非参加。外部入力Pは一定のWで、正は加熱、負は冷却。内部温度分布・対流/伝導との連成・鏡面反射・気体放射・外部への開口・幾何からのF計算は対象外。

- Gᵢ=ΣFᵢⱼJⱼ、Jᵢ=εᵢσTᵢ⁴+(1−εᵢ)Gᵢを線形連立方程式として解く。
- Qᵢ=AᵢΣFᵢⱼ(Jᵢ−Jⱼ)、正は面からの正味流出。相反関係により面間の交換は相殺する。
- CᵢdTᵢ/dt=Pᵢ−Qᵢ。Heun法。予測状態と修正状態の正の絶対温度・監視上限を確認してから状態を変更する。
- 同温度近傍の桁落ちを避け、共通の黒体射出能からの射度差を解く。T⁴差は因数分解した式で計算する。
- 監視上限Tmaxから保守的な刻み0.2 min[C/(4σATmax³)]を設定。陽的更新の温度依存係数の上限に対する余裕であり、材料の適用温度を保証しない。
- 形態係数は0〜1、行の総和1（数値丸め1e−12）、相反関係（面積×Fの相対差1e−12）を要求。極小放射率等の悪条件・完全反射面だけの独立閉領域は連立計算を拒否する。入力を物理的に都合よく大きく正規化しない。

必要条件を満たす行列が、任意の実形状で実現可能という意味ではない。プリセットは内外2面（内面が全て外面を見る）、端部を無視した等面積2面、他の2面を等しく見る等面積3面という理想閉鎖系。面数を増やす操作は等配分の数学的な例を作る。実形状の自動推定と表示しない。熱容量一定・等温の仮定は実物へ適用する際に別途確認が必要。

## 検証と再現

`node --test tests/dynamic-radiation.test.mjs`：2面の独立した表面/空間抵抗式、凹な外面の自己形態係数、3黒体面の個別収支、完全反射面と分離した完全反射部分系、同温度/近接温度極限、熱容量で重み付けした最終温度、一定外部入力の熱収支、巻き戻し再現、範囲外/失敗時の原子性。

`node scripts/dynamic-radiation-benchmarks.mjs`：別に実装した2面抵抗式のRK4解（dt=0.0001 s）をHeun解と比較。記録は`RADIATION_BENCHMARKS_20261104.json`。600/300 K、ε=0.8/0.6、等面積1 m²の瞬間交換は3594.5243056095646 W。射度系との差は約4.55e−13 W。t=2 s、内部刻み0.04/0.02/0.01 sの温度誤差は約0.00066374/0.00016540/0.00004129 K、観測次数2.0046/2.0023。これはこの滑らかな2面例の時間次数であり、任意の行列/物性の万能精度を証明しない。全体系の顕熱は外部入力だけと比較し、放射を外部入力へ含めて保存誤差を見かけ上ゼロにしていない。

## 操作・表示・共通基盤

熱伝導と同じ`worker.mjs`/`actor.mjs`を利用し、CPU Float64で計算。Workerは`kind`で数値モデルを選択し、共通のinit/advance/restore/cancelとスナップショット形式を使う。途中の取消・失敗はadvance開始時点に戻す。比較は最大2条件、次のadvance前に両モデルを表示スナップショットへ復元し、片側だけ先へ進む状態を残さない。

図は接続の模式配置。矢印は面間のAᵢFᵢⱼ(Jᵢ−Jⱼ)の符号、注記はW。4面以上では注目面に関係する線のみを描く。位置・円の大きさ・線の本数を距離・面積・エネルギーの測定値として扱わない。全ての面の温度/J/G/Qは表でも読める。スマートフォンで文字を縮小しないよう、SVGとグラフの座標系を実表示幅へ合わせる。体験/自由/専門の3段階、明暗、再生/停止/1コマ/過去状態、500コマのメモリー履歴、共通色範囲、A/Bグラフがある。

ブラウザー試験は`node tests/dynamic-radiation-browser.mjs`。2面手計算、3/4面、比較、巻き戻し、F不整合、安定上限超過時の状態保持、Worker配信不能時の日本語案内、390/412/1280px、明暗、オフラインで再読込・Worker起動・新しい比較Workerを含む。Chromiumはブラウザーのオフライン状態、WebKitは従来と同じ配信サーバー停止の代替経路。実機Safari・Android・スクリーンリーダーは未実施。最新保存SHAのCIはPR #18で追跡し、過去コミットの成功を転用しない。
