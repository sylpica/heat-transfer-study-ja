# 開発専用：定常乱流平均流が運ぶ受動平均温度

## 計算する現象と省略

既存のCess基盤（CESS_MEAN_FLOW.md）の定常平均U(y)を用い、

∂T̄/∂t + U(y)∂T̄/∂x = ∂x(αeff∂xT̄) + ∂y(αeff∂yT̄)、αeff= k/(ρcp)+νt/Prt

を計算する。xは周期、上下y壁は断熱、全高さ2δ、一定物性、流れに影響しない受動温度。νtは代数式から既知の位置依存係数。Prtは利用者が仮定する一定値（開発入力0.5〜2、独立数値参照は1）で、測定済み物性値や普遍定数と呼ばない。

平均運動量の時間発展、瞬間乱流渦/温度変動、浮力/熱膨張、入口/出口、壁冷却/熱伝達率、一般形状/3D、圧縮性は対象外。定常平均せん断応力の確認は温度閉包の物理的検証を代用しない。

圧力の駆動は既知の一定dp/dxと周期的な速度/温度であり、周期全域で単一値の圧力場をPoissonで解いたとは説明しない。

**粘性/乱流の仕事を温度源へ戻さない。** 本モデルで省略した平均機械仕事の温度換算は−(dp/dx)Ub/(ρcp)=aUb/cp [K/s]、累積の目安はそれにtを掛ける。これは局所の散逸分布でも、加熱を含む温度解の誤差上界でもない。固定物性/受動温度近似を使えるか判断する補助値である。既知の局所発熱であるかのように一様源を追加しない。

## 数値法と受理条件

直交セルの有限体積。行速度はCessの行体積平均。x移流は風上、拡散は係数を各面で評価する2点流束。各面の寄与を等大逆向きに加え、固定エンタルピー基準からの温度差を運ぶ。一様場は厳密静止。y壁は面流束0。

陽Eulerの各セル流出率D=|Uj|/dx+2αrow/dx²+(隣接する内部y面αの和)/dy²よりsafeDt=0.8/max D。温度正値・初期最大原理・周期断熱の収支・時計・有限値を**更新受理前**に検査する。熱量基準273.15 Kの顕熱、初期平均から別に積分した収支、明示的な浮動小数点予算を返す。

復元はlaw/条件署名/配列/時計/最大原理/再計算した収支を検査してから受理。エラー時に受理状態を変えない。公開Workerへ登録せず、開発専用Worker/UIを後続で接続する。

## 別方法による検算

`scripts/dynamic-rans-temperature-reference.py` は第三者データ/ネットを使わない自作参照。xの第1Fourier成分とyの正規直交cosine-Galerkin、独立な変係数Gauss積分、行列指数で連続PDEを計算する。JS有限体積/Eulerは流用しない。初期T=300+cos(2πx/L)[1+0.25cos(2πy/H)] Kの**セル平均**を照合する。

64/96モードでは差1.61×10⁻⁴ K、512/768では高Reケースが1.35×10⁻⁷ Kとなり、事前の1×10⁻⁷ K条件に不合格だった。条件を緩めず768/1024モードへ精細化し、差は3条件で最大1.55×10⁻⁸ K。4096/5120積分点の精細化も別確認。参照はRANS_TEMPERATURE_REFERENCE_20261105.json。独自モデル出力のみで生DNSは入れない。

RANS_TEMPERATURE_BENCHMARKS_20261105.json：t=0.2 s、32×16→64×32→128×64、dt=0.1 safeDtで、連続PDEとの差RMSは最細で0.00879/0.02158/0.03360 K（実Reτ178/392/587）。最大差0.01405/0.03411/0.05277 K。同時格子/刻み精細化の次数0.889〜0.964で風上1次の影響を残す。純粋な空間次数や高精度な乱流熱予測とは呼ばない。

さらに**固定32×16格子**のFourier有限体積記号を独立に組み、行列指数へEulerを照合して時間誤差だけを検査。dt=0.5/0.25/0.125 safeDtでRMS=0.02443/0.01210/0.00604 K、次数1.014/1.002。この時間参照は連続PDE参照と明確に区別する。
