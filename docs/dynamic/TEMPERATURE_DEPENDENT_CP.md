# 温度依存比熱：エンタルピーで保存する更新

2026-11-04。密度一定、相変化なしの板の実験に、利用者が出典を確認したcp(T)表を手動で指定できる。実在材料の比熱曲線は捏造しない。プリセットの比熱は従来の20℃一定値を保持する。温度依存密度・熱膨張・潜熱・多相は対象外。温度依存物性付きのフィンは側面対流との独立検証待ちのため画面で拒否する。

## 数値処理

`dynamic/properties.mjs`のheatCapacityTableは、正の昇順表を区間線形補間し、比エンタルピーh(T)=∫cp(θ)dθ [J/kg]を区間ごとに厳密積分する。逆変換も単調な区間内の二次式から求める。熱容量が正なので一意。二次方程式の差の桁落ちを避ける式を使う。積分が非有限/識別不能な表、温度/エンタルピーの範囲外、悪条件な逆変換は停止する。

セル質量m=ρVを一定とし、面と熱源からの正味入力P [W]に対してm h(Tnew)=m h(Told)+Δt Pを更新する。cp(Told) ΔTで熱量を近似する方法ではない。伝導・境界の熱流評価は既存の前進Eulerの時刻で行うので、一般の時間精度は1次のまま。一様一定発熱のエンタルピー積分の正確さを、一般の高次時間精度と混同しない。

安定上限は表の最小cpと最大kから安全側に作る。k(T)とcp(T)は同時に指定可能。セル・材料表の状態を検査し、表の範囲外に出る壁面/表面も拒否する。物性の端点は8×Number.EPSILON×温度尺度以内の浮動小数点丸めだけを端点へ戻し、1e−7 Kの外挿は拒否する。物理的な範囲を拡張するものではない。

比熱表には表外の物性を推測しない。hのゼロは各比熱表の下端温度。一定比熱セルの既存のゼロは273.15 K。診断へ基準を明示し、異なる基準のエネルギー値そのものを比較しない。初期値との差−累積外部入力を保存誤差として監視する。内部面の熱量は等量逆符号で相殺する。

## 独立検算

`tests/dynamic-heat-capacity.test.mjs`、`tests/dynamic-properties.test.mjs`、`scripts/dynamic-heat-capacity-benchmarks.mjs`。保存値は`HEAT_CAPACITY_BENCHMARKS_20261104.json`。数学的なcp=2+0.01(T−300)を使い、実在材料の物性値として扱わない。

- 温度差θに対して、別に導出したΔh=2θ+0.005θ²を二次式として逆算する。300 K、一様発熱10 W/m³、ρ=1、t=2 sなら309.7617696340303 K。340 K、発熱−5 W/m³なら335.79652245103193 K。通常/1/4刻みで最大温度誤差約2e−12 K以下、熱量収支約5e−12 J以下。
- 初期300/340 Kの等質量2セルが断熱で平衡に達する温度は、平均hから320.9072203437452 K。初期温度の単純平均320 Kとは異なる。計算値との差約3.4e−13 K。
- 区間の上昇/下降/一定cpの積分と逆変換、一定cp表と従来の一定物性の温度/刻みの一致、k(T)と同時に指定したKirchhoff定常解、範囲外初期/壁面/更新/復元の原子性、巻き戻しの同じ前進結果を確認する。
