# 壁連成RK2の流体空間検証：実行前計画

2026-11-07 UTC、4abd8cb後。熱だけの空間検証では流れの精度を承認しない。有限Cwの履歴を固定温度ベンチマークへそのまま比較せず、同じ新RK2コアへ**明示的な理想温度制御壁**を追加して、既知のRa1000閉キャビティを検査する。既存cavity.mjs/固定壁データを変更しない。

## 追加する限定条件

wallModeはfinite-capacity（既定、現在と同じ）/isothermal-thermostat（温度制御）だけ。後者はWを初期指定値に保ち、外部制御入力を各段の実界面熱Qと同じにする。Pwallを同時に指定せず、非ゼロwallInputWを拒否する。壁の蓄熱0と外部制御入力−界面0を検査し、制御入力を一定率×時刻に置き換えない。署名で両モードを分け、旧有限Cwの数学を変更しない。

scalarSchemeに既定upwindとcentralを明示し、centralは全実面の|u|Δ/α≤2を候補段階/復元でも検査して超過拒否（係数のclip/自動切替なし）。upwindの流出率を用いる既存刻みはcentralにも保守的な上限。正方形の格子へ64を追加し、等温0/保持熱/上限/復元を再確認する。公開allowlist外・releaseApproved=false。

現在の時間/連続熱モードのv1は元結果として保持し、既定finite/upwindの数値が新コードで同一であることを新v2参照とNode/両実Workerで確認する。メタデータのsource hashだけを手で合わせず参照を再実行する。値が変わったら調査し、既定式を変えたのに同一と報告しない。

## Ra1000の事前ケースと基準

n16/32/64、幅高さ奥行1、ρcp1、ν.71/α1、Tc299.5/W300.5/流体初期300 K、gravityBeta710、β.001、全壁静止、central、圧力tol1e−12/multigrid・最大4000反復、温度制御壁。旧CFD_FINE_NATURAL（conservative2/central）と同じ連続問題。浮力基準Tcと旧300 Kとの差は一様な鉛直力で、投影圧力へ吸収される（速度/熱の差ではない）。段平均圧力を終点圧力へ比較しない。

各格子でsafeDtを使い、t .5/.75/1/1.5/2で保存。t≥1で直前サンプルからの全u/v/T最大変化<1e−8なら定常とみなす。未定常/未達は保存しexit1。Nuは高温壁Nu_0で1.117へ対応し、1.118（中央面/全体）へ読み替えない。出典は既存所有者CFDパック/DE_VAHL_DEFINITIONS/FINE_GRID記録（生表を新規配信しない）。

最細64の目標は旧事前6基準をそのまま使用：壁Nu絶対差<.002、局所Nu最大の差<.01、中心線u最大/v最大の差それぞれ<.02、位置差それぞれ<1/64+.0005。各格子の最大div<1e−9/s、流体/壁/全体収支が丸め予算内、温度制御壁Wはexact固定・累積外部壁入力と界面積算がexact一致。格子差/次数は実測し、精度基準を件数や残差だけで達成扱いにしない。

この検証は同じ流体離散化の固定壁ケースに限る。一般形状/物体/高Ra/3D/温度依存/実機/公開・一般固体共役の承認ではない。数値検証後に実空気preset/限定GUIへ進む。root単独・逐次。
