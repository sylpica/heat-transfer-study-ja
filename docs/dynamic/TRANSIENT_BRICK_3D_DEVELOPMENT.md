# 3次元直方体 非定常熱伝導ソルバー（開発文書）

2026-11-07（Asia/Tokyo）。対象 `dynamic/dev/transient-brick-3d.mjs`。公開allowlist外、releaseApproved=false。フェイリス側の並行実装であり、Codex本線（`codex/dynamic-heat-simulation`）の成果物ではない。Phase 4 で未着手だった3次元非定常熱伝導を、軸平行な直方体・一定物性・均一初期温度の範囲で新規実装した。GUI・Worker接続・公開候補化は今回の範囲外で、数値コア＋独立検証＋本文書まで。

## 設計

- 法則識別子 `transient-brick-3d-fvm-v1`。生成関数 `createTransientBrick3d(config)` が `{step, snapshot, restore, safeDt, time, grid, config}` を返す形は既存モデル（`dynamic/thermal.mjs` の2次元矩形FVMほか）の流儀に合わせた。
- 離散化：セル中心有限体積法。各軸一様格子（軸ごとにセル幅は一定、軸間では異なる幅を許す）。未知量はセル平均温度。内部面のコンダクタンスは中心間距離に対する `kA/d`。
- 境界条件は面ごと（`xMin/xMax/yMin/yMax/zMin/zMax`）に、2次元モデルと同種の4種：`temperature`（温度指定。境界節点を面上に置く半セル抵抗 `2kA/d`）、`flux`（内向き熱流束、温度に依存しない）、`convection`（対流。半セル伝導と膜抵抗の直列 `A/(d/(2k)+1/h)`、h=0 は断熱として扱う）、`insulated`（断熱、既定）。放射・対流＋放射の同時境界は対象外。
- 時間積分：陽解法（前進オイラー）。安定条件は離散系の上限 `dt ≤ min_i C_i/ΣG_i`（内部面と温度・対流面のコンダクタンスを含む。流束面は温度に依存しないため含めない）を構築時に計算し、安全率0.8を掛けた値を `safeDt` として返す（既存モデルの流儀）。`step(dt)` はこれを超える刻みを理由つきで拒否する。伝導する相手が一切ない単一セル断熱の場合のみ `safeDt` は無限大（スナップショットでは null）になる。
- エネルギー収支：内部エネルギーは273.15 K基準の顕熱、境界からの累積入熱 `netInput` は補償付き加算で蓄積し、`energyError`（内部エネルギー変化 − 累積入熱）と相対値をスナップショットに返す。
- 入力検証：寸法・物性・初期温度・境界値の不正、未知キー、未対応の境界種別は日本語の理由を表示して拒否する。格子上限は各軸64セル・合計32768セルで、これを超える条件（計算量過大）は拒否する。
- セル番号は `i + nx*(j + ny*k)`（x最速）。

## 独立検証（参照：`docs/dynamic/TRANSIENT_BRICK_3D_REFERENCE_20261107.json`、生成器 `scripts/dynamic-transient-brick-3d-reference.py`、生成器のSHA-256をテストで固定）

### 全面温度指定の過渡解（積解との照合）
全面が同一温度・初期温度一様の直方体では、厳密解は3方向の1次元平板級数の積になる。各方向のセル平均を mpmath 50桁で評価し、セル平均の積として参照値を構成した。

- 立方体（0.1 m、α=1e-5 m²/s、初期300 K・壁350 K、t=100 s）、dt=safeDt/4 で空間誤差を分離して測定：RMS誤差 4³=0.4916 K、8³=0.1176 K、16³=0.0291 K。収束次数 2.06 / 2.02 で2次を確認した。なお dt=safeDt では時間誤差と空間誤差が部分的に打ち消し合い、RMS は 0.1055 / 0.0289 / 0.00737 K と小さく出る（見かけの改善であり、次数測定には用いない）。
- 非立方体（0.12×0.08×0.05 m、α=6e-5 m²/s、t=5 s）：RMS 12×8×5=0.5010 K → 24×16×10=0.1234 K（比4.06、次数2.02）、最大誤差 1.112 → 0.276 K。誤差は Fourier 数が小さい方向の浸透初期の急勾配に集中する。

### エネルギー収支（非対称ケース）
- 一面流束・全面他断熱（q″=5000 W/m²、60 s）：平均温度の実測が解析値 303.0303… K と一致し、`netInput` も q″·A·t と一致、相対エネルギー誤差 3.9e-16。
- 一面流束＋対向面対流（h=50 W/(m²K)、流体290 K、60 s）：温度場 299.905〜307.547 K、エネルギー誤差 −2.7e-12 J（相対 2.1e-16）。内部エネルギー変化＝境界積算熱量が丸め誤差級で成立する。

### 2次元モデルとの整合
厚さ方向（z）の両面断熱・z一様条件では場は z 一様に保たれ、同一条件の2次元矩形FVM（`createThermal`、奥行き＝厚さ）と比較して、300ステップ後の全セルの差と z 方向のばらつきはいずれも 0（ビット一致）だった。

### 定常極限
面ごとに異なる温度指定（400/300/360/310/340/320 K）の立方体で2段照合した。

- 離散定常：時間発展の到達先が、同一離散系を numpy で直接解いた独立解（6×5×4、求解残差 1.0e-11）と最大 6.8e-13 K で一致した。
- 連続定常：6面の単位解の重ね合わせ（2重Fourier級数、解析セル平均、打ち切り401項/201項の差を tail として記録）と比較し、RMS誤差 8³=0.7335 K、16³=0.3736 K（内部のみ 0.3189 → 0.1417 K）。級数側の tail RMS（0.013 / 0.026 K）は離散化誤差より1桁小さく、測定の律速ではない。この問題では面温度が12本の稜で跳ぶため、連続解に稜特異性があり、RMSの収束は約1次に落ちる（滑らかな過渡場で2次が出ることとは矛盾しない。特異性に支配される誤差であることの切り分けとして、到達先そのものは上記の離散直接解と一致している）。級数の組立自体は「6面すべて1の単位解の和＝1」の恒等式で確認し、最大偏差 3.0e-4（打ち切り誤差の範囲）だった。

### 単一セルの対流
1セル・両面対流では、陽解法の離散増幅率 `(1 − dt·ΣG/C)` を解析的に再現し、50ステップ後の温度が厳密に一致した（差0）。半セル＋膜の直列抵抗が設計どおり入っていることの確認を兼ねる。

### 全体
- 新規Nodeテスト 12件すべて合格。内容は上記の照合に加え、入力拒否（寸法・格子上限32768セル・未知キー・刻み超過ほか）と snapshot/restore の往復。
- 全Nodeスイート：本ブランチでの実測値を STATUS 追記に記録する（回帰なしを確認してからコミットする）。
