## 操作項目

- プリセット3種（非対称の混合境界／全面温度指定の立方体／一面流束＋対向面対流。選ぶと自動適用）
- 条件：寸法 x/y/z [mm]、分割数 nx/ny/nz、k・ρ・cp、初期温度 [K]
- 境界条件：6面それぞれに種別（断熱／温度指定／熱流束（内向き）／対流）と、種別に応じたパラメーターだけを表示（温度／熱流束／h／流体温度）
- 時間操作：1コマの物理時間、再生／一時停止／1コマ進める／1コマ戻す／時刻0へ戻す（核の restore によるスナップショット復元、履歴最大1200コマ）。1コマは safeDt 以下に自動分割
- 表示：断面の向き（xy／xz／yz）と位置（層スライダー）による温度分布、測定セル（列・行スライダー、断面図のクリックでも選択）、測定セルの (i, j, l)・中心座標・温度、全体の平均・最小・最大
- 診断（折りたたみ）：法則識別子、格子と総セル数、セル体積、safeDt、ステップ数、内部エネルギーと変化、累積入熱、収支誤差（絶対・相対）、直近の境界入熱率、仮定の一覧
- 理論・仮定・適用限界は画面下部に集約（常設UI/UXチェックリスト準拠）

## 画面値と核の一致確認（Chromium 実ブラウザー）

- 既定プリセット（非対称、12×10×8）で1コマ（5 s）進め、同一条件・同一刻み手順で Node 側の核を計算して照合：測定セル（i=1, j=10, l=5 表示）温度、全体の平均・最小・最大のいずれも**表示桁（小数4桁）まで一致**
- 全面温度指定の立方体プリセット（8³、初期300 K・壁350 K）で 25 s × 4コマ＝ t=100 s まで進め、中心セル（4,4,4）の画面値 **344.9804 K** が核と表示桁まで一致し、独立参照（1次元級数の積、TRANSIENT_BRICK_3D_REFERENCE_20261107.json の 8³ 格子）の中心値とも 0.1 K 以内で一致（同条件の核の RMS は dt=safeDt で 0.0289 K、開発文書に記録）
- 復元：1コマ戻すで 75.000 s へ正確に復帰、時刻0へ戻すで一様な初期場（300.0000 K）に復帰
- 拒否は核の文言をそのまま表示：格子合計の上限超過（33×32×32）で「直方体の格子は各軸1〜64、合計32768セル以下です。」、境界温度 0 K で「境界の絶対温度[K]が数値範囲外です。」。いずれも受理済みの表示・時刻は不変

## 設定層の Node テスト（6件）

- 入力ビルダー：mm→m 変換、面ごとに許されるキーだけを渡すこと（余分なキーは核が拒否するため）、核がそのまま受理すること
- 全プリセットが核に受理され releaseApproved=false を保つこと
- 核の拒否理由がビルダーを通しても変わらないこと（セル上限・境界温度・寸法）
- 断面抽出：非対称場で3断面×全層の全セルが核の直接インデックスと一致、行方向の向き（行0＝最大座標側）、範囲外の層指定はクランプ
- 立方体プリセットを画面と同じ刻み手順で t=100 s まで進め、独立参照との RMS < 0.05 K、相対エネルギー誤差 < 1e-12
- ポインター当たり判定：描画領域の四隅・中心が正しいセルへ対応し、余白は null
