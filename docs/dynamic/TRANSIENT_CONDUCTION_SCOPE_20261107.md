- 対象ブランチ：`codex/dynamic-heat-simulation`（起点 `7968146`）
- 位置づけ：Phase 3 締め可能性監査（`phase3-closure-audit-20261107.md`、非定常熱伝導の残作業 #3・#11）を受けた範囲確定記録。正本は `codex-dynamic-simulation-prompt-20261104.md`（以下「正本」）。本記録は範囲を広げるものではなく、正本 §6 の要求範囲のうち本分野（Phase 3 の非定常熱伝導）として扱うものと扱わないものを確定する。

## 項目別の詳細

### 1・2. 三角形系の変物性・複合材料

- 現状：三角形系（`dynamic/dev/triangle-*.mjs`）は一定物性・単一材料のみ。モデル自身が `constantProperties:true` を申告し、`releaseApproved:false` の開発専用である。
- 確定理由：
  - 正本 §6.1 の対象現象「複合材料」および §6.2 の温度依存物性への拡張は、分野としては矩形 FVM が既に担い、独立検証（Kirchhoff 定常解、複合壁の直列抵抗解、材料界面の熱流束整合性）まで記録済みである。分野の充足判定は「対象現象に検証済みモデルが存在するか」で行うものであり、全モデルへの横展開は要求されていない。
  - 三角形系への拡張は、Kirchhoff 変換が多角形 P1 離散化で保存性を保つか、界面での熱流束整合性をどう定義するか等、独立した検証課題を新規に生む。Phase 3 の締めにおいては実施しない。
- 帰結：三角形系は「一定物性・単一材料・凸形状」の開発モデルとして範囲を確定する。公開無効化（`releaseApproved:false`）は維持する。この確定により、監査の残作業 #3 は「文書による確定」で閉じる（実装は行わない）。

### 3. 円筒の端面効果・軸方向変化

- 現状：径方向モデルは中実円筒／球の半径対称1Dのみ（単一材料・一定物性）。端面・軸方向の扱いはモデルに存在しない。
- 確定理由：
  - モデルの支配方程式は r^(d−1) 形の径方向1項のみであり（`docs/dynamic/RADIAL_CONDUCTION.md`）、端面効果はこの方程式の範囲外である。端面効果を入れることは「径方向モデルの拡張」ではなく「2D軸対称モデルの新設」であり、§6 のモデル構成（1D径方向＋2D矩形）には含まれない。
  - 実務上の代替は既に存在する：有限長物体の断面温度分布は矩形 FVM の2Dモデルで扱える（対称性は異なるため円筒端部の代替ではないが、2D 非定常伝導としての学習対象はカバーされる）。この区別は説明側で誤認させないことが条件であり、径方向モデルの「端面なし・無限長相当」という仮定は既存文書に明記済みである。
- 帰結：監査の残作業 #11 のうち本項目は「範囲からの除外を明記」で閉じる。中空・複合の径方向モデル（監査の残作業 #1／順序5）は本確定の対象ではなく、別途の実装課題として残る。

### 4. 流体連成

- 現状：本分野の境界条件として、規定温度の流体に対する対流、大きな黒い周囲への放射、その同時境界（共通表面温度を解く `surface-exchange.mjs`）が実装・検証済み。同時境界は「流体側を解く連成」ではなく、規定された受け側温度に対する表面収支である（モジュール冒頭の明記どおり、流体 CFD や有限囲いの形態係数は推論しない）。
- 確定理由：
  - 正本 §11 は連成を独立節とし、計算順序・時間積分・反復収束条件の確認と独立検証を求めている。これは Phase 3 の非定常熱伝導の完了条件には含まれない（要件表でも連成は Q11 として独立）。
  - 共役流路（固体‐流体の共役温度）のような連成モデルは既に別モデルとして開発されており、本分野の伝導モデルの拡張として数えない。
- 帰結：本分野では「流体は規定温度の境界条件としてのみ現れる」ことを確定する。流体側を解く連成の要否判断は §11／Phase 4 側の課題であり、本分野の充足判定には影響させない。
