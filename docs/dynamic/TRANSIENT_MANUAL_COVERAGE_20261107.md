## モデルごとの要旨と残存不足

### 矩形 FVM（`dynamic/thermal.mjs`、画面 `dynamic/index.html`）

- 16項目すべてに充足場所が存在する。#manual が使い方・方程式・境界・検算・適用範囲を担い、本パッケージで使用例・誤解・グラフの読み方・参考文献を独立項目として補った。
- 残存不足：なし（項目15は、対応表に基づく主掲載70件の代表12件と複合材料（多層・界面）の主掲載31件全件の反映により解消。下記参照）。

### 径方向（`dynamic/radial.mjs`／`dynamic/lumped-radial.mjs`、画面 `dynamic/radial.html`）

- 16項目すべてに充足場所が存在する。#manual が式・記号単位・検算例・適用範囲まで含み、本パッケージで使用例・誤解（Bi の2定義、殻平均と点温度の区別など）・参考文献を補った。
- 残存不足：項目15は対応表を反映したが、円柱・球の分布系を直接扱う主掲載が3件のみで専用問題が少ない（部）。基礎は矩形 FVM と共通である旨を説明書に明記した。

### 三角形系（`dynamic/dev/triangle-*.mjs`、開発 GUI）

- 本パッケージで説明書を新設し、16項目すべてに文書上の充足場所を作った。従来は開発文書（数値検証の記録）しかなく、利用者向け説明書は存在しなかった。
- 残存不足（正直な申告）：
  - 項目14：開発専用モデルのため公開画面からの導線がなく、関連教材は教科書の節番号の対応付けに留まる。項目15：対応表の棚卸しでも本モデルに対応する問題は存在しないことが確定し、説明書にその旨と近接参照を明記した（部：問題自体が存在しないため）。
  - 説明書の置き場所：正本 §21 は「アプリ内に用意」を求めるが、三角形系は未公開（`releaseApproved:false`）のため、本説明書は `docs/dynamic/` の文書としての整備である。アプリ内への収録は、公開可否の判断と統合フェーズの課題として残る（矩形・径方向についても、本パッケージの補完分は docs 側にあり、アプリ内 #manual への反映は統合フェーズの課題である）。

### 項目15（関連問題）の反映（統合フェーズで更新）

問題データ側の棚卸し（対応表 `docs/dynamic/MODEL_PROBLEM_MAP_20261107.md`、問題バンク751問・主掲載232件、全IDを実在照合済み）が作成され、本点検の対象3モデルの説明書の項目15に反映した。矩形 FVM は主掲載70件から代表12件と、複合材料（多層・界面）の主掲載31件全件を記載して充足した。径方向は主掲載3件全件を記載したが、専用問題自体が少なく部に留まる。三角形系は対応する問題が存在しないことが棚卸しで確定し、説明書に「対応する問題はない」と近接参照を明記した（部：問題の不在によるもので、記載の不足ではない）。
