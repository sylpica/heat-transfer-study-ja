# モデル別説明書：径方向熱伝導（円筒・球）

- 日時：2026-11-07（Asia/Tokyo）
- 対象モデル：分布モデル `dynamic/radial.mjs` と集中熱容量近似 `dynamic/lumped-radial.mjs`。画面は `dynamic/radial.html`（円筒と球の熱伝導実験）。数値コアの詳細は `docs/dynamic/RADIAL_CONDUCTION.md`。
- 位置づけ：正本 §21.2 がモデルごとに求める16項目の説明書。アプリ内の既存説明（`dynamic/radial.html` の #manual「使い方と理論」）を正として参照し、独立項目として不足していた現実世界での使用例・よくある誤解・グラフの読み方・参考文献を本書で補う。数値・式の出典は各項に併記する。
- 読み分け：項目1〜2・9〜10・13 は初心者向け、それ以外は専門寄りの記述を含む。

## 1. 現象の概要

中実の円筒・球の内部で、温度が半径方向にだけ変化しながら時間とともに伝わっていく現象を計算する。温度が半径方向に分布する「分布モデル」と、内部が一様温度とみなす「集中熱容量近似」の2つのモデルがあり、近似の適用条件を満たす場合だけ後者を明示的に選べる。円筒は長さ方向に一様で端面は断熱という仮定のもとで、半径方向1Dとして扱う。

## 2. 現実世界での使用例

- 金属球の焼入れ・冷却で、中心部が表面にどれだけ遅れて冷えるか。
- 球状の食品・薬品の加熱や冷却で、中心が目標温度に達する時間の見積り。
- 円柱状のシャフトや丸棒が、表面の温度変化に対して内部まで応答する時間の見通し。
- 蓄熱用の球・円柱材料の充放熱の応答確認。
いずれも対称性と一定物性の仮定が成り立つ範囲の学習・概算のためであり、実設計の保証には使わない（項目12）。

## 3. 支配方程式

分布モデル（`docs/dynamic/RADIAL_CONDUCTION.md`）：

ρcp ∂T/∂t = k · r^(1−d) · ∂[r^(d−1) ∂T/∂r]/∂r + q‴　（円筒 d=2、球 d=3）

中心では対称条件 ∂T/∂r = 0。実装は 1/r を直接計算せず、各殻の積分保存則で組み立てる。

集中熱容量近似（一定 h の対流・発熱なしの場合）：

T = T∞ + (T0 − T∞) · exp(−hAt / (ρcpV))

## 4. 記号と単位

| 記号 | 意味 | 単位 |
|---|---|---|
| T | 温度（内部計算は絶対温度、表示は ℃） | K |
| r, R | 半径方向座標、物体の半径 | m |
| L | 円筒の長さ | m |
| A(r) | 半径 r の伝熱面積（円筒 2πrL、球 4πr²） | m² |
| k, ρ, cp | 熱伝導率、密度、比熱（一定物性） | W/(m·K), kg/m³, J/(kg·K) |
| q‴ | 一様な体積発熱密度 | W/m³ |
| h | 熱伝達率（入力値。流れから予測しない） | W/(m²·K) |
| ε, σ | 放射率、ステファン・ボルツマン定数 5.670374419×10⁻⁸ W/(m²·K⁴) | — |
| α = k/(ρcp) | 熱拡散率 | m²/s |
| Fo = αt/R² | フーリエ数 | — |
| Lc = V/A | 集中近似の代表長さ（球 R/3、円筒側面のみ R/2） | m |
| Bi | ビオ数。集中近似の判定は Bi = hLc/k、半径基準の表示は Bi = hR/k で、両者は別物（項目13） | — |

## 5. 初期条件

一様な初期絶対温度を与える。分布モデルの温度値は各殻の平均の代表値であり、中心 r=0 の点温度ではない（項目9・13）。

## 6. 境界条件

- 中心（r=0）：面積ゼロの対称条件（熱流ゼロ）。架空セルや r=0 での除算は使わない。
- 外表面：温度固定、断熱、内向き熱流束、指定 h の対流、大きな黒い周囲への放射、対流＋放射の同時境界（共通表面温度を解く。矩形 FVM の説明書項目6と同じ仕組み）。表面までの半セルの勾配抵抗 Δr/(2kA) を含み、対流では 1/(hA) と直列にする。放射では表面温度を二分法で求める（`docs/dynamic/RADIAL_CONDUCTION.md`）。
- 円筒の端面：断熱（モデルの定義そのもの）。

## 7. 数値計算法

- 殻（同心の層）ごとの保存型有限体積法。殻体積は円筒 πL(r₊²−r₋²)、球 4π(r₊³−r₋³)/3、内部面の熱量は Gᵢ(Tᵢ₊₁−Tᵢ)（Gᵢ = kA(r面)/Δr）として両隣へ等量・逆符号で計上する。
- 時間積分は前進 Euler で、Δt ≤ 0.8 × min(Cᵢ/ΣGᵢ)。
- 集中近似は指数式そのものを評価し、PDE を粗い1セルで解く方法ではない。格子・内部刻みは使わない。

## 8. 計算過程

1. 形状（球／円筒）・半径・材料・初期温度・外表面の境界を選んで適用する。
2. 殻の数と刻みで時間を進め、断面表示・断面グラフ・履歴で応答を確認する。
3. 集中近似を使う場合は、先に Bi = h(V/A)/k ≤ 0.1 を満たすかを確認する（満たさなければ選択自体が拒否される）。

手計算による検算の例（出典：`dynamic/radial.html` #manual「数値例と検算」、`docs/dynamic/RADIAL_CONDUCTION.md`）：
- 一様な断熱発熱なら全殻で ΔT = q‴t/(ρcp)。発熱なし・断熱なら温度は不変。
- 一定表面温度の発熱定常解は、球 T(r) = T面 + q‴(R²−r²)/(6k)、円筒 T(r) = T面 + q‴(R²−r²)/(4k)。
- R = 0.01 m、k = 10 W/(m·K)、ρ = 1000 kg/m³、cp = 1000 J/(kg·K) なら α = 10⁻⁵ m²/s で、t = 1 s のフーリエ数は Fo = αt/R² = 0.1。

## 9. グラフの読み方

- 画面の断面図は、半径方向1Dの計算値を円の断面へ配置した表示である。2D/3Dの温度場を解いた結果ではない（アプリ内 #manual「はじめに」に明記）。
- 断面グラフの線は殻中心の代表値と実際の外表面温度を結ぶ補助表示で、中心 r=0 の点温度は推測していない（`dynamic/radial.html` の断面表示の説明）。
- 測定値は「殻平均の代表値」であり、点温度の厳密値ではない。外表面温度は別に表示される。
- 集中近似の画面で内部が一様色・断面が水平なのは、近似の仮定そのものの表示である。内部の熱流を計算した矢印は描かれない。

## 10. 結果の解釈

- 収支誤差（ベンチマークでは概ね 10⁻¹² J 以下）と温度の離散化誤差は別の量であり、混同しない（`docs/dynamic/RADIAL_CONDUCTION.md`）。
- 検証の実測（出典：同文書のベンチマーク表。連続の固有関数級数を各殻体積で積分した独立参照との比較）：
  - 温度固定：体積重み付き殻平均 RMS は 16殻 0.044231 K → 32殻 0.011280 K → 64殻 0.002849 K（球、次数 1.97→1.99）、円筒は 0.037096 → 0.009277 → 0.002321 K（約2.00）。
  - 対流：球 0.004126 → 0.001031 → 0.000258 K、円筒 0.010641 → 0.002648 → 0.000661 K（約2次）。時間だけを細分化した収束は約1次。
  - 定常解への漸近では、球（表面等温）の測定減衰率 0.004848 /s が連続第1固有値 απ²/R² = 0.004935 /s と比 0.982 で一致（フェイリス側検証記録 `TRANSIENT_CLOSURE_VERIFICATION_20261107.md`、ブランチ `feiris/transient-closure-notes`）。
- 集中近似の誤差はゼロではない。独立した連続 PDE の体積平均との標本比較では、初期温度差の最大約 2.12% が残った（初期差 50 K なら約 1.06 K の例。アプリ内 #manual「軽量な集中熱容量近似」）。分布モデルの格子誤差と、集中近似のモデル誤差を区別すること。

## 11. モデルの仮定

- 半径対称（角度方向・軸方向の変化なし）。円筒の端面は断熱。
- 単一材料・一定物性。相変化は扱わない。
- 熱伝達率 h は入力値で、風速・浮力・流速場から計算しない。放射は灰色面と大きな黒い周囲（形態係数1）のモデル。
- 集中近似は内部一様温度を仮定し、一定 h の対流・発熱なし・一様初期温度の場合に限る。

## 12. モデルの限界

- 中空の円筒・球、複合（多層）材料、温度依存物性は扱わない（径方向の複合・中空は監査の残作業 #1／順序5として別途の実装課題に残る。範囲確定記録 `TRANSIENT_CONDUCTION_SCOPE_20261107.md` 参照）。
- 円筒の端面効果・軸方向変化は対象外として確定している（同記録）。
- 流体側を解く連成は扱わない（境界は規定温度に対する表面収支のみ）。
- 20℃の物性参考値を他の温度でも実物性として保証するものではない。無条件に工学設計へ使わない。

## 13. よくある誤解

- **「表示された殻の温度が、その半径の点温度」** — 誤り。殻平均の代表値であり、特に中心の点温度は表示から推測できない。
- **「Bi の定義は1つだけ」** — 誤り。集中近似の判定に使う Bi = h(V/A)/k と、半径基準の Bi = hR/k は別で、球では前者は後者の 1/3、円筒側面では 1/2 になる（アプリ内 #manual「数値例と検算」）。
- **「集中近似で内部一様に描かれるのは計算結果」** — 誤り。一様性は近似の仮定であり、誤差は項目10のとおり残る。
- **「円筒の長さを変えると半径方向の温度分布も変わる」** — 誤り（端面断熱の範囲）。長さは全熱量には影響するが、半径方向の変化は変えない（アプリ内 #manual「はじめに」）。
- **「同じ半径の球と円筒は同じ速さで冷える」** — 誤り。外面積/体積は球が 3/R、円筒の側面が 2/R と異なり、学習実験でもこの違いを観察する。ただし表面温度固定では内部に分布があるため、この比をそのまま集中近似の時定数へ置き換えることもできない。
