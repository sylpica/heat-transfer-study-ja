# モデル別説明書：矩形 FVM 非定常熱伝導（2D 平板・自由輪郭）

- 日時：2026-11-07（Asia/Tokyo）
- 対象モデル：`dynamic/thermal.mjs`（セル中心有限体積法）。画面は `dynamic/index.html`（平板・フィンの実験、`dynamic/lab.mjs`）。
- 位置づけ：正本 §21.2 がモデルごとに求める16項目の説明書。アプリ内の既存説明（`dynamic/index.html` の #manual「使い方と理論」）を正として参照し、#manual に独立項目として存在しない項目（現実世界での使用例、よくある誤解、グラフの読み方、参考文献）を本書で補う。数値・式の出典は各項に併記する。
- 読み分け：項目1〜2・9〜10・13 は初心者向け、それ以外は専門寄りの記述を含む。

## 1. 現象の概要

固体内部を熱が伝わり、場所ごとの温度が時間とともに変わっていく現象（非定常熱伝導）を、平板および2D断面で計算するモデルである。加熱・冷却の進行、複合材料（多層・界面の接触熱抵抗）、内部発熱、表面での対流・放射による放熱を扱う。温度分布の時間変化そのものを見ることが目的で、流体の流れは解かない。

## 2. 現実世界での使用例

- 熱処理（焼入れ・焼戻し）中の鋼板が内部までどの速さで冷えるかの見通し。
- 電子回路基板や筐体の一部が、発熱部品の影響でどこまで温度上昇するか。
- 断熱材を含む複合壁（壁＋断熱層）が、外気温の変化に対して室内側へどれだけ遅れて応答するか。
- 食品や成形品の加熱・冷却で、中心部が目標温度に達するまでの時間の見積り。
いずれも一次元の見通しや2D断面の学習・概算のためであり、実設計の保証には使わない（項目12）。

## 3. 支配方程式

一定物性・等方性の場合の熱伝導方程式（教科書 §2.1）：

ρcp ∂T/∂t = ∇·(k∇T) + q‴

物性が温度に依存する場合は k(T)・cp(T) を手動表で与え、∇·(k(T)∇T) の形を離散化する。k(T) の定常解は Kirchhoff 変換による連続解と照合して検証している（`docs/dynamic/TEMPERATURE_DEPENDENT_CP.md`、本書の項目10）。

## 4. 記号と単位

| 記号 | 意味 | 単位 |
|---|---|---|
| T | 温度（内部計算は絶対温度、表示は ℃） | K |
| x, y | 位置（幅・高さ方向） | m |
| z | 奥行き（2D断面の厚さとして一様） | m |
| k | 熱伝導率（k(T) 表を指定可能） | W/(m·K) |
| ρ | 密度（一定） | kg/m³ |
| cp | 比熱（cp(T) 表を指定可能） | J/(kg·K) |
| q‴ | 体積発熱密度（負は一様冷却） | W/m³ |
| h | 熱伝達率（入力値。流れから予測しない） | W/(m²·K) |
| ε | 放射率（0〜1） | — |
| σ | ステファン・ボルツマン定数 5.670374419×10⁻⁸ | W/(m²·K⁴) |
| R | 材料界面の接触熱抵抗 | m²·K/W |
| α = k/(ρcp) | 熱拡散率 | m²/s |
| Fo = αt/L² | フーリエ数（代表長さ L に対する無次元時間） | — |

## 5. 初期条件

一様な初期絶対温度、またはセルごとの初期温度場（配列）のどちらかを与える。k(T)／cp(T) の表を使う場合は、初期温度が表の範囲内にあることが必要で、範囲外は外挿せず生成時に拒否される（`dynamic/thermal.mjs`）。

## 6. 境界条件

外周4辺と、輪郭で露出した面（edge）に、次の面条件を設定できる。表面までの半セルの伝導抵抗を常に含む。

- 温度固定：表面温度を与える。
- 熱流束：内向き熱流束 [W/m²] を与える（正が加熱）。
- 断熱：流束ゼロ。
- 対流：半セル抵抗と 1/(hA) を直列にした表面温度で評価する。
- 放射：灰色面から大きな黒い周囲への放射。表面温度を二分法で解く（形態係数1）。
- 対流＋放射（同時境界）：セル中心と表面の間の伝導 G に対し、G(Tc−Ts) = hA(Ts−T∞) + εσA(Ts⁴−Tr⁴) を解いて共通表面温度 Ts を求める。流体温度 T∞ と放射周囲温度 Tr は別の入力である（`docs/dynamic/SURFACE_EXCHANGE.md`）。

材料界面では、両側の半セル抵抗に接触熱抵抗 R を直列に加え、面を通過する熱量を両側で等量・逆符号に計上する。

自由輪郭を指定した場合、露出面に使えるのは温度固定と断熱のみである。面積に依存する条件（熱流束・対流・放射・同時境界）は生成時に拒否される。理由と範囲の確定は `docs/dynamic/TRANSIENT_CONDUCTION_FREE_CONTOUR_SCOPE_20261107.md` を参照。

## 7. 数値計算法

- セル中心の保存型有限体積法。内部面のコンダクタンスは半セル抵抗の直列 G = A / (dist/(2k_n) + dist/(2k_m) + R)（同一材料では R=0）。境界の半セルコンダクタンスは 2kA/dist。
- 時間積分は前進 Euler。安定刻みは safeDt = 0.8 × min(C_i / ΣG_i) で、これを超える刻みは拒否される。格子は各方向1〜256、合計16384セル以下。
- cp(T) を使うセルは、比エンタルピー h(T) = ∫cp(θ)dθ で熱量を更新してから温度へ逆変換する（cp×温度差の近似ではない。`docs/dynamic/TEMPERATURE_DEPENDENT_CP.md`）。
- 放射の表面温度は二分法（52回反復）、対流＋放射同時境界の表面温度は Newton 法＋二分法で解く（`dynamic/surface-exchange.mjs`）。
- 顕熱の収支（初期値との差と外部入力の累積）を常時監視し、非有限値・0 K 以下・表範囲外では更新前の状態で原子的に停止する。

## 8. 計算過程

1. 形状・材料・境界・格子を設定し「適用」で初期状態から計算を始める。
2. 各刻みで、内部面・境界・内部発熱からの正味入力で全セルの熱量を更新する。
3. 表示（温度場・等温線・断面・履歴）と診断（顕熱収支、同時境界の表面温度と各寄与）を確認しながら時間を進める。

手計算による検算の例：
- 一様温度・断熱・発熱のみなら、全セル一様に ΔT = q‴t/(ρcp)。cp(T) の場合は ∫cp(T)dT = q‴t/ρ から求める（アプリ内 #manual「検算・適用範囲」にも記載）。
- 定常・1D・一定物性なら温度は線形分布となり、熱流束は直列熱抵抗（伝導＋接触＋対流）で手計算できる。

## 9. グラフの読み方

- 温度色は**セル平均温度**の表示である。等温線はセル中心間を三角形に分けた区分線形補間で描かれており、物理的な壁面温度の再構成ではない（アプリ内 #manual「図形・測定・比較」に明記）。
- 断面グラフは、測定点に近いセル列の温度を実座標の横軸で示す。点温度ではなくセル列の代表値として読む。
- 時間履歴は保存された計算状態に対するもので、巻き戻しは過去の状態の表示と、そこからの再計算である。
- 2条件比較（A/B）は同じ物理時刻・同じ色尺度で表示される。形状寸法が違う条件では、測定点は寸法比で対応付けられる。

## 10. 結果の解釈

- セル平均と実測点温度を区別する。表面温度は境界条件と半セル抵抗から決まる値で、端のセルの中心温度とは異なる。
- 収支誤差（エネルギー誤差）は保存則の破れ具合を示す診断であり、温度の離散化誤差そのものではない。両者を混同しない。
- 検証の実測（出典付き）：
  - 断熱・一定物性の分離解ベンチマークでは、空間 RMS 誤差 0.00347 K（10×5）→ 0.000867 K（20×10）→ 0.000217 K（40×20）、観測された空間次数 2.0009／2.0003、時間次数 1.0078／1.0039、エネルギー誤差は 10⁻¹⁵ J 級（`docs/dynamic/BENCHMARKS.json`）。
  - 定常解への漸近では、両端等温の平板で測定減衰率 9.866 /s が連続第1固有値 απ²/L² = 9.870 /s と比 0.9997 で一致（フェイリス側検証記録 `TRANSIENT_CLOSURE_VERIFICATION_20261107.md`、ブランチ `feiris/transient-closure-notes`）。
  - 熱流束ゼロ条件（断熱全境界・対称面・等温放射）は専用試験に集約され、断熱の非一様場で体積平均への最大偏差 5.68e-13 K、収支誤差 0 を確認（同記録）。
  - k(T)／cp(T) × 対流＋放射同時境界の組合せは、製品では現在も拒否されている。独立参照との照合では測定範囲（1D平板・片面のみ同時境界）で最大差 5.8e-3 K 以下・定常極限の一致 1.3e-10 K 以内という裏付けがあるが、受理の解除には残条件がある（同記録）。

## 11. モデルの仮定

- 2D断面で奥行き方向は一様。薄い板の表裏は断熱。
- 密度は一定。相変化・潜熱は扱わない。
- 放射は灰色面と大きな黒い周囲（形態係数1）のモデルで、面同士の囲い放射は扱わない。
- 熱伝達率 h は入力値であり、風速・浮力・流れ場から推定しない。周囲の流体は解かない。
- フィンの実験は、細長い一定断面の1D近似（側面対流を体積あたりの損失として含み、先端は断熱）であり、2D伝導モデルとは別扱いである。

## 12. モデルの限界

- 自由輪郭での面積依存境界は使えない（項目6の確定記録）。
- 温度依存物性と対流＋放射同時境界の組合せは製品では拒否される（項目10）。
- 温度依存物性付きフィンは、側面対流との連成検証待ちのため使用できない。
- 3D解析ではない。複雑形状の一般的な解析精度は保証しない。
- 研究・設計への無条件の適合は保証しない（アプリ内 #manual「検算・適用範囲」）。

## 13. よくある誤解

- **「格子を細かくすれば自由輪郭の表面積も正しくなる」** — 誤り。階段近似の総面積は細分化しても真の面積へ収束しない。面積依存境界を輪郭で拒否する理由である。
- **「セルの温度がそのまま表面温度」** — 誤り。表面までは半セルの伝導抵抗があり、表面温度は境界条件と合わせて解かれる。
- **「対流と放射はセル温度にそれぞれ加えればよい」** — 誤り。同時境界では表面温度 Ts を共有して収支を解くため、単純加算とは結果が異なる。片方が加熱・片方が冷却になる場合もある。
- **「cp(T) のときも cp×温度差で熱量を近似してよい」** — 誤り。本モデルはエンタルピー積分で更新しており、近似式とは平衡温度などが異なる。
- **「巻き戻しは熱の方程式を逆向きに解いている」** — 誤り。保存した過去の状態を表示し、そこから前向きに再計算する。
- **「安定刻みの範囲内なら精度も保証される」** — 誤り。安定性と精度は別であり、格子と刻みを変えた比較が必要である。
