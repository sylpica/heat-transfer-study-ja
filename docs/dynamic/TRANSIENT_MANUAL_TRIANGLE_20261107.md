# モデル別説明書：三角形系（凸 P1）非定常熱伝導

- 日時：2026-11-07（Asia/Tokyo）
- 対象モデル：凸多角形の P1 有限要素による開発専用モデル群。コアは (1) 全周固定温度 `dynamic/dev/triangle-diffusion.mjs`、(2) 線形混合境界 `dynamic/dev/triangle-linear-transient.mjs`、(3) 同一面の対流＋放射 `dynamic/dev/triangle-surface-transient.mjs`。開発 GUI は `dynamic/dev/triangle-diffusion.html`、`dynamic/dev/triangle-linear.html` ほか（開発用 allowlist サーバーでのみ配信し、公開ビルドには含めない）。
- 位置づけ：正本 §21.2 がモデルごとに求める16項目の説明書。三角形系には従来、開発文書（`docs/dynamic/TRIANGLE_TRANSIENT_DEVELOPMENT.md` 等）はあっても利用者向けの説明書が存在しなかった（監査の基準5の指摘）。本書がその新設分であり、数値の出典は各項に併記する。
- 注意：このモデル群は `releaseApproved:false` の**開発専用**であり、一般公開用の解析機能としては有効化されていない。実機・支援技術での確認も未完了である。

## 1. 現象の概要

三角形・多角形の断面を持つ物体の内部で、温度が時間とともに伝わっていく現象を、2D断面のまま計算するモデルである。矩形 FVM（直交格子）では形を階段近似しなければならない凸多角形の輪郭を、輪郭に沿った三角形要素でそのまま表す点が特徴である。奥行き方向は一様で、前後の面からは熱交換しない。

## 2. 現実世界での使用例

- 三角形・台形・多角形の断面を持つ部材（梁、成形品、放熱部材の根元など）が加熱・冷却されるときの内部温度の遅れ。
- 断面形状そのものが温度分布へどう影響するか（角部への熱の回り込みなど）の学習。
- 多角形断面の電子部品・筐体部品の温度応答の概算。
開発専用モデルであり、実設計の保証には使わない（項目12）。

## 3. 支配方程式

一定物性・等方性の場合の熱伝導方程式（教科書 §2.1）：

ρcp ∂T/∂t = ∇·(k∇T) + q‴

離散化した各節点 i については、開発文書の形で

C_i dθ_i/dt = P_i − Σ_j G_ij (θ_i − θ_j)

と書ける。θ は基準温度からの温度差（コアにより θ = T − Tw または θ = T − Tref）、C_i は節点の lumped 熱容量、G_ij は要素から組み立てた節点間のコンダクタンス、P_i は体積発熱の配分である（`docs/dynamic/TRIANGLE_TRANSIENT_DEVELOPMENT.md`）。

## 4. 記号と単位

| 記号 | 意味 | 単位 |
|---|---|---|
| T, θ | 絶対温度、基準温度からの温度差 | K |
| C_i | 節点 i の lumped 熱容量 | J/K |
| G_ij | 節点 i−j 間の伝導コンダクタンス | W/K |
| D | 奥行き（断面に一様） | m |
| k, ρ, cp | 熱伝導率、密度、比熱（一定物性のみ） | W/(m·K), kg/m³, J/(kg·K) |
| q‴（文書中 qvol） | 一様な体積発熱密度 | W/m³ |
| h | 熱伝達率（線形混合境界コア・表面コア。入力値） | W/(m²·K) |
| ε, σ | 放射率、ステファン・ボルツマン定数 5.670374419×10⁻⁸ W/(m²·K⁴) | — |

重要な区別：このモデル群の温度は**節点値**であり、矩形 FVM のセル平均ではない。要素内部の温度は節点値の線形補間（P1 場）として定義される。

## 5. 初期条件

初期温度は、スカラー（一様）で与える場合は内部節点の温度として解釈され、境界節点は境界条件の値を取る。配列で与える場合は全節点分が必要で、境界節点も条件値と一致しなければならない。不連続な初期条件は、境界近傍の要素内では線形の初期近似になる（均一な連続初期場をそのまま表したとは言えない。`docs/dynamic/TRIANGLE_TRANSIENT_DEVELOPMENT.md`）。

## 6. 境界条件

コアごとに扱える条件が異なる。

- 全周固定温度コア（triangle-diffusion）：全境界が一様な固定温度 Tw のみ。
- 線形混合境界コア（triangle-linear-transient）：辺ごとに固定温度／断熱／外向き指定熱流束／Robin（対流。境界積分の row-lumping で扱い、h を計算する流体モデルではない）。
- 表面コア（triangle-surface-transient）：同一面の対流＋放射を実境界節点で扱う。h(T−T∞) + εσ(T⁴−Tr⁴)、大きな黒い周囲を指定し、流体温度と放射周囲温度は別入力。一般の形態係数ネットワークや参加媒体は含まない。

## 7. 数値計算法

- 空間：P1（線形）三角形要素による有限要素離散化。熱容量は節点へ lumped（集中）させる。対象は凸多角形（3〜12頂点）で、未知節点に負の伝導係数が接続しない形状だけを受理する。
- 時間：SSPRK2（2段の強安定性 Runge–Kutta）。刻みは dt ≤ 0.8 × min(C_i / 対角項) を上限とし、候補温度の符号と最大原理の範囲を監視する。
- 表面コアの放射は割線コンダクタンス G = εσ(A/2)(T+Tr)(T²+Tr²) で評価し（nodal-lumping：辺の面積 A を両端節点へ A/2 ずつ配分）、放射微分の上限を刻み制限に含める。
- 境界熱の数え方：保存則に使う境界熱は、固定節点の反力などからなる**離散反力**で数える。別に、要素の片側勾配 −k∇T を境界小辺で積分した量も返すが、両者は別の量であり区別して表示する（項目13）。
- 後処理として RT0 平衡回復流束（`dynamic/dev/triangle-flux-recovery.mjs` 等）があるが、温度場を解き直すものではなく、その物理精度は未検証である（scope に `physicalFluxAccuracyVerified:false` と明示）。
- 失敗時（上限温度超過、非有限値、無効な刻みなど）は温度・時計・積算値を変えず、元の状態を保持する（原子性）。

## 8. 計算過程

1. 凸輪郭（頂点）と分割数、材料・発熱・境界条件を設定して初期化する。
2. SSPRK2 で時間を進め、温度場（P1 補間）、顕熱、累積発熱、境界出熱（反力）と収支差を監視する。
3. 分割を変えて結果を比較し、粗い格子での誤差の大きさを確認する。

手計算による検算の例（出典：`docs/dynamic/TRIANGLE_TRANSIENT_DEVELOPMENT.md`）：単位正方形で中心だけが未知節点、中心 350 K／境界 300 K の場合、中心の容量は 10000 J/K、対角コンダクタンスは 1.8 W/K、離散反力は 90 W になる。一方、要素の片側勾配から積分した境界熱は 180 W であり、両者が一致しないこと自体が、粗い要素での「境界熱」の定義依存性を示す検算になっている。

## 9. グラフの読み方

- 開発 GUI の温度場は、実際の節点温度を画素位置で P1 線形補間して描く。三角形ごとの単色塗りではなく、架空のセル平均でもない（`docs/dynamic/TRIANGLE_UI_DEVELOPMENT.md`）。
- 領域外には値を作らず、透明マスクと測定不可で示す。測定点は物理座標で選び、A/B 比較では同じ物理座標・倍率・温度凡例・物理時刻で並べる。
- 履歴は実際に保存された節点値の補間である。
- 片側勾配から描く熱流の表示は、保存的に回復した熱流束ではない。矢印があるからといって保存流束と読まない（項目13）。

## 10. 結果の解釈

- 精度は節点誤差だけでなく、要素内部まで含めた**全場誤差**で読む。検証では P1 場全体と連続場の L2 差を面積積分して評価している。
- 検証の実測（出典：`docs/dynamic/TRIANGLE_TRANSIENT_DEVELOPMENT.md`。回転した 0.4×0.2 m 矩形、k=15、ρ=1000、cp=1000、D=0.03 m、Tw=300 K、連続解は sin 積の固有モード）：
  - 全場 RMS は分割 n=2／4／8／16 で 4.70778 → 1.19817 → 0.29883 → 0.0744317 K、結合精細化の次数は 1.974／2.003／2.005。
  - 全熱の相対差は −17.061% → −0.2963%、反力による境界熱の相対差は −24.560% → −0.5816%。粗い n=2 では収支差が約 5.46e-12 J と小さくても、全熱は連続解から 17% 違う。保存則の一致を精度の証拠と読まない。
  - 固定格子の時間検証（行列指数による独立参照）：dt = 5／2.5／1.25 s で最大時間誤差 0.000987562／0.000233304／0.0000567218 K、次数 2.082／2.040。
- 線形混合境界コアの全場 RMS（出典：`docs/dynamic/TRIANGLE_LINEAR_TRANSIENT.md`）：固定温度／断熱のケースで 1.011346 → 0.0163464 K（n=2→16、最終次数 約1.996）、対流／断熱のケースで 0.421204 → 0.00672906 K（約1.997）。
- 表面コアは固定格子で DOP853 参照と照合し、時間次数 2.00109（矩形）／2.00073（五角形）、最細の最大差 1.45838e-6 K／1.30309e-7 K（`docs/dynamic/TRIANGLE_SURFACE_TRANSIENT.md`）。これは固定格子の時間検証であり、一般の連続過渡場の空間精度とは呼ばない。
- 定常解への漸近では、正方形（左右等温・上下断熱）の測定減衰率 1.484e-4 /s が連続第1固有値 απ²/L² = 1.480e-4 /s と比 1.002 で一致（フェイリス側検証記録 `TRANSIENT_CLOSURE_VERIFICATION_20261107.md`、ブランチ `feiris/transient-closure-notes`）。

## 11. モデルの仮定

- 凸多角形のみ。凹・穴・曲線輪郭は扱わない。
- 一定物性・単一材料。奥行き方向は一様で、前後面の熱交換はない。
- 表面コアの放射は、規定された大きな黒い周囲への放射のみ（囲いの形態係数ネットワークではない）。
- 熱伝達率 h は入力値であり、流れは解かない。

## 12. モデルの限界

- 変物性 k(T)／cp(T) と複合材料（多層・界面）は扱わない。これらは Phase 3 の対象外として確定している（範囲確定記録 `TRANSIENT_CONDUCTION_SCOPE_20261107.md`。変物性・複合材料は分野として矩形 FVM が担う）。
- 放射囲い連成、参加媒体、3D は扱わない。
- RT0 回復流束は後処理であり、物理精度は未検証。
- 開発専用（`releaseApproved:false`）で公開されておらず、実機・支援技術での操作確認も未完了。一般公開用の解析機能として有効化しない（正本 §6.4）。

## 13. よくある誤解

- **「節点の温度はセル平均温度」** — 誤り。節点値であり、要素内は線形補間で定義される。矩形 FVM のセル平均と読み替えると、境界近傍の解釈を誤る。
- **「片側勾配を積分した境界熱が、保存される境界熱」** — 誤り。保存則に使うのは離散反力であり、片側勾配の積分は別の量である。項目8の手計算例では 90 W と 180 W のように大きく異なる。
- **「エネルギー収支が合えば精度も高い」** — 誤り。粗い格子では収支差が 10⁻¹² J 級でも全熱が 17% ずれる（項目10）。保存性と精度は別に評価する。
- **「時間積分が2次（SSPRK2）だから熱流束も2次精度」** — 誤り。時間次数と、勾配・熱流束の空間精度は別の話である。
- **「RT0 回復流束は解き直した正確な熱流束場」** — 誤り。温度場を変えない後処理であり、物理精度は未検証と明示されている。
- **「境界節点へ配分された発熱は壁面の熱流と同じ」** — 誤り。lumped 配分による境界反力への直接寄与は格子依存の離散化効果で、連続な一様初期場の瞬時壁熱とは異なる（`docs/dynamic/TRIANGLE_TRANSIENT_DEVELOPMENT.md`）。

## 15. 関連問題

対応付けは棚卸し記録 `docs/dynamic/MODEL_PROBLEM_MAP_20261107.md`（第3.3節・第8節）に基づく。

**現行の問題バンク（751問）に、本モデル（三角形要素の2次元非定常）に対応する問題はない。** バンク全体の棚卸しでも、三角形要素・自由形状の2次元非定常を扱う問題は存在しない。推測で埋めず、その事実をここに明記する。

最も近いのは、矩形前提の2次元伝導を扱う次の問題である（いずれも主掲載は矩形の説明書の項目15であり、本モデルの関連問題として断定はしない）。

- `supp-transient-gap-product-center-v1` — 分離可能な矩形冷却の積解による中心温度。
- `supp-transient-gap-multidim-flux-components-v1` — 2次元温度場における熱流ベクトルの成分。
- `supp-transient-gap-multidim-mesh-check-v1` — 数値の2次元伝導結果に対する検証の進め方。

なお本モデルは開発専用であり、公開画面からアプリの演習への導線はない。
