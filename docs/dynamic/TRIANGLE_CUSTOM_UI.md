## 操作と条件の保持

「現在の輪郭と境界を編集」で受理済み形状/辺条件を下書きへコピーし、初期内部を一様とする設定へ移る。固定温度節点は指定値を保持するので、境界付近まで一様な連続初期場とは説明しない。辺iは反時計回りの頂点i+1→次頂点（最後は1へ）。座標・頂点番号とともに各辺へ設定欄を表示し、指定熱流束の外向き正/入熱負を明記する。異なる固定温度が共有角で衝突したら平均せず拒否。

同数頂点の移動では辺番号を保持。追加/削除では古い条件を別辺へ推測移動せず、下書きを全辺断熱へ初期化したことをlive statusで案内し、再設定を求める。前の温度/時計/熱/受理済み境界は下書きで変更しない。明示適用で時刻0から計算。物理座標精度・メッシュ資源・境界不整合で失敗しても旧状態を保持する。

辺設定は独立したdraft UIで、検出/学習保存/Worker状態へ書き込まない。関連する数値検査は別の設定builderとコアに分離。数値配列・条件は受理時に複製する。正方形/回転矩形と混在するA/Bもそれぞれ受理済みの参照情報を保持。任意編集輪郭へ矩形sin/cosを表示せず「連続解析参照は登録していません」と案内する。診断には受理済みの全辺条件、各種境界熱、蓄熱と予算、任意RT0の局所収支を表示する。

## 頂点選択の不具合

最初の実GUI試験で、頂点2を選ぶnative inputが親フォームへ伝わり、change処理より先にselectを再描画して頂点0へ戻る不具合を再現した。共有輪郭エディターでselect inputを所有し、物理下書きが変わらない選択を親の条件変更へ伝えないよう修正。新GUIと旧全周固定GUIの両方で選択番号/座標/形状不変更の回帰を追加した。許容差や頂点移動の物理計算は変更しない。
