# 保存的熱流束回復の検証前チェックポイント

2026-11-06、基点2be9ce2。開発専用の解析処理を作成、未検証。P1時間更新を変更せず、snapshotへ実演算子の瞬間節点温度率を追加。要素の平均蓄熱率と発熱から必要出熱を定義し、各辺に一意の熱移動率を持つRT0場を回復する。温度場、時計、積算熱を修正しない。

平均片側Fourier流束の辺積分Q0を基準に、正重みw=kDℓ/(h1+h2)を用いた最小補正min Σ(Q−Q0)²/(2w)、制約BQ=source−storageを解く。境界辺も未知に含める。これはFourier構成則とのずれを持つ後処理で、元の温度離散化誤差を解消しない。内部辺の法線熱を一意にし、各要素で平均蓄熱と整合させる。RT0は要素内でベクトルが一次、divが一定。

独立検証前に固定する基準：単一自由度の手計算、別の物理座標P1演算子と独立KKT/線形解の辺熱照合（相対1e−9）、局所収支（実熱量スケールの相対1.1e−11以内）、回転長方形4格子の連続熱流束全場L2評価（最細相対10%未満、最後の細分化次数>.8）、隣接法線一致、入力/状態不変、ゼロ/極小量/失敗時の拒否を確認する。基準を満たさなければ結果を保存し、値を調整して成功扱いにしない。まだ専用GUI矢印へは接続せず、公開allowlistへ追加しない。
