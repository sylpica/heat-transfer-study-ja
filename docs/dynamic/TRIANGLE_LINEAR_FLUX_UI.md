# 混合境界の既知熱流を保持した回復流束表示

## 表示の意味

実回復場の要素重心ベクトルを最大40点表示し、A/Bの長さ尺度を共通化。断熱・指定熱流束・対流の既知境界熱は回復中に変更しない。元の片側Fourier勾配、回復した測定点流束、既知辺熱の最大変更、回復境界合計と元の合計との差、局所残差/予算、全境界熱が既知かを診断へ分ける。全既知境界の場合の双対ゲージは幾何が閉じているかの分類とは区別する。

省略したベクトルも数値では保持する。一様断熱発熱で丸め級の小さな流束を自動拡大して大きな矢印にしないため、保持温度差の尺度・計算回数・k・最小要素高度から表示専用の丸め目安を作る。A/B共通の省略目安はmax(128EPS×最大重心流束、128EPS×(steps+1)×k×max|θ|/最小高度)。これは表示上の保守的な目安で、厳密な誤差上限や構成則の精度証明ではない。物理データ・源・温度率・回復ベクトルは変更しない。固定1W/m²等の下限を置かず、保持差の小ささに合わせて縮むため、1e−100W/m³源に由来する実Robin流束は表示できる。

回復は受理済みメッシュ/条件/状態だけに結び、factoryと結果をWeakMapへキャッシュ。プローブ変更や描画だけでCGを再実行しない。回復失敗は利用不可として案内し、温度計算や復元を止めない。オン/オフや省略を温度・時計・積算熱の変更にしない。
