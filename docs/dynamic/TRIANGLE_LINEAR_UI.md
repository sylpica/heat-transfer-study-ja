# 正方形の線形混合境界・開発GUI

2026-11-06。abae261で限定検証した別コアを専用画面triangle-linear.htmlへ接続した。公開allowlistには含めない。旧全周Dirichletの自由凸輪郭画面とは別に、正方形・軸平行・一定物性へ範囲を絞る。

## プリセットと参照

- 下側固定温度・他3辺断熱。初期のsin(πy/2L)分布の指定値は上側断熱端の温度。
- 上側対流・他3辺断熱。cos(μy/L)分布の指定値は下側断熱端。μtanμ=hL/k。
- 底面入熱・上側対流・側面断熱。初期は全節点同温度。表示する解析参照は定常目標のみで、過渡解と明確に区別。h0に有限の定常参照を偽装しない。
- 全断熱・一様体積発熱/冷却。初期は全節点同温度で、正負の発熱を実蓄熱として追跡。

長さ・材料・h・熱流束・発熱を範囲内で指定し、分割4/8/16または初期化時だけの自動分割を選ぶ。プリセットに無関係な入力は非表示/無効にし、物理条件へ加算しない。hは入力でありCFDから予測しない。初期温度・境界温度・蓄熱基準を℃からKへ明示換算する。

連続モードの温度/全熱/境界熱と比較し、参照0の相対差を未定義とする。Robin固有根はBi=0と極小Biを扱い、小Biでμ≈√Biとなる別の手計算極限も確認した。参照が有限な数値範囲を超えれば参照だけ利用不可とし、温度を置き換えない。

## 実状態の表示と操作

実節点温度差から物理勾配・片側Fourier流束を読み取り専用に計算し、実温度をP1線形補間して表示。入力/返り値のコピーを分離し、原状態を変更しない。混合境界の保存的回復流束はまだ接続しない。

指定熱流束、対流、固定温度反力、境界合計、発熱、顕熱、積算熱、収支差/丸め予算、刻み上限を分けて表示。底面への正の入熱は外向き指定熱では負で、冷却指定も保持する。

実WorkerのA/B、共通座標/倍率/色/時計、実保存コマへの巻き戻し、取消後復元と再開。解析参照も受理済み条件に結び、未適用フォームやAの条件でBを誤表示しない。測定点はクリック/矢印キーで動き、領域外には値を作らない。履歴はメモリー内のみで、既存の学習記録や設定を保存/送信しない。
