# 開発専用：凸輪郭の適合三角形メッシュ

2026-11-06（Asia/Tokyo）。`dynamic/dev/convex-triangle-mesh.mjs` / `planar-predicates.mjs`。rootの単独・逐次実行。cut-cellの非直交補正に最大原理違反があったため、別の離散化を検証するための幾何基盤を追加した。既存のcut-cell/公開モデル/失敗記録を変更しない。

## 作るもの

厳密凸の3〜32頂点から内部中心と各辺のfanを作り、各fanを同じ分割数nで適合分割する。隣接fanの節点は論理IDで共有し、境界の全小辺を保持。内部辺を厳密凸な四辺形の範囲だけ交換し、局所Delaunay条件が成立するまで反復する。3D、凹/穴/曲線/障害物、自由な非適合メッシュではない。

最大1024三角形/600節点、nは1〜16。範囲外/非有限/重複/一直線/凹/交差/未解像面積/辺交換の上限は拒否する。ゼロ面積要素を削除したり、輪郭外を正セルへ埋めたりしない。時計回りは同じ角点を反時計回りへ並べ替え、同じ閉終点の除去を記録する。

座標は平行移動・等方長さ正規化を行う。境界の補間点には浮動小数点の線からのずれがあり、最大の線残差を出力する。幾何述語の厳密性は**与えられた丸め済み正規化座標**についてで、無限精度の元の直線や物理形状の一致を意味しない。元角点の物理座標はそのまま保持。全要素面積/元輪郭面積、最小品質、flip数、predicate/fallback回数を出す。

## 幾何述語

向きとincircleの多項式符号を自作。十分分離した値は浮動誤差の保守的なboundで選別し、近い値/同一円/極端な桁はBigInt二進有理数で厳密に評価する。十進への再構成や第三者の述語コードは使わない。浮動filterは全非ゼロ変位成分が2^−128〜2^128の範囲にある場合だけ使用し、4次の途中積のunderflow/overflowで誤差予算を過小評価しない。その他は最初から厳密経路へ戻る。

これにより最小subnormalの符号や、通常の途中積がoverflowする座標でも符号を検査できる。一方、物理面積が表せない入力をメッシュとして受理する意味ではない。メッシュ面積/品質の有限・正値は別に検査する。
