# 凸P1の頂点編集と受理済み状態の保護

2026-11-06。基点7a1639dに続く開発専用機能。輪郭下書きの純粋なデータ操作、SVG操作、物理UIを分離した。凸P1モデルの条件・公開承認範囲は拡張しない。

## 操作と制限

受理したAの輪郭から編集を始める。各頂点はドラッグ、Tab/矢印キー、頂点選択と座標入力で移動可能。Shiftで大きく移動。輪郭は3〜12頂点、各座標−10〜10mの有限値に限る。選択辺の中点を外側へ辺長5%ずらして頂点を挿入でき、選択頂点を削除できる。追加は物理面積を変える操作で、図の見た目だけの補助点ではない。3頂点からの削除と12頂点からの追加は拒否する。

厳密凸メッシュの検査を再利用し、重複・凹・交差・一直線・向き反転・解像不能を、形状の削除や並べ替えで自動修復しない。候補を全て検査してから下書きを置き換え、拒否した移動は前の有効な下書き・選択・面積を保持する。下書きgetterの返り値も独立コピー。

編集プレビューは温度画像ではない。ドラッグ中に表示座標範囲を自動変更せず、図の再描画でもSVGホストのpointer captureを維持する。「画面へ収める」で明示的に範囲を更新する。矢印移動後も選択頂点へフォーカスを復帰する。入力欄の標準キー操作は奪わない。

## 物理状態

頂点編集開始時は正弦の長方形初期条件を「内部未知節点を同温度」へ切り替え、その点を案内する。プリセットの寸法/回転入力は編集輪郭では無効化し、入力を反映したように見せない。輪郭変更で進行中のWorker計算を取り消し、再生を無効化する。前回受理した全温度・時計・参照条件はラベル付きで保持し、途中計算や編集下書きを受理済み状態として表示しない。

明示的な「初期状態から計算」でメッシュ/温度を再初期化し、時刻0から進める。Bに固定した設定と初期分布は保持する（A変更の適用時はA/B共に時刻0へそろえる）。編集された形状が長方形に似ていても、未検証の正弦解析解を自動で付けない。未適用／適用済みを受理した状態から表示する。
