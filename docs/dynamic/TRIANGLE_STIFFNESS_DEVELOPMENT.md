# 開発専用：P1拡散係数とlumped容量

2026-11-06（Asia/Tokyo）。root単独・逐次実行。`dynamic/dev/triangle-stiffness.mjs`、`dyadic-quotient.mjs`。適合凸三角形メッシュに一定k [W/(m K)]、奥行D [m]、ρ [kg/m³]、cp [J/(kg K)]を与え、P1有限要素の拡散係数と正のlumped容量を構築する。温度の時間発展はまだ実装していない。

## 式・符号・容量

三角形の線形基底N_iに対し、K_ij=kD∫∇N_i·∇N_j dA [W/K]。内部辺の結合をG_ij=−K_ij=kD(cotα+cotβ)/2と書く。全内部辺が局所Delaunayならcot和は非負。同一円は数学的に正確な0。負の値をclipして合格させない。

各要素の体積A Dを3節点へ等分し、C_i=ρcp Σ(A D/3) [J/K]。これはlumped積分の節点重みで、節点温度はcut-cell平均ではない。全体積/容量の和を別に表示する。固定温度節点の重みも幾何積分の一部で、境界に別の物体容量を追加した意味ではない。

未知節点に接続する全Gは非負、全未知成分が正の係数で固定温度境界へ接続することを検査。グラフ二次形式は厳密演算で正定値となるが、浮動小数点の実行行列の最小固有値を全入力で保証したとはしない。`numericPositiveDefinitenessVerified:false` と時間/精度の未承認を保持する。

**固定温度境界節点同士**の辺には負のGがあり得る。一方の要素だけの余接が鈍角で負となるためで、Dirichlet消去後の未知行列の符号と区別する。その符号を捨てたり、全辺を物理的な正の熱抵抗と描いたりしない。有限要素の弱形式/境界反力として扱い、全量の保存と温度解を後続で確認する。

## 近い余接の相殺を避ける

`edgeCotangentDyadic` は与えられた正規化IEEE座標の正確な二進有理数から、余接和の分子/分母を直接構成する。Delaunay符号と正値を確認し、`dyadicQuotient` がBigIntの除算/剰余からFloat64へ一度だけnearest-even丸めを行う。subnormalのtie、非常に大きい分子/分母、正確な同一円の0を別試験。非ゼロの商や最終Gがunderflow/overflowする場合は受理せず、0へ潰して辺を消さない。

入力メッシュは複製し、呼出元の後の変更が係数結果の幾何を変えない。対応外引数、物性0/非有限、体積/容量/係数の未解像、辺の重複/反転/非Delaunay、境界へ接続しない未知成分を拒否。メッシュ構造は自作builderの出力を前提とし、一般の外部メッシュ取り込みを提供するものではない。
