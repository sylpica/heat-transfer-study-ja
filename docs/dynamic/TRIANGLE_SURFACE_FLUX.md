# 対流＋放射の既知辺熱を保持するRT0回復

2026-11-06、試作a7d5b88、誤差定義と事前予算4f9d21f。元の線形RT0と温度コアを保ち、別の読み取り専用factoryを追加した。実境界区間の両端へA/2で配分した対流/放射/指定熱の合計を固定し、内部/固定温度辺だけを回復する。P1補間温度4乗の厳密な面積分とは区別する。

## 物理成分の尺度と閉系

各既知辺へ対流W/放射W/指定Wを返し、合計と実成分の絶対和を保持する。対流入熱と放射出熱の相殺で合計だけが丸め級になる場合、成分の実熱尺度を丸め予算へ含める。1W等の定数床を置かない。既知熱の差は成分尺度で判定し、正味熱で正規化した値も別記して隠さない。

全境界熱が既知なら整合性を検査して双対1要素をゲージ固定。右辺平均・源・温度率を修正せず、丸め級の不整合と実残差をそのまま保持する。回復は温度/時計/積算熱を変更しない。上限温度を含む非線形モデル署名を検査し、別モデルの状態を流用しない。

## 独立評価

物理座標K/C/率/基底勾配/辺法線・境界線分分類を別組立し、疎行列の直接制約最適解へ照合。境界熱はmpmath160桁の直接4乗差で評価し、時間コア/回復の共有割線関数を参照へ使わない。

8ケース：開いた矩形/五角形、連続定常線形場の初期2/4/8、Dirichletなしの閉じた非線形過渡、全辺同一対流＋放射の平衡相殺、源1e−100 W/m³。最適辺熱相対差最大1.86e−12、要素収支相対差3.04e−12、既知熱の成分尺度相対差2.79e−16。両側normal traceも予算内。定常全RT0ベクトル相対L2は1.35e−14/1.38e−14/6.01e−15で<1e−8を満たす。

閉じた非線形過渡は物理P1系を独立DOP853で新たに積分し、t40sの製品との差4.574e−8K（<.001K）。平衡相殺では既知辺熱差の正味熱比が約4.46%でも、実成分比は6.04e−17。前者は参照合計が丸め級のため精度判定に使わず、値はJSONへ保持している。微小源は絶対温度が全て300Kでも正の既知放射熱を保持し、局所予算も<1e−110Wで固定床がないことを確認した。

一般非線形過渡の連続全流束解は登録しておらず、この制約最適解照合から一般全場精度を承認しない。フェイリス側の連続定常場の別求積も受領済みだが、その結果と本線値/件数を合算しない。
