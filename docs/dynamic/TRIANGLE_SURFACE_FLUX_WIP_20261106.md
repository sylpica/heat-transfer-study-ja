# P1対流＋放射の回復流束：独立検証前

2026-11-06、基点f9cd53a。既存の線形RT0を保ち、別factoryで同一面の対流/放射を合計した既知辺熱を固定する。内部/固定温度辺だけを制約付き回復し、全境界熱が既知なら1要素の双対ゲージを使う。元の温度/率/源/平均右辺は補正しない。

辺の既知熱は、その実区間の両端へA/2で配分した対流＋放射で、時間コアと同じnodal-lumping。P1補間温度4乗の厳密積分と混同しない。組立の実区間・節点IDから係数を参照し、近い座標から条件を推測しない。

対流入熱と放射出熱がほぼ相殺する場合、合計の小ささだけで丸め予算を作らず、実際の各成分の絶対熱量を記録して尺度へ含める。1W等の固定床を置かない。合計0を強制せず実残差と既知辺熱を保持し、表示だけで丸め流束を大きな矢印へ増幅しない。

## 評価前の固定予算

- 独立物理P1 K/C/率/辺法線・境界再分類、直接制約最適辺熱に対し、既知境界相対差<1e−12、辺最適解相対差<1e−9、要素収支相対差<1.1e−11、両側normal trace差<1e−9×実熱尺度。ゼロ参照に架空の相対差を作らない。
- f9cd53aの開いた矩形/五角形、連続定常線形場の初期2/4/8に加え、Dirichletなしの閉じた非線形過渡、全辺同一面対流＋放射の平衡相殺、微小源1e−100を検査する。閉系の過渡は独立DOP853を新たに実行し、同じ時間の温度差<.001K（必要なら安全な指定刻み）を確認。
- 連続定常線形場の全RT0ベクトル相対L2<1e−8。一般非線形過渡の連続流束参照は登録していないので、この最適辺熱照合から一般全場精度を承認しない。
- 微小源は高精度の4乗差で独立評価し、実絶対Kが300に丸められても正の境界放射熱を保持。平衡相殺は対流/放射成分の実尺度と実残差を記録し、右辺平均や温度率で整合を作らない。
- 入力/状態不変更、改ざん率の閉系拒否、別型状態/条件拒否、両ブラウザー実Worker/復元/状態不変更を確認してからGUIへ接続する。未検証モデルの公開は行わない。

## 実装の予備保存

別の読み取り専用field helperと回復factoryを実装。組立の実境界区間へ両端放射係数を保持し、時間コアと回復が同じ純粋な放射熱評価関数を使う。独立参照側にはこの関数を使わない。回復の物理熱尺度/閉系整合予算には実際の対流/放射各成分を追加し、各辺の成分と尺度を診断へ返す。型/署名には非線形モデルと上限温度を要求し、元の線形factoryを変更しない。

既存の非線形組立/過渡7Nodeは共有評価関数への整理後も成功。矩形・.125sの予備1例で既知辺熱を保持、最大要素残差7.12e−11W（予算4.90e−10W）。これは独立制約解や閉系検証ではない。GUI/公開へ未接続、独立検証は次工程。
