2026-11-06、数値基点f9cd53a/ed329f5。既存の凸輪郭混合境界画面へ「対流＋黒い周囲への放射」を追加。流体温度、h、放射率ε、黒い放射周囲温度を独立に入力し、℃をKへ変換する。h0は放射のみ、ε0は対流のみ。一定物性/一様奥行き、実表面節点のnodal-lumping、大きな黒い周囲への灰色放射の限定モデルで、一般の放射囲い・形態係数・変物性・凹/穴は含まない。

## 条件・状態・表示

放射を含まない各Actorは元の線形factory、含むActorは別の表面factoryへ明示dispatchする。A/Bに線形と非線形が混在しても、受理済みの種類/署名/時計/熱/復元形式を保持し、古い状態の型を書き換えない。場/RT0も状態種別に対応する別の純粋helperを使う。描画切替や回復失敗で温度計算を変更しない。

上の温度欄はカスタム形状では蓄熱基準として表示し、各辺の固定/流体/放射周囲温度と区別する。診断には受理済み全辺条件、対流/放射の別の外向きWと境界合計、顕熱/積算熱J、刻み上限/上限2000K、RT0の既知辺熱変更と局所残差・実成分尺度を表示。任意輪郭に矩形の連続解析参照を偽装しない。

既存の輪郭/辺draft分離、頂点数変更の明示的全断熱化、原子的な入力拒否、実巻き戻し、同じ物理座標/温度/流束尺度を保つA/B、共有固定角の拒否を維持する。非線形の刻み上限は上限2000Kでの放射微分を含む安全側値で、計算量の上限を超えたら黙って粗くしない。
