# 凸P1非定常伝導の開発GUI

記録日2026-11-06。dynamic/dev/triangle-diffusion.html。開発用allowlistサーバーで検査し、公開ビルドへ含めない。長方形・三角形・五角形の一定物性2D断面、全周同じ固定温度、一様体積発熱、奥行方向一様というコアの制限を保持する。

## 実装と物理表示

- 実際の三角形節点温度を画素位置でP1線形補間する。三角形ごとの単色塗りや、架空のセル平均ではない。境界近傍の所属判定は既存の正確なdyadic幾何を用いる。領域外には値を作らず透明マスクと測定不可を表示。
- 物理座標で共通の測定点を選択。クリック、矢印、Shift+矢印に対応。A/Bは同じ物理座標・倍率・温度凡例・物理時刻。履歴は実際の保存節点値の補間。DPR1/2で同じ物理配置。
- 正弦初期分布の長方形・発熱0に限り、連続解析解の点温度・全熱・境界熱と比較。初期P1補間誤差もあり、全体熱収支だけを精度と呼ばない。参照条件を受理したWorker設定に結び、条件変更・巻き戻し・A/Bでも未適用条件の参照へすり替えない。
- 内部節点同温度という別の初期設定を区別。非長方形や発熱ありには未実装の参照を表示しない。手動分割で要素/節点予算を超えれば拒否し、自動では許容範囲内へ選択する。自動分割は初期化時だけ決まり、画面サイズ変更だけで物理状態を作り直さない。
- 発熱、境界節点への直接発熱配分、顕熱、累積熱、離散境界反力、片側勾配の境界積分、両境界熱の差を表示。片側勾配は保存的に回復した熱流束ではなく、熱流矢印に偽装しない。
- 実Workerによる時間進行・A/B・実状態の巻き戻し・取消と復元後の再試行。無効刻みは直前状態を保持。既存の回答や設定を書き換えず、実験履歴はメモリー内のみ。

## 検査

ChromiumとWebKitで実GUI/Worker試験成功。t20s、dt1.25sの中心温度は連続解との差約.013555K、CPUコアと表示丸め幅内で一致。既存コアの独立全場RMS/時間検証はTRIANGLE_TRANSIENT_DEVELOPMENT.mdを参照。GUIの一点一致を新しい全場承認にしない。分割8/16のA/B、無効dt、参照可能条件の限定、五角形16の拒否→8で復旧、三角形、外側測定、キーボード、実progress後取消→再開、390/1280px・明暗・DPR2、localStorage不変更、pageerror0を確認。
