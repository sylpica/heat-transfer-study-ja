# 3次元直方体エンクロージャーの形態係数（2026-11-07、フェイリス並行実装）

締め可能性監査（放射分野の残作業：一般形状の形態係数）への部分対応として、
3次元の形態係数計算を新規モジュール `dynamic/dev/view-factor-3d.mjs` に
実装した。対象は**軸平行な矩形面6面で構成される直方体状エンクロージャー**
に限定する。一般形状・曲面・開口・参加性媒体は対象外であり、放射
ネットワークへの接続と GUI も本作業の範囲外（後段の課題として明記）。
開発専用（releaseApproved=false、公開 allowlist 外）を維持する。

## 定義と手法

形態係数の定義は教科書 *A Heat Transfer Textbook* 6th ed. の式 (10.17a)
（二重面積積分）そのもの：

F_i→j = (1/(π A_i)) ∬ cos β_i cos β_j / S² dA_j dA_i

直方体の面ペアは、対向する平行矩形ペア（3組）と辺を共有する垂直矩形
ペア（12組・方向込み）しかない。どちらの配置でも核は面内座標の
**差（分離）だけに依存する**ため、並進不変な方向の積分は厳密に実行し
（近似でも表の転記でもない、同じ積分の厳密な簡約）、残りを数値積分する：

- **平行ペア**：分離 (dx, dy) への帰着で、テント重み (a−|dx|)(b−|dy|) と
  核 c²/(dx²+dy²+c²)² の2次元積分になる。核は分離 c のスケールで
  原点近傍に集中するため、パネル幅を c/6 から幾何級数（×1.45）で
  広げる分離軸＋ Gauss–Legendre パネルで評価する。
- **垂直ペア**（共有辺の長さ L、両面の辺からの広がり eFrom, eTo）：
  辺方向への厳密な帰着で核は atan(L/ρ)/ρ³（ρ = hypot(v, w)）になり、
  さらに共有隅を中心とする極座標では動径積分も厳密に実行できて、
  G(a) = atan(a) + (a/2) ln(1 + a⁻²) = ∫₀¹ atan(a/t) dt を用いた
  極角 φ の1次元積分 cos φ sin φ · r_max(φ) · G(L/r_max(φ)) が残る。
  r_max が切り替わる対角角 φ* = atan2(eTo, eFrom) に向けてパネルを
  冪 grading（3乗）で寄せる。元の核の隅の特異性はこの帰着で解析的に
  除去されている。

帰着を使わない素朴な4次元テンソル求積は、開発中の実測で辺共有ペアに
ついて ~1e-2 級の誤差に停滞した（辺近傍のピーク幅が現実的なパネルでは
解像できない）。これが厳密帰着を採用した理由であり、記録しておく。
結果への総和則による再正規化・クリッピングは一切していない
（diagnostics の renormalized / clipped は false で固定し、残差は
実測のまま返す）。

既定の解像度は separationPanels=10、polarPanels=16、gaussOrder=6。
工場関数は総和則・相反則の残差が 1e-9 を超える解像度では結果を返さず
理由を表示して拒否する（粗い解像度を指定すると例外になる）。

## 検証（すべて実測）

参照値は `scripts/dynamic-view-factor-3d-reference.py` が2つの独立経路で
生成し `docs/dynamic/VIEW_FACTOR_3D_REFERENCE_20261107.json` に記録した：

1. 教科書 Table 10.3 の解析式（場合1：整列平行矩形／場合2：共通辺を
   持つ垂直矩形）を mpmath 50桁で評価。生成した6×6行列は自己検査として
   総和則（行和の誤差 ≤ 5.9e-48）と相反則（≤ 1.4e-51）を満たす。
2. 式 (10.17a) の直接求積（座標から面を組み立て、共有辺と広がりを
   幾何学的に抽出、mpmath の適応求積、30桁）。10エントリで実施し、
   解析式との差は最大 3.4e-32。

製品モジュールとの照合（既定解像度）：

| ケース | 実測 |
|---|---|
| 立方体 隣接面 F | 0.200043776075403（解析値との差 −2.8e-17） |
| 立方体 対向面 F | 0.199824895698387（差 −1.9e-16） |
| 立方体 総和則残差（最大行） | 2.2e-16 |
| box 2×1×3 全エントリ最大誤差 | 1.5e-14 |
| box 1×100×1 底面→上面 | 0.4114200245（解析値との差 −3.2e-13） |
| 偏平 box 1×1×0.001 底面→上面 | 0.9980056319（差 −1.6e-12、解析値 0.9980056319075797） |
| 全ケースの相反則残差（相対） | ≤ 8.9e-16 |

解像度の収束（box 2×1×3、解析参照との最大エントリ誤差）：
粗い受理可能設定（8/16/5）2.3e-11 → （10/16/5）5.5e-12 →
既定（10/16/6）1.5e-14 → 細密（20/32/7）1.1e-15 と単調に縮小する。

2次元極限との整合（断面 1×1 の正方形、奥行き Y を伸ばす）：
底面→上面 F は Y=20 で 0.4002585821、Y=100 で 0.4114200245 と、
無限長ダクトの交差弦法の値 √2−1 = 0.4142135624 へ下から単調に近づく
（誤差 1.40e-2 → 2.79e-3）。底面→側壁も 0.2873806396 → 0.2917900673 と
2次元隣接値 1−1/√2 = 0.2928932188 へ近づき、端面への F は
0.0124900694 → 0.0024999204 と消えていく。

## 限界・未実施

- 対象は軸平行矩形6面の直方体のみ。一般の3次元形状・曲面・同軸平行
  円板（矩形近似はしない）・開口のある系は対象外。
- 放射ネットワーク（radiation-network）への接続、温度・放射率を与えた
  交換計算、GUI、Worker 化は未実施。形態係数の行列と診断のみを返す。
- 実機・専門家確認・公開判定は未実施（releaseApproved=false）。
- 解像度を極端に落とした指定は、残差ガードにより受理されない。
