# 高次運動量の壁近傍診断

2026-11-05、d87083b後続。HIGH_ORDER_MOMENTUM.mdの移動壁32格子の失敗（最大速度差.00572030>.005）を保持し、原因を調べる。これは新しい利用者向け方式の登録ではない。

scripts/dynamic-wall-closure-study.mjsは既存の2次、高次polynomial4と、片側閉包が必要な場所だけ既存2次へ戻す実験用shadowを同じ公称時間刻みで比較する。shadowは追跡ソースからignored work内へ生成し、生成物のhashも記録する。既存のcavity.mjs/mac-momentum.mjsは変更しない。rootの既定方式とshadowの既定方式の1ステップが完全一致することを実行前に検査する。

壁帯の幅を参照速度へ合わせて調整しない。移流フラックスの補間と微分を合成したステンシルが、全て内側の中心配置データで組める場所を高次のコアとする。それ以外は既存2次の式を使う。MACのu/v配置で境界帯は対称に入れ替わる。高次の点値差分と2次を混ぜるため、運動量の全体保存を証明した高次FVMとは扱わない。

Re=100、同じ4点のGhia参照転記、16/32格子、t=30 s。各格子で全方式に同じ公称dt=.5 min[.12/(ν(1/dx²+1/dy²)), .25/(1/dx+1/dy)]を使用し、各モデルの安全上限でも制限する。実際に追加制限された回数、最後の1秒の速度変化、発散/顕熱/圧力残差を記録する。既存の最大速度差.005の基準を変えない。製造解・自然対流・保存則・時間/格子の追加検査なしに方式を採用しない。

初期の--smokeは8格子・.01秒で、生成モジュール/共通既定式/有限値/保存則だけを確認し成功。物理参照への合否は評価していない。全比較はこのソースを先に保存してから実行し、成功/失敗どちらも結果を保存する。

## 滑らかな連続場での追加検査

scripts/dynamic-wall-manufactured-study.mjsは、従来と同じ連続製造解のu/v/平均ゼロ圧力/温度を全保存点で比較する。既定2次・元の高次・両方壁帯2次・移流のみ・粘性のみの5方式、16/32格子（--fullは64も）、t=.025 s、同じdt=.05/n²を用いる。既存高次32格子の圧力RMS<.0003 Paの目標を維持し、新方式の各値も合否を併記する。単に発散が小さいことと連続圧力誤差を分ける。

共通のNode専用shadow生成をscripts/lib/wall-closure-shadow.mjsへ分離した。最初の共通化で追加した常真のifとquoteの違いによりhash比較が失敗したため、元の生成バイトを再現するよう修正し、保存済み全3種類のmomentum/cavity hashが完全一致することを確認した。各追加検査の起動時にも照合する。既存演算子・公開物を変更せず、過去の全計算を別の演算子の結果として扱わない。

8格子/.025秒の5方式smokeは有限値/連続の式/顕熱を満たした。粗い格子の連続圧力誤差は大きく、精度承認ではない。16/32格子の計算はソースを保存してから実行する。


製造解の16/32格子結果：WALL_MANUFACTURED_STUDY_20261105.json、ソース5a4a759。32格子の圧力RMSは既定2次.0133216 Pa、元の高次.000232284 Pa、両方壁帯2次.00364338 Pa、移流のみ.00121439 Pa、粘性のみ.00349819 Pa。新しい3方式はいずれも既存の滑らかな高次目標.0003 Paを満たさない。発散/顕熱/既存高次の対照は正常だが、このことを新方式の精度合格と数えない。結果JSONのpassedは数値監視と元の対照の保持であり、新方式の目標達成は各行でfalseと明示している。

粘性だけの壁帯変更は移動壁の4点では近づいても、滑らかな全圧力場を悪化させるため、そのまま採用しない。次の仮説は、一定の動く上壁と静止側壁が接する不連続な上の2角にだけ、粘性の2次処理を限定すること。帯幅を参照値に合わせず、元の2階微分の半径2ステンシルが両壁へ届く場所で判定する。lid=0で境界が連続な製造解は元の高次式を保つべきだが、それは不連続な角を含む新枝の精度検証そのものとは扱わない。既定/公開方式は引き続き不変更。
