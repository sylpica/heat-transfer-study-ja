# 風速→熱伝達率 h 推定（開発専用）

対象モジュール：`dynamic/dev/wind-heat-transfer.mjs`（法則識別子 `wind-heat-transfer-correlation-v1`、`releaseApproved:false`、公開 allowlist 外）

正本プロンプト §7 の要求「風速から熱伝達率を推定する場合は、流れの条件と相関式の適用範囲を確認する」「任意の風速変更に対し、根拠なく熱伝達率を比例変更しない」に対応する。相関式は教科書 *A Heat Transfer Textbook*, 6th ed.（Lienhard）の記載だけを使い、教科書にない相関は持ち込んでいない。

## 入力と物性

- 入力：形状、主流速度 u∞、代表長さ（平板長さ L／円柱直径 D／フィン代表長さ）、膜温度で評価した物性（密度 ρ、粘度 μ、比熱 cp、熱伝導率 k）、表面温度と主流温度（膜温度 Tf＝(Ts＋T∞)/2 の報告用）。
- 物性は既存の静的モデル（`cylinder-crossflow.mjs`、`forced-convection-flat-plate.mjs`）と同じく利用者供給であり、流体データベースや温度補間の推定はしない。物性は膜温度で評価することが教科書の指定である（§6.5、§7.6）。
- 未知キー・非有限・範囲外の入力は日本語の理由を付けて原子的に拒否する。適用範囲外では推定値を返さない。

## 採用した相関（すべて教科書の式番号）

### 平板（等温・板全体の平均 Nu_L、物性は膜温度）

| レジーム | 式 | 適用範囲（拒否条件） |
|---|---|---|
| 層流 `laminar` | Nu_L＝0.664 Re_L^{1/2} Pr^{1/3}（式 **6.68**） | Pr≧0.6、Pe_L＞100（境界層近似）、Re_L≦5×10⁵（全体が層流）。Re_L＞5×10⁵はレジーム未指定では拒否 |
| 液体金属 `liquid-metal` | Nu_L＝1.13 Pe_L^{1/2}（式 **6.69**） | Pe_L＞100（式(6.62)と同条件）。液体のみ |
| 観測遷移 `mixed-observed`（気体） | 式 **6.120**（乱流部＋層流部＋遷移部の3領域平均）、勾配 c は式 **6.115** | 気体のみ。遷移開始 Re_l≦5×10⁵（式(6.115)の範囲）、Re_l＜Re_u≦Re_L、Pr≧0.6 が必要 |
| 急峻遷移 `mixed-abrupt`（気体） | 式(6.120)の例題 **6.11** による縮約：0.037 Pr^{0.6}(Re_L^{0.8}−Re_trans^{0.8})＋0.664 Re_trans^{1/2} Pr^{1/3} | 0≦Re_trans＜Re_L、Pr≧0.6。遷移域省略の近似である旨を警告に明示 |
| 急峻遷移 `mixed-abrupt`（液体） | 乱流部を局所式 **6.113** から教科書の示唆どおりに展開：0.040 Pr^{0.43}(Re_L^{0.8}−Re_trans^{0.8})＋0.664 Re_trans^{1/2} Pr^{1/3} | 同上。これは式(6.120)そのものではなく、式(6.113)からの導出であることを識別子 `6.120-abrupt-liquid` と本書で明示する |

層流で 2×10⁵＜Re_L≦5×10⁵ の場合は、遷移が始まり得る領域である旨の警告（教科書 §6.9）を返す。

### 円柱横流れ（円周平均 Nu_D、物性は膜温度、Churchill–Bernstein 系の構成式選択）

| 条件 | 式 |
|---|---|
| Pe_D≦0.2 | Nu_D＝1／(0.8237−ln Pe_D^{1/2})（式 **7.67**、Nakai–Okazaki） |
| Re_D＜4000 | Nu_D＝0.3＋0.62 Re_D^{1/2} Pr^{1/3}／[1＋(0.4/Pr)^{2/3}]^{1/4}（式 **7.66**） |
| 40,000＜Re_D＜400,000 | 式(7.66)の分子に [1＋(Re_D/282,000)^{1/2}] を掛けた式 **7.68**（4/5 乗は付けない。原典 p.391 の印刷どおり） |
| その他 | Churchill–Bernstein 全体式 **7.65**。既存の静的モデル `cylinder-crossflow.mjs` の `churchillBernsteinNu` をそのまま呼び出し、実装間の値の drift を構造的に防ぐ |

- Re_D≦10⁷ を保守的上限として拒否する。これは式自体の理論限界ではなく、教科書 Fig. 7.11 のデータ範囲と既存静的モデルの教育用制限に合わせた上限であり、既存モデルと同じ扱いである。
- 式(7.68)の帯域では、教科書が述べるように式(7.65)はデータを約20%過小評価するため、式(7.68)の値が式(7.65)より大きくなる。これは矛盾ではなく教科書自身の構成式選択であり、テストで差を定量化している（下記）。
- Pe_D≦0.2 の領域は既存静的モデルでは拒否範囲だった。本モジュールは教科書の式(7.67)で拡張しており、式(7.65)が選ばれる範囲では既存モデルと値は完全一致する。

### フィン付き面

- `fin-plate`（プレートフィン）は代表形状として平板相関、`fin-pin`（ピンフィン）は円柱相関を適用し、代表形状であることを結果に明示する。
- フィン間干渉・バイパス流れ・フィン効率は含まない（警告で明示）。推定される h は表面の対流熱伝達率そのものであり、フィン／ヒートシンクモデル側の規定一様 h として渡す量である。

## 接続（既存ファイルは変更しない）

`heatSinkHFromWind(input)` が推定結果から h を取り出して返す。呼び出し側はその h を既存の開発モデル `createHeatSink`（`dynamic/dev/heat-sink.mjs`）やフィン学習モデルの規定 h としてそのまま渡せる。テストでは実際に `createHeatSink` へ渡し、構築・1刻みの進行・`prescribedUniformH` 仮定の保持を確認している。

## 検証（実測）

参照値の生成器：`scripts/dynamic-wind-heat-transfer-reference.py`（mpmath 50桁）。記録：`docs/dynamic/WIND_HEAT_TRANSFER_REFERENCE_20261107.json`（生成器 SHA-256 をテストで固定）。回帰テスト：`tests/dynamic-wind-heat-transfer.test.mjs`（15件、全成功）。モジュール値は50桁参照と相対差 10⁻¹² 以内で一致し、教科書の印刷値とは印刷丸めの範囲で一致する。

| 照合対象 | 50桁参照 | 教科書の印刷値 | 備考 |
|---|---|---|---|
| 例題6.5（層流平板）：Re_L | 384,615.38 | 384,600 | |
| 同：Nu_L／h | 366.156／21.3835 W/m²K | 366.2／21.4 | 膜温度65 ℃も一致 |
| 例題6.9（観測遷移）：c | 2.54536 | 2.55 | 印刷値は c を丸めて使用 |

| 同：Nu_L／h | 1434.03／18.9292 | 1433／18.92 | |
| 例題6.11（急峻遷移）：Re_trans＝4×10⁵／8.7×10⁵ | 1759.87／1151.71 | 1760／1152 | |

## 未実施・限界

- GUI・ブラウザー確認・公開可否は未実施（数値コア＋検証＋文書まで）。`releaseApproved:false`、公開 allowlist 外。
- 対象外として明示的に扱わないもの：平板の局所 h（式(6.63) Churchill–Ozoe 等は局所式であり、平均 h の推定には使っていない）、一様熱流束平板（式(6.71)系）、非加熱始端、粗さ壁、圧力勾配、管群（式(7.69)以降）、球・その他の形状、自然対流との混合対流、放射、物性の温度依存の自動評価（物性は膜温度で利用者供給）。
- 式(7.66)と式(7.65)の間には Re_D＝4000 の境界で構成式由来の段差がある（教科書の構成そのまま）。境界付近の値はどちらの式でも相関のばらつき内とみなすべきである。
- 急峻遷移の液体形は式(6.113)からの導出であり、教科書に印刷された完成形ではない。識別子と本書でその旨を区別している。
