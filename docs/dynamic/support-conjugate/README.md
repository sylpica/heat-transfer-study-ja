## 独立時間計算と熱収支

8格子・非対称初期温度・S=1で、製品の結合RHSを用いず別の物理抵抗/容量グラフを構成した。浮力0はアフィン行列指数、Ra1000は別の直接LU圧力投影MAC＋DOP853へ照合。全固体/流体温度・全u/v・4熱積算を比較した。

Ra1000の最細最大差は温度5.97326e−7、速度2.50211e−6、4熱6.40896e−8。最後の時間次数は温度2.01361/速度2.00878、参照二許容差の自己差8.58203e−14。浮力0も全予算成功。これは小格子の時間精度/新界面結合の独立確認で、64格子全過渡の絶対精度を承認しない。

背面・冷壁・源・界面の4積算から、固体/流体/全体の3収支を個別に監視。全実測系列の最大相対誤差は**6.09265e−14**（高K256も含む、基準1e−9）。分母は実蓄熱/熱積算の尺度で1J床なし。Ra0の完全0や、極小時刻1e−20でも正の固体/流体蓄熱・小さな実スケールを保持する試験を実施した。非対称初期/源ありの過渡で確認しており、対称0収支だけに依存しない。
