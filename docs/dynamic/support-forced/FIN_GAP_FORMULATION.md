# 件B：フィン間強制対流の定式化と独立極限検算

2026-11-07 UTC。依頼は定式化可否と限定試作の検証であり、ヒートシンク全体の完成ではない。Museの`feiris/graetz-channel-2`に既に指定発達流の定常Graetz実装があるため、同じ解法/画面を作らず、先端1eb670ba4eec9caa85ad678904b8de0371d6e91eを読み取り専用で検算した。元ソースのSHA256をCHANNEL_CASESへ記録。Muse枝に書き込み/マージしていない。

## 適用する理想化と方程式

直線の隣接2フィンの間を、全隙間s、流れ方向長さL、幅Wの平行平板とする。W≫sで側面/先端/底面の影響を無視し、同一の流れが各隙間に入る理想化。2D平面・定常・非圧縮・Newton流体・一定物性。低Mach、単相、浮力が十分小さい強制対流。物性変化、粘性散逸を省く条件も必要。

速度入口も発達させる上位の定式化は、x∈(0,L)、y∈(0,s)で

```
u_x + v_y = 0
rho (u u_x + v u_y) = -p_x + mu (u_xx + u_yy)
rho (u v_x + v v_y) = -p_y + mu (v_xx + v_yy)
rho cp (u T_x + v T_y) = k (T_xx + T_yy)
```

入口に速度分布/流量とTin、両フィン面にno-slip、出口に整合した開境界の応力/基準圧を与える。全速度と出口圧を過剰に固定しない。入口一様速度と壁no-slipの接点は特異になるため、入口形状/助走部・格子収束の検証も必要。**この速度入口発達の圧力連成ソルバーは今回実装していない。**

既存の限定モデルでは速度を`u=6U z(1−z), v=0, z=y/s`と既知にして、軸方向熱伝導を省いた

`rho cp u(y) T_x = k T_yy`

だけを解く。これは熱入口のGraetz問題であり、速度入口を解くものではない。初期断面T(0,y)=Tin、壁の熱条件は次のどちらか一方。

- 両壁同一一定壁温：T(x,0)=T(x,s)=Tw。
- 両壁同一一定流入熱流束q：−k T_y(x,0)=q、+k T_y(x,s)=q（q>0が流体加熱）。

壁温と壁熱流束を同時に指定しない。バルク温度は`Tb=∫uTdy/(Us)`。Nuは`h Dh/k`、hは局所のq/(Tw−Tb)。入口付近の局所Nu、長さ平均の局所Nu、全体熱量/LMTDからのhは定義が異なる。

## 無次元数と範囲

Dh=2s、Re_Dh=U Dh/nu、Pr=nu/alpha、Pe_Dh=Re Pr、Gz=Re Pr Dh/x、x*=x/(Dh Pe_Dh)。有限幅の矩形ではDh=2sW/(s+W)で、全濡れ縁を使う。加熱縁だけをDhの分母に使わない。Wが小さいままDhだけ変えても無限幅の速度/Nuが矩形流へ変わるわけではない。

速度助走長≈.05 Re_Dh Dh、熱助走長≈.05 Re_Dh Pr Dhは代表的な目安であり、入口分布・断面形状・十分発達の判定に依存する。今回の成立を証明する境界値には使わない。Muse実装の入力上限Re_Dh≤2300/Pe_Dh≥100はコードの範囲であり、全条件の遷移/入口精度を検証済みという意味ではない。今回の照合条件はRe_Dh約635、Pr約.706、Pe_Dh約448に限る。低Pe、強い浮力Ri=Gr/Re²、自然/混合対流、物性変化、沸騰、乱流は対象外。

圧力駆動はp_x=−12μU/s²、両側せん断で釣り合い、Darcy f=96/Re_Dh。入口・出口・分岐の局所損失を含まない。複数隙間の流量配分、ファン曲線との作動点、空気の回り込み/バイパスは、この単一流路から決まらない。

## 原本対応と独立な連続解

*A Heat Transfer Textbook* Version6.00の§7.5、書籍p386/PDF通算400ページを**画像で確認**。式7.62の平板発達速度、式7.63の境界条件別Nuに対応する。原図/本文抽出/翻訳は追加していない。第5〜6章の保存則・境界層の枠組みと第7章の内部流を用いる独自の定式化であり、原書全文の収録/照合完了ではない。

両壁一定qでは、断面平均を引いた温度を独自に積分すると

```
T = Tb(x) + (q s/k) f(z)
f(z)=17/70 - z + 2 z^3 - z^4
dTb/dx=2q/(rho cp U s)
∫_0^1 6z(1-z) f(z) dz=0
Tw-Tb=(q s/k)17/70
Nu_Dh=140/17=8.235294117647058...
```

となる。記号演算でf''=2u/U、両壁微分/重み付き平均を独立検算した。原本8.235は丸め値。

両壁一定Twの下流第1モードではeta=2y/s−1を用い、半断面で

```
phi'' + mu (1-eta^2) phi=0
phi(0)=1, phi'(0)=0, phi(1)=0
Nu_Dh=8mu/3
```

を解く。70桁べき級数の根と、別のDOP853射撃＋Brent求根で照合。mu=2.8277628277760392...、Nu=7.5407008740694379...。独立2経路の相対差5.81e−15、壁勾配/バルク積分からのNu差9.43e−16。原本7.541は丸めであり、厳密に7.541へ収束しなければ不正としない。片壁q・他壁断熱の原本5.385も画像で確認したが、両壁同じ条件の試作の出力として流用しない。

## フィン効率・共役へ進むための条件

実フィンは壁面温度が与えられるとは限らず、固体の`rho_s cp_s T_s,t = div(k_s grad T_s)+q'''`と流体を連成する。界面でT_s=T_f、同じ向きの熱流束連続を課す。フィンの根元/先端/外面条件、厚さ、ksが追加で必要。薄板一様断面近似ならm²≈2h/(ks t_fin)、Bi_t=h t_fin/(2ks)等が関わるが、hやTbもx/高さによって変わる。既知一定hのフィン効率を計算しただけで、この共役問題を解いたことにはならない。

今回扱わないもの：速度入口発達、有限幅側壁/3次元フィン列、流れの再循環/剥離、円柱フィン、乱流、入口/出口圧損、複数流路の分配、フィン先端/底面/空気バイパス、隣接流路の異なる壁条件、固体温度と局所流体熱伝達の共役、一般の周方向/軸方向壁温分布。これらへ8.235/7.541を無条件に当てはめない。

**結論**：理想化された発達流＋熱入口をフィン間の第一近似とする定式化は可能で、既存の限定試作が解析極限へ帰着することも独立に確認できた。完全なヒートシンクのフィン間流れ/固体共役は未実装・未検証であり、統合/公開可否はMuse判断。重複実装を避けた結果として、新しい同一のソルバーや画面を本支援枝に追加していない。
