# 件A：ヒートシンクの限定連成方式

2026-11-07 UTC。専用枝`codex/support-heatsink-performance`、起点1836092。原書の一般法則に基づく独自の方式検討/オフライン参照であり、原書にこのヒートシンクの完成モデル/性能保証が掲載されているとはしない。本線・Museの実装/画面/公開は変更しない。

## 対象と結合

| 要素 | 今回の参照方式 | 解かないもの |
|---|---|---|
| ベース | 3D定常有限体積、下面の局所発熱、フィン根元/露出面との熱交換 | 接触の未知値、異方性、相変化、温度依存k |
| フィン | 厚さ方向一様、流れ方向xと高さzの2D伝導 | 厚さ内の完全3D温度、ピンフィン/任意形状 |
| 流れ | 断面の発達Stokes/Poisson解、共通圧力差の並列流量配分 | 速度の入口発達、出入口/マニホールド損失、3D剥離/再循環、乱流/ファン |
| 流体温度 | 指定された断面速度の3D受動温度輸送、横断/高さ方向の拡散 | 浮力、流れへの温度フィードバック、軸方向熱伝導 |
| 放射 | 各x列の長ダクト断面・拡散灰色射度、上部開口/反射/遮蔽 | x方向の非局所放射、端部/外面/先端の3D形態係数、鏡面/参加気体 |

固体と流体の熱交換は双方向に結合するが、速度は一定物性/浮力なしで温度から独立である。**3Dの温度配列があることは3D Navier–Stokes CFDを解くことを意味しない**。標準ケースとその検証極限に限る研究用Python参照で、一般入力エンジンとして公開しない。

### 固体と流体

ベース内は`div(ks grad Ts)=0`、加熱面は指定流入熱流束、その他の外側面/下面は断熱。フィン根元は温度/熱流連続、接触抵抗0（単一材料）。一般化する場合は界面の面積接触抵抗を直列に足す必要があるが、今回その未知値を推定していない。

厚さtのフィンは`ks t (Ts,xx+Ts,zz) = q_left,out''+q_right,out''`。先端断熱。前後の薄い端面だけは、比較用モデルと同じ規定h_refで300Kへ対流させる。これら端面の熱は流路出口の流体エンタルピーに含めず、別の外部放熱として全収支に入れる。

流体は`rho cp u(y,z) Tf,x = kf (Tf,yy+Tf,zz)`。入口Tin、固体境界は熱連成。一定Tw/一定qのいずれかを全面へ仮定していないため、Nu7.541/8.235を各場所に強制していない。流路の底面からの熱も高さ方向拡散を介して流体に入る。各セルでは速度平均×温度平均でエンタルピーを評価し、その相関の細格子誤差は格子検証に含む。

固体‐流体の近接セル間熱コンダクタンスは`G=A/[ds/(2ks)+df/(2kf)]`、同じ`G(Ts−Tf)`を内部交換として一度だけ組む。フィン/ベース内も面積と中心間距離を使う。x方向移流は保存的な1次風上で、全体温度の2次精度は主張しない。

### 圧力損失と流量配分

隙間s、高さH、長さLの各流路で、断面上の`−laplacian_perp psi=1`を解く。側面と底面no-slip、上面free-shear（対称Neumann）。`u=(Delta p/(mu L)) psi`、`Qv=C Delta p`、`C=∫psi dA/(mu L)`。熱的な上面は断熱・非貫通とする仮想境界で、放射については開口として扱う。実際の開放フィン列の上方からの空気流入/プルームは表さない。

並列流路は共通の入口/出口圧を持つとして

```
Delta p given: Qv_j = C_j Delta p
Qv_total given: Delta p = Qv_total / sum_j C_j
```

で解く。ファン曲線は不要だが、マニホールドで圧が揃わなければ成立しない。速度用断面格子を温度用の各方向2倍に細分化し、セル面積平均で保存的に制限する。下流に沿って速度分布が変わるモデルではない。

上面free-shearの流量を、no-slip矩形s×2Hの半分とする独立連続級数で検証する：

`∫psi dA = H s^3/12 [1−96s/(pi^5 H) sum_(n odd) tanh(n pi H/s)/n^5]`。

H≫sでは平行平板の`−p_x=12mu U/s²`へ戻る。有限高さを無視してこの式をそのまま圧力参照にしない。自由上面を濡れ縁に数えない定義なら`Dh=4sH/(s+2H)`。平板極限の比較用`2s`とは区別する。圧損は正の上流‐下流差で、逆流は本参照の受入外。

標準は8個の等隙間なので流量も等しい。別の3隙間の試験ではC_jの違いによる配分も検算したが、異なる全隙間を持つヒートシンクの熱場を一般に検証したわけではない。

## 広がり抵抗の扱い

原書の熱抵抗/多次元伝導の枠組みを使えるが、任意のヒートシンクへ加算できる普遍的なspreading抵抗はない。相関を採用するには、加熱面が等流束か等温か、熱源/受熱面の形と寸法、板厚/有限外形、側面、受熱面の等温/一様Robin/部分フィン接触の別、相関が既に含む1D抵抗を照合する必要がある。原本内で標準ケースと完全一致する閉形式相関は確認していない。円形/半無限/等温コレクタの式を無検証で矩形有限板へ転用しない。

今回の標準では**3Dベースを直接解き、追加のspreading抵抗を足さない**。別に解析できる境界として、L×W、厚さdeltaの矩形板、側面断熱、底面の中央矩形一様熱流束、上面全体が等温または一様hのRobinを考える。cosモード分離で独自に得られるsource-area平均抵抗は

```
lambda_mn = sqrt[(m pi/L)^2+(n pi/W)^2]
C_mn = alpha_m alpha_n/A * <cos(m pi x/L)>_source^2
                              * <cos(n pi y/W)>_source^2
R_source = sum_mn C_mn Z(lambda_mn),  alpha_0=1, alpha_m>0=2
Z_D(lambda) = tanh(lambda delta)/(ks lambda)
Z_h(lambda) = [1+h/(ks lambda) tanh(lambda delta)]
              / [ks lambda tanh(lambda delta)+h]
Z_D(0)=delta/ks, Z_h(0)=delta/ks+1/h
R_spread = R_source - Z(0)/A
```

ここで<>は加熱面での平均であり、発熱量で割る温度も同じsource-area平均である。上面温度条件と熱源条件が変われば別の抵抗になる。原書の印刷済み相関として出典を捏造せず、独自導出/コード/数値打切りをVALIDATIONに記録する。

この解析試験のR_spreadを、フィン接触と流体昇温のある標準ケースへ単純加算しない。標準で測った`(Tsource−Tbase-volume-average)/Q`も、流れ方向の非一様冷却等を含むため、材料/形状だけで決まる普遍的なspreading抵抗ではない。1D厚み抵抗を含んだ相関とベースの3D解を併用すると二重計上になる。

## 対流と放射の同時境界

物理的な境界条件は同じ表面温度Tsに対して

`−ks grad Ts·n = q_conv,out'' + q_rad,out''`。

流体を解く場合q_convは界面の伝導流束から求め、規定hを使う場合だけh(Ts−Tb)とする。放射に使う温度はK。`T^4−Trad^4`を温度差の4乗にしない。

灰色拡散不透明面の射度Jと照射Gを

```
J_i = epsilon_i sigma Ts_i^4 + (1-epsilon_i) sum_j Fij J_j
Qrad_i = A_i (J_i - sum_j Fij J_j)
```

で連立し、開口のJをsigma Trad^4に固定する。各断面の底面/左右フィンを分割した交差弦法でFを作る。ガード流路の外側壁は理想断熱鏡面ではなく、epsilon0の**拡散反射壁**として扱う。フィン同士の交換は内部熱で、開口から出た熱だけが系外放熱。全フィン面積へ直接epsilon sigma(T^4−Trad^4)を足す方法は、遮蔽を無視するので採用しない。

今回の離散化では放射に隣接固体セル温度/フィン断面平均を使い、独立の表面節点は解いていない。対流の固体半セル抵抗を含む界面温度と完全に同じではない小さい近似が残る。最細の辺長と最大温度から、断面伝導の温度落差の保守的尺度はフィン側で約.013 K以下、基部側で約.003 K以下（半セルの対流上限＋放射放出上限）。これは境界温度の尺度であり、全解の誤差保証ではない。厳密な表面未知量を追加して対流/射度を同時に解く拡張は残る。

実装は温度差theta=Ts−300を未知にし、`(300+theta)^4−300^4`を展開形で安定に計算する。線形熱行列のLUを使う放射Picard反復で、更新差/局所残差の双方を確認する。300〜500K内・60反復以内の限定方式であり、強放射条件で収束しない場合は停止する。一般化するならNewton法/表面節点と適切な残差制御が必要。

## 無次元数と適用範囲

基準はRe_Dh、Pr、Pe_L/Pe_Dh、断面H/s・L/s、板厚/外形・熱源/ベース面積比、ks/kf、フィンmHと厚さBi、基部Bi、epsilon、放射対対流尺度`4epsilon sigma Tref^3/h`、浮力Ri_H=Gr_H/Re_H²、粘性散逸Br。流路速度は水力直径の定義と対応付ける。

標準の平板Re_(2s)≈380.95、自由上面の濡れ縁Dh基準Re≈362.81、Pe_(2s)≈269.11、フィン厚さBi≈9.93e−5、Ri_Hの尺度≈.0164。層流・薄いフィン・強制対流優勢を想定する。一定物性は仮定であり、実材料の温度依存性/表面状態を保証しない。軸方向熱伝導/粘性発熱の省略、上面の仮想流れ境界、局所長ダクト放射にはそれぞれモデル誤差があり、格子細分化では消えない。

**停止流**ではこの強制対流解をh=0や同じ有限Nuのまま自然対流と見なさない。コードは流量0を明確に拒否する。自然対流へ進むにはBoussinesqの質量/運動量/熱、固体伝導、適切な開口/圧力境界を連成し、Ra_s/Ra_H、H/s、流入/流出/プルームを検証する必要がある。孤立鉛直板の相関を密なフィン列へ無検証で使わない。放射だけでの平衡も、重力あり停止空気の自然対流解ではない。
