標準条件：7本のAl相当の仮想一定物性フィン、k167 W/(m K)、厚さ1mm、高さ30mm、流れ方向長さ120mm。全隙間3mmを8個（両側は断熱壁のガード流路）、ベース幅31mm・厚さ3mm。下面中央30×9mmに10W、他の下面/外側面は断熱。空気の仮想固定物性rho1.177/cp1006/k.0264/nu1.575e−5、入口/放射周囲300K。総流量7.2e−4m³/s（43.2 L/min）、灰色拡散表面epsilon=.8。ファンモデルなし。前後フィンの薄い端面は、比較モデルと同じ規定h_refで300Kへ対流、先端は断熱。長い流路断面の上部開口への放射を計算し、放射の流れ方向非局所性/端部は省く。

方式：3DベースFV＋厚さ一様の2Dフィン伝導＋指定された発達層流の3D受動温度輸送を定常結合する。流れは断面Poisson（側面/底面no-slip、上面free-shear）から流量/圧損を与え、入口速度発達/3D運動量/浮力は解かない。流体は流れ方向風上＋断面拡散、固体界面熱交換を同一内部熱として組む。流量配分は共通圧力差と各流路の断面コンダクタンスから定める。放射は各x列の長ダクト断面の交差弦法/射度を用い、遮蔽/相互反射/開口を含める。全表面を直接周囲へ放射する近似は使わない。

事前の検証：

1. 熱の全収支/固体‐流体内部交換/放射交換の相対差<1e−8。線形/非線形残差と総熱を別記。rho/温度差/Kを区別。
2. 断面流量を鏡像矩形流路の連続Fourier級数へ照合：最細相対差<2%。与えた総流量と圧力差での解の往復<1e−12、幅の異なる並列流路で配分/圧損を照合。
3. 標準r1/2/4（Nx8r、基部Ny31r/Nz=r、フィンNz4r、流体Ny3r/Nz4r）を実測。最後の発熱部平均温度上昇/最大基部温度上昇の変化<3%を限定参照の目標とし、未達なら保持して追加格子か未達記録。格子収束は理想化の実機精度の承認ではない。
4. ベース単体の局所下面発熱/上面等温/側面断熱を連続cos級数へ別に照合し、source-average抵抗の最細差<2%。級数打切りの収束も確認。これによりspreadingを便宜的な1つの抵抗で置く場合の条件を明示。
5. 単一フィンの断熱先端cosh効率へ帰着：最細温度/熱流相対差<.2%。放射ネットワークの黒体/灰色2面の解析解と相互性/閉包を検算。
6. 同じ標準条件のepsilon0（対流/流体のみ）を解き、放射の寄与と温度変化を実測。Q=0/T=300Kの等温不変、流量0では自然対流モデルへ切替が必要と明確に拒否。強制対流解を自然対流と呼ばない。
7. 現行の規定hモデルは同寸法/本数/k/Q/Tinでh_ref=7.540700874 k_air/(2s)を使用し、連続coshと元JSの定常固定点を照合。局所熱源/流量/遮蔽は現行モデルが表現できない差として明記。hを今回の温度へ合わせて逆算しない。
