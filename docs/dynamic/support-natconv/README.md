# 自然対流キャビティ：Ra範囲拡大の検証支援結果

2026-11-07（Asia/Tokyo）。所有者のサポート依頼1だけを扱う。専用枝 `codex/support-natconv-ra-range`、起点ca8fc25。**試作でRa=10⁴/10⁵/10⁶の3点が事前の比較基準を達成した。現行ブラウザー版のRa≤1000は変更していない。** 一般の全Ra区間、他Pr/形状、全過渡精度、工学的な公開承認とは別。

## 結論と採用候補

等間隔正方形のMAC・保存形2次運動量/中心温度・全未知SSPRK2、各Euler候補速度のNeumann圧力をtype-II DCTで直接投影するPython/NumPy/SciPy試作。中心差分の実セルPe≤2、温度0〜1、閉壁法線速度0を保持する。格子をRaと一緒に増やし、**冷スタートでは10⁴に64²、10⁵に128²、10⁶に192²**で照合を達成した。これらは検証した格子の組合せであり、必要最小格子を同定した結果ではない。

圧力の緩和係数や合格幅の調整で通したものではない。矩形一定係数Poissonの分離性を使うDCTが今回の候補。任意形状・不等間隔・変係数へそのまま使えず、一般モデルへは既存多重格子等の別検証が必要。時間は陽的なので細格子の計算量は残る。

- Ra1e5の64→128：4.56149622→4.53163242。64は壁Nuと局所最大の予算未達を保持。
- **Ra1e6の64/128の冷スタートはPe超過で失敗**。試作64ではt=.00167292、128ではt=.00354986。192の冷スタートだけが今回成功した。128は192の定常場を保存的に制限/速度補間・再投影する明示的な暖スタートで別途定常化し、体積Nu8.88686117となった。暖スタートを冷スタートの成功として数えない。

```sh
python3 scripts/support-natconv/test_prototype.py
```

Python3/NumPy/SciPyを使う**開発検証用**で、一般利用者にPythonを要求する機能ではない。通常Node回帰はPythonを呼ばず、保存済み結果と本来の拒否条件を検査する。既存JSON/NPZは上書き拒否、baseline/followthrough/reportの再生成は別の出力名/作業用コピーで既存証拠を保護する。

統合の候補は、今回のMAC/RK2の式・段ごとの圧力投影・保持温度/熱・格子に応じたPe監視・定義別Nu評価。**単に既存JSのRa値を1e6へ書換える統合は不可**。JS/Workerへの移植、同一全場照合、時計/完全復元/取消/メモリー/実端末性能、UIと受入条件をMuse側で別途確認する。DCTのブラウザー実装か既存MGの128/192対応かは、同じPoisson/全場の比較後に選ぶ。

残る数値課題：256以上または境界集積格子での追加全場・局所最大の空間確認、Ra中間点とPr/縦横比の範囲、冷スタート全過渡の独立精度、実物性/Boussinesqへの対応、非正方形/非一様格子/一般連成、時間性能。今回の3点で全Ra≤1e6の包括受入を宣言せず、Museが統合可否を判断する。本線/統合枝/画面/用語/§21/公開条件には変更していない。
